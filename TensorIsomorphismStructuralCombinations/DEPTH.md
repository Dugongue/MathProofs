# Finite reachability removes the fixed product-depth bound

The short-product reduction can have unbounded word depth. Its polynomial-time requirement is a bound on the number of distinct word values reached before the sparse relation condition holds. This transfers the reachable-set idea from weighted automata, while retaining actual vectors so they can be vertices in the graph.

Fix the field $k=\mathbf F_q$ and constants $c,C,s$, with $s\ge3$. For each integer threshold $b\ge0$ with $q^b\le(n+1)^c$, start with the complete vector sets of Peirce blocks of dimension at most $b$, the idempotents, and a separate zero for each block. Let $P_t$ be the collection of blockwise distinct values of composable words of length at most $t$ in these starts. Use $Q_t=P_{2t}$. Include a choice of $b,t$ if both conditions from the short-product theorem hold with $P_t,Q_t$, and the total number of occurrences in $P_t$ is at most $(n+1)^C$. Select the first successful $b$, and then the least successful $t$. These choices are invariant under frame-respecting algebra isomorphisms.

For each $b$, compute $P_1,P_2,\ldots$ by multiplying the current values on the right by every composable starting value. Distinct values are compared in the original coordinates. If the cardinality exceeds the cap, no later stage qualifies. If $P_{t+1}=P_t$, all subsequent sets agree, so a failed test cannot become successful. Absent these stopping conditions, every round adds at least one occurrence. At a stage within the cap, compute $Q_t$ as the set of all composable pairwise products of $P_t$ values, including zeros. This identity follows by splitting any word of length at most $2t$ into two words of length at most $t$, with an endpoint idempotent supplying an empty factor if necessary. Its size is polynomial, even for unbounded $t$. Perform both span and sparse-relation tests on these sets. There are logarithmically many thresholds and polynomially many rounds for each one. Construct the same graph from the selected $P_t,Q_t$ and use the same determinant calibration. Thus raw GL-TI and SL-TI on this class have the same respective many-one and Turing reductions to GI.

For every fixed $c,\ell$, choosing $C$ large enough includes the earlier fixed-depth class. The earlier start set is obtained by taking the allowed maximal $b$. Its layer $\ell$ has polynomially many values with an exponent depending on $c,\ell$, and the cap can exceed this count.

For a family whose depth cannot be bounded in that earlier formulation, let the quiver have one source, one sink, and $r$ intermediate layers with two vertices per layer, joined by all arrows forward between consecutive layers. In its path algebra, the source-to-sink block has dimension $2^r$ and the full dimension is $\Theta(2^r)$. Use threshold $b=1$. The nonidentity nonzero starting values are scalar arrows. Their composable products are scalar path monomials and never exceed a constant depending on $q$ times $n$ distinct occurrences. At stage $t=r+1$, they span all blocks, and each relation kernel is generated by the zero relation and relations identifying scalar multiples of a path. The recognized depth is unbounded. For the earlier fixed-depth formulation, a pair of endpoints separated by a gap of $g$ layers has $2^{g-1}$ paths. Therefore every low-dimensional starting block spans paths of gap $O(\log r)$, since its dimension cap is $c\log_q(n+1)=O(r)$. Reaching the source-to-sink block requires $\Omega(r/\log r)$ factors, which eventually exceeds any fixed $\ell$.

The result uses finite reachability only to ensure polynomial enumeration of the recovered signature. General tensor isomorphism remains outside the established class. [Weighted realization reachability](https://arxiv.org/abs/2009.01217)
