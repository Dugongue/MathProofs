# Checking the finite obstructions

The [LO proof](../lo-three.md) uses the supplied DIMACS formula and its text certificate. Build the checker and run it as follows.

    g++ -O3 -std=c++17 rupcheck.cpp -o rupcheck
    ./rupcheck cert43.cnf cert43t.drat

The [symmetric promise CSP proof](../symmetric-rae.md) uses a larger formula, generated by the supplied source.

    g++ -O3 -std=c++17 tightR.cpp -o tightR
    SMALL=2 ./tightR 4 3 NAE 3 2 001 010 100 002 020 200 112 121 211 > trs.cnf
    ./rupcheck trs.cnf trs3.drat

The project audit recompiled the checker and verified both certificates. It independently regenerated the second formula. It recorded 809 and 3,313 checked lemmas, respectively, each ending in the empty clause. The first formula is supplied directly so it can be checked without regenerating it.
