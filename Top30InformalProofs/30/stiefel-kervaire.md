# First-stage Stiefel extension and the Kervaire invariant

The first-stage classification has the stated bottom-group restriction. In the two-frame Kervaire case a conclusion requiring an order-two representative remains conditional at the unresolved dimension. The separate all-ranks and higher-stage questions remain open.

## 1. Inputs used

- Paper thm:NP (NP membership), thm:Hspace (P when P_{D−1}Y is an H-space), cor:NPlevel (Σ⁰₁ above d(Y)), cor:Lie(2) (P for D ≤ 2c−1, c-connectivity), thm:firstunstable (template for Thm F), thm:MQhard (gadget).
- Theorem T (R-L11, audit-ladder-tower: PASS WITH FIX): if Y is simply connected and finite, k* the least k with P_kY not an H-space, and Y a rational H-space through k*, then EXT_{k*+1}(Y) is NP-hard.
- Cell structure (James; Hatcher §3.D): V_{n,k} has cells e^{i₁}⋯e^{i_r}, n−k ≤ i₁ < … < i_r ≤ n−1, dimension Σ i_j; the singleton cells form RP^{n−1}_{n−k}. Product cells have dimension ≥ m + (m+1) = 2m+1, so **V^{(2m)} = RP^{min(n−1, 2m)}_m**.
- Amelotte 1707.04185, Thm 3.2 (with BJM, Wu) and Thm 3.3 (d)⇔(f); Lin–Wang–Xu 2412.10879 (θ₆ exists; order 2 open); Hill–Hopkins–Ravenel (θ_j does not exist for j ≥ 7); Frankland's exposition of BJM Cor 3.2; Browder (finite H-complex of rank one is S¹, S³, S⁷, RP³ or RP⁷); Hubbuck–Kane 1975 (π₃ of a finite H-space is torsion-free).

## 2. Rows R2 and R3 (rational type)

V = hofib(BSO(m) → BSO(n)). Relative model: H*(BSO(m);ℚ) ⊗ Λ(y_j), with dy_j the restriction of the j-th generator of H*(BSO(n);ℚ).

**m = 2r even, n ≥ m+1.** Restrictions: p_j ↦ p_j (j < r), p_r ↦ e², p_j ↦ 0 (j > r), e_n ↦ 0 if n is even. Since ⌊n/2⌋ ≥ r, p_r exists in BSO(n). Cancelling the contractible pairs (p_j, y_j), j < r, leaves the minimal model Λ(e, y_r, closed odd y's) with dy_r = e², |e| = m, |y_r| = 2m−1. So d(V) = 2m−1.
- D ≥ 2m: Σ⁰₁-complete (cor:NPlevel).
- D ≤ 2m−1: P (cor:Lie(2), V is (m−1)-connected).

**m odd.** BSO(m) has no Euler class, and every p_j of BSO(m) is a restriction, so all of H*(BSO(m)) is killed. V ≃_ℚ a product of odd spheres, a rational H-space. So EXT_D(V) ∈ NP for every D (thm:NP), and P for D ≤ 2m−1 (cor:Lie(2)). π_m(V) = ℤ/2 for k ≥ 2, because the bottom of RP^{n−1}_m is S^m ∪₂ e^{m+1} (m odd, so the (m+1)-cell has attaching degree 1 + (−1)^{m+1} = 2).

## 3. Theorem F (first unstable stage with cyclic bottom group)

**Theorem F.** Let Y be simply connected and finite, (c−1)-connected, c ≥ 2, with π_c(Y) cyclic, generated by ι, and let w = [ι, ι] ∈ π_{2c−1}(Y).
1. If H_{2c−1}(P_{2c−1}Y ∧ P_{2c−1}Y) = 0, then P_{2c−1}Y is an H-space iff w = 0. This holds whenever π_c is cyclic.
2. If w ≠ 0 and Y is a rational H-space through D−1 (D ≥ 2c), then EXT_D(Y) is NP-complete.

*Proof.*
(1) Let P = P_{2c−1}Y. P∧P is (2c−1)-connected, and π_q(P) = 0 for q ≥ 2c. So the only obstruction to extending the fold P∨P → P over P×P lies in H^{2c}(P∧P; π_{2c−1}). We have H_{2c}(P∧P) = H_c ⊗ H_c = π_c ⊗ π_c (cyclic), H_{2c−1}(P∧P) = 0 (Künneth: Tor terms need i + j = 2c−1 with i, j ≥ c), so the group is Hom(π_c ⊗ π_c, π_{2c−1}). The obstruction is primary, hence well defined.
- Restrict along ι×ι: S^c×S^c → P×P. On H_{2c} of the smash, ℤ → π_c ⊗ π_c is onto, so the induced map on Hom(−, π_{2c−1}) is injective. The pulled-back obstruction is the obstruction to extending ι∨ι over the top cell of S^c×S^c, which is ±w.

(2) Hardness, when |π_c| = 2. This is the case for V; for π_c = ℤ it is thm:firstunstable.
- Write ι of order 2. Then 2w = [2ι, ι] = 0 (bilinearity, c ≥ 2; Whitehead 1978, X.7). Since w ≠ 0, w has order exactly 2.
- Reduce from MQ over F₂ (Garey–Johnson AN9): A = S^c with f a fixed simplicial representative of ι; X = A ∨ ⋁_{i≤N} S^c_i ∪ ⋃_q e^{2c}_q, with e_q attached along Σ_{i≤j, a^{(q)}_{ij}=1} [ι_i, ι_j] + c_q[ι_*, ι_*].
- An extension restricts to classes x_i ι on S^c_i, x_i ∈ ℤ/2, and every choice occurs. It extends over e_q iff (Σ a_{ij} x_i x_j + c_q) w = 0, using [x_iι, x_jι] = x_i x_j w and x_i² = x_i.
- The cells e_q are attached to the c-skeleton, so they are independent once the x_i are fixed. cd(X, A) = 2c. Size is linear, as in thm:MQhard (cites CKMVW constructions).
- Membership is thm:NP. ∎

Applied to V: c = m, ι the bottom cell. So **R3a: if w(m,k) ≠ 0 then EXT_D(V_{m+k,k}) is NP-complete for every D ≥ 2m; if w(m,k) = 0 then P_{2m−1}V is an H-space and EXT_{2m}(V) ∈ P** (thm:Hspace).

## 4. Theorem K: where w vanishes

**L1 (k = 2).** w(m,2) = 0 iff [ι_m, ι_m] ∈ 2π_{2m−1}(S^m).

*Proof.*
- Fibration S^m → V_{m+2,2} → S^{m+1}. Its fibre inclusion is the bottom cell, and ∂ι_{m+1} = ±χ(S^{m+1})ι_m = ±2ι_m.
- For β ∈ π_{2m−1}(S^m), ∂(Eβ) = (∂ι_{m+1})∘β = (2ι_m)∘β = 2β + [ι_m, ι_m]∘H(β) (Hilton).
- H(β) ∈ π_{2m−1}(S^{2m−1}) = ℤ, and π_{2m−1}(S^m) is finite for m odd, so H(β) = 0.
- E: π_{2m−1}(S^m) → π_{2m}(S^{m+1}) is onto (Freudenthal). So im ∂ = 2π_{2m−1}(S^m), and exactness gives the claim. ∎

This is Amelotte's Thm 3.2 (a)⇔(d) with a two-line proof. Then:
- BJM (Cor 3.2; Frankland Thm 3.1): for m = 2^{j+1}−1, [ι_m, ι_m] is divisible by 2 iff a Kervaire class θ_j of order 2 exists.
- For m+1 not a power of 2 it is not divisible (Frankland Rmk 3.2; also reproved by the k = 2 run of §5).
- θ_j of order 2 exists for j ≤ 5 (Kochman for j = 4; Xu for j = 5). θ_j does not exist for j ≥ 7 (HHR). θ₆ exists (LWX), but its order is open (LWX Question 1.6).

So w(m,2) = 0 iff m ∈ {1,3,7,15,31,63}, or m = 127 and θ₆ of order 2 exists. (m ∈ {1,3,7} have [ι,ι] = 0 already.)

**L2 (monotone).** V_{m+k,k} ⊂ V_{m+k+1,k+1}, by appending e_{n+1}, carries bottom cell to bottom cell. So w(m,k) = 0 ⇒ w(m,k+1) = 0.

**L3 (Radon–Hurwitz section lemma).** If k ≤ ρ(m+k), then V_{m+k,k} → S^{m+k−1} has a section (Adams/Hurwitz–Radon). So π_*(V_{m+k−1,k−1}) → π_*(V_{m+k,k}) is split injective, and w(m,k) = 0 iff w(m,k−1) = 0.
- Example: m ≡ 1 (mod 4), m ≥ 5. Then ρ(m+3) ≥ 4, so w(m,3) = w(m,2) ≠ 0.
- L3 is subsumed by §5 for m < 130. It is the only place Radon–Hurwitz numbers appear.

**L4 (stabilisation).** For k ≥ m+1, V^{(2m)} = RP^{2m}_m, so w(m,k) = w(m,m+1).

**L5 (EHP criterion, used by §5).** Let m be odd ≥ 3, 2 ≤ k ≤ m+1, and P = RP^{m+k−1}_m.
- Then w(m,k) = 0 iff there is α ∈ π_{2m+1}(ΣP) with Sq^{m+1}u ≠ 0 in H*(ΣP ∪_α e^{2m+2}; F₂), u the bottom class.
- Equivalently (Freudenthal: π_{2m+1}(ΣP) → π^s is onto), iff some stable map f: S^{2m} → P has Sq^{m+1}x^m ≠ 0 in its cofibre.

*Proof.*
- Metastable EHP for the (m−1)-connected P: π_{2m+1}(ΣP) →H π_{2m+1}(ΣP∧P) →P π_{2m−1}(P) →E is exact.
- π_{2m+1}(ΣP∧P) = H_{2m}(P∧P) = ℤ/2, and P of its generator is ±[ι, ι] (Whitehead XII.2).
- So w = 0 iff H is onto. H(α) ≠ 0 iff u² = Sq^{m+1}u ≠ 0 in the cofibre, since H_{2m}(P∧P; ℤ) = ℤ/2 injects into H_{2m}(P∧P; F₂) = F₂.
- Finally π_{2m−1}(V) = π_{2m−1}(P) by the skeleton statement in §1. ∎

**Primary obstruction.** If w = 0, then H*(C_f) is an A-module extension N of M = H*(RP^{m+k−1}_m) by Σ^{2m+1}F₂. Here f* = 0 on F₂-cohomology, because the integral Hurewicz image in H_{2m}(RP^{2m}_m; ℤ) = 0. In N, Sq^{m+1}x^m = e.
- Such N exist iff [Sq(m+1) ⊗ x^m] ≠ 0 in (Ā ⊗_A M)_{2m+1} ≅ Tor₁^A(F₂, M)_{2m+1}.
- Concretely: c(θ, y) := the e-coefficient of θy must satisfy c(θψ, y) = c(θ, ψy). It suffices to impose this for ψ = Sq^{2^i}, by induction on word length.
- **If the target is forced to 0, then w(m,k) ≠ 0.**

## 6. Theorem S2 (the second stage for k = 2)

For V = V_{m+2,2} with w(m,2) = 0, P_{2m}V an H-space ⇒ there is a map S^m × P^{m+1}(2) → V restricting to the skeletal inclusions.

*Proof.* A multiplication on P_{2m}V gives S^m × M → P_{2m}V of type (ι, incl). V → P_{2m}V is (2m+1)-connected and dim(S^m × M) = 2m+1, so this compresses into V rel S^m ∨ M (the obstruction groups H^{q+1}(−; π_q(fibre)) vanish, since q ≥ 2m+1 forces q+1 > 2m+1). ∎

- Amelotte Thm 3.3 (d)⇔(f) (using Selick 1988 for 2n > 16): such maps exist iff m+1 ∈ {2, 4, 8, 16}.
- So for m ∈ {31, 63}: P_{2m−1}V is H and P_{2m}V is not, so k* = 2m. Theorem T gives NP-hardness at D = 2m+1, and thm:Hspace gives P for D ≤ 2m.
- m = 127: either w ≠ 0 (k* = 2m−1) or w = 0 and then k* = 2m by the same argument. In both cases NP-complete for D ≥ 2m+1 = 255.
- m ∈ {3, 7, 15}: V_{m+2,2} has rational rank one and is simply connected with π_m = ℤ/2, so by Browder it is not an H-space. Then k* ≤ 2·dim V − 1 = 4m+1, since a multiplication on P_dV with d+1 ≥ 4m+2 compresses to V. So the threshold k*+1 lies in [2m+1, 4m+2]. Not pinned down.
- m = 3, any k ≥ 2: π₃ = ℤ/2 and Hubbuck–Kane ⇒ V_{3+k,k} is not an H-space, so the threshold is finite.
- For m ∈ {7, 15, …}, k ≥ 3, I have no proof that V_{m+k,k} is not an H-space (expected; not claimed).
