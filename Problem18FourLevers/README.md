# Four Directions from Problem 1.8

[Informal proofs and scope](PROOFS.md), [Lean block assembly](BlockOracle.lean), and [exact finite checks](check_examples.py).

- Graph isomorphism embeds into orthogonal tensor isomorphism with deliberately coarse marginals. A separate rooted spanning promise gives a polynomial-time graph algorithm.
- A finite-field exterior-power Fourier argument gives positive limiting coverage for exact orthogonal search on uniform alternating forms. The public ALTEQ key distribution uses general-linear masks, so this is a different search problem.
- An affine-linear reduction embeds arbitrary ordinary three-tensor isomorphism into orthogonal and, in the stated fields, unitary tensors with fixed invertible Gram marginals.
- The Lean file checks a zero-error composition rule for unordered blocks. The correctness of the supplied matching procedure and tensor decomposition are interface hypotheses.
