# Single-instance conjunctions for determinant signs

Let $A$ be one-sign tensor isomorphism and $B$ two-sign tensor isomorphism over $\mathbb F_3$, as in the preceding comparison packet. The target is the unrestricted deterministic many-one reduction $B\le_m^p A$. Equivalently, by the previous conjunction bounds, the target is $A^{\wedge2}\le_m^p A$. The unrestricted reduction remains open in this packet. The proofs below give exact one-instance reductions on the stated domains and a sufficient route to the stronger ordinary TI collapse.

| Result | Exact scope |
| --- | --- |
| [Neutral conjunction](NeutralConjunction.md) | Pack one arbitrary signed comparison together with any polynomial number of ordinary TI comparisons into a single signed instance. The auxiliary cubes reflect ordinary TI and have determinant one on every transporter. This includes two signed queries whenever either can first be compiled to ordinary TI. |
| [Two signs with a small tested mode](Complexity.md) | For a raw shared-transporter two-sign query, a single one-sign instance suffices if either tested dimension $k$ is logarithmic in the dense input length. The size is polynomial in input length and $2^k$. An exterior-top relation makes one sign constraint part of ordinary algebra isomorphism. |
| [An ordinary test supplies an optional sign correction](Twists.md) | One signed instance can realize $O(X,Y)\land O(B_1,B_2)\land(A(X,Y)\lor O(C_1,C_2))$, where $O$ is ordinary TI. A swap of odd-sized blocks donates a sign exactly when the ordinary $C$-test succeeds. |
| [Conjunction from a common object map](Algebra.md) | Any successful conjunction encoding of this kind would give $A\le_m^p\mathrm{TI}$, with an explicit compiler using two ordinary TI comparisons. The argument covers a common context computed from the unordered set of the four raw tensors. In that common-context model the converse also holds. |

In the raw two-sign problem, the paired adjoint algebras of the source give a computable subgroup of stabilizer signs. Whenever its projection onto the two tested signs is nonzero, one signed instance suffices, without having to find an original relative transporter. A line in this projected subgroup gives one annihilating character. The full plane makes the verdict ordinary TI. The proof also gives precise multiplicity formulas for computing those certified signs.

For two opposite signed tests on the *same* raw pair $(T,S)$, one signed instance suffices even with no dimension promise. Let $R$ be a fixed sign-reversing target rebase. Then $A(T,S)\land A(T,R\cdot S)$ is equivalent to $O(T,S)\land A(T,R\cdot T)$: a nonempty relative sign coset contains both signs exactly when its stabilizer has an odd sign. Use the neutral conjunction compiler.

A separate exact upper bound is $\mathrm{SL\!-\!TI}\le_m^p B^{\wedge3}$, using three nonadaptive two-sign tests. Their allowed lines are generated by $u,v,u+v$ for any independent $u,v$ in the sign space. A nonempty affine coset avoiding zero cannot contain all three of those representatives, because their sum is zero and they form an odd affine combination. [Three-query proof](Complexity.md)

The common-object argument is a sufficient compiler, not a complexity separation. If $f$ were a common object map encoding two independent comparisons, use the three tuples $(X,X),(X,Y),(Y,Y)$. When $A(X,Y)$ holds their images all lie in one ordinary orbit. Otherwise they have three different signed orbits. Each ordinary orbit can contain at most two signed orbits, so conjunction of two ordinary TI comparisons recovers the answer and compiles to one ordinary TI instance. The prior seven-character decomposition then gives $\mathrm{SL\!-\!TI}\le_m^p\mathrm{TI}$. A general pair-dependent reduction can change all of its output data when the comparison pairing changes. The proof does not apply to such a map without its common-context hypothesis. Conversely, given an ordinary TI reduction for $A$, ordinary comparisons across the constant-size cuts of the unordered input set give a common-context conjunction encoder. [Fortnow and Grochow on kernel reductions](https://arxiv.org/abs/0907.4775) · [Open Question 1.9](https://arxiv.org/html/2306.03135v2#S1.SS5)

The proofs are informal. Exact finite controls checked 64 neutral multiplication-tensor isotopies, 5,376 affine three-line comparisons, and a complete tangent check for the protected exterior lock in dimension two. Publication priority and the unrestricted deterministic one-instance comparison remain unresolved.
