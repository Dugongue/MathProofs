# Projective slice recovery and short certificates for ordinary four-tensor nonisomorphism

Let \(k=\mathbb F_q\) be a fixed finite field. Use dense ordered \(n\times n\times n\times n\) tensors and one independent general linear change in each mode. All conclusions below use the ordinary four-factor action.

**Theorem.** There is an invariant, deterministically polynomial-time source test of density \(1-o(1)\), with exact polynomial-time comparison and witness construction against every target. On this source set an isomorphism determines all four mode maps projectively, and the algorithm recovers the four projective maps by linear equations. It never enumerates repeated-primary commutants or solves a field-unit image problem.

Use the polynomial-calculus encoding with the quartic action equations and quadratic two-sided inverse equations for all four mode matrices. On every recognized source with invertible prescribed pair cut, every NO instance has a constructible absolute constant-degree refutation without field axioms. On a recognized source with singular prescribed cut of corank \(c\), every NO instance has a refutation of degree at most \(C+4c(q-1)+2q\) using the field axioms for the original variables, with an absolute \(C\). The recognized set requires \(q^c\le n\). Thus the degree is logarithmic for every recognized source, is bounded in expectation over recognized uniform sources, and is bounded by a constant depending only on \(q,\varepsilon\) on at least a \(1-\varepsilon-o(1)\) fraction of all sources. There is also a deterministically constructible polynomial-size linear Ideal Proof System certificate on every recognized NO instance, using the same axioms. The logarithmic-degree polynomial-calculus construction is claimed to have polynomially many lines, with dense expansion size potentially quasipolynomial.

The rank-one-projector recovery argument is a different use of the covariants in the [almost-all ordinary four-tensor decision theorem](https://github.com/Dugongue/MathProofs/blob/main/FourTIAlmostAll/FullCoverage.md). The result for the invertible sector also holds for geometric nonisomorphism over the algebraic closure, and on that recognized sector every geometric YES pair of base-field tensors already has a base-field transporter.

## 1. Recovering four mode lines from tensors with spectral anchors

Suppose for now that four ordered source and target endomorphisms \(E_i,F_i\) obey the necessary identities
\[
 F_iX_i=X_iE_i
\]
for any transporter \(X=(X_1,X_2,X_3,X_4)\). We specify how to derive these identities in the two cut branches in Sections 3 and 4. Write \(Y_i\) for the inverse-matrix variables. Over the algebraic closure, use the simple eigenlabels of \(E_i\), meaning the roots of its characteristic polynomial that have multiplicity one. For each such root \(\lambda\), choose a polynomial \(f_\lambda\) giving the projector \(P_{i,\lambda}=f_\lambda(E_i)\) onto its eigenline. For example, use the Chinese remainder conditions \(1\) at \(x-\lambda\) and \(0\) modulo the rest of the characteristic polynomial. This polynomial has coefficients in \(k(\lambda)\). Define \(Q_{i,\lambda}=f_\lambda(F_i)\). Intertwining with the two projectors is linear, and \(Q_{i,\lambda}=X_iP_{i,\lambda}Y_i\).

Reject if any such \(Q\) is not a rank-one idempotent. This rejection has a bounded-degree certificate even though a general rank test in polynomial calculus can be hard. Idempotence is derived by substitution of \(P^2=P\) and the two-sided inverse equations. If \(Q=0\), derive \(P=Y_iQX_i\). If \(Q\) has rank at least two, a known nonzero constant \(2\)-by-\(2\) minor contradicts \(Q=X_iP Y_i\): the latter factors as an outer product, whose minor vanishes identically. This calculation does not compare full rational canonical forms.

Write \(P=v\alpha\), \(Q=v'\alpha'\), with \(\alpha(v)=\alpha'(v')=1\), using column vectors \(v,v'\) and row functionals \(\alpha,\alpha'\). All choices can be made in \(k(\lambda)\) and Frobenius conjugated for the other roots of the same irreducible factor. The projector equations give \(\alpha'X_i=x_{i,\lambda}\alpha\) and \(\alpha Y_i=y_{i,\lambda}\alpha'\), with \(x_{i,\lambda},y_{i,\lambda}\) linear in entries of the original variables. They also give \(x_{i,\lambda}y_{i,\lambda}=1\), by applying the inverse identity between the indicated row and column.

Fix a simple anchor \(\lambda_i\) in mode \(i\). A context \(J\) chooses one simple eigenlabel in each of the other three modes. Define \(a_J\) by contracting the source against the three corresponding source functionals and define \(b_J\) by contracting the target against the three target functionals. For every context with \(\alpha_{i,\lambda_i}(a_J)\ne0\), applying the action equations and the rank-one identities gives
\[
 b_J=\Big(\prod_{j\ne i}x_{j,J_j}\Big) X_i a_J,
 \qquad
 \alpha'_{i,\lambda_i}(b_J)=\Big(x_{i,\lambda_i}\prod_{j\ne i}x_{j,J_j}\Big)\alpha_{i,\lambda_i}(a_J).
\]
If the displayed target coordinate is zero, it contradicts the second equality after multiplying by the four reciprocal linear forms and using their inverse equations. Otherwise subtract the first identity times \(x_{i,\lambda_i}\alpha_{i,\lambda_i}(a_J)\) from the second times \(X_i a_J\). This yields the linear equations
\[
 \alpha'_{i,\lambda_i}(b_J) X_i a_J
   =x_{i,\lambda_i}\alpha_{i,\lambda_i}(a_J)b_J.                 \tag{1}
\]

The source test for this mode is that the vectors \(a_J\) with nonzero anchor coordinate span the entire mode space over \(\overline k\). Under this test, equation (1) determines any solution matrix from the scalar \(x_{i,\lambda_i}\). In particular the solution space over the base field has dimension at most one. If zero, the inverse equation refutes the branch. If the solution line consists of scalar multiples of a singular matrix, take any nonzero constant row in its left kernel and apply the inverse equation. Otherwise the solution line is spanned by an invertible constant matrix \(G_i\) over \(k\) and the calculus derives \(X_i=z_iG_i\) with \(z_i\) a base-field linear form in the original variables. After all four lines are obtained compare the target with the tensor obtained by applying \((G_1,G_2,G_3,G_4)\) to the source. The action equations now demand equality up to the single scalar \(\prod_i z_i\), which is nonzero by the inverse equations. A failure is a bounded-degree contradiction, found by using one nonzero coordinate of the transformed source and testing all the other coordinates or by using reciprocals when the ratio is zero. If instead the tensors differ by a nonzero constant scalar, rescale one mode and obtain a true transporter.

This procedure works with source and target tensors over the base field. All linear equations using extension coefficients are converted to base-field equations by taking coefficients in a field basis, and constant-degree derivations over an extension can be simulated componentwise at the same degree. Each context and its anchor use at most four extensions of degrees at most \(n\). Their compositum has degree at most \(n^4\). These fields can be constructed and embedded by the compatible finite-field model construction of the [four-tensor algorithm](https://github.com/Dugongue/MathProofs/blob/main/FourTIAlmostAll/FullCoverage.md#2-exact-decision-for-every-accepted-first-input). It uses deterministic factorization of squarefree polynomials at fixed characteristic. No compositum of all eigenfields is constructed.

The spanning test is effective with these same local fields. The accepted contexts are stable under the Frobenius fixing the anchor field. For each accepted context expand its vectors into coefficients over the anchor field. The span of the coefficients is the span of the Frobenius conjugates over the algebraic closure. One direction follows from the coordinate expansion and the converse follows from separability, or from the trace-dual basis applied to the expansion. Thus solving over the anchor field certifies the span. All acceptance tests can be phrased in invariant terms, taking all simple labels or checking all of them as possible anchors. Rescaling a selected eigenfunctional does not change any span. Above, one passing anchor suffices for recovery.

## 2. Simultaneous spanning for almost every source

The following estimate is taken with respect to the **unconditioned** uniform tensor. It will apply even when the operators depend on that same tensor. Fix \(i\), choose three endomorphisms over \(k\) in the other modes, and suppose each has at least \(n/2\) simple eigenlabels. Choose their Frobenius-compatible simple eigenfunctionals, for example by normalizing the first nonzero coordinate. Fix an anchor functional \(\alpha\in k_d^{n*}\setminus\{0\}\), where \(k_d=\mathbb F_{q^d}\) and \(d\le n\). The span of the \(a_J\) for which \(\alpha(a_J)\ne0\) is stable under \(q^d\)-Frobenius. If it is proper, it is annihilated by a nonzero functional \(\beta\in k_d^{n*}\): the unique reduced row-echelon form of the span has its entries in \(k_d\), by Frobenius stability.

For each Frobenius orbit of contexts, consider one representative. If the orbit has length \(s\), then its vector \(a_J\) is uniform in \(\mathbb F_{q^s}^n\), independently of the representatives of the other orbits. In fact, for each of the three complement spaces, all the simple evaluation functionals are independent over the closure. The tensor product evaluation is a surjection onto the corresponding simple coordinates. It has a Frobenius-compatible right inverse on the simple primary subspaces, obtained by taking the eigenvectors dual to the normalized functionals. Over \(k\) its output is exactly a Frobenius-compatible coordinate array, whose value at each representative is independently uniform in its orbit field. This applies separately in every coordinate of mode \(i\).

If \(\beta\) annihilates the span, each such vector lies in the union of the zero sets of \(\alpha\) and \(\beta\). In the orbit field vector space, each zero set is a proper linear subspace, including when the functional has coefficients only in a larger field. The probability of this union is at most \(2/q^s-1/q^{2s}\le q^{-s/4}\): enlarge the subspaces to hyperplanes and count their maximum union. Since the orbit lengths sum to the number of contexts, at least \((n/2)^3\), the probability is \(q^{-\Omega(n^3)}\). The three chosen matrices have at most \(q^{3n^2}\) possible choices, and the total choices of \(d,\alpha,\beta\) are at most \(nq^{2n^2}\). Union over all these choices and the four modes. With probability \(1-q^{-\Omega(n^3)}\) the spanning test works simultaneously for all such operators and all eligible anchors. This estimate avoids any independence assumption between the source covariants and the contexts they select.

## 3. Invertible prescribed cut

Let \(A,B\) be the source and target matrices of the prescribed \(12\mid34\) cut. The flattening equation is \(B=X_L A X_R^{\mathsf T}\), with \(X_L=X_1\otimes X_2\), \(X_R=X_3\otimes X_4\). Write \(Y_L=Y_1\otimes Y_2\) and \(Y_R=Y_3\otimes Y_4\). Their two-sided inverse identities are consequences of the original quadratic inverse equations in degree four. If exactly one of the two cuts is invertible, applying any nonzero constant null vector of the singular cut and using the given inverse of the nonsingular cut refutes the flattening equation with bounded degree. We never compare two arbitrary unequal nonzero ranks using this argument.

When both cuts are invertible, apply their known inverse transposes to form the two dual tensors. The flattening identity gives \(B^{-\mathsf T}=Y_L^{\mathsf T}A^{-\mathsf T}Y_R\) by multiplying by the known numerical inverses and using the two-sided quadratic inverse equations. Apply the crossed contractions and squared partial traces of the [almost-all four-tensor theorem](https://github.com/Dugongue/MathProofs/blob/main/FourTIAlmostAll/FullCoverage.md#1-the-operators-and-their-laws). All covariances are bounded-degree polynomial-calculus derivations. In detail, substitute the action equation and its dual in the crossed contraction and cancel the inverse pairs in the contracted modes. Each resulting crossed matrix has conjugation rule with factors \(X_i\otimes X_j\) and \(Y_i\otimes Y_j\). Multiply two such rules and telescope through the middle inverse pair. Partial trace then cancels the inverse pair in the traced mode. Multiplying the resulting covariance on the right by \(X_i\) derives \(F_iX_i=X_iE_i\). Each local multiplication uses only an absolute number of variable factors. The subsequent conversion to polynomial projectors of high degree in the **constant numerical matrices** does not increase that bound: \(F_i^r X_i-X_i E_i^r\) is a sum of constant left and right multiples of \(F_iX_i-X_iE_i\).

Conditional on cut invertibility, the old mixing estimate is \(o(1)\) from the appropriate uniform matrix law for each of the four operators. The expected repeated-primary budget under that comparison law is bounded at fixed \(q\). In particular the total dimension of repeated-primary blocks is \(o(n)\) with probability \(1-o(1)\). This gives at least \(n/2\) simple eigenlabels for each operator with that probability. Cut invertibility has probability bounded away from zero, so the unconditional simultaneous spanning bound also applies after conditioning. Use Section 1 to finish. No field axioms were used. The branch is valid over the algebraic closure, and if it is satisfiable there, the one-dimensional solution spaces given by (1) have invertible generators over \(k\) by base change of a linear system over \(k\). The final constant scalar ratio belongs to \(k\), so the construction gives a transporter over \(k\).

## 4. Singular prescribed cut

Let the source cut have corank \(c>0\) and require \(q^c\le n\). Its left and right kernels are spaces of bilinear forms on the two associated pairs of modes. Fix nonzero source left and right kernel forms \(L,M\). Contract the two paired modes into the duals of their mates via \(L,M\), giving a tensor \(Z\in\operatorname{End}(V_1)\otimes\operatorname{End}(V_3)\). Take the two squared partial-trace endomorphisms \(\operatorname{Tr}_{V_3}Z^2\), \(\operatorname{Tr}_{V_1}Z^2\). Reverse both pair orientations to get the two others on \(V_2,V_4\). If the two source forms are the pullbacks of fixed target forms, these four endomorphisms obey the same necessary conjugation identities. Substituting the action and the two form identities into the contractions, then canceling the inverse pairs, gives the polynomial-calculus derivation of covariance exactly as for the crossed matrices. In particular no extra variables for the paired ambient spaces are required.

In live and radical coordinates each endomorphism factor of \(Z\) has block shape \(\left(\begin{smallmatrix}A&0\\ D&0\end{smallmatrix}\right)\). Multiplication and trace restrict to its live block. Consequently the live blocks of the two squared partial traces are exactly those analyzed in the [singular-cut decision proof](https://github.com/Dugongue/MathProofs/blob/main/FixedFieldOrdinaryFourTI/PROOF.md#3-the-live-partial-traces-have-almost-uniform-joint-law), with the radical dimension adding only factors of the polynomial \(x\). Reversing both orientations transposes both live blocks in paired dual bases. Conditional on any fixed source corank \(c\), uniformly chosen nonzero kernel forms have radical dimension \(o(n)\) with probability \(1-o(1)\). The cited live mixing and repeated-primary bounds show that all four original operators have at least \(n/2\) simple labels with the same probability. Here there are \((q^c-1)^2\) source form pairs, a constant for fixed \(c\). Multiplying the failure bound for a uniform pair by this number proves that *every* source form pair satisfies the simple label test with probability \(1-o(1)\) conditional on that fixed corank. Singular corank is tight as \(n\) grows. For example the expected number of nonzero right-kernel vectors is at most one, giving \(\Pr[c\ge t]\le 1/(q^t-1)\). Truncate to fixed \(c\) and then let the truncation bound grow to prove the claimed overall density. The spanning requirement is supplied by the simultaneous bound in Section 2.

For exact comparison, if the target cut is invertible reject as in Section 3. If it is singular, choose one nonzero left and one nonzero right target kernel form \(\ell,m\), even if the coranks of the source and target differ. Their pullbacks by a transporter are \(X_L^{\mathsf T}\ell\) and \(X_R^{\mathsf T}m\). The flattening equation and its inverse imply that these belong to the two source kernels and are nonzero. Enumerate all possible pullbacks, at most \(q^{2c}\), then use Section 1 for every nonzero pair and directly verify each returned transporter. The invariant source test runs Section 1's test for every source form pair. All source tests and comparisons have polynomial cost, since \(q^{2c}\le n^2\). The test on the source alone is independent of the target. Because the proof of the four projective lines also applies to the self-comparison on every branch, uniqueness of projective maps *across* branches would require a further argument when different form pairs survive. To make the theorem's uniqueness assertion, include a scalar-stabilizer check in the source test. Run the self-comparison with the same target kernel forms across all branches and require each successful candidate tuple to be projectively the identity. Every branch fixes all four mode lines, so this check is exact. A uniform tensor has scalar stabilizer with probability \(1-o(1)\) by the [rank-and-union estimate](https://github.com/Dugongue/MathProofs/blob/main/FourTIAlmostAll/SearchAndLifting.md#1-generic-stabilizers). The extra check is invariant and leaves the density unchanged.

## 5. Proof degree, branching and circuit size

On the singular branch, write \(z_1,\ldots,z_{2c}\) for the base-field coordinate expressions of the two pulled-back forms in bases of the two source kernels. These are polynomials of degree at most two in the original matrix variables, using fixed linear coordinate selectors. The equations saying the forms equal the corresponding basis combinations follow by Gaussian elimination from the flattening equation and its inverse. The derivations use only a bounded number of factors of the action and inverse variables. For a fixed tuple \(a\in k^{2c}\), add the branch axioms \(z_j-a_j=0\) provisionally. In a zero-form branch, the inverse equations force the corresponding nonzero target form to vanish. In every other branch the form identities hold, so Sections 1 and 4 give a constant-degree refutation whenever the full pair is a NO instance. The max degree is absolute: tensor substitutions, cancellation, partial traces, rank-one minors, reciprocal normalization and the final scalar test all use at most a fixed number of original variable factors. Repeated linear elimination and polynomial evaluation on numerical matrices use constant multipliers and do not increase degree. This gives an absolute \(C\) for the branch proof.

The field axioms of the original variables derive \(z_j^q-z_j=0\) in degree \(2q\), by Frobenius additivity and subtraction of the original field equations one factor at a time in each quadratic monomial. Define
\[
 \Delta_a=\prod_{j=1}^{2c}\big(1-(z_j-a_j)^{q-1}\big).
\]
The sum of the indicators over all tuples is identically one, by the univariate interpolation identity for polynomials of degree less than \(q\). For each branch axiom,
\[
 \Delta_a(z_j-a_j)=-\!
 \prod_{r\ne j}\big(1-(z_r-a_r)^{q-1}\big)(z_j^q-z_j).
\]
Multiply each branch proof by \(\Delta_a\). The displayed identity derives the multiplied branch axioms from the original field axioms. The ordinary axioms can be multiplied by \(\Delta_a\) a factor at a time, using bounded-degree factors, so no expansion of a product of all the factors is needed to plan the derivation. The resulting proof derives \(\Delta_a\) for each \(a\). Adding gives the refutation. The degree is bounded by \(C+4c(q-1)+2q\). Forming each multiplied axiom takes polynomially many variable multiplications and linear combinations because each factor has polynomially many monomials for fixed \(q\), and the number of branches is polynomial. Expanded lines have at most \(n^{O_q(1+c)}\) monomials. The corank tail from Section 4 proves the claimed bounded expectation and the constant-degree statement for density \(1-\varepsilon-o(1)\).

For the linear IPS bound, introduce an axiom placeholder for each original equation and, temporarily, each branch assumption. Store a circuit for each line of a constant-degree branch derivation by replacing initial axioms by their placeholders. The circuit update is linear combination or multiplication by a variable. At the final line this yields a circuit homogeneous linear in the placeholders, zero when they are zero, and evaluating to one on substitution of the actual branch axioms. Substitute \(\Delta_a\) times each original placeholder and the displayed factored identities for the multiplied branch assumptions. The field-axiom derivations themselves have polynomial-size linear placeholder circuits. By homogeneity the circuit for the branch now evaluates to \(\Delta_a\) on just the original axioms. Sum these circuits over branches. This gives an explicit polynomial-size linear IPS refutation directly in the original variables. It uses only polynomially many arithmetic gates and branches and preserves the ordinary tensor-isomorphism constraints.

## Scope and attribution

The source density uses the previous distribution estimates for ordinary four-tensor isomorphism. The new spanning argument turns one rank-one spectral coordinate and many ordinary slices into a linear projective recovery theorem, including for matrices with repeated spectra on the other primary components. The proof-complexity application uses the standard two-sided inverse encoding and separates a bounded-degree geometric sector from the finite-field branching sector. The result concerns almost all sources, including ones with unbounded tensor rank. It does not imply a worst-case upper bound for arbitrary ordinary TI instances.
