# The binary field and external oracles

Let \(A\) and \(B\) be the fixed ternary signed and ordinary tensor-isomorphism languages. Let \(H\) be \(A\le_m^P B\), and let \(H_R\) and \(H_{\mathrm{adv}}\) denote, respectively, bounded-error randomized polynomial-time many-one and deterministic polynomial-size circuit many-one reducibility of these same fixed languages. A map counted under \(H_R\) must output a correct ordinary instance with probability at least \(2/3\) on each signed input, where “correct” refers to the comparison's YES/NO value. Amplification to the same target works by the positive Boolean majority compiler in the preceding work. In particular \(H\Rightarrow H_R\Rightarrow H_{\mathrm{adv}}\).

## 1. Exactly which external oracles erase the separation?

For an external set \(O\subseteq\{0,1\}^*\), write \(H[O]\) when some polynomially clocked deterministic oracle machine prints a correct ordinary target for every signed input. The two languages themselves stay fixed. Regard oracle space as Cantor space, with the fair independent measure and the topology whose basic open sets fix finitely many coordinates.

**Category.** \(H\) is equivalent to the set \(\{O:H[O]\}\) being nonmeager, and also to that set containing a nonempty open subset. When \(H\) holds all oracles work. When \(H\) fails the erasing oracles form a dense meager set, disjoint from every weakly 1-generic oracle. To prove this, fix an oracle machine and polynomial clock. Its correctness set is closed: a violation on a finite input persists after fixing that computation's finite query-answer transcript. An interior cylinder would yield a deterministic reduction by replacing the oracle with its finite assignment and answering zero elsewhere. Under \(\neg H\) each correctness set is therefore nowhere dense, and their countable union is meager. The complements are uniformly effectively open because exact tensor membership is decidable by exhaustive finite search. Every weakly 1-generic sequence meets each of those dense effectively open sets. Erasing oracles do exist, since one can store membership in \(A\) and output a fixed YES or NO instance of \(B\). Every finite modification of an erasing oracle still erases, by hardcoding the corrections. This proves density. There is no group oracle in this argument.

**Effective simultaneous avoidance.** Under \(\neg H\), any finite prescription of oracle bits can be extended to a recursive separating oracle. At stage \(j\), enumerate extensions and inputs until an answer transcript certifies that clocked machine \(j\) errs. The search terminates by the nowhere-density argument, and the certificate is decidable. Fix its transcript and at least one more coordinate in length-lexicographic order. The resulting total recursive oracle defeats all clocked machines. The same proof handles any countable uniformly decidable list of fixed-language separations, provided every asserted unrelativized separation holds; dovetail their clock requirements.

**Measure.** As in the Bennett–Gill argument, the set of erasing oracles has fair-coin measure one if \(H_R\) holds and zero otherwise. For completeness, for the forward direction amplify using a polynomial block of independent random tapes from oracle positions indexed distinctly by the entire input and tape position. Compile their strict majority to one ordinary test. The failure probabilities can be made at most \(2^{-2|x|-c}\) for \(c\) fixed. The sum over inputs is finite, so almost every oracle needs only finitely many per-input corrections, which a single machine can hardcode. For the converse, positive measure for the union gives positive measure for one clocked machine's closed correctness set \(C\). There is a finite cylinder with \(\Pr[C\mid\text{cylinder}]>2/3\): finite prefix conditional probabilities approximate the indicator of \(C\), or use the decreasing clopen approximations to the closed set and average conditional probabilities on their cylinders. Simulate that machine with the prefix fixed and generate fresh random replies on first queries outside the prefix, reusing them on repeats. Its target on each input is correct with probability greater than \(2/3\). This is \(H_R\). [Bennett and Gill, *Relative to a Random Oracle*](https://doi.org/10.1137/0210008).

Consequently, in the negative branch two exact alternatives exist. If \(H_R\) fails, the erasing oracles are null and meager. If \(H_R\) holds, the erasing oracles are conull and meager: every weakly 1-generic oracle preserves the degree gap even though almost every independent random oracle erases it. This measure/category distinction does not infer an unrelativized contradiction.

**Sparse oracles and advice.** \(H_{\mathrm{adv}}\) holds exactly when some sparse oracle erases the gap, and equivalently when some recursive tally oracle erases it. For the forward sparse-to-advice direction, a clocked reduction queries only strings of length polynomial in the input. Supply the polynomially many short members of the sparse oracle as advice and check membership in that list. For the reverse, a deterministic polynomial-size circuit reduction can be supplied as advice to a uniform evaluation machine. At length \(n\), encode the advice bit \(i\) in the membership of the tally word of length \(1+\langle n,i\rangle\), taking any explicit invertible polynomial pairing. The length traveled is polynomial in \(n\) for all required bits. Furthermore the advice can be made computable: for each \(n\), search the bounded set of advice strings, verifying each on all inputs of length \(n\) by exhaustive membership in \(A,B\). A fixed polynomial advice bound exists by hypothesis, so this search terminates. The tally oracle has at most one member at each length. A finite oracle always gives exactly the original reduction power because its complete table can be hardcoded. If \(H_{\mathrm{adv}}\) fails then every sparse oracle, recursive or otherwise, preserves the separation.

**Refining the two alternatives.** If \(H_{\mathrm{adv}}\) fails, \(H_R\) fails and the separation holds relative to all sparse oracles and almost all full random oracles. If \(H_{\mathrm{adv}}\) holds while \(H_R\) fails, there is an explicitly specified recursive tally encoding of correct nonuniform advice even though full-measure many-one erasure fails. If \(H_R\) holds while \(H\) fails, a recursive tally oracle also erases the gap, every finite oracle preserves it, and generic and random oracles differ as above. These implications are conditional descriptions, including when it is unknown whether an intermediate region is realized by these particular two languages.

## 2. Cross-characteristic transporter preservation has an exponential cost

The identities \(\mathrm{SL}_n(\mathbb F_2)=\mathrm{GL}_n(\mathbb F_2)\) settle the binary field locally. A route through the binary field that preserves the source stabilizers by faithful homomorphisms would have exponential output size already on full-support identity-matrix tensors. This conclusion is unconditional and applies in any different target characteristic. Classical cross-characteristic representation bounds give related and often stronger dimension estimates. The following direct proof needs only an abelian subgroup and also gives a projective variant. [Landazuri and Seitz, *On the Minimal Degrees of Projective Representations of the Finite Chevalley Groups*](https://deepblue.lib.umich.edu/handle/2027.42/22240).

Let \(q\) be a power of \(p\), \(k\) a field of characteristic different from \(p\), and \(n\ge4\). The group \(\mathrm{SL}_n(\mathbb F_q)\) contains the elementary abelian subgroup \(E\cong\mathbb F_q^{n-1}\) of upper block root matrices with identity diagonal blocks, and it contains a block \(\mathrm{SL}_{n-1}(\mathbb F_q)\) acting as the natural vector action or its dual on \(E\). The multiplicative characters of \(E\) over \(\bar k\) are identified with \(\mathbb F_q^{n-1}\) via the nondegenerate trace pairing and a primitive \(p\)-th root of unity. The block group is transitive on the nontrivial characters.

For any ordinary linear representation, restrict to \(E\) over \(\bar k\). Its elements commute and have minimal polynomials dividing \(X^p-1\), whose roots are simple, so the representation decomposes into character weight spaces. If \(E\) acts nontrivially, all \(q^{n-1}-1\) nontrivial characters occur by conjugation. This proves that lower bound for the dimension.

Suppose instead \(\rho:\mathrm{SL}_n(\mathbb F_q)\to\mathrm{PGL}_d(k)\) has nontrivial image on \(E\). The scalar commutator of lifts of \(\rho(u),\rho(v)\) is a well-defined alternating bicharacter \(\omega:E\times E\to\mu_p(\bar k)\): central commutators are multiplicative in both entries, and \(E\) has exponent \(p\). It is invariant under the block group. In coordinates for the natural block action, take \(i,j\) and choose \(h\notin\{i,j\}\). An elementary shear taking \(a e_h\) to \(a e_h + a e_i\) fixes \(b e_j\), including when \(i=j\). Invariance and bilinearity give \(\omega(a e_i,b e_j)=1\) for all \(a,b\). The dual action contains the same shears. Thus \(\omega=1\). Choose lifts of an additive \(\mathbb F_p\)-basis of \(E\) of order dividing \(p\), scaling over \(\bar k\) to make their \(p\)-th powers one. They commute and give a linear lift of the restriction to \(E\). Conjugation by the block group on these lifts agrees with the indicated action on \(E\) up to a scalar character on \(E\). Thus it induces an affine permutation of the weight space labels, with linear part the ordinary dual block action. In particular all nonzero differences of occurring weights form an invariant set under a transitive action. There are at least two different occurring weights, since otherwise \(E\) would act by scalars and its image in \(\mathrm{PGL}_d\) would be trivial. Therefore the weight differences cover all \(q^{n-1}-1\) nonzero characters, giving \(d(d-1)\ge q^{n-1}-1\).

Apply either result to the \(n\times n\times1\) identity matrix slice, whose determinant-one stabilizer contains \(\mathrm{SL}_n(\mathbb F_q)\) via \(M\mapsto(M,M^{-\mathsf T},1)\). For an embedding of its stabilizer into a target tensor stabilizer, some target mode representation must be nontrivial on \(E\). The same conclusion holds for a projective transporter model that keeps \(E\) nontrivial in at least one projective target mode. Its side length is exponential in \(n\), hence superpolynomial in the dense source length \(O(n^2\log q)\) at fixed \(q\). A map of decision instances with no required homomorphism on stabilizers can discard this subgroup, so the obstruction applies to the faithful models stated here.

## 3. Short witness-producing oracle trees

Let \(R(x,w)\) be any polynomial-time verifiable witness relation with all YES instances admitting polynomial-size witnesses. A deterministic polynomial-time algorithm that finds a valid witness on every YES instance using at most \(c\log(|x|+2)\) decision-oracle answers implies that the witness language is in polynomial time. Unroll every answer transcript, ignoring consistency. Test each returned witness directly. On a YES input the true transcript occurs, and on a NO input none can return a valid witness. This works even with an undecidable external decision oracle. It also applies to polynomial-time reduction to an explicitly enumerable polynomial list of possible witness-producing executions.

Hence \(\neg H\) rules out this short-oracle-query form of signed witness search irrespective of which decision language is supplied. If an algorithm on a YES input only provides an arbitrary ordinary transporter, its output need not pass the signed verifier. The randomized unblinding result in the complexity chapter supplies the exact probabilistic comparison.
