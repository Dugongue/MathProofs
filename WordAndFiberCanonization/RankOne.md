# Canonizing an occupied fiber of sparse measurements of a rank-one matrix

Fix any finite field K. The input consists of a labelled list of linear measurements and an explicit matrix M of rank exactly one over K. Return a rank-one matrix with the same measurements, consistently for all supplied matrices with the same measurement list, shape and values. Dimensions are explicit (for example, in unary), including in variants with no supplied matrix, so the full matrix has polynomial length. Indices, field encodings and ambient order are fixed. No choice of generators or relabelling is involved. A linear measurement has support k if it reads k entries with nonzero coefficients.

**Informal theorem.** For support at most one, there is a deterministic polynomial-time canonizer. For support at most two, the problem is complete for canonizing equal-length polynomial-time kernels by one polynomial-time witness-preserving encoding and decoding. The hard measurements use only coefficients 1 and −1. Each reads entries in one row or one column and itself has coefficient matrix of rank one. Hardness persists for symmetric Boolean rank-one inputs with their top-left entry fixed to 1. All the conclusions include the two-element field.

As a consequence, polynomial-size circuits solve the two-entry problem precisely when NP is contained in P/poly. A uniform polynomial-time canonizer exists precisely when all length-preserving polynomial-time kernels admit one. By the [length-window theorem](../CanonizationConsequences/Refinements.md), this last criterion is also equivalent to canonizability of all polynomially length-bounded polynomial-time kernels. The uniform equivalence does not assert P = NP.

## One observed entry at a time

Normalize each nonzero coefficient by division in K and discard zero measurements. Build a bipartite graph between row and column indices with one labelled edge for each observed *nonzero* entry. In each nonempty connected component set the factor of its least-indexed row to 1. Propagate factors along the edges, dividing each edge label by the known endpoint factor. Every cycle is consistent because the supplied matrix is feasible. Set factors of vertices outside these components to zero. The outer product realizes all specified nonzero entries. An observed zero must have at least one endpoint outside the components, since the actual rank-one factorization has a nonzero factor at every endpoint of a nonzero observation. Thus all observed zeroes are realized as well. If there is at least one nonzero observation, the output has rank exactly one. If every observed value is zero, output a matrix with a single 1 at the first unobserved position. Such a position exists because an exact-rank-one matrix was supplied. For the variant allowing rank zero one may instead return zero in this last case.

For the promised symmetric Boolean domain with M₀₀ = 1, a direct unary algorithm uses the vector which is 1 at the marked index and all endpoints of observed ones, and zero elsewhere. Its outer square satisfies the observations by feasibility. All choices in these procedures depend only on the measured values and the list.

## Two-entry measurements encode circuit fibers

Let C be a Boolean circuit on b input bits. Its fiber task takes x and returns some z with C(z)=C(x), identically for all x with the same value. Use AND and NOT gates, allowing fan-out and constant wires. Number all input, internal and output wires and add a reference index 0. The constructed measurement list depends only on C. Use a square matrix with one row and one column per index. A factorization M = u vᵀ is used to explain the proof; the reduction may work entirely with entries.

Read M₀₀ and prescribe value 1. For every wire i prescribe zero for the two measurements

    Mᵢᵢ − Mᵢ₀,      Mᵢᵢ − M₀ᵢ.

The normalization u₀v₀ = 1 gives Mᵢⱼ = Mᵢ₀ M₀ⱼ. Thus sᵢ = Mᵢ₀ and tᵢ = M₀ᵢ satisfy sᵢtᵢ = sᵢ = tᵢ. Over a field this forces sᵢ=tᵢ in {0,1}. Every feasible matrix for these values is literally s sᵀ with s₀ = 1. No square-root choice is involved, including in characteristic two.

For the gate k = i AND j prescribe zero for

    Mᵢⱼ − Mᵢₖ,      M₀ₖ − Mᵢₖ.

These equations say sᵢ(sⱼ−sₖ)=0 and (1−sᵢ)sₖ=0. When sᵢ is 1 the output equals sⱼ, and when sᵢ is 0 the output is 0. They hold for every correct gate assignment. For k = NOT i prescribe value 1 for Mᵢ₀ + Mₖ₀. With Boolean wires this enforces sₖ=1−sᵢ over every field. Constant wires are pinned by single entries Mᵢ₀. Finally read Mᵢ₀ for every output wire and prescribe the corresponding bit of C(x). Each measurement is a coordinate or a sum or difference of two coordinates in a common row or column. Its coefficient matrix is an outer product of a coordinate vector and a vector with at most two nonzero positions, in one order or the other. Gates have a fresh output wire.

The caller knows x. Evaluate C at x, put its wire trace and s₀ = 1 in s, and supply M = s sᵀ. This is polynomial time and produces exactly the prescribed measurement values. Two inputs in the same circuit fiber produce the same list and values. Any returned rank-one matrix satisfying them has Boolean input wires, a correct gate trace and the right outputs, so reading its input wire entries recovers z. This proves the circuit-fiber reduction for the full rank-one problem and for the symmetric Boolean variant. It uses no feasibility search.

One may use a single uniform list at each size parameter: take a polynomial-size uniform universal circuit on a padded circuit description and data bits, output the description along with the simulated circuit output, and run the same construction. Circuit size and output length fields are included in the padding. Changing only the data within a fiber preserves all the observed values.

The statement uses matrices as representatives. If algorithms instead input and output pairs of factors, multiplying a pair recovers the matrix. From a nonzero rank-one matrix, choose its lexicographically first nonzero entry Mᵣ𝒸, set u to column c, and set v to row r divided by Mᵣ𝒸. This selects one factorization for each matrix deterministically in polynomial time. Thus neither reduction requires an arbitrary choice of scalar.

## Feasibility, exact counting and the number of mixed measurements

For a b-input Boolean circuit with one output, construct the same list and prescribe output 1. This time the input consists only of the list and the right-hand sides. The correspondence between accepting b-bit strings and feasible rank-one matrices is a bijection: every wire, including every unused input bit, has a distinct index; internal wires follow by deterministic circuit evaluation; and every matrix entry is sᵢsⱼ. Over each fixed finite field, feasibility is consequently NP-complete and counting the distinct matrices is #P-complete under parsimonious reductions, even on the symmetric Boolean hard instances above. Membership follows by guessing the explicit matrix once in its unique encoding and verifying its rank and measurements in polynomial time. Counting all pairs of factors would introduce an extra scalar multiplicity.

Even when one matrix must be supplied, exact counting is #P-hard under a single call and subtraction of one. From C(x) build the circuit accepting precisely (1,x) with C(x)=1 and the single extra assignment (0,0…0). The extra assignment gives a known matrix in polynomial time. Subtract one from the returned count. The parsimonious claim above concerns the model without the supplied matrix.

If k measurements use two entries and q is the field order, canonization and feasibility take q^k times a polynomial in the explicit input length. Branch over a value for the first entry in each of these k measurements, solve for its partner using the nonzero coefficient, then test and canonize the resulting one-entry system by the component algorithm above. For feasibility, check all repeated readings and cycle consistency, reject any observed zero joining two forced nonzero vertices, and check the all-zero case admits an unobserved position if rank exactly one is required. Choose the first feasible branch in a fixed field order. Conversely a sparse n-variable 3-CNF with O(n) clauses has an AND/NOT circuit with O(n) wires and gates, giving k = O(n). A feasibility algorithm in 2^o(k) times polynomial input length over a fixed finite field would yield a 2^o(n) algorithm for sparse 3SAT. The reduction for that running-time implication starts with a formula and supplies no feasible matrix.

## Completeness, scope and attribution

Any polynomial-time complete invariant restricted to input length b has a polynomial-size Boolean circuit constructible in polynomial time for that length; encode both output length and padded contents. If its kernel preserves input length, normalization inside the resulting circuit fiber returns a legal representative of its original class. Conversely, canonization of rank-one measurement fibers itself has a length-preserving polynomial-time invariant. For a valid record, return a tag, the exact measurement-list encoding and dimensions, and the computed field values. Use fixed-width canonical matrix entries and one exact record for each fixed list and matrix. Handle invalid records by a distinct tag and their unchanged input. This gives both reductions. It also covers a promised subdomain whose membership can be verified in polynomial time, such as the stated symmetric Boolean matrices.

The circuit consequence follows on the lower side already by using SAT-verifier circuits and requiring output 1 for a given satisfying assignment. Grohe proved that canonizing supplied satisfying assignments by polynomial-size circuits implies NP is contained in P/poly. Conversely SAT circuits permit shortlex search for every kernel in question by querying polynomially many prefix instances. These claims concern circuits with polynomial advice across lengths. [Grohe, *Canonization for Lᵏ-equivalence is hard*, §3.4](https://doi.org/10.1007/BFb0028017)

Earlier universality results concern feasibility of bilinear equations, tensor rank and rank minimization. The theorem here places a threshold on the support of each measurement for the task of canonical choice **with a feasible point already supplied**. It concerns the occupied fibers of a bilinear measurement map. It establishes no reduction from general tensor isomorphism to special-linear tensor isomorphism. Independent priority for this support threshold remains unverified. [Hillar and Lim](https://arxiv.org/abs/0911.1393) · [Derksen](https://arxiv.org/abs/1406.0080) · [Shitov](https://arxiv.org/abs/1611.01559)
