# How many input bits does a hard complete invariant need?

## Statements

A complete invariant f labels a pair of strings equally precisely when they are equivalent. A canonizer for its kernel returns a string in the input's fiber and returns the same string throughout that fiber. The input already gives one member of the fiber. These informal results concern explicit strings, with ordinary sequential output.

Call f **k-local** if each output bit depends on at most k input bits. At input length m the output length is fixed and polynomially bounded in m+1. Given m and an output index, a deterministic logspace procedure supplies the output length, indices and Boolean truth table, with m provided in unary. Constants and projections are allowed. Strings at different input lengths may have the same label unless the relation is explicitly required to preserve lengths. FL denotes deterministic logspace functions. An FL machine with an NL oracle may query directed reachability using the standard logspace oracle convention.

| Locality of the complete invariant | Canonization theorem on unrestricted strings |
|---|---|
| At most 1 | Every such kernel has a canonical form in FL. |
| At most 2 | Every such kernel has a canonical form in FL with an NL oracle. All have canonical forms in FL if and only if L = NL. |
| At most 3 | All have polynomial-time canonical forms if and only if P = NP. All have canonical forms in FL if and only if L = NP. With an NL oracle on the FL machine, the criterion is NL = NP. |

For each hard row one fixed invariant suffices. The explicit hard examples still work when each input bit influences at most three output bits. For kernels required to preserve lengths we prove a different result below. A single length-preserving 3-local kernel is complete for canonizing every length-preserving polynomial-time kernel by a polynomial-time encoding and decoding of one query.

## Canonization for unary and binary output gates

On input x compute label bits as needed and inspect lengths l from zero up to |x|. At each l ask whether some l-bit string maps to f(x). Discard l if the output lengths disagree. The least feasible l depends only on the label, since the search always reaches the true minimum.

At locality 1 every required equation is constant or prescribes a single bit. Scan for false constants and contradictory prescriptions. At the first feasible length, use the prescribed value on each constrained bit and zero elsewhere. Repeated scans use logarithmic space.

At locality 2 each output equation excludes at most four assignments on two positions. Express each forbidden assignment by one clause of size at most two. Units, repeated variables and constants cause no problem. The resulting 2-CNF is accessible by index in logspace, including when its target label bits must be read from the original x. Satisfiability belongs to NL. For a deterministic choice of a satisfying assignment at the minimum feasible length, use the implication graph. Give each strongly connected component S the key consisting of the number of graph vertices reaching S and the least vertex index in S, in that order. Along a strict condensation edge the predecessor set increases strictly, so these keys give a total topological order. Logspace counters and directed-reachability queries compute both entries for the component of any literal. Set a literal true when its component comes later than that of its negation. They differ in a satisfiable instance. If a true literal implied a false one, the edge between the literals and its contrapositive would contradict the two strict comparisons in this order. This outputs a satisfying assignment determined solely by the label and length. It does not store a previously printed prefix. [Schaefer complexity refinements](https://people.cs.umass.edu/~immerman/pub/csp05.pdf)

## A uniform layout with two input lengths

The following construction implements the class-length argument of the [logspace canonization theorem](../CanonizationConsequences/Results.md) with a fixed bounded number of input wires per label bit. Fix a sufficiently large constant C. For n,d ≥ 1 use the lengths

    W(n,d) = 2^d (2n+1)^C
    A(n,d) = 1 + 2^d (2n+1)^(C(d+1)).

W is even and A is odd. The odd factor after removing the power of two from W, or from A−1, identifies n by an exact perfect-power test, and the valuation identifies d. Recognition and parameter recovery use logarithmic workspace in the physical length m. Count trailing zeroes and test candidate odd bases by multiplication capped at m+1, stopping at that cap. The remaining arithmetic and all fixed-depth rectangular indexing have the same bound.

Valid lengths for (n,d) have common output length W(n,d)+1, a zero tag, a prescribed sequence of local gate bits, and zeros in the remaining output slots. Other input lengths use a one tag and a copy of the input. Choose C so W holds every gate and input slot needed below. There are only polynomially many in n independently of d. Every length-W record is a potential witness. Every length-A record is a potential anchor. Padding is ignored. W is injective in (n,d), so no other length can contribute to their valid-label fibers.

Program an anchor on an instance with n variables or vertices by putting its constraint selection bits into designated input slots. The label gate for each such bit is a copy, or its negation when the mask convention requires it. All other required label bits are fixed constants. At length W the output gates instead test a supplied candidate and auxiliary variables, as specified below. A length-W preimage of this anchor label exists precisely on yes-instances.

Suppose a canonizer has polynomial output bound p. Fix d large enough that A(n,d) exceeds p(W(n,d)) for all sufficiently large n. This d is chosen after the bound for the single invariant, which already contains every d. On a yes-instance the canonizer must select a W-bit member even on the A-bit anchor, because its output there equals its output on a W-bit witness. On a no-instance the output length must be A. For fixed d, the desired anchor has polynomial length in the underlying input and a logspace procedure can produce its bits. A logspace decision machine can count the output, or stop after W+1 bits. The polynomial-time version simply feeds the anchor to the canonizer. Finitely many small parameter values can be handled directly on the incidence representation.

## Two input wires encode directed nonreachability

Use directed graphs on n ≥ 2 vertices with terminals 1 and n. Multiple encodings can first be standardized to adjacency bits in logspace. Introduce truth bits u_i with unary outputs prescribed to enforce u_1 = 1 and u_n = 0. For each ordered vertex pair (i,j) introduce private bits p,q and three output gates

    (u_i implies p),   (p XOR q),   (q implies u_j).

The first and third targets are 1. The middle target is 0 for a present edge and 1 for an absent edge. A present edge imposes u_i implies u_j: take p=q=u_i for a permitted assignment. For an absent edge set p=1 and q=0 for any values of the endpoints. Hence the target has a witness precisely when a forward-closed vertex set contains 1 and omits n, equivalently when n is unreachable from 1. Directed nonreachability is NL-complete because NL = coNL. Thus an FL canonizer for this one binary-local invariant puts NL in L. Conversely L = NL removes the oracle from the upper bound above.

## Three input wires encode satisfiability

For each possible ordered triple of signed literals a,b,c introduce fresh p,q and emit

    (a OR b OR p),   (NOT q OR c),   (p XOR q).

The targets are 1, 1 and a mask bit. Mask 0 identifies p=q. An extension then exists exactly when the corresponding clause holds: if a or b holds choose p=q=0, and otherwise choose p=q=1 and require c. Mask 1 allows p=1 and q=0 regardless of the literals. With a mask over the O(n³) possible signed triples the target has a witness precisely when the selected 3-CNF is satisfiable. This dense mask is constructible in logarithmic workspace from a standard 3SAT instance. Thus the hard directions in the third row follow by the length argument and logspace completeness of 3SAT.

For the positive direction under P = NP, find the shortest feasible length and then the lexicographically least feasible string at that length by NP prefix tests. In general its output length and individual bit predicates are in P with an NP oracle. Under L = NP this decision class is L; under NL = NP it is NL. A logspace transducer can stream those bit predicates without storing a polynomial-length prefix. In the lower direction for the NL-oracle model use the closure of NL under deterministic logspace NL-oracle computations with polynomial query and output bounds.

To limit influence in either hard example, give each occurrence of an assignment bit its own input position and impose equality along a path through its copies. For each neighboring pair emit their XOR with target zero. Each copy feeds at most one original gate and two equality checks. Pins count as occurrences, and p,q already feed at most two original gates. The new gates retain the claimed locality and use only polynomially many extra wires.

## Classification for any fixed Boolean gate library

Let B be any fixed finite library of bounded-arity Boolean output gates, with copies and constants permitted. Let Γ contain both inverse images of the bits 0 and 1 under every gate and the unary singleton constraints. Interpret Horn, dual-Horn, bijunctive and affine as properties shared by *all* relations of Γ. With unary singleton constraints available, Schaefer's theorem gives two alternatives. In the first, Γ belongs to at least one of these four families and pinned constraint satisfiability is polynomial-time decidable. In the second, every fixed Boolean relation can be defined by existentially quantified auxiliary bits and a conjunction of Γ constraints, allowing constants and variable identification. [Schaefer, *The Complexity of Satisfiability Problems*](https://doi.org/10.1145/800133.804350)

In the first alternative all uniform B-local kernels admit polynomial-time shortlex canonization. On each trial length express an output label as a conjunction of the corresponding inverse-image constraints; prefix tests add only unary pins.

In the second alternative there is a single uniform B-local kernel that admits a polynomial-time canonical form exactly when P = NP. Apply the preceding two-length layout. For each possible signed clause, choose a fixed conjunctive definition of the four-variable relation saying that either the switch s is 0 or the clause on the other three wires holds. Include the switch and auxiliary witnesses in the W-bit record, using disjoint fresh auxiliary bits per copy. For an atom defined by g⁻¹(t), emit g on its wires with target t. For a unary pin emit a copy with the required target. Eliminate equality atoms by identifying variables inside the fixed definition. The optional-clause relation forces no distinct external positions equal, so eliminating equality cannot bind different external inputs. Constants in atoms may be implemented by private pinned wires. Emit the switch itself as a copy with the activation mask supplied by the anchor. The short preimages exist exactly when the active clauses are simultaneously satisfiable. All definitions are fixed finite tables, hence the layout is uniform. The logspace and NL-oracle criteria of the locality-3 hard example also apply here.

Furthermore, in this second alternative one fixed **equal-length** B-local kernel is complete for canonizing all equal-length polynomial-time kernels. Use one layout per n with a switch and the same conjunctive optional-clause gadget per signed triple. Emit the switch values and all individual gate outputs. Give distinct input lengths distinct output lengths, for example by including sufficient constant padding for a strictly increasing polynomial output length. Choose an injective polynomial, logspace-decodable record length for each n, ample for all switches, data, and auxiliaries. At all other lengths use padded identity with a distinct tag.

Given a circuit C on b input bits and input x, compute y=C(x). Form a 3-CNF on z and gate variables for C(z)=y via the standard local gate equations. Insert a tautological clause for each otherwise-unused input coordinate if needed and use fixed-length encodings for y. The layout and its activation mask depend only on C and y. Supply the assignment z=x and its true evaluation trace. For each gadget extend these values using a fixed finite lookup table; disabled clauses impose no restriction. The full label now consists of the mask and fixed passed-test values. Any selected preimage with this label decodes a satisfying z. All x with the same C(x) yield the same label, so they decode the same chosen z. For any equal-length FP kernel, compile its invariant computation at the input length into a Boolean circuit, including output length bits and zero-padded contents. This circuit canonization procedure returns a representative inside the original kernel. Conversely the universal local example is itself an equal-length FP kernel. The [three-window reduction](../CanonizationConsequences/Refinements.md) then gives the same equivalence of uniform canonization principles for polynomially length-bounded FP kernels. The nonuniform consequence is that polynomial-size circuits for this universal local canonization task exist exactly when NP is contained in P/poly. One direction follows by the same reduction from supplied-witness SAT canonization and Grohe's lower bound. The other follows by compiling polynomially many shortlex prefix searches with SAT circuits. [Grohe, *Canonization for Lᵏ-equivalence is hard*, §3.4](https://citeseerx.ist.psu.edu/document?doi=46cc9b5f1ddb57ad7e9ce94fbf6490a7f7da92b1&repid=rep1&type=pdf)

As a concrete instance take only monotone AND and OR gates on at most three bits. Their fibers enforce positive or negative ternary clauses. For each variable introduce its complementary rail, enforcing opposite values using a binary OR with target 1 and a binary AND with target 0. All signed ternary clauses can now be imposed with the rails. This basis falls on the expressive side: alternatively, the positive ternary clause fails Horn, affine and bijunctive closure, while the negative ternary clause fails dual-Horn closure. Consequently even a depth-one array of monotone gates can realize both universality statements. Using only AND yields Horn fiber constraints, and using only OR yields dual-Horn fiber constraints.

The classification concerns choosing an actual class member from an already occupied fiber. Schaefer classifies satisfiability for the constituent constraints. Grohe studied canonical choice given a satisfying assignment and proved the nonuniform SAT implication in 1997. The constructions above transfer these results to individual fixed local maps, with the two input-length regimes specified separately. Publication priority for these particular transfers has not been established.
