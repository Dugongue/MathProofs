# Canonizing a supplied perfect three-dimensional matching

**Theorem.** Consider labelled simple 3-partite, 3-uniform hypergraphs of maximum vertex degree three. The input gives both a host H and a perfect matching M in it. The output must be a perfect matching of H, identical for all supplied perfect matchings of the same labelled H. This task is complete, by polynomial-time encoding and decoding with one call, for canonizing equal-length equivalence relations with polynomial-time complete invariants. Polynomial-size circuits solve the task exactly if and only if NP is contained in P/poly. For ordinary labelled graphs there is a deterministic polynomial-time solution. This is an informal proof.

An equal-length relation only equates strings of the same length. A complete invariant gives the same label precisely on equivalent inputs. A canonical form selects an actual representative and agrees on every member of its class. The algorithm can use the supplied matching. It needs no behavior on hosts without a perfect matching. The ordering of vertices is part of the host.

### From circuit fibers to matching

Fix a Boolean circuit C and an input x. Write y = C(x). We build a host depending only on C and y. We also give polynomial-time maps taking x to a perfect matching and taking any perfect matching back to a z with C(z) = y.

1. Express C(z) = y as a CNF of width at most three using gate variables. For each fan-in-two Boolean gate the CNF forbids its inconsistent triples of input and output values, and unit clauses pin the output bits. A satisfying assignment extends x by evaluating the gates. Every satisfying assignment gives a valid z. Include all input bits as variables, even if unused.
2. Replace each variable by two Boolean variables for the positive and negative literals, with one row requiring their sum to be 1. For each clause add one selector per literal and a row requiring exactly one selector to be 1. For each selector s for literal l add a fresh slack bit h and the row s + (opposite literal of l) + h = 1. Thus a selected literal must be true. Given a satisfying assignment, choose the first true literal and fill the slack bits. We now have a list of nonempty exact-one rows of size at most three. Every Boolean solution projects to a satisfying circuit input.
3. Let T count all variable occurrences in the rows, and let r count the rows. The first part of the host has one vertex for each row and T−r additional vertices called fillers. Each of the other two parts has one vertex per occurrence, denoted b_i and c_i. Cyclically order the occurrences of each variable and write next(i) for the next occurrence of the same variable. Include the triple (row(i), b_i, c_i) and, for every filler j, the triple (j, b_i, c_next(i)). In a perfect matching the coverage of b_i and c_i forces all occurrences of a variable to use the row triples together or the filler triples together. Each row vertex then enforces its exact-one constraint. Conversely a satisfying assignment selects exactly r row triples and leaves exactly T−r occurrences to match bijectively to the fillers. The matching can be constructed in input order. These conclusions include variables with just one occurrence. The number of triples is polynomial.
4. Reduce the maximum degree without losing either witness map. Replace each old vertex of degree d by d clones in its original part, one for each old incidence. An old triple uses the respective three clones. For each consecutive pair of clones v_i,v_(i+1) add two fresh vertices in the other two parts and add exactly two triples, one using each clone together with that fresh pair. In a perfect matching, each of the d−1 private pairs uses one clone, leaving exactly one clone to meet an old triple. If the required outside clone is j, choose the left endpoint in pairs i < j and the right endpoint for i ≥ j. Projecting the old triples of any perfect matching recovers a perfect matching of the previous host. Distinct fresh pairs and incidence labels keep the host simple. Every clone meets at most three triples and every auxiliary vertex meets exactly two. Isolated vertices do not arise on the constructed feasible instances.

Apply the canonizer once to this host and the supplied matching. Decode its answer by reversing the projections. Two circuit inputs with the same y gave the same host, hence the same normalized matching and the same decoded z. With uniform polynomial-time compilation of an FP invariant at each input length, this canonizes its equal-length kernel. Normalize the circuit output by an explicit length field and zero padding when it has variable length. The compiled circuit depends only on the invariant and the input length.

For the reverse direction encode (H,M) with the matching as a bit mask in the host's prescribed edge order. Give valid matchings of H the common tagged invariant H and give invalid records uniquely tagged singleton labels. This is an equal-length FP kernel. For ordinary graphs, construct the lexicographically first perfect matching by successively forbidding an edge when feasibility survives, otherwise fixing it and removing its endpoints. Each test is ordinary polynomial-time perfect matching. [Edmonds, *Paths, Trees, and Flowers*](https://doi.org/10.4153/CJM-1965-045-4)

### Circuit complexity and priority

Grohe defined SAT-witness canonization with a satisfying assignment supplied and proved the advice lower bound by a tournament of satisfiable formulas. The construction above transfers it to bounded-degree three-dimensional matching. Conversely, under NP contained in P/poly, feasibility with any prescribed matching prefix has polynomial-size circuits. Polynomially many copies of those circuits find the lexicographically first perfect matching. This proves the claimed equivalence. The uniform theorem here is completeness for equal-length canonization. Its nonuniform characterization does not establish uniform equivalence to P = NP. [Grohe, *Canonization for Lᵏ-equivalence is hard*, §3.4](https://doi.org/10.1007/BFb0028017)

For clarity, the lower bound can also be seen directly. For a fixed formula length, make a deterministically ordered disjunction of each pair of distinct satisfiable formulas with disjoint assignment bits and a selector bit for the chosen disjunct. A witness of either suffices to supply a satisfying input. The normalized witness chooses one disjunct. Draw an arrow from the other disjunct to that one. Supplying a witness for the tail now recovers a witness for the head. A tournament on at most 2^n vertices has a dominating set of at most n+1 vertices, by repeatedly picking a vertex that beats at least half the others remaining. Advise these formulas and one witness each. Against a new formula try each advised formula, always supplying the known witness, and accept only upon verifying a witness for the new one. Every satisfiable formula is covered, and verification prevents false acceptance. Include the polynomially many circuit lengths used by the encodings in the advice. This gives SAT circuits.

Classical NP-completeness of existence for 3-dimensional matching is distinct from the premise here: every oracle query already comes with a correct perfect matching. The transfer needs both witness maps. The bounded-size matching construction and its interaction with arbitrary equal-length kernels are the claims to compare for priority. [Garey–Johnson, Theorem 3.2](https://perso.limos.fr/~palafour/PAPERS/PDF/Garey-Johnson79.pdf)
