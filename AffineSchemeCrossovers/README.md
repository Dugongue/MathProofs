# Nine extensions of relative affine-scheme realization

The manuscripts give complete informal arguments. They use the earlier [affine-scheme realization](https://github.com/Dugongue/MathProofs/blob/main/Top10CrossoverProofs/UniversalRelativeMappingSchemes.md) and the classical results cited in each proof. The portfolio assessment is provisional pending external review and a broader priority search.

| Result | Main conclusion |
| --- | --- |
| [Closed aspherical realization](ClosedAsphericalMappingSchemes.md) | Every affine integral point set is realized by relative maps between closed smooth four-manifolds, with one fixed virtually nilpotent aspherical target and three marked loops. Two-dimensional source complexes also suffice. A six-dimensional target variant gives the full coefficient-ring functor. |
| [Analytic-complete restriction](AsphericalRestrictionUniversality.md) and [the simply connected version](CountableMappingUniversality.md) | One fixed restriction map with two-dimensional countable sources and a closed aspherical target has a universal analytic image. The same construction realizes every closed Baire path space and every closed finite-ary relation, with continuous choices of representatives. |
| [Derived zero loci](DerivedZeroLoci.md) | Relative mapping spaces retain the derived points of polynomial zero loci over truncated simplicial commutative coefficient rings. A mapping diagram also treats arbitrary connective coefficient rings. |
| [Bounded-probe indistinguishability](ProbeIndistinguishability.md) | A single finite pair has halting-complete integral extension, even though all field probes and all local probes of any preassigned nilpotence depth have identical point functors and weak mapping-space types. Every instance has an explicit compatible profinite witness. |
| [Finite alternating extension games](QuantifiedExtensionGames.md) | Each level of the arithmetical hierarchy occurs in a fixed finite extension tower, even when every terminal map extends over every local coefficient ring. |
| [Compact complex flags](CompactFlagMappingSchemes.md) | Fixed compact flag varieties realize affine integral points from simply connected four-dimensional pairs and from closed simply connected six-manifolds. The degree-scheme identity for the smaller flag holds after inverting 3. |
| [Quasi-projective schemes](QuasiProjectiveRelativeNerves.md) | Strict semisimplicial relative mapping presentations recover all ring-valued points, including those carried by nonfree lines. Graph spans implement morphisms and compose by refinement. |
| [Projective representation groupoids](ProjectiveModuleStackNerves.md) | Finite relative four-complexes in each nerve degree recover representations of any finitely presented algebra on projective modules, including nonfree modules and automorphisms. |
| [Effective Frobenius spectra](FrobeniusLocalExtensions.md) | Finite Galois data determine all good-prime Henselian extension spectra and their densities. Every conjugacy- and power-closed condition occurs. |

The closed aspherical model, analytic restriction, and derived construction are the strongest portfolio candidates. The probe and game theorems give precise limits on local tests in the finite affine-encoded setting. The Frobenius and nerve results apply classical inputs to that setting.
