# Deterministic closures for determinant-one tensor isomorphism

[Atlas determinant and query compiler](baseline/expansion/LinearAlgebraAndCounting.md) · [Earlier ordinary search](baseline/baseline/ComplexityWorlds.md)

Work over \(\mathbf F_3\) with dense three-tensors and positive mode dimensions. Let \(H\) denote the unrestricted deterministic polynomial-time many-one reduction from determinant-one to ordinary TI. The two theorems below give ordinary many-one reductions on specified classes. They do not settle \(H\). The framework uses typed systems with shared named modes and order at most three, their polynomial packing into a constant-size tensor system, and ordinary TI's positive Boolean compiler. The atlas's query-dependent determinant compiler is used only when complementary ordinary queries are explicitly available. [Chen, Grochow, Qiao, Tang and Zhang, Theorem 4.1 and Open Question 1.9](https://arxiv.org/html/2306.03135v2) · [Mahajan and Vinay, determinant branching program](https://repository.ias.ac.in/127977/).

## One-query orientation from parallel marginal pinning

**Theorem.** Suppose a deterministic polynomial preprocessing algorithm returns, for each endpoint, a finite set of actual vectors \(\mathcal F_i(T)\) spanning each mode \(V_i\), and an anchor list of source vectors drawn from these sets. Assume the frame sets have polynomial cardinality and every ordinary tensor transporter maps each source set bijectively to the corresponding target set. Assume the source ordinary stabilizer fixing all anchors pointwise is trivial. The product of target candidate counts for the anchor images must be polynomially bounded. On this paired promise, testing determinant one has a deterministic polynomial-time many-one reduction to ordinary TI. The frame sets may themselves be intrinsic projective line sets after expanding each line to its two nonzero \(\mathbf F_3\)-vectors.

Choose a source basis in each frame set. Branch over all anchor-image assignments and for each assignment \(b\) form an ordinary pinned TI query \(Q_b\). It is constructible by adding one unary vector comparison per pin to the tensor system. On a YES branch there is exactly one ordinary transporter \(g\): any two such witnesses differ by a source stabilizer element fixing all anchors. For each source basis vector \(u\) in mode \(i\) and each candidate \(v\in\mathcal F_i(T')\), form the query \(Q_{b,u,v}\) with that extra pin. On a feasible branch exactly one candidate per vector is YES. For each candidate, the OR of its competitors is therefore an explicit complementary ordinary comparison on that branch. The two rails are both ordinary comparisons even without a general complement-TI reduction.

For every column \(u\), the coordinate entries of its image matrix in the original target frame are the known linear combinations \(\sum_v \mathbf1_{Q_{b,u,v}}v_r\). If \(S_i\) has the chosen source basis as columns, the unknown action matrix in the raw source basis is the matrix of recovered columns times \(S_i^{-1}\). Thus all its entries are linear combinations of the rail values in \(\mathbf F_3\). The atlas's determinant compiler evaluates each of the three conditions \(\det=1\) using the acyclic determinant branching program and switch variables. At every multiplication by a Boolean rail \(r\), its two complementary tests allow the split \(x=p+q\), where \(p\) can be nonzero only on the positive rail and \(q\) can be nonzero only on the negative rail. Hence \(p=rx\) on any feasible branch. There is no need to evaluate a pin query or extract an actual witness while building the decision instance. Conjoin the determinant checks with the ordinary guard \(Q_b\), and disjoin over all assignments. If \(Q_b\) is NO, its determinant decoder can have arbitrary behavior and the guard still rejects. The balanced Boolean compiler gives one ordinary TI instance. A signed witness survives its actual anchor-image branch. A successful branch's unique witness has all desired determinants, proving reflection.

**Scalar kernel case.** Suppose the whole ordinary stabilizer of the source consists of the unavoidable scalar tuples \((\lambda_i I)\) with \(\prod_i\lambda_i=1\). One nonzero source anchor in mode 1 and one in mode 2 kill the entire kernel, so the anchor-assignment product is polynomial. The same theorem applies. The promise may be verified separately or simply treated as the input domain. A useful automatic source of frame sets is an intrinsic operator algebra whose central idempotent summands on each mode have dimension \(O(\log L)\), for the dense input bit length \(L\). The covariant direct sum of those subspaces has its nonzero vectors enumerated in polynomial time. All center-idempotent summands are invariant as a set of subspaces under every ordinary transporter.

**Without rigidity.** The same spanning frames yield deterministic polynomial-time Turing reductions from complete ordinary coset search, and hence from signed decision, to ordinary TI. Greedily find the image of each source basis vector by ordinary pin queries among the corresponding target frame vectors. This uses at most polynomially many adaptive queries. For the source stabilizer, its standard pointwise chain on a basis of the three modes has at most polynomially many orbit points per stage. For each orbit point with a feasible pin, run the same greedy algorithm to find a transporter. The stored elements generate the whole stabilizer by the orbit–stabilizer chain, and their determinants give its character image. This last conclusion alone does not compile to one ordinary question.

## Low-rank orientation channels from an intrinsic operator algebra

Let \(V_1,V_2,V_3\) be the modes. Suppose a deterministic polynomial-time algorithm computes a unital associative subalgebra
\[
  R(T)\ \subseteq\ \prod_{i=1}^3\operatorname{End}_{\mathbf F_3}(V_i)
\]
such that every ordinary tensor transporter \(g=(g_i)\) from \(T\) to \(T'\) gives an algebra isomorphism \(R(T)\to R(T')\) by simultaneous componentwise conjugation. One unconditional example of such an algorithm takes the associative algebra generated by all infinitesimal derivation tuples of \(T\). The derivations solve the linear system \(\sum_i (I\otimes\cdots\otimes X_i\otimes\cdots\otimes I)T=0\), which is covariant under simultaneous conjugation. Close the solution subspace and identity under products using linear-span updates. Its ambient dimension is \(\sum_i(\dim V_i)^2\). Other computable intrinsic operator algebras with the stated covariance can be used.

Write \(J=\operatorname{rad}R\) and \(S=R/J\), and consider \(Q_{ik}=J^kV_i/J^{k+1}V_i\) for \(k\ge0\), where \(J^0V_i=V_i\). The action of \(R\) on each quotient descends to \(S\), which is a product of matrix algebras over finite fields. Group the simple factors into classes \(C\) of equal data
\[
  (a_C,e_C,(m_{ik,C})_{i,k}).
\]
A factor in \(C\) is \(M_{a_C}(E_C)\) for \(E_C=\mathbf F_{3^{e_C}}\), and its isotypic part on \(Q_{ik}\) is \(E_C^{a_C}\otimes_{E_C}E_C^{m_{ik,C}}\). Let \(b_C\) be the number of factors in the class. Further polynomial-time invariant colors may refine the classes, for example radical-bimodule dimension refinements that all simultaneous conjugacies preserve. Choose ordered raw-frame splittings of the filtration and ordered block frames, coherently with a common explicit field model per class for the two endpoints. This is deterministic polynomial-time preprocessing over fixed characteristic by constructive finite-algebra decomposition and finite-field isomorphism algorithms. In particular the \(Q_{ik}\), constituent modules, center inclusions, \(E_C\)-coordinate tables, and endpoint basis change signs are computable. [Friedl and Rónyai](https://doi.org/10.1145/22145.22162) · [Rónyai, finite-algebra structure](https://www.sciencedirect.com/science/article/pii/S074771710880017X) · [Lenstra, finite-field isomorphisms](https://doi.org/10.1090/S0025-5718-1991-1052099-2).

Fix any list of desired binary determinant characters \(\ell=(\ell_1,\ell_2,\ell_3)\in\mathbf F_2^3\). All three coordinate characters give the raw determinant-one problem. If a known explicitly realizable source stabilizer subgroup has sign image \(D_0\), one can instead use a basis of \(D_0^\perp\) and test for trivial values there. Indeed a sign vector in \(D_0\) is correctable by composition with a source stabilizer. The central scalar kernel supplies one always available \(D_0\).

Put \(M_C(\ell)=\sum_{i,k}\ell_i m_{ik,C}\bmod2\). Call the inner factor relevant if \(M_C(\ell)=1\) for any listed character. Call the \((i,k)\)-multiplicity factor relevant if \(a_C\ell_i\equiv1\bmod2\) for some character and \(m_{ik,C}>0\).

**Theorem.** If \(a_C=O(\log L)\) for each relevant inner factor and \(m_{ik,C}=O(\log L)\) for each relevant multiplicity factor, and \(b_C=O(\log L)\) whenever the class has any relevant factor, the prescribed character test has one ordinary TI comparison. This gives a deterministic polynomial-time many-one reduction on the stated class. The \(e_C\) and all irrelevant ranks can be arbitrary. No bound is needed on radical length, total number of classes or collective products \(b_Ca_C\) and \(b_Cm_{ik,C}\) beyond the individual hypotheses. The hypotheses are recognizable given the covariant operator-algebra construction and the listed characters. If two endpoints fail the same format and constituent dimension checks, reject by a fixed ordinary NO.

**Exact character factorization.** On \(C\), a transporter induces a permutation \(\pi_C\) of simple factors. On a given factor its algebra action is conjugation by \(A_j\in\mathrm{GL}_{a_C}(E_C)\) after a field automorphism \(\sigma_j\). This follows from Skolem–Noether after identifying the transported centers. The same \(A_j,\sigma_j\) can be used on every module layer. Each transported \(Q_{ik,j}\) is then given by
\[
 (A_j\otimes_{E_C}B_{ik,j})\circ\sigma_j
\]
in the chosen frames, for some \(B_{ik,j}\in\mathrm{GL}_{m_{ik,C}}(E_C)\), with \(\sigma_j\) acting coordinatewise once. This follows by removing the common semilinear map and taking the centralizer of the standard \(M_a(E)\) action, which is the full multiplicity endomorphism ring. Define signs
\[
 \begin{aligned}
 p_C&=\operatorname{sgn}\pi_C,&f_C&=\prod_j\det_{\mathbf F_3}(\sigma_j:E_C\to E_C),\\
 u_C&=\prod_j N_{E_C/\mathbf F_3}(\det_{E_C}A_j),&
 w_{ik,C}&=\prod_j N_{E_C/\mathbf F_3}(\det_{E_C}B_{ik,j}).
 \end{aligned}
\]
Then
\[
 \prod_i(\det_{\rm raw}g_i)^{\ell_i}
 =\kappa_\ell\prod_C
 p_C^{e_C a_C M_C(\ell)}
 f_C^{a_C M_C(\ell)}
 u_C^{M_C(\ell)}
 \prod_{i,k} w_{ik,C}^{a_C\ell_i}.
\]
The known calibration \(\kappa_\ell\) is the product of the endpoint ordered basis changes to the raw frames. Each layer isometry contributes the determinant norm of its two \(E_C\)-linear factors and \(\det_{\mathbf F_3}(\sigma_j)^{a_Cm_{ik,C}}\). A class permutation on \(b_C\) blocks of \(\mathbf F_3\)-dimension \(e_Ca_Cm_{ik,C}\) contributes its sign raised to that dimension. Multiplying the layer determinants gives the formula. Replacing \(A_j\) by a scalar multiple and \(B_{ik,j}\) by the inverse-scaled matrices cancels exactly in the displayed product.

**Shared witness realization.** Include the original tensor and its three actual mode maps in the typed system. Add the multiplication tensor of \(R\), its three module action maps, and the quotient map to \(S\). Link the subspaces \(J^kV_i\), their inclusions, their quotients \(Q_{ik}\), and the \(S\)-actions on them. These are ordinary linear or bilinear typed relations. For each class include the semisimple factor sum and its inclusion into \(S\), and the center \(P_C=E_C^{b_C}\) linked to it. Add \(U_C=P_C^{a_C}\), with the standard module for \(M_{a_C}(P_C)\), and \(W_{ik,C}=P_C^{m_{ik,C}}\), with its \(P_C\)-action. Add the componentwise tensor product pairing
\[
 U_C\times W_{ik,C}\longrightarrow Q_{ik,C}
\]
and the inclusion \(Q_{ik,C}\hookrightarrow Q_{ik}\). The maps on these spaces express precisely the shared semilinear factorization above. All ordinary witnesses lift: choose one representative \(A_j\) per simple factor and then each \(B_{ik,j}\) by the centralizer argument. All extended witnesses restrict to an ordinary original witness, and the commutation relations tie their supplementary signs to its actual induced action. An equation on \(R\)'s action in the faithful product of the three endomorphism rings forces the map on \(R\) to be the simultaneous conjugation by the original witness. The links to the quotients then force the specific induced action.

**Small channels.** The pure permutation sign \(p_C\) is the determinant on \(P_C^0=\{x\in P_C:x^3=x\}\cong\mathbf F_3^{b_C}\). For odd \(e_C\) the Frobenius determinant \(f_C\) is always one. For even \(e_C\) it is the determinant on \(P_C^{(2)}=\{x:x^9=x\}\cong\mathbf F_9^{b_C}\), because a block permutation has even-dimensional blocks there. On each field factor the determinant of Frobenius on a normal basis is the sign of an \(e_C\)-cycle. Its \(k\)-th power acts on the quadratic subfield with determinant \((-1)^k\), giving the matching sign. These subspaces are determined by kernels of explicit linear Frobenius maps and are included by actual links.

For a relevant semilinear module \(P_C^d\) attach its exterior algebra over \(P_C\), explicitly represented in dimension \(b_Ce_C\,2^d\). Include the grade spaces, \(P_C\)-actions and wedge multiplication, and link degree one to the original module. These conditions uniquely force the semilinear exterior action. Identify its highest line with \(P_C\) in the chosen frames. The line map on factor \(j\) has form \(z\mapsto h_j\sigma_j(z)\) under the common permutation. Link \(e_C\) copies of that line by the explicit coordinatewise \(\mathbf F_3\)-linear Frobenius powers \(z\mapsto z^{3^r}\). Frobenius commutes with all factor field isomorphisms. Thus copy \(r\) has scalar \(h_j^{3^r}\). Multiply the copies in order using the componentwise multiplication of \(P_C\), with intermediate product lines. Each product map is surjective and uniquely forces the resulting action. The final line's factor scalars equal \(N_{E_C/\mathbf F_3}(h_j)\). Its \(\mathbf F_3^{b_C}\) coordinate subspace therefore has monomial action of determinant \(p_C\prod_jN(h_j)\). Its sign times \(p_C\) exports the appropriate \(u_C\) or \(w_{ik,C}\). There is no exterior algebra of dimension \(2^{e_Cd}\).

Take highest-volume lines of the small \(\mathbf F_3\)-spaces \(P_C^0,P_C^{(2)}\) and the norm-output subspaces that are actually used. Their base dimensions are at most \(2b_C\). Multiply the required \(\mathbf F_3\) signs in the factorization on shared lines by scalar multiplication chains, pinning the required right hand side after \(\kappa_\ell\). A scalar unit line is fixed by its own multiplication, and linking its unit to the final line fixes the required scalar. Classes with no relevant factor have all contributions equal to one and need no sign channel. All input widths and dense table sizes are polynomial under the stated bounds. The polynomial typed-system packing followed by the ordinary TI compiler finishes the many-one reduction. For example field multiplication as a bilinear tensor over \(\mathbf F_3\) has the centroid \(E\) acting on its three modes with rank one. The criterion permits arbitrary degree \([E: \mathbf F_3]\), although no mode need be small over the prime field.

## Why direct matrix-entry pinning does not supply the missing unrestricted search

Consider the zero tensor of shape \(2\times1\times1\). Its first-mode transporter projection is \(\mathrm{GL}_2(\mathbf F_3)\), of order 48. The matrices with top-left entry 1 have 18 elements. Choose the two off-diagonal entries freely and then choose the lower-right entry to make the determinant nonzero, leaving exactly two choices. As 18 does not divide 48, this first-entry restriction is not a coset of any subgroup of the first-mode group.

A nonempty ordinary transporter for a typed tensor system is a coset of its source stabilizer. Its projection to the map on a named mode is a coset as well, because that projection on stabilizers is a homomorphism. Thus no exact transporter-preserving system of this form can realize this individual matrix-entry prefix, already on the zero tensor. Whole-vector pins behave differently: they are honest point stabilizer cosets and are directly represented by unary tensors. The parallel search theorem uses only these legitimate pins plus one-hot logic in branches where uniqueness is proved. The example identifies a failure of exact entry-prefix simulation and leaves arbitrary decision-only maps outside its scope.

## Independent audit of the square-zero carrier

For a finite-dimensional commutative local \(\mathbf F_3\)-algebra \(A\) of even dimension and scalar residue, write \(N_A\) for the square-zero operator space on \(A^2\oplus A\) whose nonzero row is \([L_a,L_b]\) from the first two summands to the last. The common kernel and sum of images are both the last summand, by testing \([I,0]\) and \([0,I]\). Any ambient ordinary conjugacy therefore gives a quotient-domain map \(P\) and a bottom-space map \(Q\) with \(Q\mathcal M_A P^{-1}=\mathcal M_B\). The left idealizer of the row space is exactly \(L(A)\), as testing \([I,0]\) forces any such left operator to be a left multiplier. Hence \(Q\) induces an algebra isomorphism \(\phi:A\to B\) and \(Q=L_{Q(1)}\phi\), where \(Q(1)\) is a unit. After removing the two copies of \(\phi\) from \(P\) and the unit and \(\phi\) from \(Q\), testing the two coordinate rows forces each of the four blocks of the residual \(P^{-1}\) to be a left multiplier. Thus the residual quotient-domain freedom is \(\mathrm{GL}_2(A)\). Every such map has ternary determinant \((\det\bar P)^{\dim A}=+1\) by the filtration on \(A^2\) by powers of the local radical, whose two-copy graded matrix is \(\bar P\) on each residue multiplicity. The remaining unit multiplier has determinant \(\bar w^{\dim A}=+1\). The ambient shears have determinant one. It follows that the ambient determinant of the original conjugacy is \((\det\phi)^3=\det\phi\) in compatible raw frames. Conversely \(\phi^{\oplus3}\) gives an ambient lift. This reduction preserves both answers and the sign on every witness. It does not give an ordinary compiler for the resulting ambient sign constraint.

## Scope and verification

The closures proved here are complete for their stated classes. The key positive cases use one-hot data guaranteed by genuine pinning uniqueness, or intrinsic operator-algebra decompositions with logarithmic parity-relevant factors. The generic scalar operator algebra can leave an original large mode as an unresolved multiplicity factor, and a polynomial intrinsic spanning frame is not available from this argument on arbitrary tensors. All proofs are written mathematical arguments. No Lean verification was run.
