# What collapses in the upper determinant interval

Work over F3. Write A, B and S for one-sign TI, two-sign TI and SL-TI. This note concerns the ten upper candidates from the preceding interval packet. The reductions here are deterministic polynomial-time many-one unless described as a fixed conjunction of several calls. No unrestricted reduction from S to B is obtained.

For a raw comparison X, its attainable sign set D(X) is empty or a coset of its source stabilizer sign subgroup. The earlier exact compiler realizes any binary linear map on D(X) and any sum of a fixed number of such mapped profiles, including profiles of self-comparisons. It does so by sign projection, determinant-preserving scalar-centroid tags, and block sum. All constructions below using that compiler output actual raw tensors.

## 1. One two-sign instance whenever a surviving sign freedom is certified

Consider a comparison that asks for zero in
$$
P=\sum_i L_i D(X_i),
$$
where the terms may include source self-comparisons and the ambient sign space is $\Gamma=\mathbb F_2^3$. This includes S itself, the tilted-line and Fano balance comparisons, and cross-mode stabilizer correction.

Suppose there is a polynomially computable nonzero $h\in \Gamma$ with $P+h=P$. Then the comparison reduces to exactly one B instance. In fact choose a rank-two linear map $\pi:\Gamma\to\mathbb F_2^2$ with kernel $\langle h\rangle$. If $0\in\pi P$, one of $0,h$ belongs to $P$. These two possibilities are equivalent by invariance under adding $h$. The converse is immediate, and the empty set is preserved. Replace each term by its image under $\pi L_i$, use the signed sum compiler, and put the two quotient bits on the two tested axes. The untested axis can be set to zero by the same sign map.

A directly usable certificate is a source automorphism of one slot whose determinant vector has nonzero image under its $L_i$. Verify the automorphism and this image explicitly. Such a witness yields $P+h=P$ by ordinary coset translation even when some slot has no relative transporter. There are unconditional, recognizable raw-input branches. If a relevant source mode is nonconcise, take a reflection on its unused complement. If it has odd dimension, multiplying that mode and one other by minus identity gives a source automorphism, and its sign vector is computable from the parities. If the resulting sign survives any tested slot map, the one-instance reduction applies. Coordinate reflections on unused complements are independent. Scalar changes in two modes can be tried for the three possible pairs. More general verified stabilizer sign certificates work without modification.

For example, in every Fano balance condition each slot uses its first two determinant signs. If either tested mode of any source tensor is odd, put the compensating scalar in the untested third mode. The first-two-bit image is then nonzero and its embedded direction in that slot's plane is nonzero. Thus all eight Fano balance comparisons collapse to B on this input domain, even if every other tensor pair is unrestricted. The same holds for any deficient tested mode. This criterion does not assume that scalar and complement automorphisms find every stabilizer sign.

## 2. Cross-mode correction and full SL-TI have an exact three-probe relationship

The cross-mode correction candidate U2 takes a relative sign set $D=a+H$ and asks for zero in $D+QH$, where $Q=e_3e_1^*$ is the map $x\mapsto x_1e_3$. Empty relative sets are rejected. For nonempty D, its verdict is $a\in H+QH$.

Every nonzero rank-one map $R$ with $R^2=0$ is conjugate to Q. To see this, write $R=u f$ with a nonzero vector u and a nonzero functional f such that $f(u)=0$. Choose a basis with u third, a first vector on which f takes value one, and the remaining vector in its two-dimensional kernel. Conjugating by the basis map gives the displayed form of Q. Given such an R, apply the corresponding invertible sign transform to a raw tensor pair before asking U2. The transformed stabilizer sign subgroup is the direction of the transformed nonempty profile, so the resulting test is exactly $a\in H+RH$. An empty profile remains empty.

Fix any nonzero f, and take the three nonzero vectors u,v,u+v of $\ker f$. Use the three maps $uf,vf,(u+v)f$. Then for every H,
$$
H=(H+uf(H))\cap(H+vf(H))\cap(H+(u+v)f(H)).
$$
If $f(H)=0$ this is immediate. Otherwise membership outside H in all three would give $u,v,u+v$ the same nonzero class in $\Gamma/H$. Adding the first two gives the third, contradicting this common nonzero value. Consequently S reduces to the conjunction of three U2 instances. Each U2 itself reduces to S by the exact sign-sum compiler. Thus a single-instance conjunction theorem for U2 would make U2 equivalent to S.

Two fixed probes of this particular conjugation form cannot recover S. Given $R_i=u_if_i$ with $f_i(u_i)=0$, consider first $u_1=u_2=u$. Find a vector w with $f_1(w)=f_2(w)=1$, which exists because the two nonzero functionals are either equal or independent. Then $H=\langle w\rangle$ omits u, but $u\in H+R_iH$ for both i. If $u_1\ne u_2$, put $w=u_1+u_2$ and choose a plane H through w other than $\langle u_1,u_2\rangle$. It omits both $u_1,u_2$. If $f_i(w)=1$ then $f_i(H)\ne0$. If $f_i(w)=0$, then $\ker f_i=\langle u_1,u_2\rangle$, again giving $f_i(H)\ne0$. The vector $a=u_1$ is not in H, but it is congruent to $u_2$ modulo H and lies in both extended spaces. All these profiles are realizable by the earlier sign projector from the same zero tensor: choose the image of a projector to be H, then reflect target axes to translate by a. This exact limitation concerns fixed conjugate probes, not arbitrary reductions between U2 and S.

## 3. Exact ordering for uniform affine mixtures of independent sign profiles

This section treats a specific witness-preserving construction model. It explains which upper collapses can come from repeated copies and linear mixing alone. It does not assert a separation between many-one degrees.

Take independent affine nonempty input profiles $D_i=a_i+H_i$ contained in given nonzero subspaces $U_i\le \Gamma$ and suppose $\sum_i U_i=\Gamma$. The source rule tests $0\in\sum_i D_i$. This covers the tilted-line comparison and the Fano comparisons after their slot projections. A target sum rule has fixed coefficient subspaces $V_j\le \Gamma$. Each target profile is built by taking any finite sum of linear images of independent copies of the original $D_i$, independent copies of their stabilizer spaces $H_i$, and fixed affine constants or slack subspaces. Each term in a target slot has image in that slot's $V_j$. All those choices are fixed before seeing the affine profiles. The exact output verdict again tests zero in the total sum. For the necessity proof we allow arbitrary nonempty affine input profiles in their prescribed source subspaces.

**Classification.** An exact construction in this model exists if and only if there is one $G\in\mathrm{GL}_3(\mathbb F_2)$ that sends each $U_i$ into some $V_j$.

For necessity, first take every $H_i=0$. The source computes the zero fiber of the surjective addition map $F\colon\bigoplus_i U_i\to\Gamma$. The target has a fixed offset and a fixed slack space W after totaling the slots. The zero input must accept, so the offset belongs to W and can be removed. The target singleton rule is then the zero fiber of a linear map into $\Gamma/W$. Since its kernel is exactly $\ker F$ and has codimension three, W must be zero and the target total effect is $GF$ for an invertible G. Denote the per-copy maps on source i by $M_{ji\ell}$, where the index $\ell$ enumerates copies and distinguishes relative and stabilizer copies.

Now take $H_i=\langle v\rangle$ for a nonzero $v\in U_i$, with all other $H_k=0$. The target offset is $G\sum_k a_k$. The target direction is generated by the $M_{ji\ell}v$. Since $\sum_k a_k$ ranges over all of $\Gamma$, exactness forces this direction to be exactly $\langle Gv\rangle$. In particular every $G^{-1}M_{ji\ell}$ sends every v to either 0 or v. A linear map with that rule on a vector space over $\mathbb F_2$ is identically zero or the identity into that space. If two nonzero vectors were treated differently, linearity would send their sum to just one of them, which is neither zero nor their sum. Thus each nonzero copy map on $U_i$ is G restricted to $U_i$. At least one relative copy is nonzero for each i, since their sum is $G|_{U_i}$. Its image is contained in one target slot, proving necessity.

For sufficiency, assign each source slot to a target slot containing its image. Compose each source profile with the prescribed restriction of G and sum the resulting terms assigned to each slot. Empty target sums can be filled with a fixed sign-zero pair. The output accepts if and only if the original sum contains zero. The raw realization uses the existing compiler and a fixed format tag per contributing comparison. This is a many-one construction of the advertised kind with polynomial output.

For the Fano candidates all slot subspaces are planes. The criterion consequently becomes exactly inclusion of plane arrangements up to a common invertible linear change of the ambient signs. Repeated affine mixing does not remove one plane or change a dependent triple of normals into an independent one. In particular the two-plane balance cannot compile to the tilted-line balance in this model, because one of its distinct planes would have to fit in a line. The tilted-line balance cannot compile to the independent conjunction of one B and one A in this model either. Its plane must be sent to the target plane, while its two distinct transverse lines would both have to be sent to the one target line. The known forward reductions in each case do use the model. Hence these two comparisons are strict within the model even though unrestricted Karp equivalence remains undecided.

The same necessity proof applies if the source has one unrestricted three-dimensional sign slot. No target built entirely from plane or line slots can then preserve all affine profiles by this kind of mixing. The model does not allow choices based on additional raw tensor invariants, disjunctions of different mixes, or correlated witness searches. The results therefore do not settle the unrestricted upper collapse.

## 4. Six one-sign probes suffice for the tilted-line and two-plane comparisons

Consider the aggregate profile $P=\sum_iD_i$ before the test for zero. For nonempty inputs its direction is $H=\sum_iH_i$, with $H_i$ arbitrary in $U_i$. The tilted-line and two-plane comparisons have exactly six attainable direction planes in $\Gamma$.

For two distinct plane slots $U,V$, write $L=U\cap V$. Both U and V are attainable as directions. A different plane W is attainable if its intersections with U and V are distinct lines: these then span W and may be selected as the two slot directions. If the intersections coincide, the common line is L and no choices of directions in the two slots can sum to W. There are exactly three planes through L, so the third such plane is the unique unattainable direction plane.

For tilted-line balance the slot spaces are a plane U and two lines $X,Y$ outside it. Their span is a second plane V, with $U\cap V$ the line generated by the sum of the nonzero vectors of X and Y. The attainable planes are U, V, and the joins of X or Y with any line in U other than $U\cap V$. These last four are distinct: two joins with the same transverse line and different lines in U cannot coincide, and an equality between joins involving both X and Y would force their common plane to be V. Thus there are again six attainable direction planes, with no other possibilities by the possible dimensions of the slot directions.

Test the six linear functionals whose kernels are these six planes, each in a separate one-sign query. Compute each scalar sign image of P by the exact sum compiler; zero in that image is a single A test. If the aggregate P is empty all six tests reject. Otherwise write $P=a+H$. For $H=0$, the six tested normals span the whole dual, so all tests passing forces $a=0$. For H a line, exactly three planes contain H and at most one is missing, so at least two distinct tested normals span its two-dimensional annihilator. For H a plane, its sole nonzero annihilator is a tested normal by attainment. For $H=\Gamma$, zero already belongs to P. In every case all six tests pass exactly when $a\in H$. This gives the unrestricted many-one reductions from U1 and U3 to six independently encoded A queries whose answers must all be yes.

In contrast, with at least three distinct plane slots every direction plane W is attainable. If it is one of the slot planes this is immediate. Otherwise each intersection with a slot is a line. If all were the same line, there would be at least four distinct planes through that line, counting W. There are only three. Choose two distinct intersection lines to realize W. Seven A probes always suffice by testing every nonzero normal.

These six and seven counts are sharp for an algorithm accessing only the hidden aggregate P through one-sign affine probes. Even within a probe it may independently copy P and its direction H, and use any finite disjunction of one-bit affine equations in those copies. The all-full aggregate $P=\Gamma$ is attainable by starting with all slots full and gives a positive instance. For every attainable direction plane $\ker f$, the opposite affine hyperplane $f^{-1}(1)$ is attainable as an aggregate: after choosing realizable slot directions for $\ker f$, choose the total offset outside it. Any offset is available because the slot spaces span $\Gamma$. A probe that fails on the full input also fails on every one of these restricted inputs. For a probe that accepts the full input choose an accepting affine branch. To reject $f^{-1}(1)$, every nonzero linear functional on a witness copy in that branch must vanish on $\ker f$, since a copy on which it is nonconstant can supply either output bit. At least one copy coefficient is nonzero, because an accepting constant accepts all profiles. Thus the chosen branch can reject at most one opposite hyperplane, determined by its nonzero coefficient f. An accepting full-input path must distinguish all six or seven opposite hyperplanes, giving the claimed bound even with adaptive probes. This is a query lower bound for the hidden aggregate. It does not rule out arbitrary raw-input reductions, nor queries using the individual component profiles separately.
