# Sharp deterministic query bounds for determinant sign profiles

Work over $\mathbb F_3$, so a transporter determinant is one sign bit in each mode. An ordinary transporter set, when nonempty, has sign profile $D=a+H\subseteq V=\mathbb F_2^3$, where $H$ is the sign image of the stabilizer of the source. Writing all three signs as zero is exactly the test $0\in D$. For two tested coordinates, project $D$ onto $\mathbb F_2^2$ before testing zero. This note analyzes a stated information model rather than the raw tensor decision languages.

## Allowed probes

A probe may choose arbitrarily many independent copies of $D$ and $H$. Within one branch it forms an arbitrary linear combination of these sign variables and asks if the result equals a prescribed vector in an output space of dimension at most $r$. A probe may return the OR of any finite list of these branches. It may also use fixed auxiliary affine sign spaces. Their contributions are removed by translating the prescribed vector and passing to the quotient by the sum of their images, so they do not increase $r$. Constant no branches are allowed. A deterministic algorithm can choose a probe from all its preceding answers and perform arbitrary postprocessing of the transcript.

The coefficients and branches carry no other information about the hidden profiles. In particular the model permits arbitrarily large and arbitrarily many hypothetical constructions using sign projections, independent block copies, basis rebasings, and independently chosen stabilizers. It does not model structural analysis of the actual raw tensor coordinates or restrictions on witnesses other than the displayed linear sign equation.

## The lower bound

More generally, let $V=\mathbb F_2^n$, and let the hidden profile $D$ range over the nonempty affine subspaces. For $r\ge 1$, any deterministic exact algorithm in this model needs at least
$$
\left\lceil \frac{2^n-1}{2^r-1}\right\rceil
$$
probes in the worst case, where the numerator counts the nonzero members of $V^*$. For $r=0$ no number of these probes suffices.

Follow the transcript on the yes-profile $D=V$, for which $H=V$. For each nonzero $\ell\in V^*$ consider a no-profile $D_\ell=\{x\mid\ell(x)=1\}$ with stabilizer sign space $H_\ell=\ker\ell$. A probe that rejects $V$ also rejects every $D_\ell$, since every branch on $D_\ell,H_\ell$ restricts the allowed tuples on $V,V$. For a probe that accepts $V$, choose one accepting branch. It suffices to bound the number of $D_\ell$ for which this branch fails, since rejecting the whole probe requires every branch to fail.

Write the accepting branch as $\sum_j L_j z_j=b$, with each coordinate $z_j$ allowed to run through its assigned $D$ or $H$. Let $c_j=1$ for a relative-transporter copy and $c_j=0$ for a stabilizer copy. The branch rejects $D_\ell$ precisely when the linear equations
$$
\sum_j L_j z_j=b,\qquad \ell(z_j)=c_j \text{ for every }j
$$
are inconsistent. A linear combination certifying that inconsistency gives a functional $\lambda$ on the output space and coefficients $\epsilon_j\in\mathbb F_2$ with
$$
\lambda L_j=\epsilon_j\ell\ \text{ for every }j,\qquad
\lambda(b)+\sum_j\epsilon_j c_j=1.
$$
Some $\epsilon_j$ must be nonzero. Otherwise $\lambda$ annihilates the image of the full branch map, contradicting acceptance on $V$ and $\lambda(b)=1$. Accordingly $\lambda\ne0$, and for any fixed $\lambda$ a nonzero component $\lambda L_j$ identifies the unique possible $\ell$. At most $2^r-1$ nonzero $\lambda$ exist. This proves the per-probe bound.

An exact algorithm eventually outputs yes on $V$. Every $D_\ell$ whose answer does not differ at any probe on this transcript follows the same adaptive branches and receives the same output. Hence all $2^n-1$ of them must be distinguished by probes along this one transcript. This establishes the bound. For $r=0$ no accepting branch can distinguish any $D_\ell$ from $V$.

The same proof applies when the desired signs form a quotient $P:V\to \mathbb F_2^m$ of rank $m$, and the goal is $0\in P D$. Take just the negative profiles with nonzero $\ell$ pulled back from the quotient. There are $2^m-1$ of them, so the numerator improves to this value even if every probe can use the unprojected sign vectors.

## Tight bounds for the three determinant gaps

* For full SL-TI tested using rank-two probes, the lower bound is three. Three nonadaptive probes attain it. Choose independent $u,v\in\mathbb F_2^3$, and ask if $D$ meets each of the three lines generated by $u,v,u+v$. Every line contains zero. If all three probes answer yes for a profile omitting zero, then it contains $u,v,u+v$. A nonempty affine subspace over $\mathbb F_2$ contains the sum of any three of its members. The displayed sum is zero, a contradiction.
* For full SL-TI tested using rank-one probes, the lower bound is seven. Seven nonadaptive probes attain it by querying all hyperplanes through zero. An affine subspace omitting zero has a separating linear functional that vanishes on its direction and equals one on the subspace, so misses one of these hyperplanes.
* For two-sign TI tested using rank-one probes the lower bound is three, using the quotient argument. The three lines through zero in $\mathbb F_2^2$ attain it by the same affine-sum argument. For a one-sign input tested using rank-zero probes, the zero-information lower bound applies.

The upper bounds also reject an empty transporter profile. The lower bounds already hold with the promise of a nonempty profile. The earlier determinant-subgroup constructions realize $V$ and each displaced hyperplane as actual $\mathbb F_3$ tensor profiles. They start with a tensor of trivial stabilizer sign image, add tagged blocks generating the chosen subspace, and rebase one target mode for each nonzero coordinate of the desired shift. This supports applying the abstract lower bound to constructions whose sole access to the original tensor comparison is through the stated profile operations.

## Independent conjunctions

The counting argument also applies to several independently hidden profiles $D_i\subseteq V_i$. Allow a branch to mix independent transporter and stabilizer copies of all of them in one rank-$r$ linear equation. Follow the transcript where every $D_i=V_i$. For each index $i$ and nonzero $\ell\in V_i^*$, consider the input with just $D_i$ replaced by $\{\ell=1\}$. For a branch accepting the baseline, an inconsistency certificate for this single substitution has $\lambda L_j=0$ on every segment drawn from all the other profiles. It has some nonzero component on a segment drawn from $i$, and all nonzero components there equal $\ell$. Thus each nonzero $\lambda$ can certify failure for at most one choice of $(i,\ell)$. Every probe excludes at most $2^r-1$ single substitutions on the all-full transcript, even when it is the OR of many branches. The required number of probes is at least
$$
\left\lceil \frac{\sum_i(2^{\dim V_i}-1)}{2^r-1}\right\rceil
$$
for $r\ge 1$ when all zero-membership tests are required.

In particular, two independent two-sign profiles cannot be joined by one two-sign probe of this kind. The bound is two, attained by querying each original profile separately. An independent two-sign and one-sign profile also cannot be joined by a single rank-two probe. Two independent one-sign profiles need two rank-one probes. These are lower bounds for the stated operations, with no restriction on computational time, branch count, the number of replicated blocks, or adaptive postprocessing in this model.

## With only sign-rigid inputs

The obstruction to a single **positive** probe persists when every comparison is promised to have trivial stabilizer sign image. In this case $H=0$, each $D=\{d\}$ is a singleton, and every branch of a rank-$r$ probe is simply an affine system $M d=b$ with rank at most $r$. If it accepts the required vector $d=0$, at least one branch contains zero. That branch contains its entire kernel, which has a nonzero vector if $r<n$. Thus a positive single-probe construction fails even on the sign-rigid promise. For independent singleton profiles the same proof takes $d$ to be the concatenated vector. For a projected predicate of rank $m>r$, a branch containing zero has kernel too large to be contained in the desired kernel.

Here a positive probe means that the output decision is the probe's yes/no answer, as in a single many-one query. Arbitrary negation on the singleton promise has different power. For example over $\mathbb F_2^3$, every nonzero vector lies on an affine line missing zero. The OR of probes for all such lines gives exactly the complement of the rank-three sign condition when $D$ is a singleton. The earlier adaptive lower bounds used profiles of multiple dimensions and already allow negation and other postprocessing.
## Ambient representations give sign-profile probes

There is a direct criterion for this lower bound to apply to witness representations. Suppose a branch uses independently chosen unrestricted source transporters or stabilizers, and its target mode maps, up to fixed left or right translations, are given by group homomorphisms on the product of the ambient general linear groups of those copies. If the branch's ordinary isomorphism behavior is exhausted by those choices and additional independent fixed slack, each target determinant factors through the source sign bits.

Indeed, every homomorphism from $\mathrm{GL}_d(\mathbb F_3)$ to $\mathbb F_2$ is a function of the determinant. For $d\ge2$, take a diagonal matrix $J$ that negates coordinate $i$ and fixes coordinate $j$. Its commutator with $I+aE_{ij}$ is $I-2aE_{ij}=I+aE_{ij}$. Thus the homomorphism kills every elementary transvection. These generate the special linear group by elimination. The claims for $d=0,1$ are immediate. A character on a product is a sum of its restrictions to the factors. Hence the pullback of each target mode determinant is an affine linear equation in the source sign vectors after translations are included, exactly as in the model above.

The hypothesis concerns the entire ambient general linear groups and independent witness choices. An additional character defined only on a tensor stabilizer subgroup need not be the restriction of an ambient determinant character. An ordinary target isomorphism condition that cuts down witness choices or mixes copies by a further relation may also fall outside the model.
## Scope relative to TI

The earlier exact sign construction gives equality of the upper two many-one degrees if and only if actual two-sign TI is closed under binary conjunction. The lower bound above excludes the specified sign-profile method of proving that closure. A polynomial-time many-one map on tensor coordinates can build a target pair whose ordinary isomorphism condition itself depends on how the determinant information is encoded in the input. Treating that new ordinary isomorphism condition as one of the displayed probes would require a separate theorem. No unrestricted separation is proved here.

For background on the distinction between reductions on isomorphism objects and on comparison pairs, see [Fortnow and Grochow, *Complexity Classes of Equivalence Problems Revisited*](https://arxiv.org/abs/0907.4775). For the tensor setting, see [Chen, Grochow, Qiao, Tang and Zhang, *Actions by classical groups*](https://arxiv.org/html/2306.03135v2). An earlier workspace note establishes an indistinguishability result for separately GL-covariant ordinary queries. The current bound adds arbitrary affine sign constraints, independent stabilizers, arbitrarily many replicated copies, and adaptive signed queries. Publication priority has not been established.
