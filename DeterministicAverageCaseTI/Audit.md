# Earlier average-case algorithms with deterministic replacements

Three further transfers are direct consequences of the existing proofs and standard deterministic algorithms. The random source in each density theorem is still sampled in the theorem statement. The decision and witness algorithms themselves use no random bits.

## 1. The one-eigenline hull algorithms for algebra and matrix code isomorphism

**Corollary.** The recognition, decision and witness algorithms in Li–Li–Qiao–Tao–Wang v2, §§3.1 and 3.2, can be run deterministically in \(\operatorname{poly}(n,\log q)\) bit time. They retain the paper's fixed-\(q\) asymptotic \(\Theta(1/q)\) first-input coverage and its guarantee against an arbitrary second input. No finite-field factoring premise is needed.

The hull generator in both algorithms is accepted when it has exactly one eigenvalue in the base field, which is nonzero and simple. For its characteristic polynomial \(f\), compute
\[
g=\gcd(f,X^q-X)
\]
by modular binary powering. It lists precisely the distinct rational roots, each with multiplicity one. Check \(\deg g=1\), extract its root \(\alpha\) from the coefficients, and check \(\alpha\ne0\) and \(f'(\alpha)\ne0\). This exactly preserves the required spectral test in every characteristic. After scaling the matrix so its eigenvalue is one, a left eigenvector is obtained by linear equations. For the code algorithm's projector, choose a left and a right eigenvector and use their normalized outer product. Their pairing is nonzero because a simple eigenvalue has complementary generalized eigenspaces.

In the residual comparison solve the simultaneous linear intertwiner equations for the two matrices specified in the original proof. The source commuting algebra is tested to be one-dimensional. If an invertible solution exists, every solution is a scalar multiple of it. Hence reject when the solution dimension differs from one or the basis element is singular. Otherwise use that element in the final scalar calibration for algebra isomorphism or the final span comparison for code conjugacy. Both tests and the resulting witnesses are exactly those of the original correctness proofs. The other steps were already linear algebra. Only the algorithm was changed, so the fixed-\(q\) coverage estimates apply exactly as before. [Li–Li–Qiao–Tao–Wang, §§3.1–3.2](https://arxiv.org/html/2604.00591v2#S3)

## 2. The unitary three-tensor classifier

**Corollary.** On the previously recognized unitary three-tensor class over \(K=\mathbb F_{q^2}\), ordinary unitary witness search is deterministic polynomial time, including in characteristic two. Its earlier density estimate \(1-O((\log n)^2/n)\) is unchanged. The conclusion uses that density theorem as an input.

The earlier covariant comparison uses matrix-unit recovery and linear algebra to get the first and third intertwiners up to scalars. If \(P_0\) is an invertible candidate intertwining the Hermitian covariants, then \(P_0^*P_0=\delta I\), since it commutes with the whole generated matrix algebra and is nonsingular. The scalar \(\delta\) is fixed by conjugation. Replace the random rescaling step by van de Woestijne's deterministic norm equation algorithm in \(K/\mathbb F_q\), to obtain \(a\) with \(N(a)=\delta^{-1}\). Then \(aP_0\) is unitary. Do so in both outer modes. The remaining map is recovered by the full-row-rank equality of two Gram matrices as in the earlier proof, using a right inverse obtained by linear algebra. This changes no recognition or comparison equation. The same norm lemma treats the earlier quadratic Hermitian norm corrections in this form of the algorithm. [Earlier Problem 18 proof index](https://github.com/Dugongue/MathProofs/tree/main/Problem18) · [Van de Woestijne, §7.3, Theorem 7.1 and Proposition 7.4](https://math.leidenuniv.nl/scripties/Woestijne.pdf)

For the determinant-one variant on the same class, the old central stabilizer computation gives \((xI,yI,zI)\) with \(N(x)=N(y)=N(z)=1\) and \(xyz=1\). An arbitrary prescribed determinant triple in the norm-one group is feasible precisely when the three required corrections multiply to one and each is an \(n\)-th power in the group of order \(q+1\). There are \(g^2\) witnesses when feasible, for \(g=\gcd(n,q+1)\). Test powers directly and, under the factoring premise, factor the two degree-\(n\) binomials over \(K\), keeping norm-one roots. The final correction is the inverse product. Thus the ordinary unitary witness is unconditional, and the additional prescribed-determinant witnesses are deterministically quasipolynomial under the premise.

## 3. The corank-three branch of ordinary four-tensor isomorphism

**Corollary.** The corank-three kernel-code proof of Li–Li–Qiao–Tao–Wang v2 gives deterministic \(q^{O(1)}\operatorname{poly}(n,\log q)\) decision, witness search, and exact ordinary transporter counts on a recognizable class of uniform density at least \(q^{-9}/1024\) for fixed \(q\) and all sufficiently large \(n\). Prescribed determinant counts in the same time follow. Under the factoring premise, prescribing the determinants also yields a witness in \(q^{O(1)}n^{O(\log n)}\operatorname{poly}(\log q)\) bit time.

In a three-dimensional kernel code \(C\), find an invertible element \(A_1\) by enumeration and complete it to \(A_1,A_2,A_3\). Require that the commutant of \(A_1^{-1}A_2,A_1^{-1}A_3\) be one-dimensional, by linear algebra. This is intrinsic to \(C\) under two-sided equivalence. Indeed the commutant algebra in question is identified with all pairs of endomorphisms \(X,Y\) satisfying \(X A_i=A_iY\) for every basis element, since \(X=A_1 Y A_1^{-1}\). Its dimension therefore does not depend on the selected basis or its invertible element. Do the test on both kernel codes of the balanced flattening. The source event used to prove the old bound already gives invertibility and scalar commutants, by full algebra generation of the displayed pair. Each code independently meets the event with conditional probability at least \(1/8\) at corank three for sufficiently large \(n\). Corank three has probability at least \(q^{-9}/16\). So this deterministic test has the claimed coverage. [Li–Li–Qiao–Tao–Wang, §4, Proposition 4.2 and generation argument](https://arxiv.org/html/2604.00591v2#S4)

For each of the two codes independently, enumerate the at most \(q^9\) ordered bases \(B_1,B_2,B_3\) of its target. For a branch with \(B_1\) invertible, solve the two linear similarity equations of the normalized matrices, as in the original proof. Each branch has either no invertible solution or a line of scalar multiples of one. In the latter case compute one representative of the two-sided transporter. Its only ambiguity in that branch is reciprocal nonzero scalars on its two tensor mode maps. Combine representatives for the two kernel codes and check the original tensor equation. Scaling reciprocally on either pair cancels in that equation. Every witness induces a unique pair of target ordered kernel bases, so successful branches are disjoint. Each contributes \((q-1)^2\) ordinary witnesses, and one suffices for construction. This avoids enumerating the scalar ambiguity.

For each successful branch, a prescribed determinant correction on a pair of sides requires two inverse values, each an \(n\)-th power in \(k^\times\). The inverse condition and the power test \(a^{(q-1)/\gcd(n,q-1)}=1\) suffice. A feasible branch contributes \(\gcd(n,q-1)^2\) witnesses for the two pairs together, and factoring degree-\(n\) binomials gives a constructive correction when wanted. The algorithm still has explicit \(q^{O(1)}\) basis enumeration. The same argument at corank \(c\) applies whenever each kernel code has an invertible element and scalar pointwise intertwiner algebra, with \(q^{O(c^2)}\) enumeration. The density analysis quoted above concerns \(c=3\).

## 4. What these transfers leave open

The exact substitutions above remove random arithmetic and linear-algebra choices. The old density theorems still govern which sources receive the fast guarantee. For example, the fixed-\(q\) corank-three density does not imply near-full coverage at fixed \(q\), and changing the factoring oracle does not make a growing-field enumeration of all kernel bases run in polylogarithmic field size.

Likewise the open balanced dense ordinary three-tensor, cubic-form and alternating-form average-case targets require their own structural recognizers. A bounded-mode theorem applies when the tensor actually has a fixed small mode. The generic even-order spectral proof concerns a balanced invertible cut, while the corank-three proof concerns a different rank condition. Neither changes the format in the open three-tensor question. [Li–Li–Qiao–Tao–Wang, v2 §1.5](https://arxiv.org/html/2604.00591v2#S1.SS5)
