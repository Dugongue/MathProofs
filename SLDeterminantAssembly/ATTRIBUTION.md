# Attribution and exact controls

MathProofs, AI-assisted informal mathematics. PROOF.md cites the primary
sources and credits existing methods. STATUS.json gives the exact scope.
No external library or Lean source code is copied into this package.
Internal independent reviews found no gap in the stated scope; this does
not establish external peer review, Lean verification or publication priority.

Run controls.py and matching_controls.py from this directory with Python 3.10 or newer. These standard
library controls rewrite their JSON receipts. They corroborate selected
finite identities; the written arguments establish the universal results.
