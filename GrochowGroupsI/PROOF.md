# Logspace membership in quasigroups affine over groups

Given a raw multiplication table of a finite quasigroup, one can recognize in deterministic logspace whether it is affine over a group. This means that in some group law its product has the form \(x*y=f(x)g(y)c\) for automorphisms \(f,g\) and a fixed \(c\). On this class the subquasigroup membership problem is in deterministic logspace, with a polynomial-length witness stream on acceptance. The result allows nonabelian group laws and quasigroups with no identity. In particular it applies to medial quasigroups by the classical affine representation theorem. This combines reconstruction from an isotope with the Reingold-based search in the earlier group and loop membership proofs.

For a nonempty generating set choose \(a\) from it. Let \(R_a(x)=x*a\) and \(L_a(x)=a*x\), and define
\[
x\cdot y=R_a^{-1}(x)*L_a^{-1}(y),\qquad e=a*a .
\]
The identity of this isotope is \(e\) on either side by substitution. Check its associativity by a table scan. Define \(u=R_a(e)\) and \(v=L_a(e)\) and test whether
\[
\phi(x)=R_a(x)\cdot u^{-1},\qquad \gamma(x)=L_a(x)\cdot v^{-1}
\]
are automorphisms of the group just obtained. These operations and tests use only a constant number of table indices. For recognition alone an arbitrary \(a\) may be chosen.

The test is exact. If the original operation is \(f(x)g(y)c\) over a group, set \(b=g(a)c\) and \(u_0=f(a)\) in the original group coordinates. Then the isotope is \(x\cdot y=x b^{-1}u_0^{-1}y\), and \(x\mapsto xe^{-1}\), with \(e=u_0 b\), gives the group isomorphism to the old group law. Under this coordinate map the two normalized translations above become \(f\) and the conjugate of \(g\) by \(u_0\). Conversely, if the tests pass, the identity \(x*y=R_a(x)\cdot L_a(y)\) expresses the original operation as
\[
\phi(x)\cdot (u\gamma(y)u^{-1})\cdot uv,
\]
which is an affine law.

The subquasigroup generated by a nonempty set contains \(e,u,v\), since \(a\) belongs to that set. A finite nonempty product-closed subset of a quasigroup is closed under both divisions, because restricted translations are injective and hence onto. Thus the subquasigroup is also closed under the isotope product and its inverses, and under \(\phi,\gamma\) and their inverses. Conversely any isotope subgroup containing the input set and \(u,v\), invariant under these automorphisms, is closed under the original product by the affine formula. Hence the sought set is exactly the subgroup generated by all automorphism iterates of the input generators together with \(u,v\).

Compute it by connectivity from \(e\) in the undirected graph whose moves are right multiplication by each input generator, \(u,v\), and application of \(\phi\) or \(\gamma\). Its adjacency is computable in deterministic logspace. The component of \(e\) lies inside the described invariant subgroup. Conversely the moves include any right multiplication by an automorphism iterate by conjugating the original right move by its automorphism word, so the component contains the whole subgroup. Reingold's algorithm gives membership. To stream a path, order graph edges and select the canonical forest by checking whether the endpoints of each edge are disconnected using earlier edges. From a currently connected vertex, test each incident forest edge by deleting it to find the edge in the direction of the target. Every test is still in logspace. Each path move can be written by a fixed bounded-length program in quasigroup multiplication and division with the known constants, since the isotope and both normalized translations have those expressions. This gives a witness of polynomial length. Under the convention that the empty set generates the empty subquasigroup, it is handled directly.

This gives an affirmative class of Collins–Grochow–Levet–Weiß Question 8.2, whose unrestricted case allows arbitrary quasigroups. This proof is informal. [Published question](https://arxiv.org/html/2402.00133#S8)
