# OEIS A005329 proof note

Informal argument accompanying the submitted formal work. [Sequence statement](https://oeis.org/A005329).

Proof: with cp(n) = sum C(n,k) a(k) and bp(n) = sum C(n,k) 2^k a(k): Pascal plus a(k+1) = (2^(k+1)-1) a(k) gives cp(n+1) = 2 bp(n); the identity sum_k C(m,k) C(k,j) x^(m-k) = C(m,j) (x+1)^(m-j) gives sum_k C(m,k) bp(k) = 2^m cp(m), so bp satisfies the A075271 recurrence (b = bp, c = cp), and the x = -1 case is binomial inversion.
