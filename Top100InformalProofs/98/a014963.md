# OEIS A014963 and the von Mangoldt function

Argument accompanying the submitted formal work. [Sequence statement](https://oeis.org/A014963).

Proof of the conjecture (true): the array A191898 has the closed form T(n,k) = sum over d | gcd(n,k) of mu(d)*d. This form satisfies the defining recurrence because its sum over any k consecutive values of n equals k * sum_{d|k} mu(d) = 0 for k >= 2 (strong induction on n+k). Then sum_{k<=K} T(n,k)/k = sum_{d|n} mu(d) H(floor(K/d)), and H(floor(K/d)) - log K -> gamma - log d (Mathlib's tendsto_harmonic_sub_log). Since sum_{d|n} mu(d) = 0 for n > 1, the limit is -sum_{d|n} mu(d) log d = Lambda(n) (ArithmeticFunction.sum_moebius_mul_log_eq).
