# OEIS A064098 proof note

Informal argument accompanying the submitted formal work. [Sequence statement](https://oeis.org/A064098).

Proof: consecutive terms are Markov triples (x^2+y^2+z^2 = 3xyz), so a(n+4) = 3 a(n+3) a(n+2) - a(n+1) exactly and the nat division is exact. Hence x(n) = log a(n) satisfies x(n+3)+x(n+2) <= x(n+4) <= x(n+3)+x(n+2)+log 3, giving (log 2/phi) phi^k <= x(k+4) <= 2 log 3 phi^(k+2); squeeze.
