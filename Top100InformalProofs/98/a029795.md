# OEIS A029795 proof note

Informal argument accompanying the submitted formal work. [Sequence statement](https://oeis.org/A029795).

Disproof: every 10^(j+1) is in P (digit sets {0,1} for k and k^3), so P is infinite and Nat.nth P enumerates P; if a(n) = m + n for all n >= N then every integer >= m + N would lie in P, but k = 2*10^j is never in P (k has digit 2, k^3 = 8*10^(3j) has digits {0,8}). So the statement as formalised (and the OEIS conjecture a(n) = n + const eventually) is false.
