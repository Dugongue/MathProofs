# OEIS A052542 proof note

Informal argument accompanying the submitted formal work. [Sequence statement](https://oeis.org/A052542).

Proof: compositions of n are mapped by blocks onto T n, the lists of positive integers summing to n (built recursively by first part); splitting by the first part p+1 gives F(n+1) = sum_{p<=n, p+1 odd} 2 F(n-p), whence F(n+3) = 2F(n+2) + F(n+1), F(1) = 2, F(2) = 4.
