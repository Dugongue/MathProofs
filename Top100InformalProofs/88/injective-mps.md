# Algorithms for the phase data of injective matrix-product states

The proof uses the stated exact tensor data and finite symmetry group input.

## 2. Theorems

### Thm A (1D injective MPS, finite G): FP, no promise. [P] 90%

**Input.**
- G finite, given by its multiplication table.
- A unitary rep u: G → U(d) with entries in Q(ζ_m).
- A TI MPS tensor A ∈ K^{d×D×D}, K a number field given by its minimal polynomial (Q(i) suffices for applications).

**Output, in deterministic polynomial time** (bit model, exact arithmetic):
1. Whether A is normal/injective.
2. Whether the state is G-symmetric, together with the character λ: G → μ_e.
3. A normal form of the class [ω_A] ∈ H²(G,U(1)).
4. For two inputs, whether they are in the same SPT phase.

**Proof.**
1. Normality: rank of span{A^{i_1}⋯A^{i_L}} for L up to the quantum-Wielandt bound, which is poly in D. Rank computations over K are P.
2. Symmetry: by PGWSVC, symmetric ⟺ ∃(λ_g, V_g) with Σ_j u_ij A^j V_g = λ_g V_g A^i, V_g invertible. Since g ↦ λ_g is a character, λ_g ∈ μ_{ord g}. For each g and each of the ≤ |G| candidates λ, solve a linear system in D² unknowns with dD² equations over K(ζ_e). Injectivity gives a solution space of dimension ≤ 1, and a nonzero solution is invertible. Total cost poly(|G|, d, D, bitsize).
3. Cocycle: ω(g,h) = V_gV_hV_{gh}^{-1}, a scalar read off from one entry.
4. Reduction to finite coefficients: ω^D = δ(det V). Approximate r(g) = (det V_g)^{1/D} to poly(n) bits, which is poly-time root approximation of an algebraic number. Then ε(g,h) = ω(g,h) r(gh)/(r(g)r(h)) lies exactly in μ_D. It is recovered exactly by rounding, since distinct D-th roots of unity are ≥ 2 sin(π/D) apart, and [ε] = [ω].
5. Triviality (Bockstein): write ε = exp(2πi a/D) with a: G² → Z. Then [ε] = 0 in H²(G,U(1)) ⟺ δa/D ∈ B³(G,Z), because the Bockstein H²(G,U(1)) → H³(G,Z) is an isomorphism for finite G (H^{>0}(G,R) = 0). This is an integer linear system of size |G|³ × |G|². It is solvable in poly time via Hermite/Smith normal form (Kannan–Bachem). For a normal form, reduce the class in H³(G,Z) using the SNF of the bar coboundaries.
6. Same phase: test [ε_1 ε_2^{-1}] = 0.
∎

The C++ check (exact algorithm, double precision) gives the predicted classes on AKLT with Z2×Z2:
- AKLT: nontrivial;
- AKLT ⊗ AKLT: trivial;
- AKLT ⊗ product: nontrivial;
- AKLT under a random non-unitary gauge: nontrivial.
The solution space has dimension 1 in every case. This is a sanity check, not evidence for the theorem.

Self-audit of Thm A.
- (a) "Same phase = same H² class" assumes the standard definition: symmetric gapped paths, allowing stacking of symmetric product ancillas, with the on-site rep allowed to change by stacking. If the on-site rep is held fixed and ancillas are disallowed, there are extra invariants. The λ character is the only one for injective MPS (CGW), and it is also computed.
- (b) Rounding needs precision poly in the bit size: |ω| = 1 is not guaranteed, because V_g need not be unitary in an arbitrary gauge. ε is still an exact root of unity by construction, since ε^D = 1 algebraically. Fine.
- (c) Non-injective input, i.e. a block-diagonal or GHZ-like MPS (SSB): decomposing into normal blocks is P via the algebra generated by the A^i (Wedderburn/Rónyai, poly over number fields). Each block then gets its own class, plus the permutation action of G on blocks. [S] 75%.

### Thm A′ (extensions in 1D) [S] 75%

Each of the following is in P, by the same linear-algebra-then-Z-system pattern:
- Antiunitary G (twisted H²): solve Σ u_ij conj(A^j) V = λ V A^i.
- Translation (extra H¹ via λ).
- Fermionic MPS (Z2-graded; invariants H¹(G,Z2) × H²; the Majorana number is read off the centre of the graded algebra, cf. Bultinck et al. 2017).
- Non-TI finite chains (site-dependent V_g^{(k)}; the class is constant along the chain).

### Thm A″ (compact Lie G) [S] 70%

**Input.** Basis and structure constants of 𝔤 = Lie(G) with rational entries, matrices of the physical rep of 𝔤, and π₁ data (the lattice ker(G̃ → G)).

1. Solve the linear system for the virtual Lie-algebra rep x ↦ x̃. It is unique modulo scalars by injectivity.
2. Decompose x̃ via Casimirs and Cartan eigenvalues, using factoring over Q (LLL, poly). This gives highest weights.
3. The projective class is the character of the finite central subgroup ker(G̃ → G)_tors on the virtual space. For example, SO(3) gives Z/2 = (−1)^{2j}, which is Haldane.

For a torus, H²_Borel = 0, so the answer is always "trivial". Weakest point: the H²_Borel(G,U(1)) identification for non-semisimple, non-connected G (component group × connected part twisting). For connected G it is standard.

### Thm B (explicit cocycle models, any d): FP. [P] 90%

**Input.** Finite G by table and ν ∈ Z^{d+1}(G,μ_N) as a table of exponents (CGLW / Dijkgraaf–Witten data).

**Claim.** Deciding whether [ν] = 0 ∈ H^{d+1}(G,U(1)), deciding equality, and computing a normal form are all P in the input size |G|^{d+1} log N.

**Proof.** This is the Bockstein argument of Thm A step 5 at degree d+1: an integer linear system with matrix |G|^{d+2} × |G|^{d+1}. ∎

Computing the group H^{d+1}(G,U(1)) itself is also P for fixed d (SNF of the bar complex). With d in binary it is not poly-sized. This is the bare classification layer, and it is linear algebra.

### Thm C (2D SPT from a locally certified tensor network) [S] 60%

**Input.**
- A 2D symmetric PEPS tensor.
- A block region R (given explicitly, side in unary) on which the tensor is injective, or MPO-injective with given MPO data.
- On-site u_g.

**Claim.** The H³(G,U(1)) invariant is computable in P.

**Construction.**
1. Pulling the symmetry through the injective block gives a linear system for the virtual action. That action is an MPO V_g of bond dimension bounded by the block data (Williamson et al.).
2. Reduction V_gV_h ≅ X_{g,h} V_{gh} X_{g,h}^{-1} gives fusion tensors X from another linear system.
3. The associator of the X's gives a scalar ω(g,h,k). The phase is fixed by normalisation, as in Thm A step 4.
4. Finish with Thm B.

Weakest link: whether an *injective* single-block PEPS can carry a nontrivial SPT at all. Pérez-García–Sanz–González-Guillén–Wolf–Cirac (NJP 2010) show that on-site symmetries of injective PEPS act on the virtual level as tensor products of local operators, which would force the trivial class. Williamson et al. instead get MPO virtual symmetries for nontrivial SPT. I did not reconcile this; I expect different injectivity or blocking hypotheses. **If PSGWC applies, then Thm C reads "injective PEPS ⇒ trivial SPT phase, decided in P (answer: trivial)", and the nontrivial cases need MPO data in the input.** Either reading keeps the problem in P once the certificate is given. Handed to P1 and P4 to settle.

Same pattern for d-dimensional input given as a symmetric finite-depth circuit (or QCA) plus a product state: Else–Nayak boundary reduction is local linear algebra on tensors of dimension d_loc^{O(range)}, giving time poly(n)·d_loc^{O(t·r)} for depth t. [S] 60%.

### Prop E (why the H-space structure gives P, concretely) [S] 75%

Setting: layered classification data (n_1, n_2, …) with stacking law and gauge transformations given by cochain formulas whose k-invariants are **stable** cohomology operations (Sq^i via Steenrod cup-i, or Bocksteins), as in supercohomology and Kitaev/Freed–Hopkins Postnikov layers. Then "same phase" is decidable in poly time for fixed depth and G by table.

Proof idea, layer by layer:
1. Layer 1 is a linear system with solution set b_0 + Z¹ (cocycles).
2. Substituting b_0 + z into layer 2 gives a discrepancy f(b_0+z). Its quadratic part q(z) is a cochain representative of a stable operation on the cocycle z. Additivity holds in cohomology, with explicit cup-i homotopies, so z ↦ [f(b_0+z)] is affine H¹ → H^{k}.
3. Solve one linear system over finite abelian groups. Iterate.

This is #1's Mal'cev tower in cochain clothing. The Taylor-collapse theorem (R-G1) is a correct but roundabout justification: what is actually used is additivity of stable operations.

**Where it fails.** Unstable operations, such as the Pontryagin square 𝔓: H² → H⁴ (𝔓(a+b) = 𝔓a + 𝔓b + a∪b) or cup squares in unstable or 2-group settings. There q descends to a genuinely quadratic map, and the equation becomes a quadratic system over a finite abelian group. This is the NP candidate. It can only appear outside invertible / Ω-spectrum phases: SET, non-invertible, or higher-group gauge theories. Handed to P4. See Prop F for why it still cannot be NP-hard in the table model.

### Prop F (quasi-polynomial cap in the table model) [S] 75%

For G given by its table, fixed d, a fixed number of layers, and coefficient groups of order poly(|G|): every layered phase-equivalence problem, stable or unstable, is decidable in time 2^{O((log|G|)^{d+1})}, which is quasi-polynomial.

Proof.
- By Lyndon–Hochschild–Serre along a composition series of length m ≤ log₂|G| (cyclic factors with dim H^j ≤ 1 per prime), dim_{F_p} H^k(G,F_p) ≤ C(m+k−1, k).
- So |H^k(G,A)| ≤ |A|^{C(log|G|+k,k)}.
- Enumerate the gauge classes of each layer, which is the only branching. Each candidate is checked by an SNF linear system.

Consequence:
- An NP-complete phase-equivalence problem in the table model with fixed d would imply NP ⊆ QP. This is the Group-Isomorphism-like regime.
- NP-completeness requires succinct G (e.g. G = Z2^r given by r: then H² ≅ alternating forms on F2^r has size 2^{Θ(r²)}, and unstable quadratic layers become MQ over F2), or lattice-size / tensor data (P3).

Self-audit.
- The LHS bound is for F_p coefficients. For Z/p^a it multiplies by a. For mixed coefficients, use Sylow restriction plus transfer to reduce to p-groups.
- I did not line-check the binomial induction. The polylog-exponent conclusion is robust even if the binomial is off.
