# Modular counting for tensor isomorphism over fixed finite fields

The modulus primes and finite-field restrictions are part of the theorem.

## 0. Exact statement and notation

[CGQTZ §1.5] defines TI_G as the class of problems polynomial-time reducible to 3-tensor isomorphism under G. Their reductions are kernel reductions, that is, many-one reductions, typically p-projections (lines 303–308).

- "Open Question 1.9. Is TI_SL contained in TI? Are they equal?" (line 603).
- TI ≤ TI_SL is ours (Lean `JouxNarayanan54`).
- Over F_2, SL = GL, so TI_SL(F_2) = TI(F_2) trivially.

Notation:
- G = GL(U_1) × GL(U_2) × GL(U_3), with n_i = dim U_i.
- A = (F_q^*)^3, and det: G → A is the triple of determinants.
- For a tensor T, Aut(T) = Stab_G(T), D(T) = det(Aut(T)) ≤ A, and Trans(T, T') = {g : gT = T'}.
- If u ∈ Trans(T, T'), then det(Trans(T, T')) = det(u)·D(T).
- A **determinant profile** is H_B = det^{-1}(B) for some B ≤ A. Then TI_{H_B}(T, T') ⟺ det(u) ∈ D(T)·B. TI_SL is B = 1.
- For a prime ℓ, π_ℓ: A → A_ℓ is the projection onto the Sylow ℓ-subgroup.

**Lemma 0 (prime splitting).** TI_{H_B}(T, T') holds iff, for every prime ℓ | q − 1, the event E_{ℓ,B} holds:

> E_{ℓ,B}: some g ∈ Trans(T, T') has π_ℓ(det g) ∈ π_ℓ(B).

*Proof.* A finite abelian group is the product of its Sylow subgroups, and a subgroup S splits as ∏ π_ℓ(S). So c ∈ DB iff π_ℓ(c) ∈ π_ℓ(D)π_ℓ(B) for every ℓ. ∎

For each ℓ, the set {g ∈ Trans : π_ℓ(det g) ∈ π_ℓ(B)} is the intersection of the coset Trans with the subgroup H_ℓ = det^{-1}π_ℓ^{-1}(π_ℓ B). If it is nonempty, it is a coset g_ℓ·Aut_ℓ, where Aut_ℓ := Aut(T) ∩ H_ℓ.

## 1. Theorem 1 (QZ: singly exponential algorithm for every determinant profile)

**Theorem 1.** Assume [QZ, Thm 8.1]. Over F_q, for every profile B ≤ A, TI_{H_B} is decidable deterministically in q^{O(n_1+n_2+n_3)}·poly(InSize). The same bound covers:
- computing D(T);
- computing the full H_B-transporter coset;
- counting H_B-transporters.

*Proof.* [QZ, Thm 8.1] (QZ.txt lines 4244–4252) takes generators of an arbitrary Γ_in ≤ ∏ GL(U_i). It returns either emptiness, or a representative u together with generators of Stab_{Γ_in}(T), in time q^{O(n_1+n_2+n_3)}poly(InSize). [QZ, Thm 8.9] states the exponent as p^{O(d)} with d = 2e(n_1+n_2+n_3), q = p^e.

Take Γ_in = G. Then D(T) is the subgroup of A generated by det of the output generators, and E_{ℓ,B} and Lemma 0 become arithmetic in A.

Alternatively, take Γ_in = H_B directly. H_B is generated by elementary transvections (which generate SL) together with diagonal matrices whose determinant tuples generate B. ∎

**Status.** This is an algorithm, not a reduction to TI. It puts TI_SL in the same singly exponential class as TI. It says nothing about a polynomial-time TI-oracle reduction.

**Novelty: low.** The repo's NovemberGroupIsoTransfers/LocalLifting already derives, from QZ and its follow-up, complete coset computation with "prescribed determinants for free tensors" over Galois rings (README entry, line 5 of its RESULTS.md). The case e = 1 is F_q. Record Theorem 1 as a **repo duplicate**. It is only a restatement for F_q. It depends on QZ, an AI-assisted manuscript that has not been refereed.

**On task (1), whether D(T) can be obtained from TI oracle calls only.**
- [D(T) : D_ω] and |D(T)| = [Aut : Aut_SL] are counting quantities. Neither the q^{O(n)} individualization in QZ nor any stabilizer-index query can be simulated by polynomially many TI decision queries without a TI counting-to-decision or search-to-decision reduction. Both are open: [GQ-pgrp] Thm A gives search-to-decision for alternating matrix space isometry only in q^{Õ(n)} time.
- The repo barrier (Lean `TISearchToDecisionBarrier_20261006`) shows generic marker search needs q^{Ω(n)} queries.
- Hence QZ does **not** give a polynomial-time Turing reduction. What it does give is Theorems 2–3 below, by a different route.

## 2. Theorem 2 (Fermat orbit-power congruence: Theorem P for every ℓ)

**Theorem 2.** Let ℓ be prime. Let Ω be a finite G-set with ℓ ∤ |Ω|. Define

p(ω, ω') := [ some g ∈ Trans(T, T') with π_ℓ(det g) ∈ π_ℓ(B) satisfies gω = ω' ].

Then

M_ℓ := #{ (ω, ω'_1, …, ω'_{ℓ−1}) ∈ Ω^ℓ : p(ω, ω'_i) = 1 for all i } ≡ |Ω|·[E_{ℓ,B}] (mod ℓ).

In particular, E_{ℓ,B} ⟺ M_ℓ ≢ 0 mod ℓ. Dropping the determinant condition gives the same statement for plain TI: there p means "some transporter maps ω to ω'", and E means T ≅ T'.

*Proof.*
- If E_{ℓ,B} fails, every p = 0, so M_ℓ = 0.
- Otherwise the admissible transporters form g_ℓ·Aut_ℓ (§0). For fixed ω, the set {ω' : p(ω, ω') = 1} is g_ℓ·Aut_ℓ·ω, of size |Aut_ℓ ω|.
- So M_ℓ = Σ_ω |Aut_ℓ ω|^{ℓ−1} = Σ_O |O|·|O|^{ℓ−1} = Σ_O |O|^ℓ, summed over the Aut_ℓ-orbits O on Ω.
- By Fermat, |O|^ℓ ≡ |O| (mod ℓ), so M_ℓ ≡ Σ_O |O| = |Ω| (mod ℓ). ∎

**Correction to the route note.** TISL-ROUTE-MATCH-20261122 §11 says "the XOR form is special to ℓ = 2, where Σ|O|² ≡ Σ|O|". That is wrong: counting ℓ-tuples instead of pairs gives Σ|O|^ℓ, which works for every ℓ. The old Theorem P is the case ℓ = 2.

**Lemma 3 (Sylow counts; checked by hand and by C++ over 420 cases, 0 failures: q ≤ 49, n ≤ 14).** Let q be a prime power, ℓ a prime dividing q − 1, and n ≥ 1.

- (a) If ℓ is odd, or ℓ = 2 with q ≡ 1 (mod 4): the number of unordered **frames** of F_q^n (decompositions into n lines) is prime to ℓ.
  - The stabilizer is GL_1(q) ≀ S_n, of order (q − 1)^n·n!.
  - By lifting the exponent, v_ℓ(q^i − 1) = v_ℓ(q − 1) + v_ℓ(i). So v_ℓ|GL_n(q)| = n·v_ℓ(q − 1) + v_ℓ(n!) = v_ℓ|GL_1 ≀ S_n|.
- (b) If ℓ = 2 and q ≡ 3 (mod 4): the number of unordered **2-block decompositions** of F_q^n (m = ⌊n/2⌋ planes, plus one line if n is odd) is odd.
  - v_2(q^i − 1) = 1 for odd i, and 1 + v_2(q + 1) + v_2(i/2) for even i.
  - So v_2|GL_n(q)| = m(2 + v_2(q + 1)) + v_2(m!) + [n odd] = v_2|(GL_2(q) ≀ S_m) × GL_1(q)^{[n odd]}|.
  - The case q = 3 is Lemma S. The Lean lemma `v2_GL_eq_wreath` covers F_3 only.

Take Ω = Ω_1 × Ω_2 × Ω_3, with Ω_i the frames (case a) or 2-block decompositions (case b) of U_i. Then ℓ ∤ |Ω|.

## 3. Theorem 3 (the localized test is a GI question, so the oracle disappears)

**Lemma 4 (localization lies in FP^GI).** Fix q, or give it in unary. For decompositions ω, ω' of the type in Lemma 3, the following can be computed in polynomial time with a GI oracle:
- (i) whether some g ∈ Trans(T, T') has gω = ω';
- (ii) the full coset of such g, given by one element and generators of Aut(T, ω);
- (iii) hence p(ω, ω') of Theorem 2, for any B.

*Proof.* Build a finite relational structure S(T, ω):
- **Points:** for each mode i and each block β of ω_i, the nonzero vectors of β. There are at most 3n·q² points.
- **Relations:**
  - unary mode colours;
  - R_add(x, y, z) ⟺ x + y = z, with x, y, z in the same block;
  - R_λ(x, y) ⟺ y = λx, for each λ ∈ F_q^*;
  - for each c ∈ F_q, R_c(x, y, z) ⟺ T(x, y, z) = c, for x, y, z in modes 1, 2, 3.

*Isomorphisms S(T, ω) → S(T', ω') are exactly the g ∈ G with gT = T' and gω = ω'.*
- Within a mode, the blocks are the connected components of R_add ∪ R_λ:
  - two independent vectors of a block have a nonzero sum;
  - two dependent vectors are joined by some R_λ.
- So an isomorphism maps blocks to blocks.
- On each block it preserves addition (the case x + y = 0 is covered by R_{−1}) and scalar multiplication. Extended by 0 ↦ 0, it is therefore F_q-linear. This gives g_i ∈ GL(U_i) carrying ω_i to ω'_i.
- Preserving R_c on the spanning block vectors, together with trilinearity, gives gT = T'.
- The converse direction is immediate.

*From structures to GI:*
- Isomorphism and automorphism generators of bounded-arity coloured relational structures reduce in polynomial time to GI. This is the standard incidence-graph encoding (assumed, see list).
- GI and AUTO are polynomial-time Turing equivalent [Mathon, as cited in AK §4, AK.txt lines 489–492].
- So (i) and (ii) are in FP^GI.
- For (iii): det of the representative and of the generators lies in A. Take the subgroup they generate (q is unary, so discrete logarithms are trivial) and test π_ℓ-membership. ∎

**Theorem 3.** Let q ≠ 2 be fixed (or unary). Then:
- (a) For every prime ℓ | q − 1, TI(F_q) ∈ Mod_ℓP.
- (b) For every profile B (TI_SL included) and every prime ℓ | q − 1, E_{ℓ,B} ∈ Mod_ℓP. Hence TI_{H_B}(F_q) = ⋀_{ℓ | q−1} E_{ℓ,B} is a conjunction of at most log₂q Mod-classes. It is decidable in P with one parallel query to each Mod_ℓP language.
- (c) If q − 1 is a power of a prime ℓ (q = 3, 4, 5, 8, 9, 17, 32, 128, 257, …), then TI_SL(F_q) and every TI_{H_B}(F_q) lie in Mod_ℓP. In particular TI(F_3), TI_SL(F_3), TI(F_5) and TI_SL(F_5) all lie in ⊕P.

*Proof.* Use the Mod_ℓP^GI machine below, then apply GI's lowness for Mod_kP.

*The machine:*
- It guesses (ω, ω'_1, …, ω'_{ℓ−1}) in canonical form: each block in reduced echelon form, blocks sorted. It rejects strings that are not canonical or not direct-sum decompositions, so each tuple of Ω^ℓ is counted exactly once.
- It accepts iff ∏_i p(ω, ω'_i) = 1.
- The number of accepting paths is M_ℓ, and M_ℓ ≢ 0 mod ℓ ⟺ E_{ℓ,B}, by Theorem 2 and Lemma 3.
- Each p is in P^GI by Lemma 4. Hence E_{ℓ,B} ∈ Mod_ℓP^GI, and similarly TI ∈ Mod_ℓP^GI.

*Lowness:* [AK, §1.1, AK.txt line 76] says GI "is in and low for Mod_kP for each k ≥ 2", so Mod_ℓP^GI = Mod_ℓP. Then (b) and (c) follow by Lemma 0. ∎

**Corollaries (via TI(F_q)-completeness and the linear-length reductions of [GQ23b]).** Every problem many-one reducible to TI(F_q) lies in Mod_ℓP for ℓ | q − 1. Examples:
- cubic form equivalence over F_q;
- algebra isomorphism over F_q;
- alternating matrix space isometry;
- hence isomorphism of p-groups of class 2 and exponent p given by matrix generators (odd p, through the constructive Baer correspondence of [GQ-pgrp] Lemma 6.2) lies in ⊕P.

**What Theorem 3 does and does not do for OQ 1.9.**
- TI_SL(F_q) and TI(F_q) now sit in the same oracle-free counting classes.
- No counting-class separation can separate them, for q − 1 a prime power.
- It is **not** a reduction TI_SL ≤ TI. Evaluating M_ℓ with a TI oracle would need a TI counting-to-decision mod ℓ, the hinge identified in route-match §13.
- So task (2) is answered with ⊕P / Mod_ℓP, without the oracle, but **not** with P^TI.
