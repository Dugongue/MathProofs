# Four Cartier–Dieudonné results for isomorphism

1. [Free tensor compilation with exact transporter fibers](Compiler.md). From explicit finite Dieudonné presentations over a finite field, construct one ordinary three-tensor instance over `Z/p^e Z`. Recover a module isomorphism from every tensor transporter and compute the number of tensor transporters above each module isomorphism. The construction handles nonfree input modules.
2. [Exact transporter counting](Algorithms.md). For explicitly presented finite Dieudonné modules, including labelled additive subgroups, find an isomorphism and count all isomorphisms in deterministic polynomial bit time. The count uses the numerical types of semisimple factors without finite-field polynomial factorization. The search uses existing module-isomorphism algorithms.
3. [Prescribed isomorphism degrees](Spectra.md). For two-chain modules, similarity of powers over the prime field decides isomorphism over each finite extension. Over any prime field every nonempty finite union of sets of multiples is realized by local-local group schemes killed by the characteristic.
4. [Subgroup parameter schemes with intrinsic Frobenius recovery](Geometry.md). Every projective scheme over a perfect field of positive characteristic is recovered, including its nilpotent structure, from the relative Frobenius image of a parameter scheme of subgroups in a marked additive group of height at most two. This gives a tensor-isomorphism reduction to abstract isomorphism of those parameter schemes and a closed immersion preserving the specified embedded Hilbert-orbit degenerations.

The four main proofs are written mathematics. The Lean kernel and an independent axiom audit checked only the [divisibility lemma](ExtensionDegree.lean) used in the third proof. The algorithm and tensor compilation take explicit Dieudonné operator presentations. The geometry result concerns the subgroup parameter scheme. The paper comparisons in each note document the ingredients and the scope of the synthesis. Publication priority remains open.
