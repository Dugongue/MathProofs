# Even graph isomorphisms and ternary code permutations as ordinary group isomorphisms

All problems in this note have explicit inputs and all reductions are deterministic polynomial-time many-one. In marked graph isomorphism the input gives vertex colors, a union of colors to mark, and an order of the marked vertices at each endpoint. The isomorphism must have positive permutation sign on that set. In marked ternary permutation-code equivalence the analogous requirement applies to the coordinate permutation. These are the graph and code predicates used in the lower determinant TI ladder.

**Theorem.** Marked graph isomorphism reduces to ordinary binary permutation-code equivalence, preserving the set of possible maps on the original vertices. Marked ternary permutation-code equivalence reduces to ordinary abstract group isomorphism of permutation groups given by generators, with every orbit of size 65. The second reduction asks for ordinary abstract group isomorphism and works also if one asks instead for conjugacy of the displayed permutation groups. It applies to arbitrary ternary codes and any marked size. Together with the graph-to-ternary-code reduction, it includes marked graph, marked graphic-matroid and marked Cayley-table group isomorphism. The results are informal.

## 1. Record the orientation in a binary column configuration

For n labeled vertices use independent basis vectors e_i. With s marked vertices, for each unordered pair of marked vertices {i,j} introduce an independent vector f_{ij}. Add another independent vector h. Define directed vectors by

    v_ij = f_ij      if i precedes j in the marked order,
    v_ji = f_ij + h  for that pair.

When s≥3 include the following binary columns in distinct palettes.

1. All e_i, with their original colors and marks.
2. The single column h and the single column a = Σ_(i precedes j) v_ij, in two separate singleton colors.
3. All v_ij for ordered pairs of distinct marked vertices.
4. All v_ij+e_i, and separately all v_ij+e_j.

The first columns span the vertex space. The directed columns span with h all other basis directions. Relative to that direct sum, each v_ij is distinct. The other columns in item 4 distinguish the two ends of its directed pair. All the columns are nonzero and distinct across the whole list, including a since there are at least three unordered pairs. In the graph case add e_i+e_j for the graph edges in one extra color. Work with simple graphs. Different or empty vertex classes work unchanged. When s=0 or 1 drop all orientation columns. When s=2 drop them and add unique colors on the first and second marked vertex. For s=2 the even bijection is exactly the one respecting these two positions.

A linear map preserving the colored column set must send e_i to e'_π(i) and h to h′. Since it preserves the directed columns, the two sums in item 4 force v_ij to map to v'_π(i)π(j). Indeed the directed component of the sum identifies the unique directed column, and the vertex component is then forced. Conversely any color-preserving bijection π of vertices extends uniquely to a linear map respecting all these columns except possibly a. On the basis (e_i,h,f_ij) it is the indicated permutation on e_i and on unordered pair directions, with shear by h for precisely the reversed pairs. Its image of a is a′ plus h times the number of inversions of π on the marked ordered set, modulo two. Thus the single marked sum imposes the exact parity. In the graph case the edge columns impose precisely graph adjacency. Consequently the possible maps on vertices are exactly the marked even graph isomorphisms.

## 2. Drop column colors and synchronize a ternary code

A full-row-rank matrix up to left basis changes and coordinate permutations is equivalent to its row-space code. To forget colors of the binary configuration replace each column by c copies, where c is the positive integer assigned to its color in a common catalogue. Different colors receive different c. Since the original columns are distinct nonzero vectors, any binary column equivalence preserves the fibers of equal columns, and their sizes give the original colors. Conversely every color-preserving map lifts. Copies can be placed in any order, and the total length is polynomial in the configuration size. This proves the first reduction to ordinary binary code equivalence.

Now start with an arbitrary ternary generator matrix on the original n vertices. Use the binary orientation columns from Section 1 without graph edge columns. On the same coordinate set put a second generator matrix over F₃, with the given ternary columns in the e_i positions and zero columns on all additional positions. As we drop colors by repeating binary columns, repeat their corresponding ternary columns as well. This constructs two codes of the same length, one binary and one ternary. Ask whether a single coordinate permutation matches both. The binary code forces exactly the even color-preserving permutations on the original n positions, considered as fibers. Ternary columns are constant within each fiber. Thus the additional requirement is precisely that the same vertex permutation preserve the given ternary code. Conversely a matching permutation of the original marked code, together with the unique required maps on the orientation columns, induces one simultaneous coordinate permutation after repetitions. This argument uses no rank restriction on the ternary code. The zero-dimensional code is included.

## 3. Synchronize the two characteristics with a fixed simple group

Let S=PSL₂(64), a nonabelian finite simple group, and let K=Aut(S)=PΓL₂(64). As 64 is even, PGL₂(64)=PSL₂(64). The field automorphism given by squaring generates the cyclic outer automorphism group of order six. The natural action of K on the projective line of size 65 is faithful. These fixed groups can be implemented by constant permutation tables or by finite-field arithmetic. [Donald White, Character Degrees of Extensions of PSL₂(q), Section 2](https://www.math.kent.edu/~white/papers/autpsl2.pdf)

For a binary code C₂ and ternary code C₃ on the same m coordinates let G(C₂,C₃) be the preimage of C₂×C₃ under

    K^m → Out(S)^m ≅ F₂^m × F₃^m.

Display G as a permutation group on m disjoint projective lines. Use a fixed set of generators of the inner group S independently on each line. Add a tuple of field automorphisms lifting each basis word from C₂ and from C₃, separately. A binary coordinate is lifted by the order-two power of the field generator. A ternary coordinate is lifted by the order-three power, raised to the given ternary digit. Label the two outer coordinates by these choices, avoiding any conversion ambiguity. These generators give exactly the preimage, since the kernel is S^m. The permutation degree is 65m and the generators are printed in polynomial time.

The commutator subgroup is exactly S^m: the quotient is abelian and S is perfect. Its simple direct factors are characteristic as an unordered family. An arbitrary abstract isomorphism of the preimages induces a permutation of those factors and, separately, an automorphism of S in each chosen coordinate identification. Under the canonical conjugation action on the commutator subgroup, its induced change on the outer action is the same coordinate permutation on both primary codes. Indeed the isomorphism conjugates each factor action by its restriction to that factor, and conjugation acts trivially on cyclic Out(S). This gives a necessary simultaneous permutation of C₂ and C₃. Conversely any simultaneous permutation induces a block permutation of the projective lines and conjugates the corresponding groups. Thus both abstract isomorphism and permutation conjugacy are equivalent to simultaneous code equivalence for the constructed inputs.

The group construction generalizes the code/outer-action method using one cyclic outer group with both primary components so the coordinate permutation is shared. Related binary sign-code constructions and semisimple group algorithms appear in the literature. The new use here is to place the binary orientation data and the ternary code on the very same family of simple factors. [Babai, Codenotti, Grochow and Qiao, Code Equivalence and Group Isomorphism](https://people.cs.uchicago.edu/~laci/papers/soda11.pdf)

## 4. Exact scope of the comparisons

For marked graph input the binary reduction works in its own right. To realize this graph problem in the permutation-group model, use that binary code with C₃ zero (one can then use A₅ and 5-point blocks instead of PSL₂(64)). Marked graphic-matroid isomorphism reduces first to marked graph isomorphism by the earlier matched-edge decomposition. Marked Cayley-table group isomorphism reduces first to marked graph isomorphism via multiplication records with three individually colored argument slots. Finally, marked ternary monomial-code equivalence when parity concerns the underlying permutation reduces to the marked permutation-code version by the earlier paired-coordinate construction.

All these are reductions of the displayed marked problems themselves. A lower rung which additionally conjoins independent ordinary TI still carries that independent condition. The group encodings have polynomial degree and generator length. The group orders grow exponentially in the number of blocks, as each contains S^m, so printing the resulting Cayley tables would take exponential time in that number. No change of field for general tensor isomorphism is used.


## 5. Several signed comparisons and stabilizer repairs

The binary construction also works for a list of graphs or ternary codes and a system of simultaneous linear equations on their parity bits, with no bound on a marked set. An isomorphism may be chosen independently for each relative or self-comparison in the list. Inside each comparison every equation reads the same chosen vertex or coordinate permutation for that comparison.

Use distinct copy colors for the graph or code comparison slots. For every tested mark having at least two entries in a slot, allocate its own independent unordered-pair directions and columns as in Section 1, with a single shared h. Use different palettes to distinguish the copy of the pair gadget, including its two endpoint attachments. Even if two marks overlap, their pair spaces remain separate and the same e_i vertices determine both of their permutation actions. Do not mark the individual sums a. Each recovered permutation shifts its sum by precisely its inversion parity times h. A mark with at most one entry contributes zero.

For equation j create a new independent tag w_j and pin it by a unique column color. Include one further uniquely colored column at each endpoint. On the source it is w_j plus the binary sum of the a's selected by the equation. On the target include the right-hand-side bit times h in addition. Any equation with zero left-hand side is first resolved as true or false, including after removing marks of size at most one. Distinct tags prevent column coincidences, even when a mark has exactly two entries. The single linear map must now preserve the pinning of every equation column, which is exactly the required system of parity conditions. Conversely every list of suitable permutations extends with its indicated actions on the auxiliaries.

For ternary code slots use the direct sum of the original ternary codes supported on their separate e_i coordinate sets, with zero on the other binary columns. All copy shapes and marks are checked before construction. Projection to each set of e_i fibers shows the actions preserve precisely the corresponding codes, as in Section 2. Color removal and the ordinary permutation-group reductions then proceed unchanged. Each construction is polynomial in the written lists and system. For example, a determinant-correction test on graph or code permutations uses one relative comparison and one source self-comparison per correction term. The common output equations implement exactly the required signed sum, even with unknown stabilizers. This application encodes the permutation-based versions of the correction predicates. The three-dimensional tensor determinants on unrestricted tensor modes are treated by the separate p-group construction.
