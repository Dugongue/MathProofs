# Simultaneous and product-constrained code equivalence

## GP-0331 · Simultaneous equivalence reduces to one monomial comparison

**Theorem.** Given two indexed lists of linear codes of equal common length $n$, decide whether one monomial transformation maps every source code to its corresponding target. The decision problem is polynomial-time many-one equivalent to ordinary same-field linear equivalence (LEP). The upper reduction makes one call, has length $O(r^2 n^2)$ for $r$ codes, and recovers a common monomial map from any witness for the call. This works for arbitrary lists, including nested flags with an unbounded number of levels.

Use full-row-rank generators $G_i$ whose columns are $v_{ij}$ in their respective column spaces $V_i$. For each side of the instance construct a projective column multiset in $V=\bigoplus_{i=1}^r V_i$. The construction uses two contributions.

1. For every distinct nonzero projective column of $G_i$, including its block inclusion in $V$, add $i(n+1)$ copies. The resulting point set for index $i$ spans the embedded $V_i$.
2. For each coordinate $j$ with nonzero tuple $v_j=(v_{1j},\ldots,v_{rj})$, add one occurrence of its projective point. Use the tuple's actual vector as the column representative if desired.

Use this multiset as columns of an ordinary generator matrix. A point lies in at most one pure block. Its multiplicity quotient on division by $n+1$ is therefore exactly its block tag, or zero. The remainder counts joint tuple occurrences. An ordinary projective multiset equivalence preserves all tags and consequently all block spans. On the tuple points it gives a matching of the original coordinates, counted with multiplicity. For each matched pair of nonzero tuples, a scalar relating the two full tuples relates every component with the same scalar. All-zero tuples match at the remaining indices, where multipliers are arbitrary. Thus the block changes of bases give a single common coordinate permutation and scaling. Conversely a common witness and the induced row operations on each level map both contributions to their matches. These arguments use actual vectors to recover the multipliers even when many coordinates have the same projective point.

Reject incompatible lengths or dimensions directly. Zero-dimensional levels and the entirely zero instance can be handled before constructing the matrix. A difference in augmented lengths implies inequivalence. All field arithmetic is bit-polynomial for explicitly presented finite fields. Taking $r=1$ gives the lower reduction. [Projective systems and LEP, Horlemann–Mazumder–Schaller–Weger](https://arxiv.org/html/2607.12870v2#S6.SS5) · [Earlier MathProofs witness models](https://github.com/Dugongue/MathProofs/blob/ef3248c44a28fcc2e97f90392942083b33dce716/ParallelGroupAlgorithmsAndIsomorphism/MonomialWitnessModels.md)

## GP-0340 · Prescribed multiplier product

**Theorem.** Monomial equivalence with prescribed product of coordinate multipliers is polynomial-time Turing equivalent to ordinary LEP over the same field, uniformly in $n$ and the field-description size. The reduction applies over every finite field, including fields with even order or with unbounded extension degree. The lower reduction is many-one.

Write a monomial map on codewords as sending input position $j$ to position $\pi(j)$ with scalar $c_j$. Its character $\chi$ is the product of all $c_j$. This is a homomorphism because composition merely permutes one list of coordinate scalars. If a transporter $t$ from $C$ to $D$ exists, its possible character values are exactly $\chi(t)\chi(\operatorname{Aut}_{\rm mon}(C))$. One zero column on either side of an equivalent pair gives complete freedom in this product. Handle zero columns by an ordinary LEP decision and assume the remaining nonempty problem has full support.

Put a normalized representative on each distinct projective column class while recording the actual original columns. We now describe how to recover a transporter and the needed generators of the permutation image on the classes. An ordinary LEP call can impose matching colors on the classes by replacing weight $w$ by $w+(n+1)c$ for class color $c$. Here original $w$ is at most $n$. Distinct tagged classes are still distinct points, and the quotient and remainder recover both quantities. Different total augmented lengths immediately imply a negative answer. With distinct colors for every already fixed point image, try the remaining possible images of the next point in turn. This gives a witness permutation in polynomially many queries. Applying the same procedure to the automorphisms that fix the first $i-1$ classes, find one full transporter for each possible image of class $i$ in that stabilizer. The union of these permutations generates the permutation image by successive reduction along the stabilizer chain. This uses polynomially many calls at polynomial length, with no field extension.

A prescribed projective witness permutation lifts by solving scalar ratios. Choose source representatives of a column basis $v_{b_1},\ldots,v_{b_k}$ and the corresponding target representatives $w_{\pi(b_1)},\ldots,w_{\pi(b_k)}$. Their target independence follows for a valid permutation. Set $P v_{b_i}=x_i w_{\pi(b_i)}$ with $x_i$ nonzero. Express each remaining source point and corresponding target point in the two bases, with coefficients $a_i$ and $b_i$. For each pair require $x_i a_i=d_j b_i$ for a nonzero variable $d_j$. The supports must match, and on each nonzero coefficient the equation fixes a ratio between two variables. One graph traversal solves all such ratios. Use actual input columns to read off the coordinate scales once a matching of class occurrences has been chosen. For example if $P v_j=d_j w_{\pi(j)}$ for actual columns, the coordinate multiplier is $d_j^{-1}$. This recovers both one transporter and one actual lift of every permutation-image generator.

For an automorphism that fixes the class permutation, the basis-coordinate ratios reduce to equalities. Construct the bipartite graph whose vertices are basis positions and point classes, with an edge at each nonzero coefficient of a point in the selected basis. Such an automorphism acts by one nonzero scalar on each connected component and the component scalars are independent. Within any projective point class the occurrences may also be permuted. Its original scale factors only contribute ratios whose product telescopes to one. If $n_i$ is the total number of coordinates in component $i$, its scalar group therefore has character image $(\mathbb F_q^\times)^{n_i}$. Together with the character values of the lifted permutation generators these generate the entire character image.

There is no need to factor $q-1$ or solve a discrete logarithm. Let $d=\gcd(n,q-1)$. A common scalar on every coordinate gives all $n$-th powers, so reduce the desired character ratio and the lifted generator values by $x\mapsto x^{(q-1)/d}$. This maps onto the cyclic group of order $d\le n$, with kernel the $n$-th powers. The image of component $i$ has order $d/\gcd(d,n_i)$. Determine the orders of the reduced explicit generators by testing divisors of $d$. The subgroup generated by all images has order equal to the least common multiple of these orders and the component orders. The desired ratio lies in it precisely when its power at that least common multiple is one. These tests and exponentiations are deterministic and bit-polynomial. Adding one zero column to each input gives the reverse many-one reduction with prescribed product one. An empty-length input has only character one. ## GP-0320 · Rank-query complexity of binary matroid isomorphism

**Theorem.** Two promised binary matroids on $n$ points can be compared after at most $2(n+r(n-r))$ rank queries when both ranks are $r$. Every deterministic rank-query comparison procedure needs $\Omega(n^2/\log n)$ total queries in the worst case at rank $\lfloor n/2\rfloor$. The upper bound counts queries and permits arbitrary computation between them.

For one input, use greedy rank tests on initial segments enlarged by one candidate element at a time to find an ordered basis $B$ with at most $n$ queries. In binary coordinates normalizing $B$ to the unit columns, the coefficient of $b\in B$ in a nonbasis column $e$ is one exactly when $B-b+e$ is a basis. These $r(n-r)$ rank tests recover a full binary representation, including every loop and parallel class. Compare the resulting represented matroids offline. This is the fundamental-circuit reconstruction, which is also available with an independence oracle. [Kwon's fundamental-graph reconstruction](https://mathsci.kaist.ac.kr/~ojkwon/ojoungthesis.pdf)

For the lower bound, fix the basis labels and consider all $2^{r(n-r)}$ binary matrices in systematic form $[I_r\mid A]$. Distinct $A$ give distinct labeled matroids by the same basis-exchange tests. There are at least $2^{r(n-r)}/n!$ distinct unlabeled isomorphism classes. In a deterministic decision tree run both input oracles on $(M,M)$ for one representative from every class. If distinct classes $M,N$ reached the same leaf, then each recorded query has the same answer from the respective representative. Thus $(M,N)$ follows that transcript and would be accepted. The different classes therefore give distinct accepting leaves. At depth $Q$ there are at most $(r+1)^Q$ leaves, since any rank response has $r+1$ possible values. At central rank this proves the claim. Unequal ranks may be decided immediately. The lower bound is deterministic and does not assert randomized query hardness.

## Prior closure excluded from the new count

The same survey's companion problem GP-0313 already has a MathProofs answer, including the stronger distinct-projective-column case and an equivariant-list size obstruction. A simple additional control is the all-ones repetition code in length at least three divisible by the field characteristic. A one-dimensional partner invariant under every coordinate permutation must have full support and must be fixed by every transposition, hence is the same repetition line. Its pairing is then zero. This control does not create a new catalogue closure.
