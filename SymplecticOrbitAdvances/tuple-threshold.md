# Dichotomy for fixed symplectic tensor tuple signatures

**Theorem.** Fix a finite list of tensor slots, each specified by a list of labels from a fixed family of symplectic spaces \(W_i\). A label may appear repeatedly in a slot or across slots. Let the product of the groups \(\operatorname{Sp}(W_i)\) act on their named factors. Over \(\mathbb C\), if every slot has order at most two, orbit-closure intersection is decidable in deterministic polynomial bit time. If some slot has order at least three, the problem is TOCI-complete via efficient algebraic reductions. Dimensions vary, and each designated group acts on a positive even-dimensional space. Zero-dimensional active slots, if allowed, may be discarded in the easy case.

**Invariant contractions.** Polarization and the symplectic first fundamental theorem express invariants as linear combinations of diagrams pairing ports with the same group label. The value of such a diagram is obtained by taking one copy of the relevant input tensor at each vertex and inserting the alternating form on each edge. Equality of all invariant values characterizes closure intersection. [Lysikov–Walter, Theorem II.7 and Section IV-C](https://arxiv.org/html/2411.04639v2).

**Orders at most two.** Scalar slots are compared directly. For every binary slot, turn its tensor into an arrow \(A:W_j\to W_i\) using the symplectic form at its second port. Include both \(A\) and its symplectic adjoint \(A^\dagger:W_i\to W_j\). For each unary vector \(v\in W_i\), include its column arrow from a distinguished one-dimensional vertex and its row arrow \(w\mapsto\omega_i(v,w)\) back. Use an endomorphism of \(E=\mathbb C\oplus\bigoplus_i W_i\) supported in the indicated block for each arrow. Add projections onto the vertex spaces. Under the input group all these endomorphisms transform by simultaneous conjugation, with trivial action on the one-dimensional vertex.

Every non-scalar connected contraction diagram is a cycle of binary vertices or a path with unary endpoints. Parallel edges and binary loops are allowed. Traverse a component, reading an arrow or its adjoint according to which port is first. Reversing a pairing changes an overall sign. Each cycle is a trace of an arrow word. Each path is the corresponding row–word–column scalar, which is the trace of the word starting at the distinguished vertex. This proves that traces of words in the displayed blocked operators suffice. They are themselves invariants, also when a word is zero because block indices do not match.

For two inputs, generate the span of paired words in \(\operatorname{End}(E)\oplus\operatorname{End}(E)\). Start with the identity pair, retain linearly independent pairs, and right-multiply each retained pair by every corresponding arrow or projection pair. Once no new pair is retained the space is closed under those right multiplications and contains every word. It has dimension at most \(2(\dim E)^2\), and retained words have length at most that bound. Test trace difference on the retained basis. Exact Gaussian elimination and exact input arithmetic use polynomial bit time. For example, clear all input denominators once in each paired generator. This scales a paired word by a nonzero common scalar, and every short word then has polynomial bit length. The span method is the same linear algebra used in the balanced general-linear tuple algorithm and in matrix orbit-closure separation. [Balanced tuple calculation](https://github.com/Dugongue/MathProofs/blob/main/BalancedQuarticOCI/PRODUCT-GROUP.md), [Derksen–Makam on matrix orbit-closure separation](https://arxiv.org/abs/1801.02043).

**A slot of order at least three.** The independent-action construction for a single ordered tensor at that order is an affine reduction from one bipartite operator. First run it with one independent symplectic space for each physical position. For every repeated label, form the symplectic orthogonal sum of the spaces for its positions, and insert each position into its own summand of that sum. Set all other tensor slots to zero. This insertion preserves closure intersection by block-diagonal equivariance. It reflects closure intersection because every contraction for the independent action becomes a valid contraction under the larger group by pairing the same physical ports. The pullback along insertion is exactly the original contraction. A common output orbit-closure point therefore implies agreement of all the source invariant values. This also handles labels appearing many times in one slot, including a single label for the entire slot. If the definition uses an equal dimension for all spaces, pad with unused symplectic summands and use the same argument. [Independent-action construction](https://github.com/Dugongue/MathProofs/blob/main/SymplecticTensorFusions/OrbitClosures.md).

**Membership.** Embed each space into a separate summand of one larger symplectic space and use the same block argument to replace all independent groups by its single symplectic group. Every source contraction remains a valid target contraction, reflecting intersection. The single-group symplectic tensor tuple problem reduces to a general-linear tensor tuple problem by the symplectic-to-general-linear reduction of Lysikov and Walter. The output maps have rational coefficients and polynomial size for a fixed signature. [Lysikov–Walter, Section V-B](https://arxiv.org/html/2411.04639v2).
