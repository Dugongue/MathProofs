# Packing independent determinant tests in tensor isomorphism

Work with explicit three-tensors over $\mathbb F_3$. Write $O$ for ordinary TI and $A$ for isomorphism preserving determinant in the first mode. This packet proves deterministic polynomial-time, single-instance reductions under the conditions below. The proofs are informal.

## A single ordinary query for linear equations controlled by ordinary TI

Given a binary linear system, allow each variable to be nonzero only if an associated raw ordinary TI comparison has a positive verdict. Deciding whether the system has a solution reduces to one ordinary TI instance. The construction uses two slots per variable, with the swap available exactly when the associated tensors are ordinarily isomorphic. Another family of slots represents the local satisfying assignments of equations of arity at most three, and incidence pins their actions to the same variable swaps. Splitting long rows by prefix variables keeps the system polynomial. This combines fixed-size coset constraints, as in the group-CSP view of CFI, with tensor comparisons that control which variables are available. [Proof](SpanParity.md) · [Berkholz and Grohe](https://arxiv.org/abs/1607.04287)

On centroid blocks this replaces every unknown block matching with linear equations. Include one variable for each available signed edge and require odd degree at every endpoint. Inside each ordinary isomorphism class the sign of an edge is the sum of two orientation offsets plus a stabilizer correction. The odd degrees count every offset exactly once. An ordinary comparison of the full tensors checks that the type multiplicities match. The sign of permuting blocks is imposed using separate inversion rows, with the exact freedom arising from repeated ordinary types. Hence arbitrary multiplicities require no supplied type partition or matching. If each relevant block sign test has a uniform polynomial-time ordinary TI reduction, the entire signed comparison has one as well. In particular the first-mode version applies when each intrinsic block has logarithmic first-mode dimension, even if there are many blocks and the entire first mode is much larger. [First-mode proof](SpanParity.md) · [Joint three-sign proof](VectorAssembly.md) · [Centroid recovery](Logic.md)

## Other ways to remove one sign before packing

- **Represented adjoint algebras.** Compute the radical flag and cancel determinant factors across its module grades. The sign that survives is carried by explicitly computable spaces attached to the simple factors, with a correction for field automorphisms and permutations. Polynomial complexity requires logarithmic width in each intrinsic group, even when their total width is large. The construction allows nonzero radicals and nonsplit simple factors. [Determinant identity](Swaps.md) · [Several intrinsic groups](AdjointGroups.md)
- **Small projective mode over each block's own field.** An exact deterministic algorithm computes all three achievable signs when each block has a mode of dimension $r$ over its intrinsic coefficient field of degree $d$, with $d(r^2-1)=O(\log L)$. The narrow mode may vary between blocks, and $r=1$ allows unbounded $d$. The algorithm enumerates normalized projective mode maps and uses constructive module isomorphism for the remaining maps, retaining the correlation between their signs. [Exact profile algorithm](Structure.md)
- **Alternating matrix pencils with a small evaluation table.** A one-dimensional space of right symmetrizers allows deterministic raw recovery of a congruence problem. A polynomial-size table of Pfaffian values over a fixed or suitably small extension pins the first determinant, provided one value is nonzero. The first mode can be arbitrarily large. [Pfaffian construction](Pfaffian.md) · [Pfaffians in alternating-space isomorphism](https://joshmaglione.com/papers/Genus2.pdf)

If either of two independent signed comparisons meets one of the above sufficient conditions, use its ordinary output as a determinant-neutral extra condition on the other. This produces one signed instance with the original conjunction verdict on that domain. The [neutral conjunction proof](NeutralConjunction.md) supplies this last step. The projective-mode case can instead directly compute the qualified predicate and return the other comparison or a fixed no instance.

## Keep one determinant live in a tensor system

A second construction compiles a whole order-at-most-three tensor system to one signed TI instance while preserving the determinant in any one designated role. A tagged triangular algebra encodes the shared maps. Calibrated auxiliary corners cancel all other determinant contributions, and the multiplication tensor's total isotopy sign is the determinant of the underlying algebra isomorphism. Exact sign projection places that sign on the first physical mode. This addresses a live sign on the same transporter as the diagram's ordinary constraints. Thus if the adjoint construction can pin one determinant, a shared-transporter two-sign comparison reduces to one-sign TI. With two such pins, the same construction reduces a shared three-sign comparison to one-sign TI. [Determinant-preserving compiler](SignedCompiler.md)

## The unrestricted target

The target $A\land A\le_m^p A$ for two arbitrary independent raw comparisons remains unresolved. The new block assembly removes the need to recognize or match ordinary types during preprocessing, once the local signed comparisons can be compiled to ordinary TI. It supplies no ordinary compiler for a single arbitrary large indecomposable block. In particular the adjoint test can leave full width when the represented adjoints are scalar, and the Pfaffian test has alternating recovery and nonzero evaluation hypotheses.

If the unrestricted binary reduction is obtained, iterate it a fixed number of times to combine the seven nonzero binary characters on the three determinant coordinates. An affine sign profile contains zero exactly when its projection to every nonzero character contains zero. [Exact sign projection](SignProjections.md) implements these character tests as one-sign instances, and the fixed seven-to-one assembly would give $\mathrm{SL\!-\!TI}\le_m^p A$. The upward reductions would then make all three signed tiers equivalent. No new unrestricted collapse follows from the results in this packet. [Published endpoint question](https://arxiv.org/html/2306.03135v2#S1.SS5)

The reductions use earlier MathProofs tensor constructions and the published bounded-order tensor-system compiler. The claims concern the stated sufficient families and the general ordinary-TI-controlled linear system. Publication priority has not been determined.
