# Linear feasibility with ordinary tensor-isomorphism gates

All reductions are deterministic polynomial-time many-one reductions on explicit inputs, and the arguments are informal.

## A general ordinary TI construction

Let $H$ be an explicit binary matrix and $b$ an explicit binary vector. Associate to each column $i$ an arbitrary independent ordinary tensor-isomorphism comparison $(P_i,Q_i)$ over $\mathbb F_3$. Require
$$
Hx=b,\qquad
x_i\in\{0,1\},\qquad
x_i=1\ \Longrightarrow\ P_i\simeq Q_i.
$$
The problem of whether such $x$ exists reduces to one unrestricted ordinary TI comparison over $\mathbb F_3$. Equivalently, one ordinary TI instance tests whether $b$ lies in the $\mathbb F_2$-span of the columns whose associated ordinary TI comparisons are true. Comparisons can be constructed jointly from the same raw input, and the reduction never computes their verdicts.

Replace every long row by equations of arity at most three using successive XOR partial sums. Each partial-sum bit is an additional independent variable enabled by a fixed true ordinary comparison. This preserves feasibility and the input size grows at most linearly in the number of nonzero entries of $H$. Eliminate constant rows and reject an inconsistent constant row. An empty remaining system can be sent to a fixed positive ordinary comparison. The remaining nonempty equations are ordered lists of between one and three distinct variable positions and a right-hand side bit. Repeated variable positions can be cancelled modulo two. Let $m$ and $s$ denote the counts of bits and equations after this operation.

We build two tensor systems of the same type. All their linear spaces are over $\mathbb F_3$. The bit arithmetic in the definition specifies finite supports by a computation over $\mathbb F_2$, and is not field arithmetic in the output.

Use the following split label algebras, each carrying its multiplication as a bilinear map.

- $K$ has $m+s$ primitive idempotents, one per bit position and then one per equation. Its directed-path linear operator sends each idempotent to its successor and sends the last to zero. An algebra automorphism permutes the idempotents, and commuting with the path operator forces that permutation to be the identity.
- $B$ has two primitive idempotents $f_{i,0},f_{i,1}$ for each bit position $i$. The linear map $K\to B$ sends the idempotent for bit $i$ to $f_{i,0}+f_{i,1}$ and all equation idempotents to zero. Isomorphism forces an independent swap or identity within each designated position, say $f_{i,a}\mapsto f_{i,a+x_i}$.
- $C$ has one primitive idempotent for each satisfying assignment within each equation. For an equation of arity $r$, we use the $2^{r-1}$ assignments of even binary parity at the source, and the $2^{r-1}$ assignments of parity equal to its right-hand side at the target. The linear map $K\to C$ sends each equation label to the sum of its assignment idempotents and bit labels to zero. Thus assignment idempotents never move across equations. The three linear maps $C\to B$ read the first, second, and third value of an assignment as the corresponding $f_{i,a}$, using zero when that position is past the arity. For fixed swaps on $B$, commuting with these three maps forces the permutation of each set of assignment idempotents to send $a$ to $a+x$ on that equation's variables. Such a permutation exists exactly when those swaps have parity equal to the equation's right-hand side. The forced map is then bijective.

The remaining spaces are three data spaces. In each data mode take the direct sum of the mode spaces of each $P_i$ under the bit-zero idempotent and each $Q_i$ under the bit-one idempotent. The three bilinear $B$ actions project onto the designated data slots. In both systems use the same data tensor, the sum of the copies of $P_i$ and $Q_i$ in their respective triples of slots. If the input formats differ, the ordinary comparison is a known false one and can first be replaced by a fixed false pair of equal format. The $B$-module action forces an isomorphism on the data spaces to match slots exactly according to the chosen bit swaps. Keeping a bit at zero allows identity maps in both slots. Swapping its slots is possible exactly when $P_i\simeq Q_i$. In the positive case any witness and its inverse can be used for the two directions. Constraints at different positions use independent data slots. The assignment maps share the same $B$ action as the data maps, so they use the exact same bits.

There are a fixed number of supported spaces, a fixed list of tensor types, and all maps have tensor order at most three, including the three algebra multiplications, three module actions, and single plain data tensor. Each space has polynomial dimension in the full explicit input. The fixed-signature tensor-system compiler therefore yields one ordinary three-tensor pair of polynomial size. The direction from a tensor-system isomorphism extracts its bit choices and the required ordinary transporters. The reverse constructs the assignment permutations and independent data maps from any feasible choices. [Chen, Grochow, Qiao, Tang and Zhang, Theorem 4.1](https://arxiv.org/html/2306.03135v2#S4)

The parity assignment sets are the group-CSP coset mechanism that underlies the Cai–Fürer–Immerman construction. Here the additional tensor data gates the admissible columns by arbitrary ordinary tensor-isomorphism comparisons, while leaving each zero value available. With all columns unconditional, the auxiliary linear feasibility problem is already decidable by Gaussian elimination. [Berkholz and Grohe, Linear Diophantine Equations, Group CSPs, and Graph Isomorphism](https://arxiv.org/abs/1607.04287)

One immediate consequence is that undirected connectivity with edge existence given by ordinary TI comparisons itself reduces to one ordinary TI instance. Use a binary incidence column for each potential edge and right-hand side $e_s+e_t$. If a path exists, its edges solve the system. Conversely, a set of enabled edges with even degree away from $s,t$ and odd degree at $s,t$ puts them in the same component by the degree-sum identity. This consequence concerns connectivity on an explicitly listed candidate graph, with no algorithm needed to decide which of the edges are present.
## Exact application to an arbitrary collection of small first-mode blocks

Let $A$ denote first-mode determinant-one isomorphism. Given raw input tensors, compare support dimensions and compact untested modes, preserving the first-mode raw frames. Ordinary TI decides the branch with a deficient first mode, where the unused complement corrects the sign. On nonzero concise tensors, the intrinsic centroid decomposition can be computed by polynomial-time linear algebra over $\mathbb F_3$. Its primitive idempotents give all indecomposable blocks over the base field. A transporter permutes these blocks and restricts to block isomorphisms, and conversely every such matching extends. See [centroid decomposition and frame calibration](Logic.md).

Suppose every block in each endpoint has first-mode dimension $O(\log L)$ in explicit input length $L$. If any source block has odd first width, multiplying its first two maps by $-I$ on that block is a stabilizer with negative first determinant. Again ordinary TI decides this branch. Thus assume all first widths are even. All permutations of matched blocks now have positive first determinant, because swapping blocks of even widths $a,b$ contributes $(-1)^{ab}=1$. Let $\eta$ be the sign of the two raw frame changes combined, so to get first determinant $+1$ the product of signs in block coordinates must be $\eta$.

For every source block $u$, target block $v$, and sign $c\in\mathbb F_2$, form the ordinary comparison asking whether there is a block isomorphism of first determinant $(-1)^c$. Exclude unequal formats directly. Compile the other tests by marking a choice of top exterior vector in the first-mode exterior algebra, with source and target pins differing by the desired sign. The algebra has dimension $2^{O(\log L)}$. These are ordinary TI comparisons by the same fixed-signature compiler.

Build one optional incidence column for every such triple $(u,v,c)$, enabled by that ordinary comparison. The column contains one in the rows for vertices $u,v$ and contains $c$ in a final row. Prescribe right-hand side one in all vertex rows, and $0$ or $1$ in the final row according as $\eta$ is positive or negative. Hence used edges have odd degree at every vertex and the prescribed total sign parity. Independently require the original unsigned comparison. The earlier neutral conjunction theorem combines the span test and this unsigned requirement in one ordinary TI instance.

The construction is exact. A genuine signed transporter supplies a matching and local signs, so choosing those edges meets all rows. Conversely, suppose ordinary equivalence and the incidence equations hold. If any source block has a negative first-determinant stabilizer, any full ordinary matching can correct its sign. Otherwise each block sign between two ordinarily isomorphic blocks is unique, including on target blocks by conjugation. In each ordinary type choose an abstract oriented reference block and denote by $a_v\in\mathbb F_2$ the sign from the reference to each block. On any available edge $(u,v,c)$ one has $c=a_u+a_v$. Therefore in every solution of the incidence equations
$$
\sum_{(u,v,c)} c x_{u,v,c}
=\sum_v a_v \deg_x(v)
=\sum_v a_v
\quad\text{in }\mathbb F_2.
$$
The sums over vertices range over both endpoints. Every ordinary perfect matching gives this exact same sign in block coordinates. Since there is one by the guard, the prescribed row gives the required full first-mode determinant. The proof needs neither a choice of reference at runtime nor a computed matching, and it works with any number of repeated or heterogeneous ordinary block types.

As a consequence, two independent $A$ comparisons reduce to one $A$ comparison if either has all its intrinsic first-mode block widths $O(\log L)$. Compute the single unsigned query for that comparison and absorb it into the unrestricted other signed query by the known ordinary-conjunction construction. The original side length may grow arbitrarily, and there is no restriction on how many blocks have the same format or ordinary type. High-dimensional single blocks are outside this result, so it does not supply the unrestricted signed collapse.
