# Counting finite-group epimorphisms with central lifts and fixed commutator maps

Grochow, Srivastava, and Thakkar ask in Open Question 2 for the complexity of counting epimorphisms between groups given by Cayley tables. Here are two deterministic exact algorithms. The first counts the lifts over any prescribed central quotient map in polynomial time and gives a polynomial-time algorithm whenever the target's center has bounded index. The second allows an arbitrary source and an odd-exponent-\(p\), class-two target and runs in \(p^{sh}\) times a polynomial in the table sizes, where \(s,h\) are the derived dimensions specified below. Both are partial answers to the unrestricted counting question. [Algorithms for Finite Group Epimorphism Testing, §7](https://arxiv.org/html/2609.07429v1#S7)

Throughout, the input groups have full Cayley tables. The order of an explicitly listed group is bounded by the length of its table encoding. Generated subgroups, quotients by explicit normal subgroups, commutator subgroups, centers and maps on the resulting groups can be computed by table lookups and closure in polynomial bit time.

## 1. Counting epimorphic lifts through a central subgroup

**Theorem 1.** Let \(G,H\) be finite groups, let \(Z\le Z(H)\) be given by its list of elements, and let \(\psi:G\to H/Z\) be an epimorphism given by its values. The number of epimorphisms \(f:G\to H\) with \(\pi f=\psi\) can be computed in deterministic polynomial bit time.

Choose a section \(s:H/Z\to H\) taking the identity to the identity, and use additive notation for \(Z\). Compute the cocycle \(c(q,r)=s(q)s(r)s(qr)^{-1}\), valued in \(Z\). A lift has the form \(f(g)=z(g)s(\psi(g))\). It is a homomorphism exactly when \(z(gh)=z(g)+z(h)+c(\psi(g),\psi(h))\) for every \(g,h\in G\). This finite system of linear congruences is solvable in polynomial bit time by writing \(Z\) in cyclic prime-power coordinates and introducing integer slack variables for the congruences. Standard polynomial-time integer linear equation algorithms via Smith normal form decide feasibility and produce one solution. An infeasible system gives count zero. Given one lift \(f_0\), all lifts are uniquely \(f_0(g)t(g)\) for \(t\in\operatorname{Hom}(G,Z)=\operatorname{Hom}(G_{\rm ab},Z)\). This follows by cancelling the fixed section value in the two cocycle equations and using centrality.

For every lift \(f\), one has \(f(G)Z=H\), since \(\psi\) is onto. Centrality gives \([f(G)Z,f(G)Z]=[f(G),f(G)]\), so \(H'=f(G')\subseteq f(G)\). Therefore \(f\) is onto exactly when its induced homomorphism \(G_{\rm ab}\to H_{\rm ab}\) is onto.

Write \(A=G_{\rm ab}\), \(B=H_{\rm ab}\), and \(\iota:Z\to B\) for the map induced by inclusion. The abelianization of \(f_0t\) is \(\overline f_0+\iota t\). This is onto precisely when its restrictions to Sylow parts are onto. For an abelian \(p\)-group \(B_p\), a subgroup \(C\le B_p\) with \(C+pB_p=B_p\) is all of \(B_p\), by iterating the equality and using \(p^kB_p=0\) for sufficiently large \(k\). Thus it is enough to count surjective reductions \(A_p\to U=B_p/pB_p\) for each prime.

Fix a prime and write \(A_p\) as a direct sum of cyclic groups with respective generators \(x_i\) and orders \(p^{e_i}\), numbered so that \(e_1\le\cdots\le e_k\). The independent choices for \(t(x_i)\) range over \(Z_p[p^{e_i}]\). Let \(a_i\in U\) be the image of \(x_i\) under \(\overline f_0\) followed by reduction. Let \(S_i\subseteq U\) be the image of \(Z_p[p^{e_i}]\) under \(\iota\) followed by reduction. The possible columns for \(x_i\) make up the affine space \(a_i+S_i\), and each column occurs with multiplicity \(w_i=|Z_p[p^{e_i}]|/|S_i|\). The ordering by \(e_i\) gives \(S_1\subseteq\cdots\subseteq S_k\).

Suppose the previous columns span \(V\le U\) with dimension \(r\). Let \(\pi_i:U\to U/S_i\) denote the quotient map. All previous columns project to their fixed \(a_j\) offsets. Thus \(\pi_i(V)\) is the fixed subspace \(P_i=\operatorname{span}\{\pi_i(a_j): j<i\}\). Its dimension \(d_i\) and membership test for \(\pi_i(a_i)\) are determined before any column is chosen. If \(\pi_i(a_i)\notin P_i\) the new affine column space has no intersection with \(V\). If \(\pi_i(a_i)\in P_i\), the intersection with \(V\) is one fiber of \(\pi_i|_V\) and has size \(p^{r-d_i}\). For reachable \(r\), let \(v_i(r)\) be this intersection size, using zero in the first case. Exactly \(w_i v_i(r)\) choices preserve rank \(r\), and \(w_i(p^{\dim S_i}-v_i(r))\) choices increase rank to \(r+1\). Dynamic programming on the column number and rank counts the \(t|_{A_p}\) reaching \(\dim U\). Multiplying these counts over primes gives the desired number of lifts. The dimension-zero case counts every choice as it should.

The data used by the algorithm can be computed in polynomial bit time from tables. In particular, one can decompose a finite abelian table group by computing element orders and taking the primary parts. In a nontrivial abelian \(p\)-part, choose a maximum-order element \(x\) of order \(p^k\). A homomorphism to \(C_{p^k}\) taking \(x\) to its displayed cyclic generator exists by the finite-abelian-group structure theorem, since \(x\) has a unit coordinate in a summand of that order. Find such a map by modular linear equations for its values on the table. Its kernel splits off, and repeating on the smaller group yields cyclic generators and then coordinates. A basis of an elementary abelian quotient can also be found by successively adjoining listed elements outside the span. Enumerating each \(Z_p[p^{e_i}]\) costs at most \(O(|Z|)\) table elements per column. Gaussian elimination computes the projection ranks, and only polynomially many rank states occur. Counts and weights have polynomial binary length, since the number of lifts is bounded by \(|Z|^{\log_2 |G|}\) for nontrivial \(G\). This proves Theorem 1.

**Corollary 2.** Put \(q=|H/Z(H)|\) and let \(d\) be the length of a greedy generating list for \(G\), so \(d\le \log_2|G|\). The exact count \(\#\operatorname{Epi}(G,H)\) can be computed in \(q^d\operatorname{poly}(|G|+|H|)\) bit time. In particular it is polynomial in the raw table sizes for bounded \(q\), with both the target order and its exponent allowed to grow.

Enumerate the \(q^d\) possible tuples of generator images in \(H/Z(H)\). For each tuple, traverse the generator Cayley graph of \(G\) to propagate the images and check the resulting table map and surjectivity. Each epimorphism to \(H/Z(H)\) appears once. Apply Theorem 1 to each and add the results. Every epimorphism to \(H\) has exactly one composite with the quotient map, so this counts each epimorphism once.

## 2. Counting with a prescribed commutator map in odd exponent

**Theorem 3.** Suppose \(H\) has class at most two and exponent dividing an odd prime \(p\), and let \(G\) be any finite group. Put
\[
  G_0=G/\langle\gamma_3(G),\ g^p\ (g\in G)\rangle,\qquad
  s=\dim_{\mathbb F_p}G_0',\qquad h=\dim_{\mathbb F_p}H'.
\]
There is a deterministic exact algorithm for \(\#\operatorname{Epi}(G,H)\) running in \(p^{sh}\operatorname{poly}(|G|+|H|)\) bit time. In particular the problem is polynomial in the table sizes for any fixed bound on \(h\). The same holds whenever \(sh\log p=O(\log (|G|+|H|))\).

The target \(H=1\) gives count one, so suppose \(p\le |H|\). The displayed denominator of \(G_0\) is normal and is computed by closing the indicated elements and taking the quotient. Every homomorphism to \(H\) vanishes on it. Composition with the quotient map is a bijection on epimorphisms. We now work with \(G_0\), which has class at most two and exponent dividing \(p\).

For either group, with the convention \([x,y]=x^{-1}y^{-1}xy\), put \(x+y=xy[x,y]^{-1/2}\). The square root is exponentiation by \(2^{-1}\bmod p\) in the central derived subgroup. The commuting rule \(xy=yx[x,y]\) proves commutativity for \(+\). Centrality and \([xy,z]=[x,z][y,z]\) show that either parenthesization of \(x+y+z\) is \(xyz([x,y][x,z][y,z])^{-1/2}\). The resulting additive group has exponent dividing \(p\) and bracket an alternating bilinear map, with scalar multiplication given by powers in the original group. The original group operation is recovered as \(xy=(x+y)+\tfrac12[x,y]\). Consequently homomorphisms are exactly bracket-preserving \(\mathbb F_p\)-linear maps.

Let \(W_S=G_0'\), \(W_T=H'\), and let \(V_S,V_T\) be chosen additive complements to these spaces. Write \(\beta_S:V_S\times V_S\to W_S\), \(\beta_T:V_T\times V_T\to W_T\) for the brackets. A possible epimorphism is uniquely
\[
   (v,w)\longmapsto (Av,bw+cv)
\]
for surjective linear maps \(A:V_S\to V_T\), \(b:W_S\to W_T\) and a linear map \(c:V_S\to W_T\). It is an epimorphism exactly when \(b\beta_S(v,v')=\beta_T(Av,Av')\) for all \(v,v'\). Indeed an epimorphism induces surjections on the derived subgroup and abelianization, and conversely the block formula with both surjections is onto. Preservation of brackets is independent of \(c\), since \(W_T\) is central.

Enumerate the at most \(p^{sh}\) possible \(b\) and discard the nonsurjective ones. Fix one of those remaining. Set \(\alpha=b\beta_S\) and \(\tau=\beta_T\). Let \(R_S,R_T\) be their radicals, meaning the vectors that bracket to zero with every vector. If \(A\) is onto and preserves these two brackets, then \(A^{-1}(R_T)=R_S\). In fact, \(A v\in R_T\) implies \(\alpha(v,-)=0\), and the reverse implication follows by applying the equation to preimages of all vectors of \(V_T\). In particular \(A(R_S)=R_T\). The induced map \(V_S/R_S\to V_T/R_T\) is an isometry of the two nondegenerate \(W_T\)-valued alternating forms, where nondegenerate means their common radical is zero.

Conversely, fix a splitting of each radical inclusion. Choose an isometry on the radical quotients, a surjection on the radicals, and an arbitrary linear map from the source complement to \(R_T\). These three maps give a unique onto \(A\) by the resulting block formula. Since bracket values factor through the quotients, the unique \(A\) obeys the bracket equation. If the quotient dimensions agree and are \(u\), write \(r_S=\dim R_S\), \(r_T=\dim R_T\), and let \(I_b\) be the number of quotient isometries. The contribution of this \(b\) is therefore
\[
 p^{h\dim V_S}\, I_b\, p^{ur_T}
 \prod_{j=0}^{r_T-1}(p^{r_S}-p^j).
\]
Treat unlike quotient dimensions and \(r_S<r_T\) as contribution zero. The product counts full-row-rank \(r_T\)-by-\(r_S\) matrices by successively choosing independent rows. The two powers of \(p\) count the free \(c\) and the complement-to-radical map. The empty quotient causes no complication, with its isometry count equal to one.

Choose a basis of \(W_T\) to express the bracket on each quotient as an ordered tuple of alternating matrices. Ivanyos and Qiao's Theorem 7(1) decides if there is a simultaneous isometry in a deterministic time polynomial in the dimension, tuple size and \(p\). If there is an isometry, their set is a coset of the simultaneous isometry group of the target tuple. Brooksbank and Wilson's Theorem 1.2 and Remark 2.1 give generators for this group in a deterministic time polynomial in the same parameters. It acts faithfully on the \(p^u\) elements of the target quotient, with \(p^u\le |H|\), so one may explicitly write its generating permutations and use deterministic permutation-group order computation. This gives \(I_b\) in polynomial time in the raw table sizes. Here the running times polynomial in \(p\) and in the point-action degree are justified by the Cayley-table model. [Ivanyos–Qiao, Theorem 7](https://arxiv.org/abs/1708.03495) · [Brooksbank–Wilson, Theorem 1.2 and Remark 2.1](https://doi.org/10.1090/S0002-9947-2011-05388-2)

All vector spaces, complements and brackets can be constructed by choosing additive bases and using the original tables. Every count uses at most polynomially many bits, because an epimorphism is determined by the images of a greedy generating list. Summing the displayed integer over all \(b\) proves the time bound and counts every epimorphism exactly once. For a fixed bound on \(h\), the enumeration bound satisfies \(p^{sh}=|G_0'|^h\le |G|^h\).

## Relationship to previous results

Theorem 1 takes the usual description of homomorphism lifts using a section and a cocycle and adds an exact surjectivity filter based on ordered, nested column spaces. Theorem 3 uses ordered-tuple isometry algorithms after fixing the map on the derived subgroup and accounts for all radical and section choices. It extends the target regime permitted by the formula for single alternating forms, and it places no class-two or exponent promise on the original source. Neither running time establishes a polynomial-time count for all finite groups. [Matei–Suciu, Counting homomorphisms onto finite solvable groups](https://bpb-us-e1.wpmucdn.com/sites.northeastern.edu/dist/0/2652/files/2023/04/Quotients.pdf)
