# Matrix hitting for branching programs with bounded-product-depth labels

## GP-0694

Over $\mathbb Q$, take an acyclic noncommutative branching program whose edge labels are supplied by division-free noncommutative arithmetic circuits. If their product depth is bounded by a fixed $h$ and size counts wires, there is a deterministic matrix identity test with polynomial bit cost. The same guarantee applies to binary-fan-in labels of arbitrary product depth and total depth logarithmic in their size. The test evaluates each original succinct label circuit directly on the fixed query matrices. It does not construct the expanded branching program.

### An implicit state bound

For the bounded-product-depth case introduce a separate source for each product gate, variable input, or scalar input in a label circuit. A gate reachable through additions alone computes a linear combination of these sources, where a source is counted only at its first encounter on a path back through the addition gates. This follows by induction on the addition gates. There are at most $s$ terms for a circuit of wire size at most $s$. The coefficients are sums over paths of products of scalar weights, allowing weighted addition lines. With rational edge weights, put these path products over the product of all edge denominators. The path length is at most $s$, each path uses each edge at most once, and the number of paths is at most $2^s$. Consequently these linear combination coefficients have polynomial bit length in the circuit description.

Expand these collapsed addition gates only for the purpose of bounding formula size. A product gate has at most $s$ children, and following any child through addition gates introduces at most $s$ first sources. There are at most $h$ levels of product gates. The resulting formula has at most $(2s)^{2h+3}$ vertices, with rational coefficients of polynomial bit length. For binary-fan-in logarithmic total depth one can instead unfold the original label directly into the binary tree of depth $O(\log s)$, also of polynomial size.

Every noncommutative formula of size $F$ has a branching program with at most $O(F)$ vertices and affine-linear labels. A scalar or variable is one edge. Addition joins disjoint subprograms in parallel, and ordered multiplication joins them in series in the order of the factors. In each case the path-sum identity proves correctness. Use a separate copy for each original edge and splice it between that edge's endpoints. Thus the result polynomial has an ordinary noncommutative ABP of size $S$ bounded by a polynomial in the full supplied description when $h$ is fixed, even if the outer program shares vertices among many paths.

### Testing the succinct input

Use the explicit single matrix tuple for an $S$-vertex affine-linear ABP over $\mathbb Q$. The theorem supplies integral entries of polynomial bit length and polynomial matrix order, with the guarantee that every nonzero output of the stated ABP bound has a nonzero evaluation. The size bound depends only on the supplied input sizes and depth limits. On that tuple evaluate every succinct label circuit exactly by ordinary matrix addition and ordered matrix multiplication. Evaluate the outer ABP by acyclic path-sum recurrence with matrix labels. The returned matrix is the ordinary polynomial evaluation and zero precisely for identities. [Explicit matrix hitting theorem](https://arxiv.org/html/2610.37677#S1)

The computations at every label gate have polynomial bit length. Its implicit expansion has polynomially many formula vertices, so each scalar product contributing to an entry uses polynomially many rational coefficients of polynomial bit length and the logarithm of the number of summands is polynomial. A common denominator is a polynomially bounded power of the product of the input denominators. The outer recurrence combines such label evaluations along acyclic paths of polynomial length, and the same estimates apply. This gives the bit cost using the supplied DAG throughout.
