# An exact floating-point cycle for steepest-descent residuals

[Simons Workshop Problem 2.15](https://arxiv.org/html/2602.05394v3#S2) asks for sufficient conditions or examples where updated residuals in conjugate gradient or steepest descent fail to drop below machine precision. In binary64 round-to-nearest ties-to-even, standard steepest descent with the recursive residual has a period-two residual of constant norm, starting from an exactly specified 2 × 2 positive definite diagonal system.

Use A=diag(1,2^(-60)), x₀=0, and b=(1,1). At step k let p_k=r_k, compute α_k=(r_kᵀr_k)/(r_kᵀ A r_k) by ordinary dot products, and update both x and r with the standard recurrences, using separate rounded operations. If r_k=((-1)^k,1), the matrix-vector product and the dot-product summands are individually exact. The numerator is exactly 2. The denominator 1+2^(-60) rounds to 1, so α_k is exactly 2. The first residual coordinate becomes exactly (-1)^(k+1). The exact second coordinate before rounding is 1−2^(-59), which rounds back to 1 since the predecessor of 1 is 1−2^(-53). Thus the displayed cycle holds for every k by induction. The resulting residual norm remains √2, equal to its initial value. No overflow, underflow or tie occurs in these residual operations. Using fused multiply-add in the update gives the same values.

The same phenomenon holds in binary precision p if the format represents 2^(-p−3) and its double normally, by using that diagonal entry in place of 2^(-60). The perturbation below 1 remains closer to 1 than to its predecessor. The example concerns the recursively updated residual in the stated implementation.
