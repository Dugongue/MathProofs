# Ordinary subgraph circuits and the parameterized clique polynomial

**Theorem (over the complex numbers).** The following are equivalent for ordinary nonuniform arithmetic circuits.

1. The bound in the ordinary-circuit reading of Grochow–Urisman Question 1.11 holds for every pattern $H$, with size $f(H)n^{O(\mathrm{tw}(H))}$ and an absolute exponent constant.
2. For some function $g$ and constant $c$, every symbolic simple-path polynomial of length $m$ has circuits of size at most $g(m)n^c$.
3. The same bound holds for symbolic matchings of size $m$.
4. $\mathrm{VFPT}=\mathrm{VW}[1]$.

Here $n$ is the number of host vertices. Polynomially changing the host-size parameter preserves the assertion. The polynomial $S_H$ is the sum of distinct relabelings of the edge monomial, each with coefficient one. Patterns are supported on their nonisolated vertices and can be padded by isolates to the host size. The empty monomial is constant. The paper places “symmetric” in parentheses in the numbered question and motivates it specifically for symmetric circuits. The theorem here treats its ordinary-circuit reading. The symmetric version already has a negative answer from the hereditary-treewidth bounds. [Grochow–Urisman, §§1.3 and 3.3](https://arxiv.org/html/2606.26244v2#S1.SS3) · [Earlier MathProofs symmetric proof](https://github.com/Dugongue/MathProofs/tree/main/SymmetricSubgraphCircuits)

**From clique to all patterns.** Bläser and Engels prove that parameterized clique is complete for $\mathrm{VW}[1]$ under fixed-parameter circuit-oracle reductions. Its summands have a variable for each chosen vertex and each chosen edge. Under equality in item 4 it has circuits of size $a(k)n^c$. For $h$ pattern vertices make $h$ parts, each a copy of the $n$ host vertices. Use the size-$h$ clique polynomial. Set vertex weights to one. Give within-part edges and edges joining copies of the same host vertex weight zero. For distinct parts and distinct host indices $u,v$, use $x_{uv}$ if the parts are adjacent in $H$ and one otherwise (use the appropriate power for an edge multiplicity). Surviving terms are exactly the injections. Divide by the automorphism-group order of the pattern on its support to obtain the orbit sum. Computing the substituted weights costs at most $f(H)n^2$. This proves the stronger bound $b(H)n^{O(1)}$ for all patterns. Since paths and matchings have treewidth one, item 1 implies both 2 and 3. [Bläser–Engels, Example 4.4 and Theorem 7.22](https://arxiv.org/abs/1907.12287)

**Matchings suffice.** Restrict the matching polynomial on $2n$ vertices to the complete bipartite graph with two parts of size $n$, by setting all within-part edge variables to zero. The result is the weighted partial matching permanent (one monomial per matching). Parameterized hardness of these bipartite matching polynomials under circuit-oracle reductions is known. Replacing each oracle gate by its circuit preserves fixed-parameter tractability. [Curticapean, §2.3, including the relation to the partial permanent](https://arxiv.org/abs/2102.04340)

**Connected paths suffice.** We give the reduction since a path has neither disconnected components nor high-degree vertices. To compute the vertex- and edge-weighted $k$-clique polynomial, first let $r=k$ for odd $k\ge3$. For even $k\ge2$, let $r=k+1$ and give the last color just one new dummy vertex. All other colors have an independent copy of $[n]$. Set $m=\binom r2$. The cases $k=0,1$ have elementary circuits.

For color $i$, replace each of its base vertices by $t_i$ clones. Within a color disallow edges. Between ordinary colors disallow equal base indices and give every other edge weight $X_{uv}$. Edges to the dummy have weight one. To include vertex variables, designate one incident color pair for each ordinary color $i$. Multiply the weight of an edge of that pair by the vertex variable at its color-$i$ endpoint. Both endpoints may designate the same pair.

Evaluate the undirected simple-path polynomial with $m$ edges on this host. By inclusion–exclusion over subsets of the $m$ color pairs, retain just paths using every pair. Each pair then occurs exactly once. Temporarily count oriented paths, twice the unoriented sum. Their color sequences are exactly the oriented Euler traversals of the complete graph on the $r$ colors. This graph has such a traversal since $r$ is odd. The two endpoints of the host path are distinct even though its color sequence returns to its starting color.

Fix a traversal and a choice of base vertex for every position. If base vertex $v$ in color $i$ occurs at $d_{iv}$ positions, the number of lifts to simple host paths is

$$\prod_{i,v}(t_i)_{d_{iv}},\qquad (t)_d=t(t-1)\cdots(t-d+1).$$

For $d>0$ the constant coefficient of $(t)_d$ is zero and its linear coefficient is $(-1)^{d-1}(d-1)!$. Extract the coefficient of $t_1\cdots t_r$. It keeps exactly one base vertex per color. Every pair of ordinary colors occurs, so the chosen ordinary vertices are distinct. Their weight is precisely the clique monomial, including each chosen vertex variable once. For a traversal with $d_i$ positions in color $i$, the coefficient is $(-1)^{m+1-r}\prod_i(d_i-1)!$. All traversals have the same sign. Hence the resulting polynomial is a nonzero scalar times the clique polynomial. The scalar depends only on $k$ and includes the $k!$ orders of ordinary vertices and the orientation factor.

The degree in each $t_i$ is at most $m+1$. Interpolate at the integers $0,\ldots,m+1$ independently. The inclusion–exclusion and interpolation need only a parameter-dependent number of oracle calls on hosts of size $O(r(m+1)(n+1))$. Scalar normalization is valid in characteristic zero. Thus item 2 puts clique in $\mathrm{VFPT}$, which proves item 4. This is a symbolic reduction; arbitrary complex circuit constants and nonconstructible parameter-only size factors are allowed on both sides.

**Consequence.** Bläser–Engels Theorem 6.4 gives $\mathrm{VFPT}\ne\mathrm{VW}[1]\Rightarrow\mathrm{VP}\ne\mathrm{VNP}$. Thus a negative answer even for paths would separate classical VP from VNP. Equivalence to the *classical* separation is not established. Numeric parameterized path-counting hardness predates this argument, as does related work on symbolic homomorphism polynomials. Priority for the exact path formulation and its connection to Question 1.11 has not been established. [Bläser–Engels](https://arxiv.org/abs/1907.12287) · [Flum–Grohe](https://doi.org/10.1137/S0097539703427203) · [Related symbolic lower bounds](https://arxiv.org/abs/2601.09343)
