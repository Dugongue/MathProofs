# New sufficient reductions for four determinant comparisons

We use deterministic polynomial-time many-one reductions over the field of three elements for the ordered tensor problems. The following are informal proofs on recognizable input families. Each single-instance construction decides the exact signed predicate on its allowed inputs.

| Target | Proven sufficient reduction |
| --- | --- |
| Marked Cayley-table group parity to ordinary TI | For each active color, recover a 3-group of intrinsic conjugations or left-right translations, then compile the action's orbit signs and the permutation of its orbits. Logarithmically many orbits per active color suffice, with arbitrary orbit size and an arbitrary ambient group. In particular a single marked conjugacy class in a 3-group gives one ordinary TI instance. Arbitrarily many regular orbits of a noncyclic 2-group also suffice. [Odd-size orbits](CayleyOrbits.md) · [Regular even-size orbits](CayleyRegularOrbits.md) |
| Marked graph parity to ordinary TI | A polynomial bound on the local parity compiler per connected component suffices, with arbitrary numbers of components and arbitrary overall marked color lengths. The construction uses one ordinary GI instance without determining an isomorphism type or a matching. It also treats a fixed number of simultaneous parity equations. [Proof](GraphComponents.md) |
| Marked subspace parity to marked ternary-code parity | Small intersections among subspaces and annihilators may generate the required data separately in each computed indecomposable summand. The output code synchronizes the label permutation across all summands. This works for some indecomposable arrangements whose subspaces all have dimension and codimension growing linearly with the ambient dimension. Pairwise complementary half-dimensional subspaces also have a compiler when a normalized slope algebra is commutative semisimple in every chart or is generated in some chart by a fixed number of actual slopes. [Intersections](IntersectionCodes.md) · [Spreads](SpreadCodes.md) |
| One-sign TI with an independent odd-automorphism test to one-sign TI | Exact odd-automorphism criterion for raw multiplication tensors of associative algebras with square-zero radical. It yields a single unrestricted one-sign query if either the independent self-comparison or the relative pair belongs to this family. In contrast, the entire odd-automorphism degree already occurs on local multiplication with radical cube zero. [Proof](OddAutomorphisms.md) |

The first three comparisons can retain the independently supplied ordinary TI requirement by ordinary conjunction. In the fourth comparison either input can be unrestricted when the other meets the square-zero multiplication hypothesis. The four general reverse reductions on their unrestricted whole input classes remain open in this packet. The [component control](check_components.py) checks the new disconnected parity assembly against the full matching search on 2,240 finite cases. Mathematical correctness for arbitrary sizes comes from the proofs.
