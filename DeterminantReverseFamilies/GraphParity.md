# Removing parity constraints from graph comparisons with logarithmic color classes

Consider ordered, vertex-colored finite graphs. A marked set is a union of color classes, and the order on its vertices is inherited from the displayed vertex order. A parity bit is the parity of a color-preserving isomorphism on such a set, using the two displayed orders. Isomorphisms between different pairs are independent. Some pairs may be self-comparisons and therefore ask for automorphism parities.

Given a polynomial number of explicit graph pairs and any explicit binary linear system in their marked-set parity bits, ask whether there is a transporter for every pair such that the linear system holds. A variable used for a particular pair represents the same transporter wherever it occurs. Separate copies of a pair can instead select independent transporters.

**Theorem.** This problem reduces to one ordinary graph-isomorphism query in polynomial time when each color class used in the parity equations has size at most C log L, where L is the full written input length and C is fixed. The graph degrees, number of colors, number of comparisons and sizes of unmarked color classes are unrestricted. The graph encoding preserves every feasible list of permutations of the old vertices. This includes the graph variants of the relative determinant tests, the stabilizer corrections by operator spaces, and the fixed conjunction rungs. It also applies to graph-input graphic-matroid versions after the earlier marked edge-action reduction.

## One orientation graph for one color class

Let X be a color class of s vertices. For each subset U of X add one subset vertex, adjacent to its members among the original vertices. Give it a new color recording the old color of X and the cardinality of U. Under every isomorphism extending an original permutation p, its image is the unique subset vertex for p(U). Add two orientation vertices (U,0) and (U,1), both adjacent to the subset vertex, in a further palette recording the class and cardinality. They can in principle be interchanged. Give the two vertices for U empty distinct colors, so that their swap is zero.

For every inclusion U⊂W with W=U∪{i}, connect the two orientation pairs by a matching: (U,b) meets (W,b+e), where e is the parity of the number of elements of U after i in the displayed order. The displayed order on U followed by i has orientation e relative to the displayed order on W. No edges of this type join nonnested pairs. Cardinality colors distinguish the two sides of the matching even if graphs have other edges. The original graph edges and all gadget types have disjoint vertex palettes, so the construction adds no ambiguity about which old adjacency is being checked.

Suppose a candidate graph isomorphism induces p on X and has orientation swap bits d_U and d_W. Preservation of this matching is exactly

    d_W = d_U + e(source U,i) + e(target p(U),p(i)).

The right side is the formula for the parity of p on W in its displayed orders when d_U is the parity on U. The empty pin therefore forces d_U for every U to equal the parity on that subset. The assignments satisfy all matchings simultaneously, because the parity formula holds on every inclusion. Thus every old permutation lifts uniquely on the orientation vertices, and its swap on the top pair (X,0),(X,1) is its parity on X. The construction uses O(s 2^s) vertices and edges, including all memberships and matchings.

## Combining colors and equations

For a union of colors, fix a common order on those color names. The parity on the union equals the sum of the class parities plus a constant, namely the two signs for changing the displayed marked orders into class-concatenated orders. These constants are explicitly computable from the input and are absorbed into the right sides of the binary equations. Reject any mismatch of color-class cardinalities in the two endpoints, since a transporter would preserve them.

Take disjoint copies of the old comparisons and their orientation gadgets, each with a distinct palette. The top pair for a color class gives exactly one bit, the swap of that pair. For each equation make a chain of auxiliary two-vertex state pairs, with separate colors for the different state positions. Each step enforces that the incoming state bit plus one required top-pair bit equals the outgoing state bit. Its graph encoding has one record for each of the four triples satisfying the XOR relation. Connect a record to the three selected vertices of the pairs via separate slot-colored ports. Translation by a triple of swap bits preserves the relation if and only if their sum is zero. Fix the initial state's swap to zero and the terminal state's swap to the right side of the equation by individually coloring the two vertices in each endpoint, with opposite orders for a forced swap of one. Use a fresh palette for each constraint and step. An equation with no terms is checked directly. Any shared top pair is used as the same two vertices in all its equations.

The original graphs can only match their corresponding copies. Their possible lifts to the orientation graphs have precisely the class parities established above. For each equation a lift extends to its state pairs and record vertices if and only if the equation holds, by the prefix-sum recurrence. Every compiled graph isomorphism therefore decodes to exactly the desired list of witnesses. The size of the output is polynomial under the displayed logarithmic bound. Vertex colors are removed by the standard many-one reduction from colored to uncolored GI, which is enough because the final instance has no parity constraints.

To see explicitly how this applies to sign-profile comparisons, give a graph relative pair one copy for a relative witness and a separate self-copy for each independently chosen stabilizer correction. A prescribed linear combination of their sign vectors is then an equation of the displayed form. Several such equations can share their relative witness or use separate relative copies, as the original predicate specifies. A requirement that a sign be attainable with a correction allowed precisely when a certain character is nonzero on the stabilizer can be expressed with one independently chosen self-isomorphism and a single equation. Identity supplies the zero correction. This covers the graph versions of the previously defined correction problems without supplying any generator or transporter.

## Enlarging the recognized domain

One can first refine colors jointly on the disjoint union of each comparison pair. Use canonical color refinement: split each existing class by its counts of neighbors in each current color. Use a shared name for each resulting color. An original colored isomorphism always respects every refinement round, so the induced parity profiles are unchanged. Every old marked set remains a union of refined colors. The size bound can be tested after refinement.

A further extension allows a fixed number k of anchored source vertices per pair. For a single comparison, choose k vertices deterministically from the source. If refinement after individualizing these vertices satisfies the bound, enumerate every ordered target image of those k positions, assign aligned singleton colors, and run joint refinement. Every transporter occurs in one of these branches. Branches with incompatible refined class sizes have no witnesses. For comparisons with one shared system of constraints on a constant number of pairs one can enumerate the joint choices in polynomial time too. If a polynomial number of pairs are present the direct joint enumeration is valid when the total number of anchors used is constant.

The resulting polynomial list of ordinary GI queries is converted to one GI query by polynomial disjunction. For two pairs (G,H) and (K,L), make the unordered pair of ordered objects ((G,K),(H,L)) on one side, and ((G,L),(H,K)) on the other. Ordered pairs and unordered pairs are encoded by a bounded number of colored root and slot nodes with disjoint palettes for their roles. The two structures match exactly when G is isomorphic to H or K is isomorphic to L. Balanced recursion keeps the size polynomial since each level introduces only a fixed multiplicative factor. This is an actual many-one OR operation, and it is used only after complying with the orientation size cutoff in every surviving branch.

There is also an elementary way to delete irrelevant live colors before the size test. A pair of vertices with identical neighborhoods outside that pair can be swapped by an automorphism. If the vertices have the same color, this changes only its color-class parity and none of the others. In a parity equation system, each such swap contributes the coefficient vector of that color in the equation space. Let K be the span of these certified contributions, taking independent copies for independently selected transporters or automorphisms. In every ordinary transport fiber these changes are freely available by composing with source automorphisms. Testing the original equation is thus equivalent to testing its image in the quotient by K. In coordinates, multiply the equation matrix and right side by a linear map with kernel K. Only the color columns that remain nonzero require orientation gadgets. This can remove large color classes with evident automorphism slack without making any assumption about the other classes.

## Location relative to graph and tensor isomorphism

The marked graph-equivalence problem is GI-hard under deterministic polynomial-time many-one reductions by using the empty mark. Even with unbounded marked classes it is polynomial-time Turing equivalent to GI. Standard individualization with GI calls finds a transporter or detects emptiness and obtains generators of the source automorphism group by a pointwise-stabilizer chain. At each level, for every candidate image of the next unfixed vertex, a colored GI call checks feasibility and ordinary search recovers one witness for each possible image. Together with the next level's pointwise-stabilizer generators, these witnesses generate the current pointwise stabilizer via its cosets. Reading a sign on the initial transporter and restricting the sign homomorphism to these generators gives exactly the obtainable signs. With finitely many marked sets or linear equations, their entire joint affine sign image is obtained by binary linear algebra, keeping all correlations for each copy. This procedure uses polynomially many GI calls; the orientation construction above gives a single query under its stated width promises. The ordinary marked graph-equivalence problem without those promises continues to sit below the one-sign tensor comparison via the earlier code and tensor-system constructions.

The graph-input graphic-matroid reduction supplied earlier preserves the action on every marked edge, so the theorem also applies when the resulting marked real-edge colors satisfy the size bound, possibly after refinement. The proofs here are informal.
