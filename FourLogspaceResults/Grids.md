# A treewidth boundary for choosing a common constraint solution

Fix a finite set of labels and a finite library of unary and binary constraints on them. A network is an explicitly numbered finite simple graph with a list of such constraints on its vertices and ordered adjacent pairs. Its underlying graph is part of the instance. Given the network and any satisfying assignment, a normalizer must return a satisfying assignment that depends only on the network. Two differently numbered networks may receive different answers. FL denotes deterministic logarithmic work space with a read-only input and a write-only output.

**Theorem.** There is a single fixed library with the following property for every fixed minor-closed class of underlying graphs. On bounded-treewidth classes an FL normalizer exists, even if the supplied assignment is discarded. This direction holds for every fixed library. On an unbounded-treewidth class, normalizing the solutions for the one library is equivalent, under deterministic logspace witness transformations, to normalizing all equal-length fibers of FL functions. Square grids already suffice, with a bijection between each source fiber and all solutions to the resulting grid. The equivalence also holds with FP in place of FL and polynomial-time witness transformations.

An equal-length fiber for a fixed total function f consists of all n-bit words z with f(z) = y. Its normalizer takes x and returns some z in the same fiber, consistently for all such x. The theorem gives a completeness classification. It leaves open whether all these fibers have logspace normalizers.

## Bounded treewidth

Compute a rooted tree decomposition of fixed width in logarithmic space. At each bag enumerate its finitely many assignments, with vertices sorted by their input indices. Call an assignment feasible if it extends to the vertices covered below the bag and respects every constraint assigned there. Assign each constraint to the highest bag containing its arguments. Such a bag exists and is unique by the subtree-intersection property of decompositions.

Feasibility for a specified bag and assignment is an L test: present the graph and constraints covered below that bag, with the finitely many additional unary pins, to logspace bounded-treewidth MSO model checking. The derived input can be streamed or regenerated in logspace by scanning bags and testing descent in the decomposition. The fixed existential formula guesses a partition into label sets and checks the relations. Directed or multiple constraint types are a fixed relational vocabulary. Decomposition and model checking use the results of Elberfeld, Jakoby and Tantau. [Logspace versions of the theorems of Bodlaender and Courcelle](https://eccc.weizmann.ac.il/report/2010/062/)

At the root choose the first feasible assignment. At each child choose the first feasible assignment agreeing with the parent on their intersection. Feasibility of the parent guarantees such a child assignment. Two child subtrees can share a vertex only in the parent bag, so the choices can be glued independently. To print a vertex label, find its highest bag, replay just the path from the root, then read the chosen label there. Keep the current bag, its constant-size label tuple, and indices into the virtual decomposition. The same choices are reconstructed for every vertex, independently of the supplied witness. An empty network has the empty assignment.

## Encoding an entire fiber on a square grid

Use a topologically numbered Boolean circuit with m gates, fan-in at most two, including input gates, constants, and one designated acceptance gate. The graph is an m by m grid. Use one row per gate and one column per gate. A vertical wire carries one bit. A horizontal bus carries two bits. A cell label records the input and output on both wires. Use just two fixed binary relations, one matching horizontal output to the next horizontal input and one matching vertical output to the next vertical input. A fixed finite set of unary masks determines local operations and boundary pins. The alphabet consists only of the six port bits; no auxiliary label can vary independently.

Start every vertical wire and every row bus at zero. At column j of row i, if gate j is the first or second predecessor of i, overwrite the indicated bus bit with the incoming vertical bit; if both, overwrite both. These cells pass the vertical bit straight through. At diagonal cell (i,i) replace the vertical bit by the gate output on the two bus bits, or by its fixed constant, or by a free bit for an input gate. All other ports pass through unless specified. Pin the acceptance output to one. All intersecting masks can be taken as one mask, since the alphabet is fixed. In row i all predecessors lie strictly to the left of the diagonal, so the bus is ready at the gate. The left and top boundary conditions and gate relations determine all ports in row-major order once the input bits are chosen. Reading the free diagonal bits is the inverse. This proves a bijection, including repeated predecessors and arbitrary fan-out.

For a fixed FL function f, form a circuit accepting z exactly when |z| = n and f(z) = y. The circuit, and hence the grid network, depends only on (n,y). Computing it and lifting the supplied x to its particular satisfying grid assignment must *both* take logspace. Here are the uniformity details.

Use the fixed logspace decider comparing the transducer output on z to y online, checking its length at the end. It runs for a fixed polynomial number of steps on inputs of lengths n and |y|, with a frozen halting state. Unroll its configurations into a polynomial-size circuit. Each layer stores O(log(n+|y|+2)) bits for tape, state and head addresses. Bit selection at a read-only address is an equality-and-OR multiplexer over input positions; a write step updates the individually indexed work cells. These elementary transition circuits can be generated with gate and time counters in logspace. On the particular x, each gate value can also be computed in logspace: simulate to that layer, retain the preceding configuration and evaluate the designated local bit, address comparison or interval of the multiplexer. Output y is available on demand by replay of f(x). Values of binary OR subtrees are obtained by scanning their explicitly indexed intervals. No general circuit-value oracle is used. Vertical and bus values at any grid cell now follow from its row, column, the predecessor indices and the values of the indicated gates. Thus the supplied grid witness as well as the grid is produced in FL. Decode any normalized grid by reading its input gate outputs. Every x in a fiber uses the identical grid network, so the answers agree. For FP, the same construction uses the usual unrolled polynomial-time computation and evaluates its gates in polynomial time.

Every minor-closed class of unbounded treewidth contains each square grid as a member, by the excluded-grid theorem. The reduction constructs the grid directly and requires no grid-minor algorithm. [Robertson and Seymour, Graph Minors V](https://www.sciencedirect.com/science/article/pii/0095895686900304)

Conversely, use a uniquely decodable input encoding with exactly one fixed-width code per vertex label. Define a total FL function on encoded pairs by returning a success tag and the network for a valid supplied assignment, and a different tag and the entire input on malformed or unsatisfying pairs. Validation scans the constraints in logspace. All valid assignments of a given encoded network have the same length. A normalizer for this function produces a valid assignment of that identical network, regardless of the class promise. This proves the reverse implication and completes the classification.

This is an informal proof. The decomposition and excluded-grid theorems are prior work. The claimed inference concerns normalization with a supplied witness, including its forward and inverse maps and the work space needed to construct the forward witness. Publication priority for this formulation has not been established.
