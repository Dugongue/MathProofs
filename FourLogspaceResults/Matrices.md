# The space complexity of rank-one coordinate completion

An informal proof. Fix a finite field $F$ of order $q$. An input specifies positive dimensions, a list of coordinate observations, and their values. Use unary dimensions and a fixed tensor order, so the dense output has polynomial length. A completion must have rank exactly one. Coordinates have the usual lexicographic order, and field elements have a fixed order beginning with zero and one.

**Theorem.** For matrices, the lexicographically first rank-one completion, or a report of infeasibility, is computable in deterministic logspace over every fixed finite field. For order three over $q>2$, coordinate feasibility is complete for $\mathrm{coMod}_{q-1}\mathrm{L}$ under deterministic logspace many-one reductions. This hardness persists for deciding whether the first coordinate can equal one when a complete feasible tensor is supplied and every completion has full support. Over the three-element field, producing the lexicographically first completion is complete for FL with a parity-logspace oracle under deterministic logspace oracle reductions. In particular, a deterministic logspace algorithm for it exists exactly if L equals parity logspace. The classification concerns labeled-coordinate completion.

### Removing zero factors

Call an index forced if it occurs in a nonzero observation. If there is a nonzero observation, all forced factors must be nonzero. Setting every unforced factor to zero in any completion preserves all observations and can only decrease the output lexicographically. A zero observation with all indices forced precludes a solution. Otherwise it suffices to solve the nonzero observations on the forced indices. If all observations are zero, the last unobserved cell carrying one and all other cells zero is the lexicographically first completion whenever an unobserved cell exists. All these preliminary tests are deterministic logspace scans. Over the two-element field the forced support also prescribes every nonzero entry, at any fixed tensor order.

### Matrices

Make a bipartite graph on forced row and column indices. An observed value $m$ imposes $xy=m$ on the endpoint factors. Lift each vertex to one copy for every nonzero field element and lift each edge to the matching $a\leftrightarrow m/a$. Normalize the least vertex in each connected component to one, using reciprocal scalings on its two sides. A consistent labeling exists exactly when the component of the normalized lift reaches precisely one lift of each base vertex. Every base path lifts, and unique reachable labels obey every edge equation. Reingold's deterministic logspace undirected connectivity algorithm implements these tests on the implicit graph.

To select the lexicographically first completion, scan the complete bipartite product of the forced supports in entry order. Whenever the two endpoints of a new cell were disconnected, append the constraint that its value is one. Its value was free by independent component rescaling, so the constraint is feasible and lexicographically optimal. For a connected pair its value is already fixed by an alternating path. For the disconnectivity test, the underlying graph consists of the original observation edges together with *all* earlier support cells. Including a skipped edge leaves the components unchanged. Thus the selection of every new constraint is a logspace predicate on its index. Run the lifted-graph solver on the implicitly augmented graph, recomputing each adjacency as needed. The composition of these fixed-depth deterministic logspace computations uses logarithmic space. The product of the recovered row and column labels gives each requested output entry.

### A single congruence system is sufficient

Let $k=q-1>1$ and fix a generator of the multiplicative group. On forced factors introduce their exponents in the ring of residues modulo $k$. A nonzero observation becomes a linear equation whose left side is the sum of its factor exponents. Together with the zero tests this yields a deterministic logspace many-one reduction to linear congruence feasibility $\mathrm{LCON}_k$. A preliminary rejection or acceptance can be emitted as a constant no or yes system. An extra coordinate requirement can simply be appended.

### A single coordinate realizes modular feasibility

Start with $Ax=b$ over residues modulo $k$. Homogenize to $Ax+hb=0$. Feasibility of the original system says exactly that $h=-1$ is attainable in this homogeneous system. Compile the equations to gates $o=i+j$ with pins of value zero. Every coefficient takes at most $k-1$ additions per variable using an initial zero wire. Pin the final sum of each row, using a fresh output wire even when the row has only one summand. The inputs $x,h$ are free. Gate indices and predecessor indices can be enumerated from row and column counters in logarithmic space.

Give each wire $i$ three indices $r_i,c_i,s_i$, one per mode. Add reference indices $r_*,c_*,s_*$. Initially prescribe one at the reference triple and at both triples $(r_i,c_i,s_*)$ and $(r_i,c_*,s_i)$ of every wire. For a gate prescribe one at $(r_o,c_i,s_j)$. For a pin prescribe one at $(r_i,c_*,s_*)$. Every index now participates in a nonzero measurement. Subtract the reference exponent in each mode from the corresponding factor exponents. The reference exponents sum to zero. The two copy measurements make the normalized exponents on wire $i$ equal to $v_i,-v_i,-v_i$, in that order. The remaining measurements are precisely the additions and zero pins. Conversely any solution of those additions and pins extends to a tensor with reference factors one.

Put $r_h,c_*,s_*$ first in their respective index orders. Multiply the entire row $r_h$ by a fixed generator of the field units, including its measured entries. This gives a bijection between old and new completions. A specific feasible tensor is now available for free. It is one everywhere except on the indicated row where it is the generator. In an arbitrary completion the new first entry is the generator to the power $1+h$. It equals one exactly when $h=-1$. The construction is computable in logspace, including the explicit dense witness when requested. For ordinary feasibility append the first-entry requirement to the measurements. For the reduction type, every coMod language at modulus $k$ has a uniform polynomial-size time-layered logspace configuration graph with membership equivalent to zero accepting paths modulo $k$. Introduce one variable per vertex, initialize the first layer with a single one at the start, and equate each later variable to the sum of its predecessors with edge multiplicities. Require that the sum at the accepting vertices of the final layer be zero, padding terminated paths uniquely. The recurrence has a unique solution before this last test. This gives deterministic logspace many-one hardness for LCON directly. Its upper bound is de Beaudrap's fixed-modulus theorem.

### The lexicographic upper bound over the three-element field

After the support tests, write the observed signs as $Av=b$ over the two-element field. Every support cell in order has a binary row form $e_j$ on the factor exponents. Mark $j$ when $e_j$ is outside the span of the rows of $A$ and all earlier cell forms. Membership in this span is a linear feasibility query over the two-element field. If the observed system is feasible, the marked forms are jointly independent modulo its row space, so their values can all be set to zero. These zero exponents give the preferred nonzero field value one. Each unmarked form is forced by the observations and earlier cells. This proves the resulting dense tensor is lexicographically least.

For each output bit test feasibility with all marked forms set to zero and the requested form set to zero. Construct its oracle-query tape by streaming the rows and using the span predicate. Equivalently this is a composition of two fixed parity-logspace oracle layers, which collapse by closure of parity logspace under its own oracle. Return an infeasibility flag when required. Conversely the first entry of the constructed occupied instances answers LCON modulo two, as all entries are nonzero. This gives the claimed function-oracle hardness by substituting such a first-entry query for each parity oracle call.

### Sources and status

The exponent equations and the separation of support and multiplicative constraints have substantial prior art in rank-one tensor completion. The contribution presented here is the explicit ternary-coordinate realization and its logspace consequences, including hardness within a supplied feasible fiber. Publication priority for the exact statement has not been established.
