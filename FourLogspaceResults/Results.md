# Four logspace results

These are informal proofs. FL denotes functions computable deterministically with logarithmic work space, a read-only input, and a write-only output. Parity logspace (⊕L) consists of the decisions recognized by the parity of the number of accepting logspace computation paths.

| Problem | Result |
|---|---|
| [Constructive subgroup membership](Groups.md) | For each fixed finitely presented subgroup of a fixed finitely generated residually free group, an FL transducer either rejects an ambient word or writes a canonical expression in the subgroup's generators. This includes intrinsic FL normal forms throughout the finitely presented residually free groups. |
| [Prescribed signs for isomorphisms](Matching.md) | For explicit systems of named partial bijections, deterministic logspace suffices with up to five points per constrained sort. Six points suffice for parity-logspace completeness, even on ordinarily isomorphic pairs with components of at most three points. |
| [Rank-one coordinate completion](Matrices.md) | Lexicographically least matrix completion is in FL over every fixed finite field. In order three over the three-element field, deciding whether one coordinate can equal one is parity-logspace-complete even when the input supplies a full feasible tensor and every possible completion has full support. |
| [Normalizing supplied constraint solutions](Grids.md) | Every fixed finite unary and binary constraint library has an FL solution normalizer on bounded-treewidth hosts. On every unbounded-treewidth minor-closed class a single fixed library on square grids represents the entire equal-length fiber normalization problem for FL functions, with a logspace bijective witness encoding on each source fiber. |

## Exact counting for the signed-isomorphism result

The five-point algorithm computes the exact number of transporters in FL as well. This counts all isomorphisms satisfying the requested signs, treating different bijections as different witnesses.

Use the component types, baseline transporter, and sign matrix A from the signed-isomorphism proof. If ordinary isomorphism or sign feasibility fails, the answer is zero. Otherwise the sign map from the automorphism group of the source has image of size 2 to the power rank(A), and each attainable sign vector has the same number of preimages. If type U has multiplicity m and pointed-image enumeration gives its automorphism group order h, that type contributes a factor of h raised to the power m times m factorial to the total group order. Multiply these factors over types and divide by 2 to the power rank(A).

For at most five points on each constrained sort, A has row weight at most two. Make one variable vertex per column and one distinguished constant vertex. Join the two variables of each binary row and join a singleton-row variable to the constant. The nullity equals the number of connected components disjoint from the constant, including isolated variable vertices: a homogeneous solution is independently constant on exactly these components and zero on the component of the constant. Count the components by recognizing their least vertices using undirected reachability. Subtract from the number of columns to get rank. With unrestricted sort size, the same computation of rank instead counts successive rows outside the span of preceding rows using a parity-logspace decision oracle. The integer product itself has polynomially many bits and polynomially many small factors. Uniform iterated multiplication produces its bits in deterministic logspace, and exact division by the power of two discards trailing bits. Thus the general count is in FL with a parity-logspace oracle, and even its nonzero test is parity-logspace-hard at six points. [Hesse, Allender and Barrington](https://doi.org/10.1006/S0022-0000(02)00025-9)

The case studies address fixed-pair algebraic data complexity, sign constraints on named partial maps, labeled tensor coordinate data, and normalization of witnesses on a fixed numbered network, respectively. They do not establish a separation of L and parity logspace. Publication priority for these exact formulations remains open.
