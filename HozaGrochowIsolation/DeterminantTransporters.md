# Isolating determinant-constrained tensor transporters

Let \(R\) be a finite commutative ring with identity, of order \(q\ge 2\), given by its operation tables. Let \(M_1,M_2,M_3\) be based free modules, each supplied as an ordered direct sum of free blocks. The block labels and their positions in the bases are part of the instance. Write \(d_b\ge 1\) for the rank of block \(b\). Given tensors \(T,S\) in \(M_1\otimes_R M_2\otimes_R M_3\), a transporter is a triple \((g_1,g_2,g_3)\) with \(S=(g_1\otimes g_2\otimes g_3)T\) and each \(g_i\) block diagonal. Its determinant vector is \((\det g_1,\det g_2,\det g_3)\in(R^\times)^3\).

The support hypergraph has one vertex per block and an edge \((b_1,b_2,b_3)\) whenever the corresponding block subtensor is nonzero. If the supports of \(T\) and \(S\) differ, there is no transporter. For common support, suppose a path decomposition is supplied, with each hyperedge entirely contained in some bag and each block occurring on a nonempty interval of bags. Set
\[
 h=\max_{\text{bags }B}\sum_{b\in B}d_b^2,\qquad W=q^{h+3}.
\]
Let \(L\) denote the bit length of the complete input including the decomposition.

**Theorem.** There is an implicit simple layered digraph of width at most \(W\) and length \(O(L)\), with one source and one sink for each determinant vector, such that paths to the sink for \(\lambda\) are in bijection with the transporters of determinant vector \(\lambda\). Its labels and adjacency are computable in deterministic space \(O(\log(L+2)+(h+3)\log q)\). In particular:

1. There is an unconditional deterministic algorithm computing the entire determinant image and all fiber counts in time polynomial in \(L+W\).
2. Hoza's isolation generator gives a single family of \((L+W)^{O(1)}\) polynomially bounded weightings, one of which isolates a minimum transporter simultaneously in every nonempty determinant fiber. The family is generated in space \(O(\log(L+W))\). For each weighting and each determinant fiber there is a univariate polynomial over \(\mathbb Z\) whose coefficients count transporters by weight. For the common isolating weighting, the first nonzero coefficient of every nonempty fiber polynomial is \(1\). It therefore certifies the same nonempty fibers after reduction in every coefficient field.
3. Using Hoza's unambiguous reachability result, a transducer with \(O(\log(L+W))\) workspace and time polynomial in \(L+W\) has exactly one accepting computation. Its output reports the entire determinant image and one canonical transporter for each nonempty fiber, relative to the supplied block order and bases. Prescribing \(\lambda=(1,1,1)\) gives the special-linear variant. In particular, if \((h+3)\log q=O(\log L)\), this is an unambiguous logarithmic-space search and decision result on the stated inputs.

The arithmetic work takes place over the supplied ring, including rings with zero divisors. Neither the graph nor the coefficient argument uses cancellation in \(R\).

## The layered transporter graph

First refine the path decomposition to start and end with an empty bag and introduce or forget a single block at a time. Between two original bags, forget the departing blocks before introducing the arriving ones. Every intervening bag is contained in one of the original bags. Keep a stage at each original bag and assign every tensor block equation to the first original bag containing its three indices. Each block enters and leaves once, so the total number of stages is at most twice the number of blocks plus the number of original bags, up to boundary stages. Repeated or empty bags are allowed. This refinement and the test assignment can be generated by counters and scans of the input. It is also possible to validate the given path decomposition by scans.

A state contains one matrix in \(\operatorname{GL}_{d_b}(R)\) for each live block \(b\), in a fixed block order, and three units \(u_i\). The units are the products of determinants of blocks already forgotten in the respective modes. The start state has no live matrices and has all products one. Introduce edges that choose a matrix for the new block, leaving all other data alone. At a forget step remove the matrix and multiply its determinant into the corresponding \(u_i\). At an original bag, insert an identity transition exactly when all tensor block equations assigned there hold. Such a test reads the three live matrices and checks coefficient by coefficient
\[
 S_{b_1b_2b_3}=(g_{b_1}\otimes g_{b_2}\otimes g_{b_3})T_{b_1b_2b_3}.
\]
For each component absent from the support, both sides are zero. Block-diagonal invertible actions preserve the support since the action on each component is invertible. The final states are the determinant sinks. Given the matrices of a transporter, every state and transition is forced. Conversely a path selects an invertible matrix at each introduction, preserves it until it is forgotten, and passes all the assigned equations. It accumulates precisely the three full determinants. These two operations are inverse. There are no parallel edges: even if different introductions ultimately have the same continuation, the chosen matrices are recorded in distinct states at the new layer.

The matrices and determinant counters need at most \(h+3\) ring symbols at once. For a uniform vertex indexing use all \(q^{h+3}\) digit strings. Pad the given layer's encoding with zero ring symbols only, and leave all noncanonical or invalid strings isolated. Store two state strings while testing an edge. A determinant at a live block can be calculated by enumeration of permutations using \(O(d_b\log(d_b+1))\) additional bits. This fits the stated bound since \(\log q\ge 1\), and the corresponding time is at most \(q^{O(d_b^2)}\). In a commutative ring a square matrix is invertible exactly when its determinant is a unit, by the adjugate identity. Check a unit by scanning the ring table. All coefficient equations are sums of products of three chosen matrix entries and a tensor coefficient, with indices and the accumulator held in the stated workspace.

Exact path counts to all sinks follow by ordinary addition along the layers. A layer has at most \(W\) states, and paths have length \(O(L)\). The count has bit length \(O(L\log(W+1))\), so deterministic dynamic programming is polynomial in \(L+W\). When one transporter \(g\) exists, the set of all transporters is a coset of the block-diagonal stabilizer of \(T\), by composition with \(g\). Because determinant is a group homomorphism, the output support is a coset of the determinant image of that stabilizer. The counts are constant on that coset, with common value equal to the size of the determinant kernel in the stabilizer.

## Isolation and witness output

Apply Hoza's Theorem 1.3 to the common layered digraph, using \(\max(W,2)\) as the width. Each reachable sink is among the endpoint pairs covered by the same good seed. The weight of a transporter is the sum over its internal graph states. For a weight assignment \(\rho\), replace each edge entering an internal state \(v\) by \(t^{\rho(v)}\), and use label \(1\) on the edges into the final layer. At the sink for \(\lambda\), the path polynomial is
\[
 F_\lambda(t)=\sum_{g\mid\det(g)=\lambda}t^{\mathrm{wt}_\rho(g)}.
\]
The path bijection proves this identity over \(\mathbb Z[t]\). Counting unique minima then proves the coefficient statement. These polynomials are computed simultaneously by the same weighted branching program, with one output per determinant vector and polynomially bounded degrees in \(L+W\). This uses the all-endpoint guarantee of the generator. [Hoza, Theorem 1.3 and §2](https://eccc.weizmann.ac.il/report/2026/323/)

Use the first seed whose min-isolation test succeeds. Hoza §1.2 describes the test and its unambiguous yes/no behavior using Reinhardt and Allender. A query on the implicit graph is simulated by computing requested bits of its adjacency encoding on demand. Select a minimum path to each reachable sink as follows. Reachability of a subpath with weight at most \(c\) is in NL in the log of the graph and cost bounds, by storing the current state, layer and running cost. By \(\mathrm{NL}=\mathrm{UL}=\mathrm{coUL}\), both the predicate and its complement have UL recognizers. A machine guesses which one applies, runs it, and emits a yes/no value only on its accepting branch. Find the least feasible \(c\) by bounded scans, then advance by testing successors for a continuation with that budget and updating the remaining cost. Use consistent endpoint weight conventions for the running cost. The chosen seed's minimum path is unique. At each introduction emit its matrix before discarding the state. Every query has exactly one branch returning a value. Thus the full computation has exactly one accepting branch, with the usual transducer convention that rejected computations have no output value. All loops have bounds polynomial in \(L+W\). All unit triples can be enumerated with three counters. This yields the entire list of fibers and witnesses with no stored adjacency matrix or dynamic programming table. [Hoza, Theorem 1.1 and §1.2](https://eccc.weizmann.ac.il/report/2026/323/) · [Reinhardt and Allender, Making Nondeterminism Unambiguous](https://doi.org/10.1137/S0097539798339041)

One can instead output the lexicographically least sequence of introduced matrices in each fiber. At an introduction test candidates in order and take the first successor that reaches the required sink. Once an introduction has been made, the present state remembers exactly the data needed for the suffix. The same unambiguous reachability and sequential composition argument gives the space and time bounds. The canonical output here depends on the ordered input presentation.

## A family with growing mode ranks

For \(m\) links take blocks \(U_0,\ldots,U_m\) in the first mode and \(V_0,\ldots,V_{m-1}\) and \(W_0,\ldots,W_{m-1}\) in the other modes. Edge slots are \((U_i,V_i,W_i)\) and \((U_{i+1},V_i,W_i)\) for \(0\le i<m\), with arbitrary local tensors. Consecutive bags \(\{U_i,U_{i+1},V_i,W_i\}\) satisfy the decomposition condition. Thus with common block rank \(d\) we obtain \(h\le4d^2\), even though all three total ranks grow linearly with \(m\) at fixed \(d\). The logarithmic-space regime includes \(d^2\log q=O(\log m)\). The algorithm handles simultaneous prescribed determinants over \(\mathbb F_3\), where all eight sign patterns can be tested in one layered graph, and over finite chain rings given by tables. Linked constraints share matrices across adjacent edge slots.

The block structure can be imposed by labelled endomorphism records: include the ordered block projectors for each mode and require \(g_i\) to intertwine the projectors with their matching target projectors. With the decompositions in the supplied bases, intertwining is exactly block-diagonality. This gives a structured case of determinant-constrained systems of tensors and operators. For ordinary unmarked three-tensor isomorphism the block restrictions are additional data.

## Relation to Grochow's questions

Chen, Grochow, Qiao, Tang and Zhang ask for a reduction from special-linear to ordinary tensor isomorphism in Open Question 1.9. The theorem is a low-workspace algorithm and exact determinant-fiber construction for the labelled block case. It extends ordered single-anchor approaches in a different direction, allowing arbitrarily long systems while the total size of matrices crossing a cut stays logarithmic. The graph construction uses the standard path-decomposition dynamic programming principle. The determinant characters, simultaneous isolation and the transporter extraction are the additional structure proved here. The general theorem is a written proof. [Chen–Grochow–Qiao–Tang–Zhang, Open Question 1.9](https://arxiv.org/html/2306.03135v2#S1.SS5) · [Bodlaender et al., Binary CSP parameterized by pathwidth](https://arxiv.org/abs/2105.14882)
