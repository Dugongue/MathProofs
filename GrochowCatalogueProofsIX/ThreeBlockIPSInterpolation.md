# Span-program interpolation at bounded ROABP interface cost

**GP-0734, restricted layouts.** Suppose a refutation of $A(X,Y)\wedge B(X,Z)$ is supplied as a linear-coefficient IPS over $\mathbb Q$, where $Y,Z$ are disjoint private variable lists and $A,B$ are CNFs. Each left coefficient, including those of the $Y$ Boolean axioms, is displayed as a sum of ROABPs in individually chosen orders. For each summand, partition its order into maximal monochromatic runs of $X,Y,Z$ and take the product of the internal separator widths between those runs. If $N$ is the sum of these products over the left summands, there is an interpolating span program of size $O(N(1+L))$, where $L$ bounds the number of shared literals in a left clause. It can be constructed in randomized polynomial time in the certificate size and $N$, with arbitrarily high success probability. In particular this allows incompatible orders with a bounded number of color switches, or logarithmically many switches at constant width.

## Proof

Write each coefficient ROABP as a product of univariate polynomial matrices. Expand the multiplication over separator indices at the switches between the three colors. Each assignment of indices gives a product of entries from run matrices. Gathering entries by color gives one separated term $F_\ell(X)G_\ell(Y)H_\ell(Z)$. All entries can be evaluated by their run matrices, so computing an evaluation takes time polynomial in the input and $N$.

Let $a_i(X,Y)=d_i(X)e_i(Y)$ be the left clause polynomial, with the shared and private falsification factors separated. For a $Y$ Boolean axiom use $d_i=1$, $e_i=y^2-y$. Turn each separated term into one polynomial vector $v_{i\ell}(Y)=G_{i\ell}(Y)e_i(Y)$, available on a Boolean shared assignment $u$ exactly when $d_i(u)=1$. The span-program target is the constant polynomial $1$.

If $A(u,Y)$ has a Boolean witness $y_0$, every available vector vanishes at $y_0$. Their span cannot contain $1$. If $B(u,Z)$ has a Boolean witness $z_0$, substitute $X=u,Z=z_0$ in the IPS identity. All right equations, private $Z$ axioms, and shared Boolean axioms vanish. The identity writes $1$ as a linear combination of available vectors with coefficients $F_{i\ell}(u)H_{i\ell}(z_0)$. Thus the span predicate interpolates.

A polynomial vector can be represented by its evaluations at $N+1$ points in $\mathbb Q^{|Y|}$. To see that suitable points exist and can be sampled, let $r\le N+1$ be the dimension of the span of all vectors and $1$, fix a basis of that span, and let $D$ bound their total degrees. The evaluation functionals span the dual because a polynomial vanishing at every rational tuple is zero. Thus the determinant of evaluations of the basis on $r$ independent symbolic points is a nonzero polynomial of degree at most $rD$. Evaluating at independent points from an integer grid of size greater than $(N+1)D/\epsilon$ makes this determinant nonzero with probability at least $1-\epsilon$ by Schwartz–Zippel. Use the first $r$ of the $N+1$ sampled points in this argument. Injectivity on the entire span makes the evaluations valid for every shared assignment at once. With explicitly given univariate coefficient lists, or sparse univariate lists of polynomial degree, these rational evaluation vectors also have polynomial bit length.

Finally, each availability condition is a conjunction of the $k\le L$ shared falsifying literal values of one left clause. For a vector $v$ with condition $\lambda_1\wedge\cdots\wedge\lambda_k$, append private tag coordinates $t_1,\ldots,t_k$ and use one always-available row $v+t_1+\cdots+t_k$. Add row $t_j$ when $\lambda_j$ is true. The target is zero in these tag coordinates. If one required literal is absent, the coefficient of the always-available row is forced to be zero. When all are present, the tag cancels and the row $v$ is available. Tags are unique across vectors, so the transformation preserves the predicate and uses at most $N(1+L)$ rows.

**Scope.** The bound is polynomial in the interface expansion size $N$; that size may be exponential for arbitrarily interleaved orders. Randomness is needed only for the uniform construction given here. [Chatterjee, Ghosal, Mukhopadhyay and Sinhababu, sum-of-ROABPs linear IPS](https://arxiv.org/abs/2507.09515).
