# Logspace greedy generator replay on Cayley tables

These are Lean components of Collins–Grochow–Levet–Weiß Question 8.1. The reader starts at any legal physical head position on the original Cayley input, restores its scratch tapes using a bounded copy, seeks the payload, and returns the exact addressed symbol of the bipartite prefix graph. It parks the work heads and reestablishes its entry invariant for the next call. The bound is logarithmic in the original Cayley-table length. [Reader theorem](Mathproof/MinimumGenerationCayleyReaderCycle.lean) · [Question 8.1](https://arxiv.org/html/2402.00133#S8)

The physical setup starts from a raw Cayley table and blank work tapes. It recovers the identity, prepares the greedy-query templates, and prepares the recurrent reader's reserved banks. The retargeting machine updates the physical query header and brings the reader to its next prepared candidate. [Candidate installation and retargeting](Mathproof/MinimumGenerationCayleyReaderRetarget.lean) · [Greedy template setup](Mathproof/MinimumGenerationPhysicalGreedyTemplateFromRaw.lean) · [Recurrent reader setup](Mathproof/MinimumGenerationPhysicalGreedyReaderFromRaw.lean)

The native Reingold certificate decides prefix subgroup membership in the addressed-input model and clears its bounded work interval on return, preserving an arbitrary exterior frame. The source includes its Lean 4.33 port and complete dependency closure. [Native Reingold window](Mathproof/MinimumGenerationNativeReingoldWindow.lean) · [Native provenance](NATIVE-PROVENANCE.md)

The physical reader contract supplies every requested symbol along a certified native Reingold run, preserves the native tapes and updates its own address after each move. The greedy scan and ordinal replay preserve the caller invariant under certified eligibility and prefix-query calls. [Physical reader contract](Mathproof/MinimumGenerationNativePhysicalReader.lean) · [Greedy ordinal invariant](Mathproof/MinimumGenerationPhysicalGreedyOrdinalInvariant.lean)

The requested-ordinal stage accepts a prepared ordinal register and initializes the live replay. [Requested-ordinal execution](Mathproof/MinimumGenerationPhysicalGreedyOrdinalRequested.lean)

From a prepared query layout on the original Cayley-table input, the finite Reingold driver computes the exact prefix subgroup membership bit. It parks all heads, restores the native work cells and makes the physical reader ready for reuse. The ordinal proof also gives the exact end state of the label, order and ordinal registers for certified query calls. [Raw-tape Reingold execution](Mathproof/MinimumGenerationNativePhysicalPrefix.lean) · [Ordinal register guarantees](Mathproof/MinimumGenerationPhysicalGreedyOrdinalRequested.lean)

For every promised group Cayley table, one finite machine starts on blank work tapes and computes the first greedy generator or the empty-list sentinel in logarithmic workspace. A second execution theorem uses the retained workspace and a stored ordinal to recover the requested greedy entry or the out-of-range sentinel. Both executions use the same native connectivity machine and logarithmic workspace constant. The indexed greedy list generates the entire group and has length at most the floor of its order's base-two logarithm. [Greedy replay theorems](Mathproof/MinimumGenerationPhysicalGreedyNativeOrdinal.lean)

The greedy generator is returned on work tapes. The unrestricted minimum-generator search theorem remains informal.
