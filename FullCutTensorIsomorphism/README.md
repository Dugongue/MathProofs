# Full-Cut-Rank Tensor Isomorphism

[Informal proof](PROOF.md) and [exact finite marker certificate](verify_marker.py).

Over fields of characteristic 5 and in characteristic zero, an explicit affine-linear map embeds arbitrary four-tensor isomorphism into the full-pair-rank, scalar-centroid promise with only a linear increase in side dimension. The outputs simultaneously rule out cyclic covariants and, over fixed finite fields, short equivariant lists of fine frames. The result transfers the worst-case counting-exponent question to this restricted class at order four.

Run the marker certificate with Python 3.
