# Counting geometric zeros of sparse affine binomial systems

**GP-0756, the sparse binomial specialization.** Given an arbitrary rectangular list of rational binomial equations with binary exponents, detecting an infinite geometric zero set is in NP. On inputs with finitely many geometric zeros, counting those distinct points is $\#\mathrm P$-complete under polynomial-time counting reductions. Without the finiteness promise the algorithm first tests infinity and then counts, giving an $\mathrm{FP}^{\#\mathrm P}$ upper bound for the integer-or-infinity output. The same statements hold over any explicitly presented finite field, using distinct points over its algebraic closure. The construction permits non-generic coefficients, arbitrary zero patterns, and monomial equations.

## One support stratum

Combine coincident monomials. Guess a subset $S$ of variables that must be nonzero and set all other variables to zero. Reject if a surviving equation has exactly one nonzero monomial. Discard equations with no surviving terms. Divide each remaining equation by one of its monomials to obtain $x^{a_i}=c_i$ for $a_i\in\mathbb Z^S$ and $c_i$ nonzero. The empty support is permitted and is handled by the same convention.

Let $A$ be the integer matrix with rows $a_i$. Compute Smith form with unimodular multipliers, in polynomial bit time by the [Kannan–Bachem algorithm](https://doi.org/10.1137/0208040). Row operations replace the constants by monomial products of the original constants, and column operations amount to invertible monomial coordinate changes on the torus. The resulting equations are $u_i^{d_i}=c'_i$ for positive Smith entries $d_1,\ldots,d_t$, and $1=c'_i$ for zero rows. It is enough to test the latter equalities, since all nonzero constants have $d_i$-th roots over the algebraic closure.

Over a finite field each $c'_i=1$ test uses repeated squaring, including integer exponents of either sign. Over $\mathbb Q$, use the exact gcd-free product test from the earlier binomial feasibility proof to avoid writing exponentially long powers. Briefly, separate the signs and repeatedly split overlapping numerator/denominator bases by their gcd, merging duplicates and omitting unit factors. The sum of logarithms of distinct bases decreases at each split, so polynomially many splits produce pairwise coprime bases. Zero total exponent of every basis factor and positive total sign decide equality to one. [Earlier exact Laurent consistency](https://github.com/Dugongue/MathProofs/blob/cbce8131e2cb46db9fcc20e31490cb13eb850e95/GrochowCatalogueProofsIX/BinomialHilbertNullstellensatz.md)

If the tests pass and $t<|S|$, at least one coordinate is free and this stratum is infinite. If $t=|S|$, the number of distinct points is $\prod_i d_i$ in characteristic zero and $\prod_i d_i/p^{v_p(d_i)}$ in characteristic $p$. In the latter case, Frobenius is bijective on the algebraic closure, and a prime-to-$p$ degree contributes exactly that many distinct roots. These integers have polynomial bit length by the polynomial bit size of the Smith form. In both cases the stratum count is $1$ for no remaining coordinates and no failed row test.

## Assemble the counts

There are finitely many supports. A binomial system has infinitely many geometric zeros if and only if some support has a nonempty positive-dimensional stratum. The support itself certifies infinity since all the above verification is deterministic polynomial time. On a finite input, a $\#\mathrm P$ machine guesses the support with one branch sequence per subset, rejects empty strata, computes its weight $w$ by the above rule, then guesses a binary integer $j$ of a fixed polynomial number of bits and accepts exactly if $j<w$. Across disjoint supports the number of accepting branches is the total number of distinct geometric points. The same counting machine is defined on all inputs by rejecting infinite strata. An infinity query handled first via an NP oracle, simulated by a $\#\mathrm P$ oracle, makes the mixed-output procedure total.

For hardness, given a graph, use $x_i^2-x_i=0$ for each vertex and $x_i x_j=0$ for each edge. The geometric solutions are exactly the Boolean indicator vectors of independent sets, in every characteristic. This is a count-preserving transformation to finite instances with degree two and coefficients from $\{0,1,-1\}$. [Valiant's counting hardness](https://doi.org/10.1137/0208032)

Cattani and Dickenstein already prove $\#\mathrm P$-completeness for their characteristic-zero binomial complete-intersection setting. The argument here gives a direct classifier for arbitrary lists and an explicit positive-characteristic distinct-root correction. The general rational or finite-field polynomial system counting question is outside this binomial specialization.
