# Pointed independent-set games detect ordinary matroid isomorphism

**GP-0961.** For loopless finite matroids, the pointed independent-set quantum isomorphism game has a perfect quantum commuting strategy exactly when the matroids are ordinarily isomorphic. The same holds for the pointed basis game if the common rank is at most three. In particular these two axiomatic formulations agree through rank three. The theorem concerns the pointed-set games of Corey, Schmidt and Wack and places no simplicity restriction on the matroids. [Matroid isomorphism games, Definition 3.1 and Theorem 3.10](https://arxiv.org/abs/2507.06225)

## Point and set projections

Let the chosen family consist of all nonempty independent sets or all bases. Ignore the rank-zero empty loopless case, which has only one matroid. A flag is $(A,p)$ with $p\in A$. A perfect strategy gives a magic unitary $W$ on the source and target flags, preserving the two equivalence relations of having the same set and having the same point. The products of entries with conflicting relations vanish. We first explain how any conserved equivalence relation gives a magic unitary on its classes. For each pair of classes define the partial sum in a row from the source class, over all columns in the target class. It is the same projection for every row in the source class. Indeed the product of one such sum and the complement of another is zero by the equivalence relation, in both directions. The analogous partial sum in columns is independent of the chosen column. Summing the whole rectangular block equates the row projection times the source class size and the column projection times the target class size. If nonzero, both projections and both class sizes must be equal. The class matrix consequently has orthogonal projections summing to the identity along rows and columns.

Let $U=(u_{pq})$ and $V=(v_{AB})$ be the point and set magic unitaries. All points are covered by the loopless hypothesis. Whenever $p\in A$, $u_{pq}$ commutes with $v_{AB}$ because both are sums from the row for $(A,p)$. Their product is $W_{(A,p),(B,q)}$ if $q\in B$, and zero otherwise. The corresponding assertion holds using the column whenever $q\in B$. The set matrix preserves cardinalities since the set-class size of $A$ is $|A|$.

Write $I_M,I_N$ for the zero-one matrices of point-set incidence, with points indexing rows. Restrict the set family on both sides to sets of any fixed positive size when desired. Then $UI_N=I_MV$ for the associated set block. To see this, insert $\sum_A v_{AB}=1$ in $\sum_{q\in B}u_{pq}$. If $p\notin A$ the corresponding contribution is zero. If $p\in A$, the sum multiplied by $v_{AB}$ is this projection, by the source row property. Unitarity gives
$$
U(I_N I_N^\mathsf{T})=(I_M I_M^\mathsf{T})U.
$$
In the independent-set game choose size two, and in the basis game use the whole basis family. For distinct $p,p'$, the $(p,p')$-entry counts joint membership and is positive exactly when the pair is independent. Thus $U$ preserves the relation of being the same point or parallel. Concretely a matrix identity $UM_N=M_MU$ implies
$$
\bigl(M_N(q,q')-M_M(p,p')\bigr)u_{pq}u_{p'q'}=0
$$
by multiplying the $(p,p')$-entry of $UM_NU^*=M_M$ on the left and right by the indicated row projections. The equality relation is already preserved by a magic unitary. If there is no pair of independent points, there is one parallel class and the loopless matroid is fixed by the number of points.

## Rounding on parallel classes

For independent $p,p'$, choose a source set $A$ of size two containing both in the independent-set game, or any basis containing both in the rank-at-most-three basis game. For each target $B$ of the same size, the matrix of elements $v_{AB}u_{pq}$ on $p\in A,q\in B$ is a magic unitary in the corner with identity $v_{AB}$. This follows from the row and column partial sums above. Its entries commute. For size two this is immediate, and for size three let $a,b,c$ be the three diagonal entries after relabeling. Row and column sums give $ab=ac$, by first writing $a u_{23}=a-ac$ and then $ab=a-a u_{23}$ in that three-by-three matrix. Permuting the roles gives $ba=bc$ and $cb=ca$. Taking the adjoint of the last equality then gives $bc=ac$, hence $ab=ba$. This checks all pairs in different rows and columns, and pairs in the same row or column are orthogonal. Entries with target point outside $B$ vanish in this corner. Therefore $v_{AB}[u_{pq},u_{p'q'}]=0$ for all $q,q'$. Summing over $B$ proves that entries from independent source rows commute.

Apply the equivalence-class construction to $U$ and its parallel classes, obtaining a class magic matrix $L$. Entries of $L$ in different source rows commute by using a representative of each of the two distinct parallel classes and summing the previous commuting entries. Entries in the same row are orthogonal. Therefore a nonzero joint projection $e$ for all entries of $L$ selects an ordinary bijection of parallel classes. Matched classes have equal sizes by the rectangular block argument.

For each source set $A$, choose a target $B$ with $e v_{AB}\ne0$, using $e=\sum_B e v_{AB}$. Each parallel class of a point $p\in A$ must have its selected image represented in $B$. Indeed, if no point of that target class occurs in $B$, the projection $L$ for that class pair annihilates $v_{AB}$ by the incidence mismatch relation. It acts as identity on $e$, a contradiction. Both sets have the same cardinality and meet every parallel class at most once. Thus the class bijection sends the class-set of each $A$ to a class-set in the corresponding target family. Reversing source and target and using the same $e$ for the transpose gives the reverse inclusion. The independent sets, or the bases, are determined by these class-sets and arbitrary choices of representatives. Any classwise bijection on the matched equally sized classes is consequently a matroid isomorphism. Conversely, a matroid isomorphism supplies a scalar permutation on the flags and a perfect strategy. This proves both statements.
