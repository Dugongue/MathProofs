# Computing the projective lift group from abstract matroid automorphisms

## GP-0321

Let $A$ be a full-row-rank generator matrix over $\mathbb F_q$, with labeled columns, and let generators of the full abstract automorphism group $H$ of the represented matroid be supplied. Fix any column basis $B$. Normalize the matrix to have identity on $B$, and let $\Gamma_B$ be the bipartite graph on basis and nonbasis elements defined by the remaining nonzero entries. Let $b$ be the largest cycle rank of a connected component of $\Gamma_B$, counting isolated vertices as components. In deterministic time $(q-1)^{O(b)}\operatorname{poly}(L)$, for input bit length $L$, one can compute the image on coordinates of the monomial code automorphism group, give lifts of generators, and compute the order of the full monomial group. The number of connected components and the total cycle rank may grow without bound.

## Labeled states of one connected component

For a fixed chosen column basis, the support of the normalized matrix is intrinsic to the labeled matroid: its entry at $i,j$ is nonzero precisely when exchanging basis element $i$ for nonbasis element $j$ gives a basis. The graph components are exactly the matroid direct-sum components. Indeed, the fundamental circuit of a nonbasis element consists of it and its neighbors. All such circuits lie in single graph components, and the normalized representation is a direct sum across those components. Conversely no matroid direct-sum partition can split a circuit, so none can split a graph edge. Loops and coloops are the isolated vertices on the respective sides.

For two representations of the same labeled matroid, row equivalence and independent column scaling reduce, after both are set to identity on $B$, to scalar gauge changes on the bipartite vertices. More explicitly, a row map sending each basis line to itself is diagonal, and scaling the corresponding basis column restores its unit coordinate. Nonbasis coordinates have their own independent column scalings. Fix a spanning forest of the support and scale all its edge entries to one by propagating scalars from each root. The nonforest labels are independent of the root scalars and determine projective equivalence. This gives at most $(q-1)^b$ labeled states on a component. It also gives explicit row and column maps between any two matrices in the same state. ## Orbit computation and component assembly

Compute the induced component orbits of $H$ using permutation generators. For each component $C$, use the Schreier orbit transversal on components to find generators of its setwise stabilizer, then restrict those generators to $C$. The image is the full abstract automorphism group of the connected matroid on $C$: any internal abstract automorphism extends by identity on the other components. Every component automorphism acts on labeled normalized states by permuting columns, setting the same fixed basis positions back to identity by row reduction, and normalizing the fixed spanning tree. The matroid promise makes the fixed basis valid after each such permutation. The procedures respect the equivalence relation, so this is an action on states.

Enumerate the orbit of the represented state using the restricted generators, retaining a permutation taking the original state to every discovered state. The orbit size is bounded as above. Using Schreier generators again gives precisely the internal coordinate permutations that lift projectively. Since the normalization algorithm is constructive, each of these generators has an explicit monomial lift.

Two components outside the same abstract orbit cannot be interchanged. Within an abstract orbit, take the supplied transversal permutation matching one component with another and use it to transport the latter's representation to the former's labels. The two representations are projectively equivalent up to relabeling if and only if this transported state lies in the enumerated internal orbit of the former. A stored permutation, followed by a gauge computation, gives a witness between them. This partitions the abstract orbit into projective isomorphism classes. Any permutation of the components of one such class is possible, since each transfer can be realized independently on its own row and column blocks. Add component swaps from a representative to every other member, using an available witness in one direction and its inverse in the other. Together with the internal liftable generators these generate the precise coordinate image. This follows by cancelling any allowed component permutation using the swaps, then applying the internal groups to the resulting componentwise stabilizer.

For the kernel of the coordinate action, normalization on the basis forces the row map to be diagonal. Each support edge enforces one inverse relation between its row and column scalars. Hence every connected component contributes one free scalar, including its own coordinate scaling for a loop. If $c$ is the number of components, the kernel has order $(q-1)^c$, with explicit scalar generators when generators of $\mathbb F_q^\times$ are supplied. One can give it without extracting primitive elements as the displayed direct product. Multiplying by the order of the coordinate image gives the full monomial group order; the image order is obtained by standard permutation-group order computation. The time bound uses a separate internal orbit per component, avoiding a product over their state-space sizes. More generally the same proof is polynomial in the actual maximum internal orbit size, even when the support-cycle estimate is large.

This is a bounded-parameter result with supplied generators of the full abstract matroid automorphism group, and does not require a bound on representation multiplicities or on the number of component swaps.
