# Near-linear hypergraph canonization with bounded cycle surplus per block

**GP-0993.** Let $H$ be a hypergraph given by incidence lists and let $N$ be the number of element vertices, hyperedge vertices and incidences. Form its bipartite, side-colored incidence graph. For each nontrivial biconnected block $B$ count $k(B)=|E(B)|-|V(B)|+1$, treating a bridge as a block with value zero. Let $k=\max_B k(B)$, or zero if there is no block. A deterministic algorithm computes a canonical labeled hypergraph and an explicit labeling map in
$$
2^{O(k\log(k+2))}N\log^2(N+2)
$$
bit time. It requires no decomposition or order of vertices in the input. This is a subfamily of bounded incidence treewidth, and the bound counts the incidence input even if individual blocks or hyperedges are large. [Bounded-treewidth canonization, Lokshtanov et al.](https://arxiv.org/abs/1404.0818) · [Tarjan, Depth-first search and linear graph algorithms](https://doi.org/10.1137/0201010)

## Canonically rooted block trees

Use the forest with one node for each vertex of the incidence graph and one node for each nontrivial block. A block is adjacent in this forest to all vertices it contains. These adjacency lists have linear size since the blocks partition the graph edges and each nontrivial block has at most twice as many vertices as edges. The incidence graph is completely recovered by drawing the edges inside each block and identifying all occurrences of every common vertex. Each tree is rooted at its center, choosing the original-vertex node when there are two centers. Two centers are adjacent and the forest is bipartite by node type, so this tie rule is intrinsic. Tarjan's algorithm finds the blocks in linear word time. The centers, parent relation and subtree heights follow by tree traversals.

At an original vertex node the signature contains its original bipartite color and the sorted multiset of signatures of its child block nodes, using interned ranks for the child signatures. At a block node the local graph is decorated by the ranks of all its child vertex nodes. If the block has a parent vertex, mark the corresponding vertex by a distinct parent symbol. This records the attachment without depending on any data above it. The root of a tree can also be a block, in which case every vertex in it receives its child rank and there is no parent symbol.

## Canonical signatures for decorated blocks

A bridge is an unordered pair of decorated endpoints and has its evident sorted signature. A larger biconnected block has minimum internal degree two. When every degree is two it is a cycle. Take the least cyclic reading of the decorations, allowing both orientations. This takes a logarithmic factor times the cycle length. For instance, in both oriented copies simultaneously, rank cyclic substrings of length $2^j$ by sorting the pairs of ranks for their two halves. After the first sort, each rank lies in a range of size at most twice the length and two counting-sort passes suffice for a new pair sort. When $2^j$ reaches the cycle length, the cyclic comparisons have the required order. A marker at the parent vertex, when present, is another decoration.

Otherwise let $S$ be the set of vertices of internal degree at least three. Since $\sum_{v\in B}(\deg_B(v)-2)=2k(B)-2$, one has $1\le |S|\le 2k(B)-2$. Suppress all maximal degree-two paths, retaining their ordered lists of internal decorations. The resulting connected multigraph on $S$ has $|S|-1+k(B)\le 3k(B)-3$ edges. For each of the at most $(2k(B)-2)!$ orders of $S$, use the ordered decorations of the branch vertices followed by a sorted list of the path records. A record begins with its two endpoint numbers and continues with the internal decorations in order from smaller to larger endpoint. For a loop use the smaller of the two readings. If the parent lies internally on a path, its marker occurs at its actual position in the list. Take the least resulting record. It determines the decorated graph up to isomorphism since it specifies the branch vertices, the endpoints of each path, and every decoration along every path. Every isomorphism preserves internal degrees and induces a permutation of the branch set and the paths, so isomorphic decorated blocks have equal records. For one branch order, a deterministic trie with balanced dictionaries sorts the lists in time linear in their total length times $O(\log(N+2))$ word operations per list symbol. This avoids extra time from repeatedly comparing long common prefixes.

## Encoding and output

Intern signatures bottom up, at each height replacing distinct records by their sorted ranks and carrying the height with each rank. Equal ranks within one run represent the same decorated subtrees. Isomorphic inputs induce equal multisets of records at each height, so they induce the same ranks and all the same choices of ordered records. The interning, including sorting vertex lists and signatures, takes $O(N\log(N+2))$ word operations apart from the time for generating the local canonical block records. In a block, the total number of symbols processed for each branch order is linear in the block's own incidence size. The same is true of the chosen record after minimizing. Using $O(\log(N+2))$-bit symbols and summing over blocks gives the stated bit bound.

For output sort component roots by their signature ranks. Expand each canonical record in order, recursively expanding labeled children and identifying each parent marker with its already emitted attachment. Enumerate element vertices and hyperedge vertices by their resulting orders to give the canonical incidence lists. Their graph reconstructs the input up to a side-preserving isomorphism. If ranks or block orders tie, the selected records, with the same decorations, reconstruct the identical labeled incidence pattern after expansion. The retained minimizing choices give the map from the original input to this output. The output is the explicit labeled incidence structure, so ranks used internally need not be comparable across unrelated input instances.

Taking one endpoint from each of the $k(B)$ edges of a block outside a spanning tree leaves a forest. This gives treewidth at most $k(B)+1$ by adding these endpoints to every bag of a forest decomposition. The decompositions glue at shared vertices. The result therefore gives nearly linear canonization on a specified bounded-treewidth subclass, allowing arbitrary subdivisions, unbounded vertex degrees and arbitrarily many cyclic blocks. It does not give the same bound for every graph of bounded treewidth.
