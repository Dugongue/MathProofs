# DAG-like Polynomial Calculus with a bounded path decomposition

**GP-0715, a sufficient structural condition.** Let a rational Polynomial Calculus refutation have $s$ lines given with their inference DAG and coefficients. Form its directed inference graph with an edge for each operand occurrence, labeled by the scalar or variable by which that operand is multiplied. Adjoin a source with one edge to each occurrence of an input equation, labeled by that equation's placeholder, and use the final line $1$ as the sink. Form an undirected incidence graph with vertices for lines, directed edge occurrences, and all variable or placeholder labels. An edge-occurrence vertex is adjacent to its two ends and to its label vertex, if any. If this incidence graph is given with a width-$k$ path decomposition, a linear-coefficient ROABP-IPS refutation can be constructed in $(s+1)^{O(k+1)}\operatorname{poly}(L)$ bit time, where $L$ is the encoded input and decomposition size. All coefficients use the same variable order. The algorithm preserves DAG sharing and does not unfold the refutation as a tree.

## Path expansion

The standard Polynomial Calculus rules are scalar linear combination of previous lines and multiplication of a previous line by a variable. For a line arising by either rule, its polynomial after replacing initial equations by placeholders equals the sum of source-to-line path weights in the displayed DAG. This follows by induction in topological order. Let $C(x,y)$ be this sum at the sink, where $y$ denotes equation placeholders. Every path uses exactly one source edge, so $C$ is homogeneous linear in $y$, hence $C(x,0)=0$. Substituting the equations for $y$ gives the final line $1$.

To compute this path sum in a prescribed read-once order, select or skip each edge, with local constraints on the selected edges. Require internal lines to have selected indegree and outdegree both zero or both one. Require $(0,1)$ at the source and $(1,0)$ at the sink. Any legal selection is exactly one source-to-sink path: the source path must end at the sink, and any selected edge off that path would need to belong to a directed cycle by the indegree and outdegree constraints. Such cycles are absent.

## A circuit from the path decomposition

For each bag containing an edge-occurrence vertex, add its up to three neighbors to that bag. The new bag size is at most $4(k+1)$. The bags containing a line or label remain an interval, since its original interval intersects the interval of every edge-occurrence vertex adjacent to it. Process each edge decision at one bag containing that occurrence and its neighbors. Now omit edge-occurrence vertices from the bags and use single-vertex introduce and forget steps. Every edge decision still has all required line and label vertices in its bag.

At a line vertex keep the partial selected indegree and outdegree, rejecting either count exceeding one. At a variable or placeholder vertex keep the number of selected edges using that label, in the range from zero to the number of edges. Initialize a counter to zero when introducing a vertex. On processing an edge, branch on selection. A selected edge increments both incident line counters and, for a variable-labeled edge, the counter of its label. A selected scalar-labeled edge contributes the scalar immediately. At a forget step for a line check its local path condition and drop its counters. At a forget step for a label $z$, multiply by $z^a$, where $a$ is the recorded count, then drop it. Thus each variable appears in exactly one layer, regardless of how it was reused in the original proof.

Use a state for every vector of current counters, and let edges between states implement the just-described transitions. The number of states in any layer is bounded by $4^{4(k+1)}(s+O(1))^{4(k+1)}$. The start and end bags can be empty. Each complete state path encodes exactly one legal selection, and its weight is the weight of the corresponding inference path. Remove layers having only rational labels by composing their transfer matrices. The result is a genuine read-once oblivious branching program in the order in which label vertices were forgotten. In any constant transfer segment, a common denominator dividing the product of denominators of its scalar inference edges is sufficient, since each decision is made once. The number of contributing decision sequences is at most exponential in the number of inference edges, so the summed coefficients have polynomial bit length. Monomial degrees in variable-labeled layers are at most the number of edges. To obtain a coefficient in the common order on the $x$ variables, substitute $y_i=1$ and all other placeholders zero. This recovers exactly the coefficient of $y_i$, by linearity established above.

The structural promise is a bound on the incidence graph that includes label vertices, rather than just on the unlabeled proof DAG. This extends tree-like simulation on the stated DAG class.
