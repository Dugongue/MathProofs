# GP-0241 · Complete Pfaffian invariants for split alternating spaces of arbitrary genus

**Result.** There is a deterministically recognizable class over every explicitly represented finite field on which the scheme-theoretic Pfaffian hypersurface is a complete invariant for pseudo-isometry. Genus, number of symplectic blocks, and block sizes are all unbounded. The algorithm constructs a transporter and determines all induced Pfaffian automorphisms in deterministic polynomial bit time. The proof is written.

Let S ≤ Alt(V) be an m-dimensional space of alternating forms. Use the class with a direct decomposition V=⊕V_j, dim V_j=2d_j, for which

    B(s) = ⊕_j λ_j(s) J_j

for all s in the abstract slice space F_q^m. Here each J_j is nondegenerate alternating, the nonzero linear forms λ_j are pairwise nonproportional, and d_j are pairwise distinct. The λ_j span the dual slice space because S is embedded injectively. The class includes, for instance, a basis of linear forms together with arbitrary additional distinct projective ones and distinct positive multiplicities. It includes examples in characteristic two.

## Recognizing blocks without a supplied anchor

Compute the shared adjoint algebra of pairs (X,Y) satisfying XᵀB=B Y for each given basis form B. For a class member, comparing the (i,j) blocks gives λ_j X_{ji}ᵀ J_j = λ_i J_i Y_{ij} as an identity of linear forms valued in matrices. When i≠j, independence of λ_i and λ_j and invertibility of each J_j force both off-diagonal blocks to vanish. On the diagonal X_j can be arbitrary, with Y_j the adjoint. Therefore projection to X identifies the underlying adjoint algebra (up to opposite multiplication) with ∏End(V_j). In particular it is injective. Obtain it by linear equations, reject if projection to X fails to be injective, and compute its center using linear commutation equations against an additive basis. Its center on class members is the scalar block algebra F_q^r.

Here is a deterministic way to recover the joint eigenspaces without assuming a general deterministic field-factoring algorithm. Write n=dim V. If q≤n², enumerate q eigenvalues for each center basis element and successively refine the current common eigenspaces by kernels. If q>n², combine center basis elements greedily into a single element with pairwise distinct eigenvalues on the blocks. For a running combination X and the next basis element Y, consider more than n(n−1)/2 distinct values α. On class members every pair of blocks separated by X or Y collides for at most one α in X+αY. Hence some choice realizes every separation attainable at that stage. For each candidate the number of distinct characteristic roots is the degree of the squarefree part of its characteristic polynomial. Choose a candidate maximizing this count; any maximizer realizes every attainable separation, because all other pairs necessarily coincide. After all center elements each pair of distinct blocks is separated. The dimensions 2d_j are distinct, so square-free decomposition by multiplicity extracts each linear factor individually. This uses only polynomial arithmetic and p-th roots of field coefficients, the latter computed by exponentiation in the explicitly represented finite field. Both branches use polynomial bit time.

Finish recognition by validating that the obtained blocks are complementary, have distinct positive even dimensions, and that the restrictions of all given forms vanish off block and are multiples of a single nonsingular alternating matrix on each block. Check the extracted coefficient forms are pairwise projectively distinct. This validation rejects any invalid candidate regardless of behavior of the extraction algorithm on invalid inputs.

## Completeness and explicit automorphisms

The Pfaffian is a nonzero scalar times ∏ λ_j^{d_j}; this follows by expanding the Pfaffian on block diagonal forms, including in characteristic two. In particular multiplicity labels each hyperplane intrinsically. A pseudo-isometry maps the Pfaffian up to nonzero scalar and slice coordinate change. Conversely any projective slice transformation matching the hypersurfaces preserves each multiplicity label. Thus it matches every individual projective coefficient form. Choose a basis from the label-ordered source coefficient forms and require that its labelled counterparts form a basis. In these two projective frames the desired dual transformation is diagonal with entries a_i∈F_q^×. For each additional labelled pair with normalized coordinates s_{ji}, t_{ji}, equality up to a row scalar b_j requires a_i s_{ji}=b_j t_{ji}. First check equality of the supports. On the supports these are ratio equations of nonzero scalars, solved by propagation along the associated bipartite graph. A component has one free nonzero scalar if its cycle products are consistent. This describes every matching slice map, including the full group of Pfaffian automorphisms if the two inputs agree. For any such matching, the needed scalar multiple of each symplectic form is realized by scaling the first vector in every symplectic pair by that scalar. Symplectic bases are constructed by elimination. The product of the block similitudes is an explicit pseudo-isometry, so no extra obstruction survives the Pfaffian condition.

The multiplicity-labelled Pfaffian criterion concerns the hypersurface scheme. The same class with equal block dimensions and with a projective frame among its hyperplanes has a reduced-hypersurface version when the field and genus are both fixed. Recognize the blocks by the small-field center procedure. A projective equivalence is determined by the images of one ordered projective frame, and there are at most r^(m+1) possible images. Test every resulting map and lift as above. In particular blocks of dimension 2 give square-free Pfaffians, including fixed genera m≥3.
