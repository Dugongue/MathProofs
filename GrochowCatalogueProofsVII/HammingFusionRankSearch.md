# Exact search for Hamming fusions parameterized by rank

## GP-0771

Given the ordered-pair color table of any homogeneous coherent configuration of rank $r$ on $n$ points, there is a deterministic $2^{r-1}\operatorname{poly}(n)$ algorithm that enumerates every nontrivial Hamming-scheme fusion, with explicit product coordinates for each. Here nontrivial means $H(d,q)$ with $d,q\ge2$. The result gives polynomial search and certification of absence for logarithmic rank, including primitivity as an allowed input case.

List all $n=q^d$ with $d,q\ge2$. For each format, enumerate the non-diagonal color subsets whose total valency is $d(q-1)$ and whose union is symmetric. Treat each union as the candidate distance-one graph. This enumerates at most $2^{r-1}$ unions per format and includes the first distance relation of every genuine Hamming fusion.

Here is a direct polynomial test and coordinate recovery for a candidate graph $B$. Choose a vertex $o$. For each neighbor $u$, form the set $L_u$ of $o,u$ and their common neighbors. In $H(d,q)$ this is exactly the coordinate line of the edge $ou$, since a vertex adjacent to both endpoints can vary only their differing coordinate. Deduplicate the sets. Require $d$ lines of size $q$, each a clique and pairwise meeting only at $o$, whose union away from $o$ is exactly the neighborhood. Compute graph distances from these line vertices. For every $x$ and line $L$, label its coordinate by the closest point of $L$, rejecting a tie or failure of connectivity. In a Hamming graph this nearest point is unique and matches precisely that coordinate value of $x$. Independently number the $q$ points of each line from zero to $q-1$ and order the $d$ lines. Require the resulting coordinate map to be bijective and verify on all pairs that adjacency is exactly a one-coordinate difference. All checks are polynomial. They accept every Hamming graph in the stated format and certify every accepted coordinate map.

Finally require that Hamming distance is constant on each input basis color. This is equivalent to the distance relations being unions of basis colors. The Hamming distance relations form a coherent configuration, so every accepted candidate gives exactly the required fusion. Conversely, if a Hamming scheme is a fusion, its first relation occurs in the enumeration, its recovered distance graph is correct, and each basis color has constant distance. This proves completeness and the running time. The same procedure returns “none” if all candidates reject.
