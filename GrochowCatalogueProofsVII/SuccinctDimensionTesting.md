# Dimension testing for circuit-defined affine sets

## GP-0760

The dimension of a rational affine variety given by unrestricted division-free arithmetic circuits can be computed in deterministic polynomial time with an oracle at a fixed level of the counting hierarchy. The empty set is detected as well. Neither numerical degree bounds nor expansion of the circuit outputs are needed. The decision version is polynomial-time many-one equivalent to dimension testing for explicitly given degree-two equations.

Let $C_1,\dots,C_m$ be circuits on $x_1,\dots,x_n$ with rational constants written in binary. Share gates within and between outputs, and give each internal gate $g$ a new variable $z_g$. A linear equation encodes an addition, subtraction or constant gate, while $z_g-z_hz_j=0$ encodes a multiplication gate. Input references use the $x$ coordinates directly. Require every output coordinate to vanish. Clear rational denominators locally, one gate at a time. For fan-in larger than two use polynomially many binary gates. An exponent supplied in binary is evaluated by repeated squaring. In the combined scalar variables this is a degree-two system with polynomially many explicitly written coefficients, even in dense degree-two encoding.

The quotient by the gate equations before adding the output constraints is isomorphic to $\mathbb Q[x_1,\dots,x_n]$ by the substitution $z_g\mapsto C_g(x)$. Indeed, elimination in a topological order solves each successive equation for its new coordinate with coefficient one. Adding the output vanishing equations therefore identifies the quotient of the new system with $\mathbb Q[x_1,\dots,x_n]/(C_1,\dots,C_m)$ itself. In geometric terms the new zero set is the graph of all gate values on the original zero set, and the projection and graph maps are inverse morphisms over every extension of $\mathbb Q$. This preserves dimension, not merely satisfiability, and also holds for nonreduced schemes.

Apply the dense-input dimension algorithm in the counting hierarchy to the degree-two system. Coefficient bit sizes and variable count grow polynomially in circuit encoding length. Asking for each dimension from zero to the original number of input variables and separately testing emptiness gives the functional bound. The reverse reduction writes the degree-two equations as arithmetic circuits. The circuit-to-equation construction is the extension-variable conversion used for satisfiability and finite point counts in the source. The graph isomorphism supplies dimension preservation and yields the explicit quadratic equivalence. [Counting-hierarchy dimension algorithm and encoding discussion](https://arxiv.org/html/2602.17904)

If divisions are allowed and the intended set is the common zero set **on the domain where all displayed division gates are defined**, use a unique reciprocal variable for each denominator and the equation that their product is one. The same construction then identifies the new closed zero set with the graph over that locally closed domain and preserves its dimension. This convention works even when there are removable singularities in a particular rational expression.
