# Canonization by return-walk covariants with repeated eigenspaces

## GP-0883

A graph is canonizable in deterministic polynomial bit time if the vectors $((A^j)_{vv})_{0\le j<n}$ separate its twin classes. This is a polynomial-time recognizable condition allowing arbitrarily many twin classes and an eigenvalue of multiplicity arbitrarily close to the full graph order. It gives spectral canonization using diagonal covariants, with no choice of eigenvectors. There are explicitly constructible examples for which the degree cannot replace the entire vector.

For a graph on $n$ vertices, set $s_v=((A^j)_{vv})_{j=0}^{n-1}$, with $A$ the adjacency matrix. Relabeling permutes the vertex-indexed vectors. Their coordinates are integers of bit length $O(n\log(n+1))$, so the first $n$ matrix powers can be computed exactly in polynomial bit time. Equivalently, write $A=\sum_{\lambda}\lambda E_\lambda$ with one orthogonal projector for each distinct eigenvalue. Then $(A^j)_{vv}=\sum_\lambda\lambda^j(E_\lambda)_{vv}$. The Vandermonde system on the distinct eigenvalues shows that these vectors contain exactly the distinct-eigenspace projector diagonals, independent of multiplicities.

Partition the graph into twin classes by the equivalence relation of agreeing on neighbors outside the pair. All twins have the same vectors, since interchanging two twins is an automorphism. Check that equal vectors never occur in different classes. If the check succeeds, order the classes lexicographically by their vectors. These classes are cliques or independent sets, with uniform adjacency between distinct classes. Therefore the adjacency matrix in this class order and in any order within each class is canonical. Canonical equality reflects isomorphism since this matrix represents the original graph.

To show the size of the class, choose any simple graph $H$ on $k\ge2$ vertices whose open neighborhoods are all distinct and nonempty. Replace each vertex $i$ by an independent set of size $w_i$, with complete adjacency between neighboring sets of $H$. The resulting twin quotient is $H$: sets for adjacent vertices cannot be twins because each size is at least two, and distinct open neighborhoods separate nonadjacent sets. There is a deterministic polynomial-size choice of sizes making the degrees of all quotient classes distinct. Indeed choose a prime $P>k\binom{k}{2}$ of size polynomial in $k$ by exact search in an interval ensured by Bertrand's postulate. For two different rows of the base adjacency matrix, form the polynomial with their entry differences as the coefficients of powers $1,\ldots,k$, and their row-degree difference as constant term. Every such polynomial is nonzero in $\mathbb F_P[t]$. Try the $P$ field elements to find one avoiding their at most $k\binom{k}{2}$ roots in total. Put $w_i=M(1+\operatorname{remainder}(t^i,P))$ for any integer $M\ge3$. Each degree difference, divided by $M$ and reduced modulo $P$, is the corresponding polynomial evaluation, hence is nonzero.

Every vector with coordinate sum zero within one independent class and zero elsewhere is a zero eigenvector. These subspaces have joint dimension $\sum_i(w_i-1)=n-k$ on the blown-up graph. Varying $M$ makes the nullity proportion approach one, and varying $H$ leaves the number and incidence pattern of its distinct quotient classes unbounded. For examples beyond the degree criterion, append disjoint components $K_3$ and $K_{2,5}$. Its size-five class has degree two and its size-two class has degree five. Both classes have zero triangles, whereas $K_3$ has two directed return walks of length three at each vertex. Take $M\ge6$, making all blown-up degrees exceed five. The resulting graph therefore passes the return-vector check while its degree-two vertices belong to distinct classes. The repeated-eigenvalue lower bound on the blown-up summand still applies.
