# Exact algorithms for extended Butson equivalence and sparse cyclic gains

## Extended equivalence of Butson matrices

**Theorem.** Two supplied $n\times n$ Butson Hadamard matrices over the $m$-th roots of unity can be tested for extended equivalence in $n^{O(\log n)}\operatorname{poly}(\log m)$ deterministic bit time. The input consists of the binary phase exponents and $m$. Extended equivalence allows row and column permutations and phase shifts, and multiplication of all exponents by one common unit modulo $m$. The algorithm returns a witness on yes instances. Transposition can also be allowed. The same theorem applies to generalized Hadamard matrices over a cyclic group, because any faithful character converts them to Butson matrices.

This is an upper bound for matrices satisfying the Hadamard promise. For a general phase array the graph encoding from the earlier phase-equivalence result applies, but the argument here uses orthogonality. A polynomial reduction from general graph isomorphism to this promised problem would give an $n^{O(\log n)}$-time graph-isomorphism algorithm. Related dephasing and graph algorithms for complex Hadamard matrices already appear in the literature. [*Equivalence of complex Hadamard matrices*](https://link.springer.com/article/10.1007/s10801-026-01568-x)

### A small set of rows or columns distinguishes every opposite coordinate

Fix one row anchor and one column anchor in the first matrix, and dephase the exponents by taking their anchored rectangle differences. For any two distinct columns of the original Hadamard matrix, their entrywise complex ratios sum to zero. Any given ratio therefore occurs in at most $n/2$ rows, by the triangle inequality. Equality of the two dephased exponents at a row means their original ratio at that row equals their original ratio at the anchor row. In at least $n/2$ rows the dephased exponents differ.

Take the pairs of columns that have yet to be distinguished. Averaging the number distinguished by each row shows that some row distinguishes at least half the remaining pairs. Repeatedly choose such a row, scanning all rows, until no pair remains. This gives $O(\log n)$ selected rows on which all column words are distinct. Swapping the roles of rows and columns gives $O(\log n)$ selected columns on which all row words are distinct. Dimension one is immediate.

Enumerate the target anchors and the injections giving the images of these two selected sets. There are $n^{O(\log n)}$ choices. Dephase the target at its candidate anchors. If its column words on the selected target rows are not pairwise distinct, or its row words on the selected target columns are not pairwise distinct, reject this choice. A genuine equivalence preserves these distinctions because multiplying by a unit preserves equality.

### Each word orbit gives an explicit abelian permutation group

Here are the arithmetic tests used throughout. Write $d_x=\gcd(m,x)$, $m_x=m/d_x$, and $b_x=x/d_x$, with canonical representatives of residues. When $m_x>1$, $b_x$ is invertible modulo $m_x$. For an ordered pair give it the invariant
$$
 C_m(x,y)=\bigl(d_x,d_y,b_y b_x^{-1}\bmod\gcd(m_x,m_y)\bigr),
$$
where the last component is zero when the modulus is one. Aligned lists $(x_i),(y_i)$ differ by a common unit exactly when all the single-entry gcds and indexed pair labels match. Indeed, each nonzero entry requires $u\equiv b_{y_i}b_{x_i}^{-1}\pmod{m_{x_i}}$. Matching the pair labels is exactly compatibility modulo the pairwise gcds. The generalized Chinese remainder theorem finds a unit residue modulo the least common multiple $L$ of the $m_{x_i}$. To lift it to a unit modulo $m$, strip from $m$ all prime powers supported on primes dividing $L$ by repeated division by its gcd with $L$. The remaining integer is coprime to $L$. Impose residue one modulo that remaining factor. The construction uses gcd and modular arithmetic, without factoring $m$.

Apply this test first to the column words on the selected rows. Partition them into unit orbits on each side, and match these classes by their invariant labels. Within one class choose an original word $v$. Its orbit is freely parametrized by unit residues modulo $L=\operatorname{lcm}_i m_{v_i}$. In fact $u v=u'v$ is equivalent to $u=u'\bmod L$, and any unit modulo $L$ lifts as above. Each source and target word in the class is represented by its unique such residue, computed by the same arithmetic tests. Distinct words give distinct residues.

Compute all bijections from this source class to its target class induced by multiplication by a single unit modulo $L$. Try the image of one fixed source word, which determines the residue of the multiplier, and verify the resulting permutation of the class. This uses at most $n$ trials. If there is none, reject this anchor choice. Otherwise all these bijections form a coset of the source stabilizer in the abelian group of unit residues. The stabilizer acts faithfully on the class, as its action on one word determines the residue. Thus we have an explicit base bijection and an explicitly enumerable abelian subgroup on the class. Take the product over classes, allowing each class its own multiplier at this stage. This gives an explicit abelian permutation group on the columns and a base bijection to the target columns. Carry out the same construction on the rows using the selected columns.

### Enforcing the one shared unit

Take the product of the two abelian permutation groups on the two sides of the matrix. Transport the target coordinates back by the base bijections already found. Make a colored string on polynomially many positions. Use positions for rows and columns, with colors marking the anchors and the chosen coordinate injections. Use one position for each cell with color $d_x$ for its dephased exponent $x$. Use one position for each ordered pair of cells with color $C_m(x,y)$. The group acts by permuting all these positions. If a genuine extended equivalence exists for this anchor choice, its row and column permutations lie in the constructed coset and match the strings. Conversely any string transporter yields one common unit by the indexed arithmetic tests, and the missing phase shifts follow from the vanishing of the anchored rectangle differences of the remaining discrepancy. In detail, an array $R$ with these differences zero satisfies $R_{ij}=R_{i b}+R_{a j}-R_{a b}$ for the anchor cell $(a,b)$.

String isomorphism under an explicit abelian permutation group is polynomial-time. For completeness, process the original group's orbits on string positions one at a time, maintaining a coset of the group satisfying the already processed constraints. On one original orbit, an element of the current subgroup is determined as a permutation on that orbit by the image of one point. Indeed, an abelian group element fixing that point fixes its translates under the original group, hence fixes that entire orbit. Enumerate the current subgroup's images of the point by orbit search, storing a representative for each. Test the induced permutation on the original orbit, accounting for the current coset representative. Acceptable images, when nonempty, give exactly one new coset. Generators for its subgroup come from the Schreier generators for the point stabilizer together with the normalized acceptable representatives. Compress the generator list using polynomial-time constructive membership at each stage. All actions in this computation are on polynomially many explicit positions. This is also a direct special case of the permutation-group algorithms for bounded nonabelian composition factors. [Luks–Miyazaki, §§1 and 3](https://ix.cs.uoregon.edu/~luks/polytimenormalizers.pdf)

The resulting time per anchor choice is polynomial in $n,\log m$. All cyclotomic arithmetic is on the supplied exponents. The Galois map sends a Butson matrix to another Butson matrix since it sends the cyclotomic orthogonality equations to themselves. The proof only needed the source Hadamard promise to find its separating sets. Strict equivalence is the special case in which the exact exponent colors are required. Transposition is handled by running both target orientations.

## Sparse cyclic gain graphs with large prime divisors

**Theorem.** Let $G$ be an undirected graph with oriented cyclic gains $g(v,w)\in\mathbb Z/m$, satisfying $g(w,v)=-g(v,w)$. Allow graph isomorphism, vertex-potential switching and an optional common unit modulo $m$. If every prime divisor of $m$ exceeds the maximum degree of the input graphs, the problem reduces to one ordinary graph-isomorphism instance of size polynomial in the input bit length. The graphs can be disconnected. The same follows if the largest divisor of $m$ supported on primes at most the maximum degree is bounded polynomially in the input length.

In a connected component, mark a root $r$. For every other vertex $v$ let $P(v)$ be its nonempty set of neighbors one step closer to $r$. Define a potential recursively by
$$
 T(r)=0,\qquad
 T(v)=|P(v)|^{-1}\sum_{w\in P(v)}(T(w)+g(w,v)).
$$
All denominators are units by the degree condition. For a switched gain assignment $g'(w,v)=g(w,v)+f(v)-f(w)$, induction on distance shows $T'(v)=T(v)+f(v)-f(r)$. The rooted normalized gains $g(w,v)-T(v)+T(w)$ are therefore invariant under switching. They are equivariant under rooted graph isomorphisms, and multiplying the input gains by a unit multiplies the normalized gains by the same unit. Conversely equality after these operations on the normalized gains gives a switching witness by subtracting the two potentials.

Here is the graph construction including disconnected supports and a single global unit. Give each connected component an identifier vertex, and attach to it a rooted copy for every choice of root in that component. Keep these copies distinct by giving every copy an identifier of a separate type. A copy has its own original vertices, a root flag and directed arc incidence. Attach to each directed arc the gcd label of its normalized gain. For every ordered pair of directed arcs across all copies, record its indexed $C_m$ label with role-colored incidences. Standard colored graph encodings realize these finite relations with only polynomially many vertices. A switching isomorphism with one common unit induces an isomorphism of the entire structure. Conversely the structure isomorphism has one common unit by the pair labels across the entire structure. Choose any one matched root copy per component. The associated rooted isomorphisms give the global graph isomorphism and independent switching potentials. Components with no edges impose no arithmetic condition.

For the second assertion write $m=m_s m_\ell$, where $m_s$ is the largest divisor whose prime divisors are at most the maximum degree. Compute the split without factoring $m$ by stripping common factors with the least common multiple of the positive integers at most the maximum degree. The preceding normalization handles $m_\ell$. For the small part $m_s$, inside each rooted copy add the explicit fibre of residues over each original vertex and the directed gain translation edges
$$
 (v,a)\longrightarrow(w,a+g(v,w)\bmod m_s).
$$
Use one shared set of reference elements of $\mathbb Z/m_s$ across all copies. A ternary relation links $(v,a)$, reference element $b$, and $(v,a+b)$. Any isomorphism preserving the relation induces an additive automorphism on the reference elements, because composing two translations corresponds to adding their labels. Thus it is multiplication by one common unit modulo $m_s$. On each fibre the isomorphism is this unit map followed by a vertex-dependent translation. The edge equations are exactly switching isomorphism with the prescribed base map. Both small and large constructions are attached to the same original vertices within each copy. They therefore use the same base permutation. Combine the two units and potentials by CRT. This remains polynomial when $m_s$ is polynomially bounded. Strict switching replaces the global unit constraint on the large part by exact colors and fixes the reference labels on the small part.

The rooted averaging argument applies to supports with arbitrarily long induced cycles. Standard gain-graph reconstruction instead represents a switching class by closed-walk gains, using a spanning tree for fixed vertex labels. The averaging gives an equivariant representative without having to choose a spanning tree under the input isomorphism action. [Cavaleri–Donno, *On cospectrality of gain graphs*](https://arxiv.org/abs/2111.12428)

## Fixed-degree connected supports with unrestricted modulus

**Theorem.** For each fixed $\Delta$, extended cyclic switching isomorphism of connected graphs of maximum degree at most $\Delta$ is decidable deterministically in polynomial time in the graph and $\log m$, for all $m$. A transporter can be returned. The strict variant is also supported.

Fix one root in the source and try its possible images in the target. For each rooted pair, use bounded-valence graph isomorphism to obtain one base isomorphism and generator lists for the source's rooted automorphism group $H$, or reject the pair. These computations are constructive in Luks's algorithm. The rooted automorphism group and its subgroups lie in a class $\Gamma_b$ of groups with nonabelian composition factors embeddable into a fixed symmetric group $\operatorname{Sym}(b)$. In fact the pointwise level stabilizers for the distance shells around the root have successive quotients that embed in products of symmetric groups on at most $\Delta$ neighbors. The nonabelian composition factors of subgroups of those products have order at most $\Delta!$, so $b=\max(2,\Delta!)$ suffices. [Luks, *Isomorphism of graphs of bounded valence can be tested in polynomial time*](https://doi.org/10.1016/0022-0000(82)90009-5)

At each stage keep a representative and generators of a coset of $H$ containing exactly the base permutations satisfying the constraints treated so far. The following two standard coset computations are used. For explicit permutation actions of $\Gamma_b$, set stabilizers and transporters of colored strings are polynomial-time. A string is a subset in the product of its position set with its color set, with the group acting trivially on colors. Likewise Luks and Miyazaki's Theorem 1.4 computes a subspace stabilizer of an explicit linear representation over $\mathbb F_p$ in deterministic polynomial time when $p\le\Delta$. To get transporters from either stabilizer routine, use the wreath product $H\wr C_2$, acting separately on two copies and allowing their swap. For subspaces $U,U'$, stabilize $U\oplus U'$ in the direct sum. It admits an element swapping the copies precisely when $H$ has a transporter. The nonswapping subgroup projects on the first factor to the stabilizer of $U$. This supplies a base transporter and stabilizer generators. The argument for sets is identical. The wreath product stays in $\Gamma_b$ and is supplied as a permutation group on twice the original degree. To transport a vector under an affine action on a vector space, add a fixed last coordinate and stabilize the line spanned by the augmented vector with last coordinate one. An affine action becomes linear on this augmented space, and the fixed last coordinate makes mapping the line equivalent to mapping the vector. [Luks–Miyazaki, Theorem 1.4 and §3](https://ix.cs.uoregon.edu/~luks/polytimenormalizers.pdf)

Separate all prime powers $p^a$ for $p\le\Delta$ by trial division and let $m_\ell$ be the remaining factor. For $m_\ell$ use rooted averages from the preceding section. Perform a colored-string transporter computation in the current coset on the indexed normalized arc gcds and pairs. This exactly imposes the switching-and-unit condition modulo $m_\ell$, and recovers a coset for the remaining computation. For the strict variant use exact normalized arc labels.

To impose the condition for $p^a$, use integral gain cohomology, namely the abelian group of integer edge gains modulo integer vertex potentials. Choose a spanning tree for the source (it need not be preserved by $H$). Every class is uniquely represented by a gain assignment vanishing on the tree. Its values on the non-tree arcs form integer coordinates, with orientation choices made once. These same coordinates identify the cohomology of gains modulo $p^a$ with the corresponding free module over $\mathbb Z/p^a$. Applying any base automorphism to gains and restoring the zero tree values gives the matrix of an integral linear action. The action is a group homomorphism since it is induced on cohomology. It is computable by applying the automorphism to each coordinate basis vector and summing along the tree. Pull back the target class by the current coset representative for the comparison.

Write $v,w$ for the source and pulled-back target coordinates. In the extended problem their common $p$-divisibility content is invariant under all permitted operations. If these contents differ, there is no transporter. If both classes vanish the constraint is immediate. Otherwise divide out the common power of $p$, reducing the exponent accordingly, so that $v,w$ are primitive and the desired relation is equality of their free cyclic submodules. Multiplication by a unit in the reduced modulus lifts to multiplication by a unit in the original prime power. At modulus $p$, use the subspace transporter just described. A nonempty transporter coset gives a representative and a subgroup that stabilizes the source line.

Suppose the coset constraints have been enforced through modulus $p^j$ for $j\ge1$. The current subgroup $H_0$ stabilizes the source line modulo $p^j$. Choose one coordinate $i$ with $v_i$ prime to $p$. For $h\in H_0$, define
$$
 a_h=(hv)_i/v_i\pmod{p^{j+1}},\qquad
 \delta_h=(hv-a_hv)/p^j\pmod p.
$$
The division is well-defined since $h$ stabilizes the line modulo $p^j$. Write bars for reduction modulo $p$, set $V=\mathbb F_p^r/\langle\bar v\rangle$ with $r$ the number of non-tree edges, and regard $\delta_h$ also as its class in $V$. The element $\bar a_h$ is the induced scalar on $\langle\bar v\rangle$. Expanding $ghv$ proves in $V$
$$
 \delta_{gh}=\bar a_h\delta_g+\bar g\delta_h,\qquad
 \bar a_{gh}=\bar a_g\bar a_h.
$$
The difference between the two scalar choices before dividing contributes a multiple of $\bar v$, which vanishes in $V$. Thus the following is an affine action on $V$:
$$
                  z\longmapsto \bar a_h^{-1}\bigl(\bar h z+\delta_h\bigr).
$$
It is exactly the action on lifts of the source line from $p^j$ to $p^{j+1}$. Every such lift can use a generator $v+p^j z$, after scaling its coordinate $i$ to equal $v_i$. This identifies the possible $z$ with $V$, since changing $z$ by a multiple of $\bar v$ only scales the generator. Applying $h$ and dividing by $a_h$ gives the displayed formula. Compute the target lift parameter from $w$ pulled back by the current representative, and transport $0$ to that parameter under this affine action. The resulting coset imposes the condition modulo $p^{j+1}$. Its stabilizer fixes the source lift and provides the next subgroup. There are at most $a$ such steps.

For strict switching, at modulus $p$ match the vectors themselves using their last-coordinate augmented lines. In subsequent steps the same argument uses $a_h=1$, so the affine action is on $\mathbb F_p^r$ without quotienting by a line. The well-defined difference $(hv-v)/p^j\bmod p$ defines the translation part. This enforces equality of the actual cohomology classes at each stage.

Apply these refinements for each small prime. The coset representative is updated by multiplication by the representative of each new transporter, so all previously imposed conditions remain valid. The number of stages is polynomial in $\log m$. The actions, field coordinates, and constructive group representations have polynomial size. The subgroup algorithms apply uniformly because the degree bound fixes $b$ and $p\le\Delta$ in the linear steps. Once a base map is found, recover the corresponding units and tree potentials in each modulus and combine them by CRT. This completes the connected bounded-degree result for arbitrary binary moduli.

## Scope and attribution

The earlier Sigil analysis used the monomial class of a descended generalized Hadamard matrix. The indexed phase comparison and the binary-modulus pair labels came from our earlier phase-equivalence work. The new algorithms use Hadamard orthogonality to bound the number of marked coordinates, or in the sparse case reconstruct switching potentials by averaging over predecessor sets. No hardness result for promised Hadamard matrices is asserted. Targeted searches found the earlier complex Hadamard equivalence algorithms, gain-switching characterizations, and recent graph-lift obstructions. They did not identify the exact composite-modulus time bound or the sparse averaging reduction above. Publication priority remains unverified. [*From Butson Hadamard switching to graph switching and back*, §3](https://arxiv.org/html/2611.18296v1#S3)
