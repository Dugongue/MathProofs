# Switching isomorphism with one common phase unit on disconnected graphs

**Theorem.** Fix a degree bound Δ. Given two arbitrary finite graphs of maximum degree at most Δ with oriented gains in a common cyclic group ℤ/m, supplied as binary residues, one can decide deterministic polynomial-time equivalence under a graph isomorphism, vertex-potential switching, and one common multiplier in (ℤ/m)×. A witness is constructible. The bound is polynomial in the graph encoding and log m, including when graphs are disconnected and m is unfactored.

Each unoriented edge has two directed arcs, with opposite gains. With source gain g and target gain g', the witness consists of a graph isomorphism φ, a unit u, and a function f on the source vertices such that
$$
 g'(\phi(v),\phi(w))=u\,g(v,w)+f(w)-f(v).
$$
The algorithm also handles prescribed vertex or edge colors. For strict switching take u = 1. Colors on the two arcs of an edge may differ if each is treated as a separate position.

The previous connected algorithm allows each component to choose its own unit. To enforce one common unit, we compute the full set of admissible units modulo each component type's effective modulus. The sets are multiplicative cosets with an explicit smooth exponent. We solve their simultaneous constraints by a composite-modulus version of the digit procedure behind Pohlig–Hellman, using gcd to separate distinguishable residue factors.

## 1. Simultaneous smooth-order multiplicative equations

**Arithmetic lemma.** Let E be a positive integer given with its prime factorization. Given arbitrary moduli M₁, …, Mₖ in binary and equations
$$
 \prod_{j=1}^{s} b_{ij}^{x_j}=c_i\pmod{M_i}\qquad (1\le i\le k),
$$
with unit coefficients satisfying bᵢⱼᴱ = 1, one can find integer exponents xⱼ satisfying all equations or decide that none exist. The deterministic bit time is polynomial in the input length, log E and the largest prime divisor of E. The moduli need no factorization. In particular, membership in a supplied subgroup of (ℤ/M)× is polynomial under this exponent bound.

Discard moduli one. Reject if cᵢᴱ ≠ 1 for any i. For every prime power ℓᵃ exactly dividing E, use generalized CRT to choose eℓ congruent to one modulo ℓᵃ and zero modulo E/ℓᵃ. Raise all inputs in each equation to eℓ. Since the original inputs have orders dividing E, equality holds exactly when all projected equalities hold. In the projected equations each exponent xⱼ matters only modulo ℓᵃ. We solve these systems independently and use CRT on the resulting exponents.

Fix a projected equation with modulus M. Strip M's ℓ-power by repeated exact division. On that known prime power, the subgroup generated by the elements of ℓ-power order is cyclic for odd ℓ. For ℓ = 2 and 2ᵗ with t ≥ 3, the unit group is the product of ⟨−1⟩ and ⟨5⟩ of orders 2 and 2ᵗ⁻². Read the first coordinate from reduction modulo four and remove it. Moduli two and four have unit groups of order one and two, respectively. In each resulting cyclic group, choose an input element of maximal order and read the exponent of every input element in that base by the usual prime-power digit test. The base generates the group spanned by all the inputs in that cyclic component. These coordinates produce linear congruences of moduli dividing ℓᵃ.

For the residual modulus D, coprime to ℓ, first note the following exact property. For every prime power qᵗ exactly dividing D, reduction modulo q is injective on ℓ-primary units modulo qᵗ. Indeed its kernel has q-power order. The ℓ-primary subgroup is therefore cyclic, because it embeds in the multiplicative group of the field of q elements. As a result, for any ℓ-primary element z modulo D,
$$
 \gcd(D,z-1)
   =\prod_{q^t\parallel D\ :\ z=1\bmod q^t}q^t.
$$
This identity is used by the algorithm without finding the unknown q.

Maintain a list of pairwise coprime factors whose product is D, starting with D alone. For each projected coefficient and right-hand side z, and each j from zero to a, split every current factor B into the nontrivial parts of gcd(B,z^(ℓʲ)−1) and its complementary factor. Carry labels already computed to both children. Each factor after these tests has a uniform local order for each input element, meaning its order agrees on all prime-power divisors of that factor. Choose an input g of maximal local order ℓᵇ on each factor. At each prime-power divisor, every input belongs to ⟨g⟩. The local exponent of an element can vary between prime-power divisors. The next refinement makes these exponents uniform without having to list the divisors.

For an input element z on one current factor, suppose the first j digits of its exponent in g are already known and combine to c, with 0 ≤ c < ℓʲ. For each digit d from zero to ℓ−1 compute the gcd with the factor of the residue
$$
       (z g^{-c-d\ell^j})^{\ell^{b-1-j}}-1.
$$
At each unknown prime-power divisor exactly one digit test is positive, because if z = gᵏ the condition is k ≡ c+dℓʲ modulo ℓʲ⁺¹. The gcds therefore partition the factor into pairwise coprime pieces. Label each piece with its successful digit. Continue until j = b, and repeat for every element. Factors split during this process retain the base and order of the parent. Every final factor has logarithms that agree at all of its unknown prime-power divisors. The argument also covers a trivial local group by imposing no equation there.

The final multiplicative equation on each factor is exactly a linear congruence in the xⱼ with modulus ℓᵇ, coefficient the recorded exponent for bᵢⱼ, and right-hand side the recorded exponent for cᵢ. Combine these with the congruences from known ℓ-powers and solve using integer linear systems, for example by adding one slack variable per congruence and applying polynomial-time Smith normal form with transforms. This treats the same xⱼ in all equations. The total number of live factors in any split is at most log₂ D. Each exponentiation and gcd has polynomial bit cost and the digit trials use at most ℓ trials per digit. This proves the lemma, including when only a single subgroup-membership test is needed. The digit identity is the Pohlig–Hellman step. The additional arithmetic here is correlated simultaneous refinement by gcd in unfactored moduli. [Pohlig–Hellman](https://doi.org/10.1109/TIT.1978.1055817) · [Kannan–Bachem, polynomial integer normal forms](https://doi.org/10.1137/0208040)

## 2. The connected transporter interface

Write U(k) = (ℤ/k)×, using the trivial group for k = 1. In each connected component use a spanning tree to represent a gain class modulo switching by its gains on the non-tree arcs after zeroing the tree gains. These coordinates give a vector in (ℤ/m)ʳ, r the number of non-tree edges. An integral change of spanning tree is invertible over ℤ and natural under graph isomorphisms. Thus d = gcd(m, all coordinates) is intrinsic. Its effective modulus is k = m/d, and the divided vector a in (ℤ/k)ʳ has coordinates that together with k have gcd one. Multiplication of a by a unit in U(k) is faithful because an integer linear combination of its coordinates equals one modulo k. Any unit in U(k) lifts to U(m). Indeed, strip from m all prime powers with prime dividing k by repeated gcd with k and require residue one modulo the remaining factor. If k = 1 the class vanishes. [Cavaleri–Donno, gain switching and closed-walk characterization](https://arxiv.org/abs/2111.12428)

We use a constructive algorithm that, for a connected pair, finds a graph isomorphism mapping the two classes projectively, or decides none exists. For any specified source and target roots it returns the transporter coset among rooted graph isomorphisms. Here is the interface proof.

- Obtain the support transporter and generators of the rooted source automorphism group by the constructive bounded-degree graph-isomorphism algorithm. The group lies in a class Γᵦ with bounded nonabelian composition factors. Indeed, successive pointwise stabilizers of distance levels have quotient embedding into a product of symmetric groups of degree at most Δ. A simple factor of a subgroup of such a product is a factor of a subgroup of one of the factors, by projection and induction. The same applies to colored supports, by further subgroup restriction. Luks–Miyazaki's set and subspace stabilizer algorithms apply to these groups, including subspace stabilizers over fixed finite fields. To compute a transporter between two sets or subspaces use the direct-sum or disjoint-union action of a wreath product with C₂ and query whether the stabilizer has an element interchanging the two copies. The nonswapping stabilizer projects to the original stabilizer. The wreath product still has bounded nonabelian composition factors. [Luks](https://doi.org/10.1016/0022-0000(82)90009-5) · [Luks–Miyazaki, Theorem 1.4 and §3](https://ix.cs.uoregon.edu/~luks/polytimenormalizers.pdf)
- Separate the prime powers in k with prime at most Δ by trial division. On the remaining factor, root the graph at r and let P(v) be the neighbors one distance level closer to r. Normalize gains using T(r) = 0 and T(v) = |P(v)|⁻¹ Σ₍w∈P(v)₎ (T(w) + g(w,v)). The denominators are units. Under switching by f, T changes by f(v)−f(r), so g(v,w)−T(w)+T(v) is switching invariant. It is equivariant under graph isomorphism preserving the root. Its comparison up to one unit is a color-string transporter on arcs and ordered arc pairs. For a normalized phase x modulo M set dₓ = gcd(x,M), kₓ = M/dₓ and rₓ = x/dₓ. Give each arc the color dₓ and give an arc pair (x,y) the ratio label rᵧ rₓ⁻¹ modulo gcd(kₓ,kᵧ), ignoring a modulus one. Equality of all aligned labels means that the entrywise required multiplier congruences agree modulo their pairwise gcds. Generalized CRT supplies one common unit. This is the indexed Sigil/Rune/Ward phase comparison. Strict comparison uses exact normalized values.
- On a small prime power pᵃ, use the linear action on the non-tree coordinates induced by graph automorphisms. Compute a generator's matrix by applying it to each coordinate basis vector and zeroing the tree again. The reduced gain vector v is primitive at p. In the extended problem, at modulus p ask for a transporter of the line spanned by v by Luks–Miyazaki. Through modulus pʲ maintain the coset of transporters and the source line stabilizer. For an element h of that stabilizer, select an index i with vᵢ a unit and set aₕ = (hv)ᵢ/vᵢ modulo pʲ⁺¹, and δₕ = (hv−aₕv)/pʲ modulo p. All lifts of the line are parametrized by z in Fₚʳ/⟨v mod p⟩ by choosing v+pʲz as generator. The action on z is aₕ⁻¹(hz+δₕ) modulo p and the line. This follows by applying h to the generator and rescaling by the unit aₕ. The next target lift is computed by pulling back the target through the current transporter representative. Add a fixed last coordinate to this affine action and use subspace transport on the line spanned by the augmented point with last coordinate one. Its fixed last coordinate forces any line transporter to transport the point. At p the strict variant uses the augmented vectors themselves. In strict lifting take aₕ = 1 and work in Fₚʳ. There are at most a lifts and p ≤ Δ.
- At each stage, transport in the current coset by pulling back the target with the current coset representative. This updates the representative and restricts the source stabilizer. Conditions for distinct prime powers or factors compose by CRT. At the end the transporter coset is exact. The unit of a given transporter is computed from a Bézout linear combination of the original primitive coordinates modulo k. Trying all target roots handles unrestricted connected pairs. For a candidate witness in the original modulus, compute the switching potential by summing the discrepancy along the source spanning tree.

This proves the required connected algorithm, including the constructive group output. Every use of a linear stabilizer is over a field of size at most Δ. Matrix sizes, number of candidate roots and number of prime-power lifting stages are polynomial in the input.

## 3. Compute all permissible units for a component type

Partition the components of both graphs into projective equivalence types by the connected algorithm. If the two multiplicities of some type differ, reject. For a type of common effective modulus k choose reference component R from the source. For every component A of this type, find a reference isomorphism φₐ from R to A and its multiplier aₐ ∈ U(k), so that φₐ* gₐ = aₐ gᵣ on the divided cohomology classes.

Let H ≤ U(k) be the group of multipliers of all projective automorphisms of R. To compute its generators, choose one root of R. Run the rooted connected transporter for every image of the root, where target equals source. Each nonempty transporter is one coset of the root stabilizer in the projective automorphism group. The generators of that stabilizer combined with one representative of each nonempty coset generate the whole projective automorphism group. Map these generators to their unique multipliers by the Bézout formula above. This gives polynomially many explicit generators for H. Its order divides |V(R)|!, since the multiplier map is a group homomorphism on a subgroup of permutations of V(R).

For A in the source and B in the target of this type, exactly the residues in aᵦ aₐ⁻¹H can occur as multipliers of a switching isomorphism A → B. Indeed, conjugating that isomorphism by the reference maps gives a projective automorphism of R, with multiplier u aₐ aᵦ⁻¹. This also proves sufficiency by reversing the composition.

In U(k)/H represent the two lists of components by multisets P and Q of the cosets aₐH and aᵦH. Given u, the whole type matches exactly when uP = Q. Any such translation must take a chosen point of P to a point of Q. Try those polynomially many candidates aᵦ aₐ⁻¹, and check the equality of multisets using the arithmetic-lemma membership test in H. A whole coset modulo H is permissible as soon as its tested representative is. If no candidate works, reject.

If there are successful candidates, their union of H-cosets is a single coset u₀K, where K is the preimage of the translation stabilizer of P in U(k)/H. To generate K, take the generators of H and the quotient of each successful candidate by u₀. Translation by K/H on the support of P is free, and its orbits preserve multiplicities. Hence |K/H| divides the cardinality of P counted with multiplicities. For n the total number of vertices, an exponent for every such K is E = (n!)². Its prime factors are at most n and its factorization is computed by a sieve and known factorial exponents. This bit length is polynomial. The case with no components can be decided before using E.

## 4. Glue units across types and recover a witness

For each type t of modulus kₜ write its computed coset as uₜ⟨hₜ₁,…,hₜₛ⟩. Introduce integer exponents xₜⱼ. A global unit exists exactly when residue choices from these cosets agree modulo gcd(kₜ,kᵥ) for every pair of types t,v. These conditions are precisely the multiplicative equations
$$
 \prod_j h_{tj}^{x_{tj}}\prod_j h_{vj}^{-x_{vj}}
       =u_v/u_t\pmod{\gcd(k_t,k_v)}.
$$
Their coefficients have E-th power one, so the arithmetic lemma solves the conditions simultaneously in polynomial time. Generalized CRT constructs the resulting unit modulo lcmₜ kₜ. Lift it to a unit modulo m using the earlier gcd procedure. Components with vanishing classes impose no condition on u.

To return a witness, scale each source component by the now known u and run the strict connected algorithm against each candidate target component. A bipartite perfect matching selects compatible partners, and the computed strict witnesses combine by disjoint union. Such a matching exists because each projective type passed its multiset test for that unit. Conversely, a global witness gives multipliers in every computed coset and the same residues on all pairwise overlaps, so it passes the algorithm. This proves the theorem.

**Vector-valued gains.** The theorem extends to any supplied product of cyclic gain groups, allowing one common integer unit acting by scalar multiplication on all factors. Use m equal to the least common multiple of the factor moduli mᵢ, and embed each into ℤ/m by x ↦ (m/mᵢ)x. The connected cohomology vectors have one coordinate per non-tree edge per factor. The interpolation of potentials in witness recovery stays in the embedded factors because it merely sums actual cycle-coordinate discrepancies along a spanning tree. Every operation and bound above applies. This extension specifies the common scalar action, as in the cyclic theorem.

## Scope

The result covers arbitrary disconnected support at each fixed maximum degree and arbitrary input modulus. The connected transporter uses bounded-degree permutation-group machinery. The smooth-exponent arithmetic lemma is independent of graph degree and applies whenever compatible residues are specified by explicit smooth-order coset generators. This note uses the indexed phase comparison from our earlier phase-equivalence work to obtain each connected transporter, and replaces separate componentwise existence tests with simultaneous computation in their full multiplier cosets. The theorem has an informal proof. Exact priority for the disconnected variable-modulus result and the composite-modulus arithmetic lemma has yet to be established.
