# UNIFORM SIGNATURE AND VARIABLE ARITY, WITH DENSE DATA

Companion to PROOF.md. Informal, no Lean verification of this new application.

Theorem. Let the one-base-space linear signature of Grochow–Qiao Definition 7.1 be part of the input, with the primal/dual arity counts written in binary. Relation bases and function values are still written out densely. Then there is one uniform polynomial-time reduction to ordinary 3-TI over the same field, with no requirement that the number of components or arity be fixed. The same holds for multisorted models with the factor words explicitly listed, not given by an arbitrary compressed grammar. Field/time conventions are those in PROOF.md.

Theorem's ingredient already available in MathProof. PRIOR-UNIFORM-PACKING.md Sections 1–6 gives a uniform polynomial reduction of arbitrary explicit mixed systems of order at most three to systems with fourteen components. Those systems then use the existing published constant-component FGS compiler. This avoids the exponential dependence of a direct FGS application on the original component count. The checked MixedTensorCompiler gives the algebraic correctness and linear dimension bound for a later variant; our proof does not treat its Lean certificate as formal verification of runtime. The fixed-round explicit packing operations, disjoint occurrence blocks and bounded number of final parts give polynomial construction time. Section 8 of the September note already records the arbitrary-order dense tensor-system consequence. The present application is to the exact basis-explicit relation/function inputs, including a binary-arity edge case.

1. Delete inactive high-arity components before expanding anything.
Compare base dimensions and each relation dimension. A mismatch is a fixed NO instance. Discard zero relations, whose preservation is automatic. If base dimension n=0, all components are uniquely zero. If no active data remain, return the fixed YES instance. Zero-valued functions on positive-dimensional domains are still supplied as dense arrays, so they count as explicit data. In multisorted models also discard zero-domain/zero-codomain maps, and ignore named spaces occurring only in discarded components after checking their dimensions.

2. Positive dimension n>=2.
Let L be the encoded input length, counting the explicitly written coefficient positions. Every retained relation has at least one basis vector of length n^a for its arity a; every retained function has a full domain array of at least n^a coefficient positions. Thus each active arity satisfies a<=log_2 L. Each active word space and each of its prefixes has dimension at most L. There are at most L data labels and at most O(L log L) named prefix spaces and product components. Each canonical bilinear map has a dense coefficient array of size at most L^2, since the product of its two input dimensions is its output dimension. The remaining structural and data arrays, and the relation-basis sorts, also have dimensions polynomial in L. Use the construction of PROOF.md; its witness equivalence is unchanged. Hence the typed front end has uniformly polynomial output length and runtime.

3. Dimension n=1 and binary arities.
Here a written coefficient array need not have length comparable to a huge arity, so an arity-long chain would be wrong. Replace the linear prefix chain by a binary addition chain. For each sign, build the one-dimensional named spaces for exponents 1,2,4,...,2^j via the fixed product map from the previous space with itself. Assemble the selected powers according to the binary expansion of the positive primal count r, and likewise of the dual count s. Combine their outputs by one last product when both are present. Every structural product is the one-entry bilinear multiplication tensor between its prescribed sorts. Their number is O(log(1+r)+log(1+s)), not O(r+s). Reuse or duplicate auxiliary power sorts as convenient; labels are stored as binary exponents, not expanded words.

The scalar sort L remains pinned, and evaluation forces the dual base action lambda^{-1} when the primal base action is lambda. Each fixed product forces multiplication of its two input scalars on its output sort. Inducting through the addition chain gives exactly lambda^r on the primal power and lambda^{-s} on the dual power, hence lambda^{r-s} on the required mixed word. The function/inclusion constraints are exactly those of the original model. The compiler does not compute or enumerate the unknown lambda. The output depends only on binary exponent bookkeeping and explicit data. This proves polynomial time in the original binary signature even in dimension one.

4. Multiple named base spaces and explicit words.
Each active word has positive-dimensional factors. Its full dimension is a product of positive integers and is bounded by the size of its explicitly written data array, as is every prefix dimension. Total explicitly listed word length is part of L, so the previous prefix construction has polynomial total dimension, occurrence dimension, and dense coefficient count. Inert dimensions can be dropped as in Section 1. No polynomial bound is claimed for arbitrary grammar-compressed words with dimensions that are not charged by dense data.

5. Final assembly.
Apply the uniform fourteen-component packing from the earlier note, then the FGS constant-component compiler. All field-valued structural coefficients are fixed small constants or copied data, with standard exact basis conversion if needed. There is no exponent depending on a variable count of source components. This establishes one uniform polynomial reduction, not merely a separate polynomial for each fixed signature. The theorem includes all fixed-signature instances of Question 7.4. Its mathematical mechanism is largely prior MathProof work; the binary-arity handling and precise application are documented here, without a public-priority claim.

This stronger explicit-input statement still does not solve unrestricted SL-TI. A dense volume tensor on an n-dimensional space is not polynomial in the length of a 3-TI input just because this reduction is polynomial in the volume tensor's own explicit length. The missing compact equivariant encoding of the determinant is unchanged.
