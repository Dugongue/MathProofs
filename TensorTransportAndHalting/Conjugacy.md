# A cyclic conjugacy class in a fiber of one fixed nilpotent group

**Theorem.** There is one finitely generated torsion-free nilpotent group G of class two with a fixed split epimorphism χ to ℤ² such that the following set is computably many-one equivalent to the halting set. The input is a nonnegative integer n. Ask whether χ⁻¹(1,n) contains an element g for which the subgroup [g,G] is infinite cyclic. The minimum rank of [g,G] on this fiber is always either one or two. A rank-two witness is given by a formula on every input. At every prime, the coordinate group over the p-adic integers has a witness with a commutator image isomorphic to the additive group of p-adic integers. The analogous real group has a witness with one-dimensional commutator image.

This is unconditional. The multiplication law, commutator tensor and quotient map are fixed. In a class-two group the conjugacy class through g is the coset g[g,G], so the question asks if a fiber contains an entire conjugacy class that is an affine lattice line. For any specified pair of elements of this group, conjugacy itself is decidable.

### Encode integral solutions as matrices of rank one

By integer DPRM there is a fixed integral polynomial U(t,u) such that U(n,u)=0 has an integral solution exactly when machine n halts. For a presentation over nonnegative integers, replace each witness by a sum of four squares. Multiply U by (z²−13)(z²−17)(z²−221). None of these factors vanishes on integers. The real numbers and the p-adic integers for each prime contain a root of some factor. For odd primes different from 13 and 17, the three Legendre symbols of 13, 17 and 221 include a +1 and the root lifts. At 13 use 17 ≡ 4, at 17 use 13 ≡ 8², and at 2 use 17 ≡ 1 modulo 8. Thus the augmented polynomial has local integral solutions at every prime for every input. [Universal Diophantine equation](https://doi.org/10.2307/2273588)

Turn this fixed equation into fixed affine quadrics by naming the values of each arithmetic gate. Homogenize to quadrics q on a vector of length d, whose coordinate with index 0 is the homogenizing variable and whose entry with index t is the machine input. Let L be the lattice of symmetric integral d by d matrices satisfying the linear equations obtained by replacing each monomial x_i x_j in q by X_ij. If X has rank one and X₀₀=1, all two-by-two minors vanish and X_ij = X_i₀ X_₀j. Therefore X is exactly xxᵗ for the integer vector x given by its first column. Imposing X₀t=n makes each gate hold at integral arguments. Conversely every solution produces such a matrix. This identity with a unit pivot works over the reals and over the p-adic integers as well. The lattice L has an effective integer basis by Smith normal form. Its base change to the p-adic integers is the kernel of the same linear constraints, by the same Smith form.

### Build one commutator tensor

Take the parameter lattice P=L ⊕ ℤ², with coordinates p=(X,c,e). Let V=ℤ⁽ᵈ⁺²⁾ and define M_p on V by acting by X on the first d coordinates and by the block

    [ c  e ]
    [ 0  c ]

on the last two. Let W=V ⊕ Λ²V. For basis indices i<j let η(v,v′) have coefficient v_i v′_j in Λ²V. Then η(v,v′)−η(v′,v)=v∧v′. Give G=P ⊕ V ⊕ W the law

    (p,v,w)(p′,v′,w′) = (p+p′, v+v′, w+w′+(M_p v′, η(v,v′))).

The central correction is bilinear, so the law is associative. Inverses exist by solving successively for the three coordinates. Projection onto the free abelian quotient P ⊕ V, with free central kernel W, shows torsion-freeness and finite generation. The nonzero wedge commutators give class exactly two. With a consistent choice of commutator sign its commutator tensor is

    ((p,v),(p′,v′)) ↦ (M_p v′ − M_p′ v, v∧v′).

Define χ(p,v,w)=(X₀₀+c, X₀t+e). This is a surjective homomorphism split by the two dummy parameters with X=v=w=0. In particular every input fiber has an elementary point.

### Exhaust all possible group elements in the fiber

If v is nonzero, the exterior projection of [g,G] has rank dim(V)−1, since the rational kernel of v′ ↦ v∧v′ is the line through v. This rank is at least two. If v=0 the commutator image is exactly the image of M_p in the central V. Its rank is the rank of X plus the rank of the displayed two-by-two block.

On χ=(1,n), rank zero is impossible. If c is nonzero, the dummy block already has rank two. If c=0, then X₀₀=1. Rank one thus forces e=0 and rank X=1, whereupon X₀t=n. The preceding unit-pivot calculation recovers an integral solution. Conversely such a solution with v=c=e=0 supplies an infinite cyclic commutator image, generated by a primitive vector because X₀₀=1. On every input the point X=v=0, c=1, e=n has image rank exactly two. These cases are exhaustive. Integer enumeration semidecides existence of a cyclic image, and n enters unchanged, proving both computable reductions. The same unit-pivot construction using the local fallback solutions gives a primitive rank-one image at every completion specified above.

### What the quantifier changes

For any specific g, the brackets with coordinate generators give an integer matrix whose column lattice equals [g,G]. Its rank is computable. For a specified pair g,h test that their projections to P ⊕ V coincide, then use Smith normal form to decide whether the central difference belongs to this column lattice. For the fiber question there is no computable bound in terms of the input length on how far to enumerate possible integral g in affirmative cases.

Systems of equations in nilpotent groups have long been known to encode undecidability. The specialization here fixes the group, its commutator tensor, a split quotient, and the rank-one conjugacy-class condition. Only one coordinate of the fiber changes. General algorithms for nilpotent-group isomorphism concern another input contract. This informal deduction makes no publication-priority claim.
