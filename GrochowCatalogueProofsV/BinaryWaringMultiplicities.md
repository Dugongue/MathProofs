# Computing representation multiplicities of binary Waring secants

## GP-0567

For binary forms over the complex numbers, the multiplicity of any irreducible representation in any specified homogeneous component of the coordinate ring of the border-Waring-rank-at-most-$r$ variety is computable in bit time polynomial in the form degree $d$, the grading parameter $e$, and $r$. The algorithm works with variable $r$ and applies also when the secant fills the ambient space. This solves the binary case of the bounded-Waring-rank multiplicity question.

Use projective coordinates $X_0,\ldots,X_d$ of the rational normal curve in the normalization where the parametrization is $(s^d,s^{d-1}t,\ldots,t^d)$. The rank-$r$ secant ideal has a diagonal initial ideal generated by products
$$
X_{i_0}\cdots X_{i_r},
\qquad i_{j+1}-i_j\ge2.
$$
Indeed its Hankel minor generators are a Gröbner basis for a diagonal term order. The main diagonal of a minor with columns $c_0<\cdots<c_r$ and consecutive rows $0,\ldots,r$ uses indices $c_j+j$, and every displayed spaced set is obtained this way. This Gröbner description is valid also when the generators are absent because no such index set exists. The polynomial and torus weight gradings are preserved, so weight multiplicities are exactly the numbers of standard monomials of the corresponding grade and weight. [Sturmfels–Sullivant, combinatorial secants and Hankel matrices](https://arxiv.org/abs/math/0506223)

A monomial $\prod_i X_i^{a_i}$ is standard precisely when the path on its occupied indices contains no independent set of size $r+1$, with edges between adjacent occupied indices. The largest independent set is found by scanning indices in order and taking an occupied index whenever the previous index was not taken. This greedy rule is optimal because replacing the first chosen index of any maximum independent set by the first occupied index cannot conflict with a later chosen index. Continue inductively. It treats zero exponents and higher multiplicities separately, as needed.

Count such monomials by dynamic programming. After an index, store accumulated total exponent, accumulated weight $\sum_i i a_i$, the greedy count up to $r$, and a bit recording if the previous index was chosen. On the next index try each exponent from zero through the remaining total degree. The greedy update is fixed by its positivity and the bit, and a count beyond $r$ is discarded. This is a polynomial number of states and transitions in $d,e,r$. Every count is bounded by $\binom{e+d}{d}$ and therefore has polynomial bit length.

Let $c(j)$ denote the resulting weight multiplicity for $\sum_i i a_i=j$ at grade $e$. In the dual of the grade-$e$ coordinate representation the corresponding weight is $(de-j,j)$. Every irreducible of highest weight $(de-b,b)$ with $0\le b\le de/2$ has weights $(de-j,j)$ for $b\le j\le de-b$, each once. Hence its multiplicity is $c(b)-c(b-1)$, with $c(-1)=0$. Dualizing determines the original coordinate ring representation. This gives every multiplicity, with support far beyond the open dense orbit. The argument depends on the Hankel initial ideal for binary forms and does not assert a general fixed-parameter theorem when the number of form variables grows.
