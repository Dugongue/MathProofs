# Monotone graph separation by walk signatures and color refinement

## GP-0887

There is a uniform polynomial-size family of monotone arithmetic invariants separating every pair that ordinary vertex color refinement separates. There is also a polynomial-bit-time monotone invariant family that separates a graph from every nonisomorphic competitor whenever its return-walk vectors distinguish its twin classes. On Boolean inputs the invariants are nonnegative combinations of squarefree subgraph orbit sums. The latter family has polynomial degree as well as polynomial circuit size.

### Separating twins by return walks

Fix the graph order $n\ge2$. For vertex $v$ put
$$
x_v=\sum_{j=0}^{n-1} B^j(A^j)_{vv},
\qquad B=1+n^n .
$$
The base $B$ exceeds every walk count used. Thus $x_v$ encodes exactly the first $n$ diagonal powers. Twinhood means agreement of neighborhoods outside the given pair. Twins have the same $x_v$ because their transposition is an automorphism.

Use as invariants the vertex moments $S_i=\sum_v x_v^i$ for $1\le i\le n$ and edge moments
$$
T_{ij}=\sum_{u,v} A_{uv}x_u^i x_v^j,\qquad 0\le i,j<n .
$$
The vertex moments determine the multiset of $x_v$ by Newton identities. If its distinct values are $\lambda_1,\ldots,\lambda_m$, let $N_{ab}$ be the number of ordered adjacent pairs with endpoint values $\lambda_a,\lambda_b$. Then the leading $m$ by $m$ edge-moment array is $VNV^{\mathsf T}$, where $V_{ia}=\lambda_a^i$ for $0\le i<m$. The Vandermonde matrix $V$ is invertible, so the moments determine all $N_{ab}$.

If each value class in one graph is a twin class, every cross-class block is complete or empty and the same holds for all allowable off-diagonal positions within a class. Thus each count $N_{ab}$ is zero or the maximum possible value for the specified class sizes. Any graph with the same invariants has the same sizes and the same extreme counts, so it has identical complete and empty blocks and is isomorphic. Evaluation uses only nonnegative constants, addition and multiplication. Vertex signatures have polynomially many bits, and their powers and moments likewise. The degrees are at most $1+2(n-1)^2$.

### Separating every distinction found by color refinement

The next construction uses arithmetic circuit size, without a polynomial bit-length guarantee for the final numerical values. Start with $x_{v,0}=1$ and $U_0=2$. At step $t$ choose the graph-independent base $B_t=(n+2)U_t^{n+1}$, and put
$$
x_{v,t+1}
=x_{v,t}+\sum_{j=0}^{n} B_t^{j+1}\sum_{u} A_{vu}x_{u,t}^{\,j},
\qquad U_{t+1}=B_t^{n+2}.
$$
Inductively $x_{v,t}<U_t$; the base exceeds the previous label and each of the $n+1$ neighborhood moments. Equality of new labels is therefore equality of old labels and all those moments. The zeroth moment determines the neighborhood size, and the first $n$ recover its multiset of old labels by Newton identities. These labels implement the ordinary refinement simultaneously across any pair of graphs of order $n$, with no input-dependent assignment of color identifiers. Take $2n$ rounds, enough for stabilization on a disjoint union of two such graphs. The first $n$ vertex moments of the final labels are equal precisely when their final color multisets agree.

Both constructions have polynomial circuit size and are invariant under all vertex relabelings. All integer constants in the iterative construction are generated by monotone powering of bounded binary constants, so their possible large numerical values do not enlarge the circuit descriptions. An invariant polynomial with nonnegative coefficients is a nonnegative sum of monomial orbits; replacing positive exponents by one preserves evaluations on Boolean inputs and preserves nonnegativity and invariance. This gives the claimed subgraph orbit-sum interpretation. These families supply separation in the stated models and leave universal monotone graph separation open.
