# When a bare tensor inherits graph algorithms

Work over fixed Fq with ordinary ordered-mode tensor isomorphism and dense input length L. We give both an unconditional decomposition step and a polynomial GI reduction on a recognizable class. None requires the input to be delivered as a network or with a chosen decomposition.

**Strip unused dimensions.** For T∈A⊗B⊗C take the three flattening images A₀,B₀,C₀ in their own modes. These are the intrinsic supports. A matching triple restricts to a matching triple of the concise cores, and any match of the cores extends if ambient mode dimensions agree. For support rank r in ambient dimension n, the number of invertible extensions of a fixed support match is q^(r(n−r)) times |GL_(n−r)(q)| (a free off-diagonal block and an invertible complement map). Multiply over modes for exact counts. The zero tensor needs only this formula and the dimension check.

**Recover the direct summands.** For a nonzero concise tensor solve the linear equations
$$(X\otimes1\otimes1)T=(1\otimes Y\otimes1)T=(1\otimes1\otimes Z)T.$$
The tuples form its centroid. For clarity, denote the action on slot i of a tuple a by a_i. For two solutions a,b and three distinct slots i,j,k, the chain a_i b_i T = a_i b_j T = b_j a_i T = b_j a_k T = a_k b_j T = a_k b_i T = b_i a_k T = b_i a_i T proves commutation on T. Concision means that an operator on any single mode killing T is zero. Thus the tuples commute componentwise. Their componentwise products again satisfy the centroid equations by moving actions between slots, and the identity is a solution. This gives an explicitly computable commutative finite-dimensional algebra. Using its primitive idempotents splits each mode and $T=\bigoplus_e T_e$: apply one idempotent to one slot, use the same idempotent on either other slot, and use orthogonality to kill cross terms. Each nonzero idempotent acts nontrivially in every mode by concision. Conversely, a direct-sum decomposition gives the three projection tuples in the centroid. Any further decomposition inside a primitive block would extend by zero to split that idempotent. Hence this decomposition is unique as an unordered collection of simultaneous summands. Center methods for multilinear direct-sum decomposition are established. [Huang–Lu–Ye–Zhang](https://arxiv.org/abs/2110.07915).

For fixed q compute the fixed subalgebra of the q-power Frobenius by linear equations. On each local factor of the centroid the fixed elements are precisely Fq: reduction to its residue field gives a scalar, and a Frobenius-fixed nilpotent difference vanishes. Hence the fixed algebra is a product of copies of Fq. Split its identity successively by the q possible values of every basis element using the coordinate-indicator polynomial 1−(x−a)^(q−1). The nonempty final pieces are exactly the primitive idempotents. This is polynomial in the dense input size and works for a nonreduced centroid as well.

An isomorphism permutes the recovered summands. A choice of block bijection and a block isomorphism for each matched pair extends uniquely by direct sum. For a concise input with indecomposable types X appearing m_X times,
$$|\mathrm{Aut}(T)|=\prod_X m_X!|\mathrm{Aut}(X)|^{m_X}.$$
Thus a solver for the irreducible *direct-sum blocks* suffices, with polynomially many calls (here irreducible means direct-sum indecomposable only). A single indecomposable input receives no shrinkage from this step.

**Transfer to one GI instance.** If each block has all three dimensions at most b, construct invariant vector labels in each support mode by taking the union of all vectors in its component subspaces, deduplicated. For dual labels take the corresponding component functionals, extended by zero across the complementary summands. Each label set spans and has size at most the number of blocks times q^b. Record all primal/dual evaluations and the evaluations of T on triples of dual labels in a bounded-arity colored relational structure. Every isomorphism acts on these sets. Conversely a bijection preserving pairings extends uniquely linearly: a putative relation of primal labels maps to a vector pairing to zero with all target dual labels, hence to zero. The same holds for its inverse. Tensor evaluations on the spanning dual labels force preservation of T. Colored incidence converts this to GI. The correspondence is exact on witnesses at the relational level; rigid position and color tags can be used for ordinary graph isomorphisms. For b≤c log_q L, c fixed, all sizes are polynomial. This applies directly to an arbitrary presented tensor passing the test, in unknown coordinates. Counts on nonconcise inputs restore the extension factors above.

**A different recognized graph class.** Let S be the third flattening image in A⊗B of a concise tensor. Compute the full left and right multiplier algebras: these are the endomorphisms of A or B whose action in that one slot preserves S. If both algebras split their mode into one-dimensional simultaneous eigenspaces and are the full diagonal algebras, their individual coordinate projections preserve S. Thus S is exactly a span of selected coordinate cells. Recover those cells by checking the projections and encode a bipartite graph on the recovered lines. All isomorphisms must permute lines in each mode. A graph isomorphism lifts by choosing nonzero representatives of the lines and mapping accordingly, and the third map is forced. In F2 all representative choices are unique. In Fq every such core graph witness has (q−1)^(dim A+dim B) lifts. Recognize the promise by linear systems for the multiplier algebras, simultaneous eigenspace refinement over the fixed field and dimension checks. Incidence spaces with pairwise incomparable neighborhoods on both sides are examples: a left matrix entry in position i,j is allowed only if the neighbor set of j is contained in that of i, and likewise on the right. [Graphical matrix spaces](https://arxiv.org/abs/2206.04815).

These are separate tests. In particular the zero-sum incidence construction of [FromGraphs.md](FromGraphs.md) uses a different decoder. Neither test assumes every tensor has an intrinsic small frame. A graph algorithm run on the recognized class solves those bare tensor instances with the cost of constructing and processing the graph included.
