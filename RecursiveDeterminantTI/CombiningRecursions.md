# Combining recursive determinant records

The cube-kernel splits and symplectic factor extractions can be used in the same polynomial-size reduction over \(\mathbb F_3\). A principal adjoint computation can also be used as an exact determinant terminal. Each record used here is an unmarked one-dimensional role giving the character of the induced map. This property lets those records be inserted below other steps and pinned only at the root. ## One diagram with several kinds of recursion

At a product of either transpose type, take an applicable compact terminal, or a symplectic extraction and cropped dual step. At a symmetric product also allow the cube-kernel split with either mixed-space rule, and allow one relation duality before retrying these steps. Use fixed priorities for the rules and a common input size bound for both tensors. A symplectic step decreases the input dimension by at least a factor of two. A cube split has two positive child dimensions summing to the parent dimension. In particular, for a node of input dimension \(n\) with children \(n_i\), one has \(\sum_i(2n_i-1)\le 2n-2\), in each case. Thus the branch tree has at most \(2n-1\) nodes, in addition to a bounded number of dual operations per node. The output and relation dimensions are bounded by the square dimensions of their input roles.

For a principal adjoint terminal with weights \((a,b)\), apply the determinant identities for the input and output flags separately. In the principal layer formula, replace the coefficient \(u\) by \(au\) in the input contribution to \(e_u\), and the kernel-read sum by \(b\) times that sum. Likewise multiply the input contribution to the cotangent exponent by \(a\) and the output contribution by \(b\). If \(b=0\), omit the cell tests and read only the input formula. Use the frame determinants with their corresponding weights. The same parity test and small exterior lines therefore give the weighted character with its full transporter linkage.

All subspace and quotient maps remain linked to the original input transporter. Inductively take the product of the child lines and the local determinant contributions in each step's exact-sequence formula. This gives the raw root character after calibration. The role packing and tensor-system compiler are applied once, with only the root sign pinned. The independent hierarchy reduction tests existence via positive switches. It can be used where local isomorphisms genuinely assemble independently, as in the graph modules, with no shared separator actions. ## Mixed families with two scalar centroids

For a symmetric seed take a sign-rigid top product from the symplectic recursion. Its cube map vanishes throughout. Indeed a product basis of decomposable vectors has every basis square in the relation space, and cubing modulo the cubic relations is linear in characteristic three. Choose \(q=v^2\) with nonzero image under the seed product, possible by polarization. In the first eight-dimensional enlargement of the cube-kernel construction, put this same \(q\) on all sixteen supported edges. The proof of that enlargement works with old cube rank zero. No old cubes are left to kill, the eight new pure cube classes survive, and the old input is exactly the new intrinsic cube kernel. The label of \(q\) has even multiplicity, so the sign proof and the two scalar-centroid calculations apply unchanged.

Continue with arbitrarily many of the eight-dimensional cube-kernel enlargements, using the rank-eight step after the first. The result has even input dimension, odd label dimension, and only positive automorphisms. Reflecting a raw output basis vector changes the prescribed-sign comparison while leaving ordinary isomorphism. The cube-kernel chain reaches the seed, where the cube split itself is improper. At every enlargement, the projection onto the eight-dimensional summand is a nonscalar self-adjoint idempotent because the mixed product vanishes. The fixed subspace of a symplectic \(M_2(\mathbb F_3)\) involution consists of scalars, so the symplectic extraction rule cannot substitute for a cube split at these enlarged nodes. The two kinds of descent can both have unbounded depth in the same family.

These are sufficient reductions for the accepted classes. They leave the unrestricted ternary case of Open Question 1.9 open. [Open Question 1.9](https://arxiv.org/html/2306.03135v2#S1.SS5)
