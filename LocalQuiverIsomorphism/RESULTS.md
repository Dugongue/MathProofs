# Four effective local-quiver comparisons

The proofs are informal and AI-assisted. Publication priority is unverified.

| Direction | Result |
| --- | --- |
| Raw tensor slices with many identity arms | An exact all-orders normal form for arbitrary perturbations of a sum of identity-pairing arms of unit size. At square-zero order the tangent quotient works in every characteristic. Over each fixed finite local nonfield, the recognizable class with logarithmic arm size is GI-complete, with witness recovery and exact counts using GI decision. [Proof](tensor-slice.md) |
| Fixed-arrow local quivers | A deterministic, factorization-free, all-orders slice for finite chain-ring representations with semisimple residue endomorphism algebra, including nonsplit fields and nonsemisimple bricks. A separate algorithm counts fixed-arrow isomorphisms exactly in deterministic polynomial time with arbitrary reduction. [Proof](semisimple.md) |
| Obstructed four-vertex lifts | Every lift in an explicit unmarked predecessor fiber is described by a tangent-quotient class and a tensor obstruction. The obstruction decides extension to the next order. Comparing genuinely obstructed lifts in that family is equivalent to ordinary tensor isomorphism with linear size in both directions. [Proof](obstructed.md) |
| Moving slice coordinates | For any fixed number of slices, the residue determinant's geometric linear factors give a polynomially recognizable frame promise. On this promise, comparison, search and exact determinant-prescribed counting over the stated truncated rings take Las Vegas polynomial time, including nonsplit anchors. [Proof](moving-base.md) |
