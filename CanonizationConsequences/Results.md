# From complete invariants to canonical representatives

Informal proofs. A complete invariant labels each equivalence class uniquely. A canonical form chooses an actual member of each class and outputs it on every member. All uniform algorithms below operate on explicit strings. Polynomial-size circuits are nonuniform. The first two results use the [unrestricted canonization theorem](../CanonicalFormsAndPNP/PROOF.md). The latter two use classes confined to a single input length.

## 1. The logspace questions

Write LEq for equivalence relations decidable in deterministic logarithmic space, FL for logspace string functions, Ker for kernels and CF for relations admitting canonical forms in the indicated model. Under the conventional deterministic logspace oracle model, the following equivalences hold.

| Statement about canonization | Equivalent collapse |
|---|---|
| Every relation in LEq has an FP canonical form | P = NP |
| Every relation in LEq has an FL with NL oracle canonical form | NL = NP |
| Every relation with an FL complete invariant has an FL canonical form | L = NP |
| Every relation in LEq has an FL canonical form | L = NP |

In particular the two implications explicitly asked in Fortnow–Grochow §6.1 both hold. CF(FL) = Ker(FL) implies NL = UL. CF(FL) = LEq implies UL is contained in RL. Each antecedent implies L = NP, which sandwiches UL and NL between L and NP. Deterministic logspace lies in randomized logspace. The first two rows classify additional inclusion questions from the same section. [Fortnow and Grochow, §6.1](https://arxiv.org/html/0907.4775v2#S6.SS1)

**One relation witnesses all the lower implications.** Use unambiguously tagged records with a self-delimiting header containing a 3-CNF formula x and a positive integer N in canonical binary. A valid anchor has this header, an anchor tag and zero padding to exactly N bits in total. A valid witness record has the same header, a witness tag and exactly one bit per variable giving a satisfying assignment in a fixed variable order. One may use the standard 3SAT encoding with variable indices bounded by the formula length. For each header put the valid records into one class. Every invalid record is a singleton. A complete invariant outputs the tagged header on a valid record and a differently tagged copy of the whole input otherwise. All checks, including comparison with the physical length and inspection of assignment bits by repeated scans, use logarithmic workspace. Two such outputs can also be compared in logspace by replaying them.

Fix a candidate canonizer from any row of the table. Its output length on an input of length m has a fixed polynomial bound. For a formula of length n, choose N = (n+2)^d with d a sufficiently large *constant chosen after the bound*. The witness records have length O(n+d log(n+2)) with standard self-delimiting encodings. For all sufficiently large n, the canonizer on a witness cannot print the N-bit anchor. On a satisfiable formula it therefore prints a witness, and must print that same witness on the anchor. On an unsatisfiable formula it prints the singleton anchor. Finite exceptions can be hardwired. For fixed d the anchor can be generated and its bits accessed in deterministic logspace. Only the output tag is needed to decide 3SAT. Logspace many-one completeness of 3SAT gives NP containment in the corresponding decision class. For the NL-oracle row use the usual equality of deterministic logspace with an NL oracle to NL, obtained by simulating and verifying the answers to logspace queries using NL = coNL. This model has polynomially bounded query and output lengths.

**Converse.** For every polynomial-time decidable equivalence relation, the shortlex-first representative of x has length at most |x|. Existence of a class member of a specified length with a given prefix is in NP. Length search followed by prefix search computes the representative in FP with an NP oracle. Its output length and individual bit predicates are therefore in P with an NP oracle. Under each stated collapse this decision class respectively equals P, NL or L. A logspace transducer can count the output indices and fetch these predicates separately in the indicated model. This avoids storing a polynomial-length prefix on a logspace work tape.

## 2. Cook reductions from complete invariants

Grochow's 2008 thesis, Question 3.14, asks whether for every equivalence problem R in NP outside P and **every** complete invariant f of R, some polynomial-time machine with oracle f computes a canonical form of R. The machine may depend on f. The universal statement holds if and only if P = NP. More precisely, under P distinct from NP there is a counterexample at each polynomial-time Turing degree of a language A in NP outside P for which SAT is outside P with oracle A. [Grochow, Question 3.14](https://www.cs.toronto.edu/~jgrochow/Grochow_UofC_Masters_08_Equivalence_Relations.pdf)

Fix such an A. Form the disjoint union R of the SAT anchor relation above and a second tagged relation on pairs (x,i) with i a bit. Merge (x,0) and (x,1) precisely for x in A. The pair language recognizing R is in NP, including on inputs of mixed tags, which it rejects. The map from x to the two copies many-one reduces A to recognition of R. Conversely R is decidable in polynomial time with A. R has a particular complete invariant f computable in FP with A. On the second part return the pair with bit 0 whenever x belongs to A and the unchanged pair otherwise. Use disjoint output tags and the logspace invariant on the first part.

If some polynomial-time machine with oracle f canonized R, simulating it would yield an FP-with-A canonizer. Its output on short witness records has polynomial length. Applying the anchor proof to the first part would decide SAT in P with A, a contradiction. This defeats even a machine designed specifically for f. If P = NP the universal quantifier over NP outside P is empty.

**Existence of the required A.** Use the polynomial-time *Turing* version of Ladner's delayed diagonalization. Here are details to distinguish it from the weaker many-one incompleteness assertion. Construct A by retaining SAT on even stages of input lengths and excluding all strings on odd stages. Assign one new length per construction step. At an even stage search for disagreement with the next clocked P decider. At an odd stage search for a disagreement between SAT and the next clocked deterministic polynomial-time oracle machine with oracle A. Dovetail a search over inputs, compute SAT by exhaustive search, and in a simulated oracle computation wait for the stage of each queried length to have been assigned before supplying its answer. In the even-stage comparison use the already assigned bit for the tested length as well. Advance the search by one elementary step per newly assigned length, with a fair simulation of candidate tests. Start a new stage after finding a completed discrepancy. Previously assigned lengths never change. The schedule of the first n length assignments is computable in polynomial time in n by simulating those n steps with a polynomial-overhead universal machine and a table of length assignments. Thus A is in NP. A permanent even stage would make A agree with SAT up to a finite change and the corresponding P decider correct on A. A permanent odd stage would make A finite and the corresponding oracle machine correct on SAT. Either would put SAT in P. Hence each stage finishes, A is outside P and SAT is outside P with A. [Ladner, *On the Structure of Polynomial Time Reducibility*](https://doi.org/10.1145/321864.321877)

## 3. An explicit equal-length matching defeats shallow canonizers on average

For every n, there is an equivalence relation on (2n+1)-bit strings whose classes each have exactly two elements and whose complete invariant uses at most three input bits per output bit. Against **any** canonical form, every family of fixed-depth, quasipolynomial-size unbounded-fan-in AND/OR/NOT circuits agrees on at most one half plus a negligible fraction of uniform inputs. The identity function attains one half exactly. The relation admits a linear-time canonical form.

Write D(u) for successive binary differences, with u at position zero set to 0. Thus D(u) at i is the XOR of u at i and at i−1. Its inverse takes prefix parities. For a bit t and two n-bit strings use the invariant

    F(0,u,v) = (D(u),v)
    F(1,u,v) = (u,D(v)).

Every label (a,b) has exactly two preimages, (0,D⁻¹(a),b) and (1,a,D⁻¹(b)). On each coordinate the tag controls whether the current bit is added to the preceding bit. This gives the three-input locality bound. Returning the tag-0 preimage of the label gives the linear-time algorithm. Across lengths include the length in the parsing convention and treat other input lengths as singletons.

Fix any mathematical selector, without any computability assumption. Exactly half the uniform inputs have the selector's tag. A correct answer on any of the others has to produce a full prefix-parity inverse on an independent uniform string, b or a according to the input tag. We bound the probability that an arbitrary shallow circuit reconstructs that inverse, even allowing it to ignore correctness elsewhere. The other input string can be fixed arbitrarily.

Partition the n bits into k = ceil((log₂ n)²) consecutive blocks of nearly equal size, for n sufficiently large. From the circuit's candidate inverse take XORs of adjacent block-endpoint bits, using zero at the initial endpoint. Full reconstruction implies correct predictions of **all k** block parities. Write e for the vector of prediction errors. The indicator of e = 0 equals the average of (−1) raised to the inner product of J and e, over all k-bit masks J. For nonzero J the true masked answer is parity on at least floor(n/k) independent bits. The predicted masked answer is the XOR of at most 2k circuit outputs. A depth-two truth-table circuit for this XOR adds at most 2^O(k) times a polynomial factor to the size and a constant to the depth. The resulting circuit still has quasipolynomial size. Fixing all bits outside the selected blocks preserves the bound. Håstad's parity correlation estimate bounds the absolute value of every nonempty-mask expectation by exp(−n/polylog(n)), where the power of the logarithm may depend on the circuit family's depth and size exponent. Averaging gives a reconstruction probability at most 2^(−k) plus this negligible bound. Apply it separately to the two possible input tags. The extra agreement beyond one half is negligible. Returning the input is correct once per pair. [Håstad, *On the Correlation of Parity and Small-Depth Circuits*](https://www.csc.kth.se/~johanh/paritycorr.pdf)

## 4. Equal-length canonization characterizes nonuniform witness recovery

Let f map n-bit strings to m(n)-bit strings in deterministic polynomial time, for polynomially bounded, efficiently computable m. At fixed n form two kinds of records of the same length. In the first, (0,u,b) has label (f(u),b). In the second, (1,a,v) has label (a,f(v)). The variables u and v have n bits and a and b have m bits. Include n in both the record header and the invariant so that different lengths and parameters cannot collide. Malformed records are singletons.

**Theorem.** Polynomial-size circuits canonize these equivalence classes if and only if polynomial-size circuits, given n and any y in the image of f on n-bit strings, return a preimage of y. Outside the image an inverter may return any n bits. In particular there is one fixed polynomial-time invariant with equal-length fibers that admits polynomial-size canonization circuits exactly when NP is contained in P/poly.

Given an inverter, attempt inversion of the first component of a label and verify the answer by applying f. If successful, choose tag 0 with that preimage. Otherwise invert the second component and choose tag 1. At least one component is in the image. Both choices depend just on the label.

Conversely fix a canonizing circuit and let Y be the image at n. Order each unordered pair of distinct elements of Y lexicographically as (a,b). If the canonical tag of this label is 1, draw an arrow from a to b. Knowing a preimage u of a, evaluating the canonizer on (0,u,b) returns a preimage of b. If the canonical tag is 0, draw the arrow from b to a. Knowing a preimage v of b, evaluation on (1,a,v) returns a preimage of a. The resulting tournament has a dominating set of size at most m+1. Repeatedly select a vertex with outdegree at least half the other remaining vertices and remove it and its out-neighbors. Give the inverter these selected labels and one preimage each as advice. For a target distinct from them, try every advised label in the appropriate ordered pair, using its known preimage to supply the opposite tag from the desired output. Verify every proposed preimage. At least one trial succeeds. The advice and circuit sizes are polynomial in n. This is the tournament argument used in the study of polynomial-time selectors, here carrying preimages as advice. [Dell, Kabanets, van Melkebeek and Watanabe, tournament lemma](https://pages.cs.wisc.edu/~dieter/Papers/isolation-full.pdf)

For the SAT specialization, at parameter h let f take a pair consisting of an h-bit formula encoding and an h-bit padded assignment. Its output is 1 followed by that formula on an accepting pair, and 0 followed by h zeros otherwise. Use n = 2h and m = h+1, a standard logspace-checkable formula encoding and at most h variables. The image contains the 1-tagged formula precisely when it is satisfiable. Circuits inverting f decide SAT by verifying a preimage. Conversely, SAT circuits yield witness circuits by self-reduction, using circuits for polynomially many possible query lengths. On the all-zero output a fixed invalid encoding gives a preimage. Even-length input parameters suffice; separate all other parameters by tags. A single canonical circuit family for this equal-length relation therefore suffices for the usual Karp–Lipton collapse of the polynomial hierarchy. This is a nonuniform equivalence: the proof selects advice using the tournament on the entire image.

## Scope and related results

The first two arguments exploit classes with widely differing representation lengths. The last two are equal-length constructions. Neither pair gives a graph or tensor canonization lower bound. The unconditional circuit lower bound concerns bounded depth; a linear-time sequential algorithm is explicit. These are informal mathematical arguments. The links identify prior tools and the original questions. Publication priority for the combined statements has not been established.
