# Length, ambiguity and randomized agreement

These informal companion results use the notation and anchor construction in [the main proof](Results.md).

## Polynomially related lengths reduce to equal lengths

Suppose a relation R has a polynomial-time complete invariant, and there is a polynomial p such that x R y implies |y| ≤ p(|x|). Canonization of R reduces to three calls to a single canonizer for an explicitly constructed equal-length relation with a polynomial-time complete invariant.

Choose an integer a so that for every equivalent pair the shifted lengths s = |x|+2 and s' = |y|+2 satisfy s' ≤ s^a. Take a at least 2. Use bins [t_i,t_(i+1)) with t_0 = 2 and t_(i+1) = t_i^a. A single class meets at most two consecutive bins. Build a new relation with a distinct window for each individual bin and each union of adjacent bins. Code an input in a window by a self-delimiting window identifier, its self-delimiting original string and zero padding to a common length depending only on the window. For example, for a window ending at exclusive upper boundary t, pad to 10(t+2)^2 using unary bin index and unary length delimiters. Valid codes are equivalent precisely when their window identifiers agree and their decoded inputs are R-equivalent. Invalid codes are singleton classes with a separate tag. The complete invariant on a valid code pairs the window identifier with the old invariant. Parsing computes boundaries by repeated powering with saturation above the input length plus a constant, rejecting oversized declared windows. For a query constructed from x, the largest boundary used is at most (|x|+2)^(a²), so constructing the codes costs polynomial time.

For x in bin i, canonize its code in each incident two-bin window, ignoring the nonexistent left window when i = 0. If a decoded answer lies in another bin, move to it; otherwise keep x. Finally canonize the resulting string inside its single-bin window and decode. A class meeting only one bin stays there. If the class meets bins i and i+1, every member queries the same shared window and obtains the very same representative there. Members on the other side move across and members on the selected side stay. No outer window can move a member to a third bin. Everyone reaches the same single-bin class and hence the same output. This proves the unrestricted equivalence of the two *canonization principles* for equal-length and polynomially length-bounded kernels. It does not impose a fixed bound common to different relations. The proof also works relative to an oracle.

There is a single concrete complete task for this principle. Given a Boolean circuit C on b input bits and a b-bit x, consistently select one b-bit member of the fiber of C(x). Include C unchanged in the record and in the label. With a canonical encoding this is an equal-length kernel. Conversely compile the window invariant on each exact query length into a polynomial-size Boolean circuit, encoding output length as well as output bits. A circuit-fiber answer decodes to an equivalent window code. For consistency the compiler must use a fixed circuit for each query length, independently of the query string. The three-call construction then applies.

## Class cardinality characterizes deterministic ambiguity

Every polynomial-time kernel relation all of whose classes have at most two members has a polynomial-time canonical form if and only if P = UP. When the allowed class cardinality is bounded by a polynomial in the length of every member, the corresponding criterion is P = FewP. In both statements the upper direction holds for relations merely decidable in P. UP means at most one accepting computation on every input. FewP allows polynomially many accepting computations on every input.

For the lower directions, use one witness record per actual accepting path of an unambiguous or few-accepting-paths machine. Use a unique encoding for each accepting path, with prescribed trailing padding after halting. A class has at most one anchor plus the number of accepting paths. Each valid encoding includes the instance, so a polynomial bound in instance size gives the claimed bound for every member. The argument forcing a witness from the anchor decides the original language.

For the upper directions, on input x ask whether there is a *strictly shortlex-smaller* equivalent y of a specified length with a specified prefix. Guess each y in exactly one way. In a two-member class this has at most one accepting computation; in a polynomial-cardinality class it has polynomially many. The assumption puts these tests in P. Search lengths, then prefixes, for the shortlex-first smaller member and otherwise return x. These bounds control cardinality, independently of length spread.

## Randomized agreement just on doubletons

For the single SAT anchor kernel, the following are equivalent.

1. A worst-case polynomial-time sampler always returns an equivalent member. For each two-member class the two output distributions have overlap at least 1/poly(M), where M is the longer input length and the polynomial is fixed. There is no agreement requirement on other classes.
2. NP = RP.

Overlap means the sum over outcomes of the minimum of the two probabilities. Apply Valiant–Vazirani isolation to a SAT input. An unsatisfiable formula remains unsatisfiable. With inverse-polynomial probability a satisfiable formula becomes one with exactly one satisfying assignment. Use a parsimonious encoding of the isolation constraints, so auxiliary circuit bits have unique extensions. On the isolated formula, choose the anchor length by the same fixed-exponent rule as in the main proof. Its sole witness cannot output the anchor under the sampler's time bound and must output itself. Overlap thus forces the anchor to output that witness with inverse-polynomial probability. On any invocation accept only after checking an assignment. Amplification gives RP. Conversely under NP = RP, amplify the shortlex length and prefix tests so their total failure probability per input is below 1/100. Verify the resulting candidate and return the original input if verification fails. This always returns an equivalent string and puts probability at least 0.99 on the very same shortlex representative from either member. This argument concerns per-input guarantees. [Valiant and Vazirani, *NP is as easy as detecting unique solutions*](https://doi.org/10.1016/0304-3975(86)90135-0)
