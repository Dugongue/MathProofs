# Shared-reference comparisons and odd automorphism gates

Work with explicit three-tensors over $\mathbb F_3$ and polynomial-time many-one reductions. Let $O$ be ordinary tensor isomorphism, $A$ isomorphism preserving determinant in the first mode, $F$ existence of an ordinary automorphism of negative first determinant, and $R$ the shared-reference problem M3. Thus $R(X,Y,Z)=A(X,Y)\wedge A(X,Z)$. The comparison $J=A\wedge A$ asks two unrelated signed questions. The previous packet identifies M4 and M5 with $A\wedge F$, with independent inputs, and establishes $O\le_m^p F\le_m^p A$. None of the reductions below assumes access to a tensor-isomorphism oracle.

## Ordinary conditions on individual arms do not change the degree

For a polynomially long explicit star of one-sign comparisons with one source and a list of targets, attach to each arm a polynomial list of independent ordinary comparisons. The problem of satisfying all arms with their ordinary conditions has the same many-one degree as the original star problem. This applies in particular to R, where there are exactly two arms. The ordinary comparisons may themselves be computed jointly from all input tensors. The only requirement is that the construction produces an explicit list of ordinary comparison instances.

Reject differing input formats or unequal support dimensions between the root and any target. If the first-mode support is deficient, each ordinary match can independently correct the determinant on its unused complement. The whole problem then consists of an ordinary conjunction. Use the standard polynomial-size packing of a list of ordinary comparisons by distinct indecomposable neutral blocks, then the known reduction $O$ to $A$, and duplicate that target in the star. This branch resolves zero tensors as well. Otherwise the first mode is full. Compact the two untested modes in each tensor independently. This preserves the determinant in the tested first mode and keeps common reduced formats.

For each ordinary comparison labeled $j$ use the earlier determinant-neutral and absolutely indecomposable encoding $(P_j,Q_j)$, with pairwise different formats and sides larger than every original tensor side. The neutral encoding is the multiplication tensor of a two-by-two matrix algebra over a marked local algebra. Every relative transporter has positive determinant in all modes and ordinary equivalence reflects the original ordinary comparison. Its polynomial format tags come from the truncation length in a fixed nilpotent branch. If the input pair of an attached comparison has incomparable formats, the desired output already rejects. Append all $P_j$ to the root and append $Q_j$ in exactly the target arms where comparison $j$ is attached, using $P_j$ in every other arm. Choose one block order on all output tensors. Primitive centroid idempotents force each marked format to match separately. Their determinants are all one. Hence each arm imposes exactly its original first determinant and exactly its intended ordinary conditions. Every input tuple of original witnesses extends blockwise, and every output transporter restricts to such witnesses. The number and total size of the appended blocks are polynomial in the input length. The lower reduction simply appends no ordinary conditions, or a fixed positive comparison when the format requires a nonempty list.

The same statement for independent signed comparisons $J$ follows by packing each arm separately. For M4 and M5, pack every additional ordinary condition into the independent $A$ comparison of the equivalent $A\wedge F$ problem. These statements give exact mergers of ordinary-augmented presentations with their core degrees.

## The degree of a star gated by odd automorphism of its own source

The two problems
$$
 A(X,Y)\land F(X)
 \quad\text{and}\quad
 R(X,Y,Z)\land F(X)
$$
are both equivalent to the independent conjunction $O\wedge F$. This gate concerns the tested first mode of the actual common source, which differs from M5's odd-automorphism requirement in another mode.

On the branch $F(X)=1$, every nonempty ordinary transporter coset of $X$ contains transporters of both first determinants. Therefore the positive one-sign comparisons in either display can be replaced by ordinary comparisons when the same gate remains in the decision predicate. Pack the one or two resulting ordinary comparisons into one ordinary instance. For the reverse, encode the input to $F$ into an absolutely indecomposable concise even tensor $U$, preserving precisely its first stabilizer-sign subgroup, using the earlier self-pair sign projection and scalar-centroid glue. Use the neutral encoding of the ordinary pair to produce $(P,Q)$ of a distinct format. Compare $(U\oplus P,U\oplus Q)$, or duplicate its target for R. The padding contributes no stabilizer or relative sign. Thus the source passes the odd gate exactly when the original $F$ input does, and the requested ordinary equivalence is the comparison of $P$ and $Q$. The two displayed degrees coincide. This does not establish $O\wedge F\equiv_m^p F$.

## Obstruction to merging independent orientations into one affine-image star

A star is more restrictive than a list of independent sign probes, even when the number of arms is unlimited. The following result isolates that distinction at the level of signs. It is a statement about a specified compilation model.

Fix $m\ge2$ hidden nonempty one-dimensional sign profiles $D_1,\ldots,D_m$, each either $\{0\}$, $\{1\}$, or $\mathbb F_2$, with 0 denoting positive determinant. The input decision is whether all contain 0. Each output arm is assigned a finite nonempty union of affine images to $\mathbb F_2$. A branch may use arbitrarily many independent variables from the $D_i$ or from their direction subgroups $H_i$, and may add a fixed affine slack set. It has no internal sign tests. Branches can be enabled by fixed ordinary information that stays constant over the nonempty profiles under comparison. Every output arm has a nonempty actual sign set on these inputs. Require that its output have the common-source property of a genuine star, so the direction subgroups of all output arms coincide. The target accepts if zero belongs to every output sign set. There is no such exact compilation of the independent conjunction, even with arbitrarily many output arms and branches.

To prove this, first take all input profiles singleton, with values $x\in\mathbb F_2^m$. All input direction variables then vanish. At each nonzero $x$ the desired answer is negative. If any arm had both signs on this input, then its direction subgroup would be full. All arm directions agree, so every arm would have both signs and the output would accept incorrectly. Thus every arm has a singleton output at each nonzero $x$.

In particular no branch can have full slack. Each branch then gives one affine bit at all singleton inputs. The affine branch functions of any one arm agree at all nonzero $x$. The nonzero vectors affinely span $\mathbb F_2^m$ for $m\ge2$: $0$ is the affine sum of $e_1,e_2,e_1+e_2$, and the standard basis is included. Consequently the branch functions agree on every singleton input, including zero. For every arm this common affine function has zero constant term, because the all-zero input must pass. Write its linear part as the corresponding row of a matrix $L$. Exactness on the singleton inputs requires that $L$ have trivial kernel.

Fix an input coordinate $i$. Some row of $L$ has nonzero coefficient there. Choose $j\ne i$. Consider the input that has profile $\mathbb F_2$ in coordinate $i$, profile $\{1\}$ in coordinate $j$, and $\{0\}$ elsewhere. It must reject on account of $j$. Its profiles contain both singleton inputs obtained by fixing coordinate $i$ to either 0 or 1. All branch output sets grow monotonically under these enlargements, since every relative witness or direction witness from the smaller input is still available on the larger one. At the selected row of $L$, the two singleton subinputs gave opposite signs. This arm therefore has both signs on the new negative input. The common-source property forces every arm to have both signs, a contradiction.

This differs from the generic affine-probe lower bound. That bound allows independent output probes, which can each use a different source direction subgroup. The present proof uses the equality of output directions even if an arbitrary number of star arms is available. A general many-one reduction can inspect individual tensor coordinates and make ordinary target isomorphism depend on information about the signed relation. Such a construction need not satisfy this profile-only model.

## The related obstruction for the independent odd gate

A parallel result holds for the predicate of M4 within this same model. Its hidden input is one relative profile $D$ and one independent stabilizer subgroup $K$ that is either zero or full. The predicate is $0\in D$ and $K$ full. Allow star arms formed by fixed affine images and unions as above, now also using independent samples from $K$. At $K=0$, both singleton inputs $D=\{0\},\{1\}$ reject. Thus all output arms are singleton there, their branch centers are affine functions of the singleton bit, and all branch centers of a fixed arm agree on both inputs. No branch has full slack.

If any branch of any arm uses a nonzero coefficient on a $K$ witness, enlarging $K$ to full with $D=\{1\}$ makes that arm full, and then every arm is full. This would accept a negative input. So every branch must ignore $K$ entirely. But now enlarging $K$ at $D=\{0\}$ does not change the output, which incorrectly rejects a positive input. This proves the model obstruction for the independent odd gate as well.

Thus the ordinary-augmented variants and the own-source gate variants above have exact mergers. The differences between the original degrees $R$, $J$ and independent $A\wedge F$ remain unresolved. The input-side sign profiles are realizable by actual dense tensors, as proved in the earlier exact sign projection packet. For context on tensor-system comparisons see [Chen, Grochow, Qiao, Tang and Zhang](https://arxiv.org/html/2306.03135v2#S4). The arguments here are informal.
