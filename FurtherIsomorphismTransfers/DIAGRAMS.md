# Isomorphism of relabelable persistence local systems

**Theorem.** Fix a finite field k and constants c≥2 and r≥1. Let the input be a connected finite poset P and a functor M from P to positive-dimensional finite k-vector spaces, given by explicit bases and matrices on the covers. Require all cover maps to be invertible. The isomorphism may relabel P and may change the basis at each vertex. Let N=1+|P|+Σ_v dim(M_v) and require at most N^c distinct actual path matrices, with the source and target counted as part of each path matrix. Traversing a cover backwards uses its inverse.

At a base vertex v the actual loop matrices form a finite group G_v. Put A_v=span_k G_v inside End(M_v). Require either that A_v is semisimple, or that A_v is generated as a unital k-algebra by at most r members of G_v. These conditions are independent of the choice of base vertex. There is a deterministic polynomial-time recognizable class of these inputs. Ordinary relabelable diagram isomorphism on this class is GI-complete under polynomial-time many-one reductions. Requiring determinant one at each vertex gives GI-completeness under deterministic polynomial-time Turing reductions, with many-one hardness. If the determinant character on one loop centralizer is surjective, the determinant-one test needs only one GI instance. The dimension of the fibers is unbounded. In particular the second branch allows arbitrary modular representations of r-generated holonomy groups within the size bound.

For a formal language version, a rejected input is a no instance. The size test and every structural item used to construct the graphs are independent of bases. All matrix entries are explicit, so N is polynomially bounded in the input length on a connected diagram with at least two vertices. A singleton is handled directly by comparing dimensions. The theorem concerns an explicitly supplied finite indexing poset, which may move by an order isomorphism. On an everywhere-invertible rectangular grid the holonomy is trivial, so the height-two posets in the hardness argument are essential to the stated scope.

## 1. The intrinsic finite groupoid of transports

Let M(p) be the linear map obtained by multiplying the matrices of a walk p in the Hasse diagram. Take a morphism occurrence to be the triple (source vertex, target vertex, M(p)). Occurrences compose by matrix multiplication when endpoints match. All morphisms are invertible and the identities are constant paths. This defines a groupoid equipped with distinguished cover occurrences. Form the groupoid by closing identities under extension by a cover and an inverse cover, with duplicates removed by comparing typed matrices exactly. The queue begins with all identities. Either the process stabilizes within the size cap or adding the next distinct occurrence violates it. The number of stored values, matrix products, and list comparisons before a decision is polynomial. All poset relations can be checked using composition on covers, if the input lacks a certificate that the diagram is a functor. For instance, for each source propagate a path product through a topological order of the upper set and reject whenever two directed paths to the same vertex give different values.

Write G_v for the automorphism group of the vertex v in this actual groupoid. Its elements are matrices and their k-span is an algebra. For any path P_v from a root v_0 to v, conjugation by M(P_v) identifies the two loop algebras, which proves the independence of the branch conditions from the root.

A relabeled natural isomorphism determines a groupoid isomorphism F by source and target basis changes, carrying distinguished covers to distinguished covers. Conversely suppose F identifies the order relations, the typed groupoid products, and the distinguished covers. Suppose a linear isomorphism X_0 between the two root fibers intertwines the loop representation with its F-pullback. For each vertex choose one actual path map g_v from the root to v and set

$$
X_v=F(g_v)\,X_0\,g_v^{-1}.
$$

For each typed path h from v to w, the composite g_w^{-1} h g_v is a root loop. Intertwining that loop gives X_w h = F(h) X_v. In particular the cover squares commute. This also describes all lifts of F, since every lift is determined by the root matrix. This is the usual holonomy description with the actual indexing object and all its possible relabelings retained. [Kenyon on graph connections and monodromy](https://arxiv.org/abs/1001.4028)

## 2. A complete polynomial-size graph decoration

The base decoration records the vertices, their order, all typed groupoid occurrences, the incidence of sources and targets, each cover and its distinguished occurrence, and every typed multiplication triple. Include fiber dimension and an intrinsic branch type as labels. This is polynomial in the cap.

**Semisimple branch.** Recognize this branch by computing the radical of A_v and testing whether it is zero. A faithful module has semisimple image algebra exactly when the module itself is semisimple. The fixed-field finite-algebra algorithms compute the radical in polynomial time. Color each loop by the full characteristic polynomial of its matrix. Every natural isomorphism preserves the color. Conversely if a groupoid relabeling preserves the colors, the two root representations of the same finite loop group have the same characteristic polynomials on all group elements. They therefore have the same semisimplification, by the following characteristic-p argument.

Let U and W be semisimple kG-modules with this property. The field k is finite and has characteristic p. Work with the simple factors of the semisimple quotient of kG. The k-valued characters of its simple modules are linearly independent over k as functions on G. Indeed the group elements linearly span kG, and in a simple factor M_a(E) one can choose a matrix with only one diagonal entry λ and with Tr_(E/k)(λ)=1. Its trace on the corresponding simple module is one, and its traces on every other simple module are zero. Such λ exists since finite field extensions are separable. Equality of characteristic polynomials implies equality of traces, so the multiplicity difference for each simple is zero mod p. Cancel common simple summands, divide all remaining multiplicities by p, and take pth roots of the equal residual polynomial products for each element of G. Frobenius is injective on k[t]. The resulting two semisimple modules still satisfy equality of characteristic polynomials. Iteration forces every original multiplicity difference to be zero. Hence the intertwiners exist over k itself. This is the finite-field semisimple form of Brauer–Nesbitt. [Brauer and Nesbitt, On the modular characters of groups](https://doi.org/10.2307/1968918)

**Bounded generation branch.** If the semisimple test fails, test the second branch. At each vertex enumerate every ordered tuple of at most r loop elements. For each tuple (g_1,...,g_s), compute a basis of the unital algebra it generates. Start with the identity and visit the retained words in queue order, appending multiplication by each next generator in tuple order. Retain a new word exactly when its matrix is independent of the prior ones. There are at most dim(M_v)^2 retained words. When the queue is exhausted the span is right-multiplication invariant and is the generated algebra. Keep the tuple if this equals A_v. This test, including the list of chosen words, is equivariant under simultaneous similarity of the generators.

Create a structure node for each retained tuple, linked to its vertex and its ordered generator occurrences. Link the tuple to each loop occurrence at its vertex, labeling the link by the list of coordinates of the loop in the chosen word basis. There are polynomially many tuples and links because r is fixed. Finally give the tuples labels that identify their simultaneous-similarity equivalence classes, computed on the union of tuples from the two inputs. Use module isomorphism for the free algebra on the fixed tuple labels, taking its finite-dimensional image in the two endomorphism algebras together. The standard finite-algebra module isomorphism algorithm over a fixed finite field finds a transporter or reports none. Pairwise tests suffice to make the shared color partition in polynomial time. It is a two-input many-one reduction, so the two structures may use the joint color partition.

A graph match must carry a source root tuple to a target tuple of the same color with preserved ordering. A simultaneous-similarity witness therefore intertwines each generator and each selected word. The coordinate links then force it to intertwine every group element with its assigned F-image. Conversely a natural diagram isomorphism preserves the selected words, the coefficient lists, and the tuple colors. This includes representations with nonzero radical in their image algebra. [Chistov–Ivanyos–Karpinski on module algorithms](https://theory.cs.uni-bonn.de/marek/publications/85169-cs.pdf)

Together the two decorations are equivalent to finding a relabeling and a root intertwiner. Encode the decorated relations by colored incidence graphs using ordered ports for relation arguments, then use standard color gadgets to get one uncolored GI instance. The graphs have polynomial size. A graph transporter gives the groupoid correspondence and an actual natural isomorphism is recovered from a computed root intertwiner. Graph gadget automorphisms are harmless since their projection is an automorphism of the decorated structure.

## 3. Determinant-one comparison

In the determinant-one version, additionally color every typed path occurrence by its determinant in the supplied bases. Any determinant-one transporter preserves this color. For any isomorphism of the decorated graph with these colors, choose its root intertwiner by the module algorithm and lift it by the path formula. Since det F(g_v)=det g_v, all the matrices X_v have the same determinant δ∈k×. The graph problem together with the attainable values of δ therefore decides the determinant-one problem.

Use GI decision with individualization to find one decorated graph isomorphism and generators of the source decorated graph automorphism group. Project each generator and lift it using the module algorithm and the path formula. The kernel of the projection from diagram automorphisms to projected groupoid automorphisms consists precisely of the root centralizer units, transported along paths. The argument is that a root-linear map commuting with every loop extends uniquely while fixing all typed path maps, and any such extension has that commuting root map. The determinant values attained by diagram isomorphisms that have constant determinant across the connected diagram form the coset of the starting witness times the subgroup generated by the determinants of these lifted automorphisms and by the centralizer-unit determinant image. Indeed their projections generate, and any two lifts of one projection differ by the kernel. This uses only polynomially many calls to graph isomorphism and linear algebra.

For completeness the centralizer determinant image is computable deterministically. Let C=End_(kG)(M_(v_0)) as a concrete linear subalgebra of End(M_(v_0)). Compute its radical J and a complete primitive orthogonal idempotent frame e_i. The semisimple quotient is a product of matrix algebras over finite fields. For each primitive e_i put E_i=e_i C e_i/e_i J e_i, a finite field. The character image is the subgroup of k× generated by all

$$
\lambda^{\,\dim_k(e_i M_{v_0})/[E_i:k]},\qquad \lambda\in k^\times.
$$

To prove this use a semisimple complement of J over the perfect field k, and conjugate primitive frames to identify one in that complement with the computed one. This conjugation does not change the ranks of the idempotents or any determinant of a unit. On e_i M_(v_0), a primitive diagonal unit has determinant the norm from E_i to k to the indicated exponent. Finite field norms are surjective. Elementary units of the matrix blocks have p-power order and determinant one. Radical units also have p-power order and determinant one. Together these generate the units. This reuses the earlier finite-algebra determinant calculation for a new moving-poset transporter. If this image is all of k×, every projected transporter can be corrected at the root and hence at every vertex. The colored graph alone is then a many-one reduction for determinant one. [Rónyai on finite algebras](https://doi.org/10.1016/S0747-7171(08)80017-X)

## 4. Hardness and scope controls

Take the join of an input simple graph with one new universal vertex. The resulting graph is connected. Its isomorphism type determines that of the input by removing any universal vertex. Form the height-two vertex-edge incidence poset of this graph. Let every vertex fiber be one-dimensional and every cover map be the identity. Poset isomorphisms are exactly graph isomorphisms of the connected joins, since a maximal edge element has precisely its two endpoints below it. The one-vertex edge-free case is direct. Every poset map lifts by the identity gauges, also for determinant one. The actual groupoid has exactly one occurrence per ordered pair of vertices, so satisfies the size cap, and its loop algebra is k. This proves GI hardness for both decision problems.

The trace test alone loses information in small characteristic, even on faithful semisimple modules of the same dimension. Over F_2 let G=GL_2(F_2) and let U be its natural simple module. The two six-dimensional modules U plus four trivial copies and U⊕U⊕U have the same traces on every element but are inequivalent. At a loop of order three, their characteristic polynomials are respectively (t²+t+1)(t+1)^4 and (t²+t+1)^3. Both modules are semisimple despite the characteristic dividing |G|. Conversely, over F_2 two faithful representations of C_2 with Jordan block sizes (2,2) and (2,1,1) have identical characteristic polynomials on every element and are inequivalent. The bounded-generation branch separates this case using a generator tuple. Either example is realized on a connected height-two incidence poset of a graph by assigning loop generators to non-tree edges and identity to tree edges.

## 5. Replace full holonomy by shortest-path transport states

**Stronger theorem.** Fix the same k,c,r. A second recognizable class has the same ordinary and determinant-one complexity equivalences, with no bound on holonomy-group size or on semisimplicity. For each root u and vertex v, let S_(u,v) consist of the distinct matrices of shortest walks from u to v in the undirected Hasse graph. Require at most N^c state occurrences (u,v,g) in all these sets together. For each root u, use the list of based-loop descriptors

$$
(g_v,h,g_w),\qquad g_v\in S_{u,v},\quad g_w\in S_{u,w},
$$

where h is an oriented cover or its inverse from v to w. The associated loop matrix is g_w⁻¹ h g_v. The second condition is that at least one root has a tuple of at most r of these descriptors whose matrices generate the image algebra of all its loop matrices. There may be many eligible roots. The criterion does not choose one of them as structure.

The complete shortest-path listing is computable by dynamic propagation through distances from each root. Start with a marked identity. Wherever an oriented cover increases distance by one, multiply every existing state by its edge matrix and deduplicate the products. This computes all shortest transports by the last-edge decomposition of a shortest walk. Once the total state cap is exceeded one can reject without proceeding. Each propagated state yields one transition labeled by its oriented cover, even when several walks have merged to the same state. Record these transitions and the root and endpoint of each state in the graph. The polynomial bound is on distinct matrix states, so it allows an exponential number of walks to merge.

Record one based-loop node for every descriptor, linked by ordered ports to its two state occurrences and its oriented edge. This is a polynomial list. It generates the full holonomy group at its root without any enumeration of that group. In fact choose one shortest transport g_v for each v. For a closed walk, the product of the loops g_w⁻¹ h g_v along its edges telescopes to the matrix of the closed walk. Include all descriptor tuples of length at most r that generate the algebra spanned by products of all listed loop matrices. Compute the two generated algebras by the word-basis closure described above. Decorate each generating tuple by its ordered descriptor links and the coordinates of every descriptor matrix in the tuple's word basis. Use the same joint similarity colors for the generators as in Section 2. This computes eligibility and the whole graph in polynomial time. Every decoration is invariant under relabeled natural isomorphism.

Any graph isomorphism carries a shortest transport state to the state obtained by the correspondingly relabeled walk. This follows from the marked root identity and the deterministic extension relation along each oriented cover. Pick a root having a qualifying tuple. Its tuple color supplies an intertwiner X_0, and its coordinate links show that X_0 intertwines all the descriptor loops with exactly their matched images. For one choice of state g_v per vertex, lift by X_v = F(g_v) X_0 g_v⁻¹. For every cover, the descriptor with that cover and the two chosen paths gives X_w h = F(h) X_v. Thus this graph isomorphism yields actual diagram gauges. The converse follows from invariance of all the data. The rank-one constant diagrams in Section 4 meet this promise, since every root-endpoint pair has one state and the loop algebra is generated by the identity. Consequently the ordinary comparison is GI-complete under polynomial-time many-one reductions.

For the special-linear comparison, label each oriented cover by its determinant. A graph isomorphism of the decorated instances then preserves the determinants of every corresponding shortest state, by the deterministic transition relation starting at the marked identity. Thus the lift gives one common determinant for the whole diagram. The kernel of projection to graph data is again the root centralizer of the full loop algebra. Fixing the indexed cover maps fixes every shortest transport state under source and target basis changes, since each state is reached by a word of those covers. The determinant-coset argument and the surjective-centralizer case of Section 3 therefore work unchanged. The exact determinant-one result is GI-completeness under polynomial-time Turing reductions with many-one hardness.

**Large holonomy example.** Take the height-two incidence poset of a fixed connected graph having two independent cycles and no further cycles, for instance two triangles sharing a vertex. Choose a shortest-path tree in its Hasse graph. Use d-dimensional fibers over F_2, identity maps on tree edges, and cyclic shift C and I+E_12 on the two remaining oriented edges. Cover orientation can be reversed by using the inverse. Those two matrices are among the root descriptors. Conjugating the transvection by cyclic shifts gives transvections along each edge of the directed coordinate cycle. Commutators of consecutive transvections give all remaining row-addition transvections. Hence the two matrices generate GL_d(F_2) and a fortiori generate its image algebra. The size of GL_d(F_2) is the product over i=0,…,d−1 of (2^d−2^i), giving 2^(Θ(d²)). Only a constant number of shortest-path states occur because the base graph is fixed. The example uses r≥2 and fits the stated cap for large enough d. Exact enumeration for d=2,3,4 gives group orders 6, 168, and 20,160, and algebra dimensions 4, 9, and 16. The input length is Θ(d²), so the actual group can be exponential even though the transport signature is polynomial. This also demonstrates why replacing enumeration of the group by enumeration of sufficient path states matters.

## Prior work and DAG reuse

The project’s earlier survey records the fixed-base local-system transporter via path conjugation and the multiparameter-persistence link to finite diagram representations. This deduction keeps the base relabeling inside one graph instance and uses either characteristic polynomials or bounded generating tuples to certify every actual monodromy representation match. The shortest-state variant retains the cover extensions of deduplicated matrix states and bypasses enumeration of the whole monodromy group. The ordering used for the tuple's words is the same finite-reachability idea that underlies weighted automata, applied to the image algebra rather than to individual states. The prior project's determinant subgroup computation supplies the remaining per-vertex SL constraint. Nine federated DAG probes each reached 103 registered catalogs with zero reported catalog errors. The relevant ports and source hits included FundamentalGroupoid, MonodromyRep, BrauerNesbitt.actionTrace, BrauerNesbitt.actionEndo, and finite-algebra module isomorphism. These were reuse and overlap evidence, rather than a Lean certificate for the combined theorem. The closest sources checked concern multiparameter functor representations, holonomy over an already matched graph, and module algorithms with fixed operators. Publication priority for these combined complexity statements is unestablished. These are informal proofs.
