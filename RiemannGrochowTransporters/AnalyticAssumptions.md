# Which Riemann hypotheses enter the tensor results?

On November 20, 2026, Levent Alpöge released a Lean development claiming classical RH and GRH for Dirichlet $L$-functions. Its declared endpoints include Mathlib's `RiemannHypothesis` and the assertion that zeros of Dirichlet $L$-functions in the open critical strip lie on the critical line. Alpöge described the broader extension as prospective. Clay still listed classical RH as unsolved when consulted, and the independent replay log consulted for this report showed a build in progress. The proofs here keep their analytic hypotheses explicit. [Alpöge's release note](https://alpo.ge/remark.pdf) · [Clay status](https://www.claymath.org/millennium/Riemann-Hypothesis/) · [Independent replay record](https://github.com/Deicyde/riemann-hypothesis/blob/main/verification/NOTES.md#results)

| Input | Consequence and scope |
| --- | --- |
| Classical RH | Cramér's prime-gap bound gives $p_{n+1}-p_n=O(\sqrt{p_n}\log p_n)$. This bounds the number of candidates in direct search, which can still be exponential in the bit length of $p_n$. [Dudek](https://arxiv.org/abs/1402.6417) |
| Dirichlet GRH | It supplies the small-base guarantee in Miller's deterministic test. Unconditional deterministic polynomial-time primality testing already follows from AKS. Miller's conditional factoring reduction takes the value of $\varphi(n)$ as input. [Miller](https://www.cs.cmu.edu/~glmiller/Publications/Papers/Mi76.pdf) · [AKS](https://annals.math.princeton.edu/2004/160-2/p12) |
| Dirichlet GRH | A reduced residue class modulo $q$ has a prime of size $O(q^2\log^2q)$ by classical explicit estimates. Direct scanning up to this bound can also be exponential in the bit length of $q$. [Bach and Sorenson](https://doi.org/10.1090/S0025-5718-96-00763-6) |
| Finite-field root extraction and factoring | Adleman–Manders–Miller gives conditional deterministic prime-field root extraction with polynomial dependence on the exponent's value. Evdokimov's classical GRH bound for factoring is quasipolynomial. An October 2026 preprint claims an unconditional polynomial-time algorithm over prime fields using a separate zero-free theorem. The tensor search equivalences here are independent of the status of that preprint. [Adleman–Manders–Miller](https://www.cs.cmu.edu/~glmiller/Publications/AMM77.pdf) · [Guo's account of the factoring bounds](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.MFCS.2020.42) · [Prime-field factoring preprint](https://github.com/openai/math/tree/main/preprints/Deterministic-Polynomial-Factorization-over-Prime-Fields-October-4-2026) |
| Dedekind-zeta GRH | Koiran's $\mathsf{AM}$ result is for complex feasibility of systems with integer coefficients. Andrews, Garg and Schost give an unconditional counting-hierarchy upper bound. The BSS and Valiant classes have separate transfer theorems. For example, Bürgisser's conditional transfer from $\mathsf{VP}=\mathsf{VNP}$ gives the Boolean consequence $\mathsf{NP}\subseteq\mathsf{P/poly}$. [Koiran](https://cs.uwaterloo.ca/~r5olivei/courses/2025-spring-cs860/K96-HN-PH.pdf) · [Rojas on the zeta hypothesis](https://arxiv.org/abs/math/0301111) · [Andrews, Garg and Schost](https://arxiv.org/abs/2602.17904) · [Bürgisser](https://doi.org/10.1016/S0304-3975(99)00183-8) |
| The 744-state machine | Its intended halting predicate is the negation of classical RH. For an unconditional machine result one must also verify the exact machine-to-statement implication. The repository records its current formalization status. [Machine and Lean statements](https://github.com/google-deepmind/cryptids) |

The prime test for square-zero algebras uses the Dedekind zeta function of the joint Galois extension after adjoining a quadratic field. In the abelian case this zeta function factors into Dirichlet $L$-functions, so Dirichlet GRH suffices there. The general nonabelian test retains Dedekind-zeta GRH. The complexity claims in the finite-field transporter note use algorithm-specific factoring and root-extraction bounds. The reductions themselves, and the small-component complex orbit result, are unconditional.
