# Four graph-to-tensor reductions preserve Polynomial Calculus degree

**Answer to Galesi–Grochow–Pitassi–She Open Question 7.5 over characteristic zero.** The following four reductions have mutually low-degree-equivalent ordinary Polynomial Calculus (PC) equations, pairwise on the same graph inputs.

1. The Petrank–Roth incidence code as in Grochow 2012, then diagonal matrix Lie conjugacy.
2. Grochow's semisimple matrix Lie conjugacy reduction.
3. Grochow–Qiao's padded alternating matrix space isometry reduction, also with the He–Qiao unpadded variant.
4. Grigoriev's associative graph algebra reduction.

In each case the last step is the actual Futorny–Grochow–Sergeichuk (FGS) compiler to ordinary TI, with its rank marker blocks. The companion proof gives its reverse constant-degree ordinary PC simulation over characteristic zero. The resulting equivalence compares the raw TI equations and allows the usual two-sided inverse witnesses. The semisimple route in the source is over $\mathbb C$, so the theorem includes a common field for all four cited constructions. The statement for positive-characteristic fields and the Agrawal–Saxena variant of the fourth route are separate from this theorem.

[Original Question 7.5](https://arxiv.org/html/2305.19320#S7.SS5). [Grochow's two Lie routes, Theorem 2.1 and Lemma 3.5](https://arxiv.org/pdf/1112.2012). [FGS compiler](https://arxiv.org/pdf/1810.09219).

## 1. Conventions and two reused calculations

Graph inputs have equal orders and edge counts, since the reductions reject the other cases before producing the normal-format pairs. The semisimple construction uses graphs with no isolated vertices, as assumed in Grochow's Lemma 3.5. Delete isolated vertices on both sides after comparing their counts. One may perform this common preprocessing for all four routes, or keep the isolates in the other three. To compare graph equations before and after equal-isolate deletion, a product of a vertex variable with the two neighbor-incidence column/row sums derives zero on the forbidden mapping from a nonisolated vertex to an isolate. In detail if $i$ has neighbor $j$ and $u$ is isolated, each $p_{ui}p_{vj}$ vanishes by mismatched adjacency for every $v$. Summing the $j$th column gives $p_{ui}=0$. The reverse proves the other zero block. In the other direction set the isolate block to any fixed bijection and all cross terms to zero. If the isolated counts differ, sum the isolated rows and columns after deriving those same cross zeros. The difference of the two integer counts is nonzero in characteristic zero and yields a constant-degree refutation. All routes may return the same fixed negative instance for this preliminary case.

Use variables $p_{ui}$ on vertex maps with row and column sums, Boolean idempotence, row and column collisions and adjacent/nonadjacent mismatch products. Write $P$ for this variable matrix. For ordered choices $i<j$ and $u<v$ of graph edge endpoints, put $s_{uv,ij}=p_{ui}p_{vj}+p_{vi}p_{uj}$. This edge matrix $S$ satisfies the same Boolean permutation axioms. For a fixed column, adding its entries is a sum over pairs of target endpoints. Extend the sum to all tuples, since equal endpoints or nonedges give zero, and use the two column sums. Row sums follow by swapping the graphs. For a product between two entries of one row or column, expand the two terms in each entry. Distinct specified edges force a collision in vertex rows or columns. In the square of one entry the mixed term has a vertex collision and the two other terms reduce by vertex idempotence. This proves all edge axioms in constant degree. For the incidence matrices $D_G,D_H$ with rows indexed by edges, $P D_G^{\mathsf T}=D_H^{\mathsf T} S$ follows because a sum over all target neighbors of $u$ can be extended to all vertices by adjacency mismatch and collision, resulting in $p_{ui}+p_{uj}$ for each source edge $ij$.

The following algebra calculation is useful in all routes. Suppose a map between coordinatewise algebras $F^a,F^b$ has matrix $Q$ on the standard idempotents, and its inverse has matrix $W$. The unit and multiplication equations give row sums, row collisions and idempotence for $Q$ and $W$ separately. Multiply $(QW)_{u,v}=\delta_{u,v}$ by $q_{ui}$ and $(WQ)_{i,j}=\delta_{i,j}$ by $w_{iu}$. Row collisions yield $q_{ui}w_{iv}=\delta_{uv}q_{ui}$ and $w_{iu}q_{uj}=\delta_{ij}w_{iu}$. Set $v=u,j=i$ to get $w_{iu}=q_{ui}$. In this way one also gets columns of $Q$. If $a\ne b$, summing both row and column sums produces a nonzero field constant in characteristic zero.

All matrix and linear space identities below denote entrywise bounded-degree PC derivations. In particular, writing that a variable-dependent matrix lies in a fixed linear subspace means that all its constant defining linear equations have been derived. Polynomial-size proofs follow by expanding each bounded-degree step and using a polynomial number of such steps. The sum over all matrix indices can be large, but each expanded monomial uses a bounded number of variable factors.

## 2. The incidence code and diagonal Lie route

Let $M_G=[I_m\ I_m\ I_m\ D_G]$ as in Grochow's proof of Theorem 2.1, where the $m$ edges index rows. The diagonal representation $A_G(v)=\operatorname{diag}(M_G^{\mathsf T}v)$ is the stated matrix Lie algebra. Let $W_G$ be the set of distinct vectors appearing as columns of $M_G$. Each $c\in W_G$ defines the coordinate projector $E_c$ onto all coordinates for which the weight is $c$.

In the forward direction set the ambient conjugating matrix to $\operatorname{diag}(S,S,S,P)$ and the Lie basis map to $S$, with transposes as inverses. Off-diagonal auxiliary entries are zero. On a private-coordinate entry the required intertwining equation uses the row collisions and Boolean idempotence of $S$. On a vertex-coordinate entry use $P D_G^{\mathsf T}=D_H^{\mathsf T}S$ and multiply the corresponding entry by $p_{ui}$, eliminating all terms with other source vertices by row collision. This produces exactly the Lie equations from the graph equations.

Conversely use a matrix conjugator $X$ and Lie coefficient map $Z$, with inverses $X',Z'$. The action equation is $X A_G(v) X'=A_H(Zv)$. The unital associative algebra generated by the constant diagonal matrices $A_G(e_i)$ is exactly $\bigoplus_{c\in W_G}F E_c$. To see this, for each fixed weight $c$ and each other weight pick a coordinate where they differ, select the affine linear polynomial in that coordinate with value one at $c$ and zero at the other, and multiply these selectors. This is a constant algebra identity. During the PC transport, products of arbitrarily many such generators are handled one at a time. For each constant product $B$ the transported object is always the quadratic expression $XBX'$. The identity $(XBX')(XCX')=XBCX'$ follows from $X'X=I$ and permits a constant-degree step from two established membership equations to the next. Since the target weight algebra is closed under products, its linear equations on each transported matrix are proved in constant degree. This construction also works in the reverse direction and gives inverse unit-preserving algebra maps.

Write $X E_c X'=\sum_d q_{dc}E_d'$ in the target weight algebra. The preceding coordinate-algebra calculation supplies Boolean bijection axioms on the weights. Taking the ambient trace and multiplying by $q_{dc}$ shows that $q_{dc}=0$ for mismatched multiplicities. Further, conjugation of $A_G(v)E_c=(c^{\mathsf T}v)E_c$ gives
\[
q_{dc}\bigl(d^{\mathsf T}Z-c^{\mathsf T}\bigr)=0 .
\]
If exactly one of $d,c$ is zero, recovering a nonzero fixed coordinate, using $ZZ'=I$ if necessary, shows $q_{dc}=0$. Thus isolates can be handled directly: the zero weight's multiplicity is their count, and if zero appears only on one side its row or column sum gives a contradiction.

For a simple graph the private weights $e_i$ have multiplicity at least three. The excess is exactly the count of degree-one vertices on edge $i$. All degree-at-least-two vertex weights are distinct and have multiplicity one, since two distinct vertices can share at most one incident edge. Use $s_{fe}=q_{e_f,e_e}$ on the private weights. In the displayed relation take $c=e_e,d=e_f$, sum over $e$, and use the row sum to obtain the equality $Z_{fe}=s_{fe}$ for every $f,e$. On two degree-at-least-two vertices $u,i$ set $p_{ui}=q_{D_H(\cdot,u),D_G(\cdot,i)}$. For degree-one vertices $i,u$, assign each a fixed slot among the degree-one endpoints of its own edge, and set $p_{ui}=s_{fe}$ if the source and target slots match and the source/target edges are $e,f$. Set every other such entry zero. Because the slot counts of $e,f$ agree whenever $s_{fe}$ can be nonzero, this induces all row and column equations for the leaves from those for edges. Use any fixed isolate bijection and set cross-type entries zero.

For the incidence condition on a degree-at-least-two vertex pair, multiply the displayed weight equation by $s_{fe}$ and use the already obtained $Z=S$ and edge collisions. It gives
\[
p_{ui}s_{fe}(D_H(f,u)-D_G(e,i))=0 .
\]
For leaves the same equality follows from the definition of their matching and the edge collisions. For isolates both incidence columns are zero. If $i,j$ form an edge $e$, but $u,v$ are distinct nonneighbors, each target edge $f$ misses at least one of $u,v$. Multiply the incidence equation by the other vertex variable and sum over $f$. The edge-column sum gives $p_{ui}p_{vj}=0$. If $u=v$ it follows from a row collision. Reversing the roles of the graphs and using the transposed weight and edge maps supplies the opposite mismatches. Consequently the exact diagonal Lie route is equivalent to GI in constant PC degree.

## 3. The semisimple Lie route

For the published construction take $L=\bigoplus_i \mathfrak{sl}_2(F)$ and the faithful representation $\rho_G$ on
\[
\bigoplus_{ij\in E(G)} \mathfrak{sl}_2(F)\otimes\mathfrak{sl}_2(F)
\]
used in Grochow's Lemma 3.5. On the edge block $ij$ the $i$th and $j$th simple factors act in their adjoint representations on the corresponding tensor factors. The other summands act by zero. Every input vertex is on some edge, so $\rho_G$ is injective. Use the same conventions for $\rho_H$.

For the forward substitution use $Z=P\otimes I_3$ on $L$. On edge blocks $ij$ and $uv$ define the ambient witness block as $p_{ui}p_{vj}I_9+p_{vi}p_{uj}\tau$, where $\tau$ flips the two factors. Use the transpose as inverse. The two terms have orthogonal coefficients, by vertex collisions. The edge equations of §1 and $\tau^{\mathsf T}\tau=I_9$ give $XX^{\mathsf T}=X^{\mathsf T}X=I$. On each fixed Lie-basis vector from vertex $k$ and each fixed pair of edge blocks, the intertwining identity can be verified for the two orientations separately. When $k$ is one of $i,j$, multiplying its target sum by the corresponding edge coefficient retains just the matched endpoint, by row collisions and idempotence. Its action on that endpoint's factor is the one on the source, and $\tau$ exchanges the two actions in the switched term. If $k$ is neither endpoint both actions are zero after these collisions. These are constant-degree derivations of the required Lie conjugacy equations.

For the reverse substitution write the decoded equations as $X\rho_G(a)X'=\rho_H(Za)$. Compare commutators for each constant basis pair $a,b$ using $X'X=I$. Apply a constant linear left inverse to the injective $\rho_H$ to obtain $[Za,Zb]=Z[a,b]$. The same argument in reverse gives the inverse Lie equations for $Z'$.

The centralizer of all $\operatorname{ad}(a)$ on $L$, considered as an associative algebra, is generated by the summand projectors $E_i$. Indeed off-block entries commute with an adjoint action that acts only on the source block, so they vanish because that block is perfect. A block commuting with $\operatorname{ad}(h)$ is diagonal in the weight basis with distinct weights $0,2,-2$. Commutation with $\operatorname{ad}(e)$ then identifies all three diagonal entries. Vertexwise or plain conjugation by $Z$ yields an automorphism of this algebra from the bracket equations, since $\operatorname{ad}(Za)$ is $Z\operatorname{ad}(a)Z'$ on the coordinate equations, and every target input can be expanded using $Z'$. Write $ZE_iZ'=\sum_u p_{ui}E_u$. The coordinate-algebra argument of §1 provides the vertex permutation axioms.

For a source nonedge between distinct $i,j$ the fixed matrices $\rho_G(a)\rho_G(b)$ are zero for $a\in L_i,b\in L_j$. Under ambient conjugation this proves $\rho_H(Za)\rho_H(Zb)=0$. The relation $ZE_i=(\sum_u p_{ui}E_u)Z$ and column collisions give $p_{ui}ZE_i=p_{ui}E_uZE_i$. The inverse identity for the restricted block follows by localizing $ZZ'=I$ at $p_{ui}$, since all other source blocks into $L_u$ vanish after multiplying by $p_{ui}$ using row collisions. For distinct target $u,v$, multiply the product identity by $p_{ui}p_{vj}$ and use these inverse identities in the source slots $i,j$. The result gives
\[
p_{ui}p_{vj}\rho_H(a')\rho_H(b')=0
\quad (a'\in L_u,\ b'\in L_v)
\]
for every fixed basis pair in those two summands. If $uv$ is an edge, choose $a'=h$ and $b'=h$ on their respective factors and read the nonzero coefficient $4$ on the corresponding edge block. This gives the adjacency mismatch equation. The inverse comparison handles a source edge sent to a target nonedge. Equal-vertex mismatches were already collisions. This proves the two-way comparison to GI on the actual semisimple representations.

## 4. The alternating route including the unpadded input

For Grochow–Qiao's private-leaf encoding, the earlier MathProofs proof gives the exact constant-degree two-way comparison to AMSI. Apply the companion FGS cancellation proof to the degree-three tensor system for AMSI, whose two uses of the vertex space are tied to the same map. [MathProofs, *Polynomial Calculus Equivalence of Two Graph-to-Tensor Routes*](https://github.com/Dugongue/MathProofs/blob/main/IsomorphismCohomologyCrossovers/proof-systems.md).

For the unpadded He–Qiao map $C_G$ sending edge $ij$ to $e_i\wedge e_j$, the forward comparison is the same calculation with the ordinary vertex and edge matrices. In the wedge matrix use the signed version of the edge map, namely $p_{ui}p_{vj}-p_{vi}p_{uj}$ for $i<j,u<v$. The weighted terms are orthogonal and their squares agree with the unsigned terms, so its transpose is its inverse. The off-edge entries vanish by the vertex adjacency axioms. Here is a reverse comparison that needs no private leaves.

The Lie algebra $L_G$ of matrices $M$ for which $D(M)C_G$ lands in $\operatorname{im} C_G$, with $D(M)(a\wedge b)=Ma\wedge b+a\wedge Mb$, has a pattern basis of matrix units. An off-diagonal entry in row $u$, column $v$ is allowed if every neighbor of $v$ other than $u$ is a neighbor of $u$. Equivalently $N(v)\subseteq N(u)\cup\{u\}$. This relation is transitive. For distinct $u,v,w$, a neighbor $x$ of $w$ other than $u,v$ is passed successively from $w$ to $v$ to $u$. If $x=v$ and $uv$ were a nonedge, adjacency $wv$ and the domination of $v$ by $u$ give $wu$, which then implies $uv$ by the domination of $w$ by $v$. Quotient the resulting preorder by its equivalence classes. These classes are the sets of vertices that have identical adjacencies away from each other. Two distinct classes have either complete or empty adjacency between them. Each class is itself a clique or an independent set, with the singleton cases indistinguishable for this property.

The allowed matrix units make $L_G$ a unital associative algebra, with full matrix diagonal blocks on those classes. Its strictly class-increasing part is a nilpotent ideal, and the diagonal quotient is a product of full matrix algebras, so that ideal is its radical. Write $E_C$ for the vertex-space projector onto class $C$. Under the AMSI equations conjugation of $M$ by $X$ transports this algebra. Concretely, if $D(M)C_G=C_GK$ for a fixed $K$, derive $D(XMX')C_H=C_H ZKZ'$ by differentiating the wedge action or expanding its two terms and using both inverse identities. The same calculation for the inverse gives inverse algebra maps. The regular trace-kernel argument in the companion proof transports the radical and thus the center of the diagonal quotient. Its idempotents give a Boolean class permutation $q_{BC}$. Trace on the vertex space and localization give $(|B|-|C|)q_{BC}=0$. [He–Qiao, Proposition 1.2](https://arxiv.org/html/2003.07200#S1).

Write $\delta_G(M)$ for the matrix of the induced $D(M)$ on the edge span, computed by constant-coordinate projection from $D(M)C_G$. Fix a total order extending the domination order of classes, oriented so every radical matrix unit strictly increases vertex class rank. Give an edge basis vector weight equal to the sum of its endpoints' class ranks. A radical unit strictly increases that weight in each nonzero term of $\delta_G(M)$. Every other unit of $L_G$ weakly increases the weight. Consequently a trace of a product of such matrices vanishes whenever one factor is radical. This is a constant bilinear coordinate identity when there are two factors, hence it holds in the PC reduction with all variable matrices after their linear radical constraints have been derived.

For distinct classes $C,D$, the number of edges between them is
\[
I_G(C,D)=\operatorname{tr}(\delta_G(E_C)\delta_G(E_D)).
\]
This holds because on an edge basis vector $\delta_G(E_C)$ is diagonal with eigenvalue the number of its endpoints in $C$. For a single class a convenient formula counts twice the within-class edges,
\[
J_G(C)=\operatorname{tr}\bigl(\delta_G(E_C)^2-\delta_G(E_C)\bigr).
\]
The wedge transporter conjugates $\delta_G(M)$ into $\delta_H(XMX')$. These traces are therefore preserved by the AMSI equations. Replace $X E_C X'$ by $\sum_B q_{BC}E_B'$ modulo the radical. The trace identities above show that all error terms vanish, even in degree-two products. Multiply by $q_{BC}q_{B'D}$, or by $q_{BC}$ for the one-class expression, and simplify using idempotence and collisions. We obtain
\[
(I_G(C,D)-I_H(B,B'))q_{BC}q_{B'D}=0,\qquad
(J_G(C)-J_H(B))q_{BC}=0.
\]
For matching class sizes these integer differences are nonzero exactly on opposite complete/empty adjacency between classes, or opposite internal clique/independent status for a class of size at least two.

Use the fixed order of vertices within each class. Set $p_{ui}=q_{BC}$ for $u\in B,i\in C$ when $|B|=|C|$ and their slots agree, and zero otherwise. The class equations imply all vertex permutation equations. The displayed interclass and within-class trace identities give the adjacency mismatch equations for different vertices, with within-class pairs using idempotence of $q$. A same-vertex mismatch follows from collision. These are constant-degree simulations of all GI equations. Applying the companion FGS lemma gives the ordinary TI comparison for the unpadded route as well.

## 5. The associative graph algebra route and assembly

Reuse the explicit ordinary-PC two-way substitutions between GI and Grigoriev's algebra equations. Its multiplication tensor is the data tensor for the FGS compiler, with shared actions on its repeated primal and dual slots. The FGS proof pulls the ordinary augmented tensor system back to those algebra equations. The earlier direct passage through the bare multiplication tensor is also available. [MathProofs, *Low-degree Polynomial Calculus Equivalence for Grigoriev Graph Tensors*](https://github.com/Dugongue/MathProofs/blob/main/IsomorphismCrossoversRoundThree/proof-complexity.md).

All four graph maps use fixed tensor-system signatures. For both Lie routes the matrix tuple is encoded by a single linear evaluation $L\otimes V\to V$ with a varying input dimension $\dim L$. This is a three-slot object with a repeated ambient sort, so the fixed number of FGS blocks is independent of graph order. The AMSI and algebra cases are also single three-slot objects. Compose a reverse FGS substitution, the respective reverse route, the forward route for any other listed option, and its forward FGS substitution. Each layer has bounded degree in its own variables and derives each substituted axiom in bounded degree. The composition is a low-degree ordinary PC comparison on the same graph inputs, with graph-size-independent bounds. This gives all pairwise equivalences.
