# Reversing the Futorny–Grochow–Sergeichuk compiler in low-degree Polynomial Calculus

**Theorem.** Over every field of characteristic zero, the ordinary three-tensor equations for the Futorny–Grochow–Sergeichuk (FGS) output of a fixed tensor-system signature and the original linked tensor-system equations admit constant-degree ordinary Polynomial Calculus substitutions in both directions. The constants depend only on the signature. Use existing two-sided inverse variables in all equations. Each substituted axiom has a polynomial-size bounded-degree derivation.

Use standard coordinate PC. Each proof below reduces fixed linear constraints by taking constant linear combinations. A bounded-size identity in variable-dependent matrix factors can be expanded, with every multiplication by a bounded-degree polynomial implemented as a linear combination of variable multiplications. All claimed identities in variable matrices are obtained this way. In particular, a nilpotence statement about an unknown matrix will only be used after deriving a specific low power equal to zero.

## 1. One augmentation

Consider the exact step of FGS Lemma 2.2 which removes the third-axis partition while extending the first two partitions. The other two steps are the same construction with axes interchanged. Partition the third-axis coordinate space into $U_1\oplus\cdots\oplus U_s$, with $p_k=\dim U_k$. Expand every frontal slice as a collection of linear maps from the column blocks to the row blocks. The resulting data diagram $A$ is a representation of the quiver with the row and column blocks as vertices and an arrow from each column block to each row block for each slice index. Write $A(z)$ for the collection of matrices in the linear combination with coefficients $z$.

Let $n,m$ be the data dimensions in the two matrix directions. Put $r=\min(n,m)+1$ and $r_k=2^{k-1}r$. Define $N_k$ as the diagram supported on the first row and column vertices, of dimensions $1$ and $p_k$ there, whose pencil acts by the row $z_k^{\mathsf T}$. Thus the $i$th arrow between these vertices is the corresponding coordinate projection if $i\in U_k$, and zero otherwise. The actual FGS augmented diagram is
\[
\mathcal A=A\oplus\bigoplus_{k=1}^s N_k^{\,r_k}.
\]
The markers occur in the first row block and the first column block, with the common block-row and private block-columns of the printed gadget. The target diagram $\mathcal B$ is constructed the same way from $B$.

An output transporter has blockwise invertible row and column maps $P,Q$, and an invertible third-axis map $Z$, so that $P\mathcal A(z)=\mathcal B(Zz)Q$. Inverse maps $P',Q',Z'$ are variables with both inverse identities. This convention follows from the usual cubic tensor action by a transpose and inverse relabeling. Multiplying the action equations by the appropriate witnessed inverse gives it at constant degree. The goal is a blockwise invertible map for $A(z)\to B(Zz)$ and block diagonal $Z$.

For each $k$, $\operatorname{End}(N_k)=F$, since a scalar on the row vertex forces that scalar times the identity on the column vertex. For $k\ne l$, $\operatorname{Hom}(N_k,N_l)=0$. The arrow relations on $U_k$ first force the row scalar zero. The relations on $U_l$ then force every column coefficient zero.

## 2. Recovering the blocks of the slice map

First work over an algebraically closed field of characteristic zero. Put $E_A=\operatorname{End}(\mathcal A)$ and $E_B=\operatorname{End}(\mathcal B)$. These are finite-dimensional algebras given by constant linear intertwining constraints inside the product of the endomorphism spaces at the quiver vertices. Vertexwise conjugation by $P,Q$ defines $\Psi:E_A\to E_B$, with entries of degree two. Its inverse is vertexwise conjugation by $P',Q'$. Membership in $E_B$ follows by substituting $\mathcal B(w)=P\mathcal A(Z'w)Q'$. The inverse and all product equations follow by inserting the given two-sided inverse identities. This derives the transported linear spaces and their algebra structure with constant-degree coordinate calculations.

The Jacobson radical $J(E)$ of a finite-dimensional algebra in characteristic zero is the kernel of the bilinear form $(a,b)\mapsto\operatorname{Tr}(L_{ab}\mid E)$, where $L_c$ denotes left multiplication. To see this, apply a composition series of the regular representation. All radical elements act by zero on its factors. In the split semisimple quotient each matrix factor acts on its natural module a positive integer number of times, since even the quotient regular representation contains that module. The resulting trace pairing on each matrix factor is a nonzero integer multiple of the nondegenerate matrix trace pairing. The form on $E$ is invariant under algebra isomorphisms. Concretely, derive $L_{\Psi(a)\Psi(b)}=\Psi L_{ab}\Psi^{-1}$ and cyclically reorder the trace using the inverse identities. Expand an arbitrary target basis vector by means of $\Psi^{-1}$. For each fixed $a$ in the source radical this derives the target's constant linear trace-kernel equations on $\Psi(a)$. Reverse the roles for the inverse. We obtain induced mutually inverse algebra maps on $E_A/J(E_A)$ and $E_B/J(E_B)$. The center is defined by linear commutator equations and is transported by a further application of the same inverse identities.

Choose a decomposition of each diagram into indecomposables. The standard endomorphism-algebra form of Krull–Schmidt identifies the semisimple quotient with a product of matrix algebras, one factor for each isomorphism type, of size equal to its multiplicity. For clarity, the endomorphism ring of an indecomposable is local. Its division quotient is $F$ over an algebraically closed field. Modulo the radical, the homomorphisms between different types vanish and maps among copies of one type give the entries of its matrix factor. In particular the quotient's primitive central idempotents are represented by the actual diagram projectors onto the sums of the copies of individual types. These are precomputed constant maps. Let $e_a$ and $f_b$ be the source and target quotient idempotents. Write
\[
\Psi(e_a)=\sum_b q_{ba}f_b .
\]
These $q_{ba}$ are polynomial entries of bounded degree in the transporter variables. The idempotent relations give Boolean entries, row collisions and row sums. Apply this also to the inverse center map $R$. Multiplying $(qR)_{bb'}=\delta_{bb'}$ by $q_{ba}$ and using row collisions gives $q_{ba}R_{ab'}=\delta_{bb'}q_{ba}$. Reversing gives $R_{ab}q_{ba'}=\delta_{aa'}R_{ab}$. Thus $R=q^{\mathsf T}$ and we get column sums and column collisions as well. This argument also applies when the counts of center factors on the two sides differ.

For each diagram vertex $v$, let $d_{a,v}$ denote the total dimension of source type $a$ at that vertex and $d'_{b,v}$ the corresponding target dimension. The vertex trace of an endomorphism vanishes on the radical because radical elements are nilpotent. This is a constant linear equality on a basis of that radical. Preserving trace of an actual projector under conjugation therefore gives $\sum_b d'_{b,v}q_{ba}=d_{a,v}$. Multiply by $q_{ba}$ and use column collisions to obtain
\[
(d'_{b,v}-d_{a,v})q_{ba}=0 .
\]

The total multiplicity of $N_k$ in an augmented diagram lies in $[r_k,r_k+r-1]$, since data copies consume at least one dimension on each matrix axis. Its vertex dimensions on the first row and column vertices are at least $r$. Any type other than the $N_k$ is wholly contributed by data, and cannot reach $r$ in one of the two directions because $\min(n,m)<r$. Two distinct marker types have disjoint multiplicity intervals, so their first row vertex dimensions differ. The displayed trace equations force every marker type to map to the same marker type. If its multiplicities differ across the pair, they give a constant-degree contradiction by the sum equation for its column. In that case the reverse substitution may assign arbitrary constants to source witness variables, since all substituted equations can be derived from the constant contradiction.

Assume the corresponding multiplicities agree. Choose the projector $D$ onto one fixed source $N_k$ copy. The class of $\Psi(D)$ is supported entirely in the target's $N_k$ factor, by multiplying the identity $\Psi(e_k)=f_k$ by $\Psi(\bar D)$. Let $I_k'$ be the actual projector onto the full target $N_k$-isotypic sum. The compression $I_k'\Psi(D)I_k'$ on that sum is a multiplicity matrix $C$ tensor the identity on one $N_k$. The entries of $C$ are obtained by constant linear maps. Possible radical terms outside the $N_k$ factor have vertex trace zero. The conjugation preserves the first row vertex trace of $D$, which is one, so $\operatorname{tr} C=1$.

For any slice $e_j$ outside $U_k$, the arrow matrices of $\mathcal A(e_j)D$ are zero, meaning composition with the column components of $D$. Transport this zero equation to $\mathcal B(Ze_j)\Psi(D)=0$. Compress both ends by $I_k'$ using the diagram intertwining equations. The resulting arrow block is $C\otimes (Ze_j)_k^{\mathsf T}$. Summing its diagonal multiplicity coefficients using $\operatorname{tr}C=1$ proves $(Ze_j)_k=0$. Thus all off-block entries of $Z$ are derived zero in constant degree. The same argument with the inverse transporter proves the corresponding equations for $Z'$. Restricting $ZZ'=Z'Z=I$ gives two-sided inverses for all retained third-axis blocks.

## 3. Cancelling every marker

Use fixed coordinates splitting $\mathcal A=A_0\oplus A_M$ and $\mathcal B=B_0\oplus B_M$, where the second summands are the full sums of copies of all the $N_k$, including any copies from the data. The first summands have no such indecomposable summand. Let $F$ be the whole vertexwise map $(P,Q)$ and $G=(P',Q')$ its inverse. Compress them to the first summands, producing $a:A_0\to B_0$ and $b:B_0\to A_0$. Their ordinary arrow equations hold with arrow change $Z$ and $Z'$, respectively, by linear projection of the output equations. At each vertex the inverse defects are
\[
ab=1-E_B,\qquad ba=1-E_A,\qquad
E_B=\pi_{B_0}F\iota_{A_M}\pi_{A_M}G\iota_{B_0},\qquad
E_A=\pi_{A_0}G\iota_{B_M}\pi_{B_M}F\iota_{A_0}.
\]

Every composition from a marker sum through a residual diagram back to a marker sum is zero for ordinary quiver maps. For different marker types the result lies in the zero Hom space. For one marker type the result is a scalar, and a nonzero scalar would split off that marker from the residual diagram by rescaling the composite. This is a bilinear vanishing identity on the two constant Hom spaces, checked on fixed bases and valid as a coordinate identity over a polynomial ring. It also applies in a path with arrow relabelings $Z,Z'$ whose sides cancel. Indeed, for any $N_k$ the twist from $N_k(z)$ to $N_k(Zz)$ is explicitly implemented by the identity on the row and $(Z_k^{\mathsf T})^{-1}$ on the column. Use this twist and its given inverse to move the arrow relabeling onto the marker end of each map. Replacing $z$ by $Z'z$ in an intertwining equation then yields the constant Hom constraints into and out of the same residual diagram. All these manipulations have bounded degree. In particular, the middle terms of $E_A^2,E_B^2$ are such compositions and both squares vanish in constant-degree PC.

The inverse of $a$ is now the polynomial matrix $b(1+E_B)=(1+E_A)b$. The equality follows by expanding both expressions with $E_B=1-ab$ and $E_A=1-ba$. The two inverse identities follow from $(1-E)(1+E)=1-E^2$. The corrections are diagram endomorphisms so the inverse is still an intertwiner with the appropriate inverse relabeling. The data contains the same number of residual marker copies on both sides, namely the total matching type multiplicity minus the fixed $r_k$. Reinsert these copies by the displayed explicit twist and identity on the copy indices. The direct sum with $a$ and its repaired inverse, in the fixed data coordinates, gives the asserted source witness and inverse.

## 4. Descent and composition

For a non-closed characteristic-zero field $F$, the marker-sum decompositions and the final substitution can be chosen over $F$. Compute the copy multiplicity of $N_k$ as the rank of the pairing $\operatorname{Hom}(N_k,M)\times\operatorname{Hom}(M,N_k)\to F$ given by composition. A full-rank choice of paired vectors followed by row reduction gives $g_i f_j=\delta_{ij}$ and splits off exactly that many copies. After splitting off the resulting copies the remaining pairing is zero, and stays zero under field extension by base change of the constant linear constraints. Thus no further copies appear over the algebraic closure. Cross-type compositions vanish, so choices for distinct $k$ combine. These fixed decompositions use just linear algebra. The final substituted equations have coefficients in $F$.

A constant-degree PC derivability statement about those equations descends from the algebraic closure. At degree $D$ the derivable polynomials are the subspace obtained by starting with the given axioms of degree at most $D$, taking spans, and iteratively adding $x_i$ times the intersection of the current subspace with the degree-at-most-$D-1$ subspace. Sums, intersections and multiplication by a variable commute with field extension, so the final subspace does as well. For fixed $D$ its ambient monomial dimension is polynomial in the number of variables, so taking bases of this saturation supplies polynomially many lines over $F$.

For the forward augmentation, extend the row map by identities on the new marker rows, and the column map by $(Z_k^{\mathsf T})^{-1}$ on each marker family, expressed using the inverse witness variables in the convention above. The marker arrow equations then follow from the existing inverse equations by multiplication and expansion. The three one-axis steps compose with constant bounds.

The fixed FGS tensor-system construction before these three steps places each label of the fixed signature in a separate block and uses fixed identity blocks to tie the bases of repeated primal or dual slots. In FGS Theorem 4.1, the three scalar anchor entries satisfy $abc=1$. Divide each axis by its own anchor by using the corresponding $1\times1$ inverse variable. The normalized scalar anchors are one and a dotted identity block then gives precisely the product of the two corresponding maps, with one transposed, equal to the identity. A chain of these equations gives the stated equality or inverse-transpose link using the witnessed inverses. The number of links is fixed by the signature, and they can be processed one at a time. Using the data block equations gives the original linked action. In the forward direction extend repeated maps by their required copies and inverses and set the scalar anchors to one. Each fixed identity-block equation is an inverse identity. Padding a two-slot component uses a separate fixed one-dimensional slot whose scale can likewise be taken as one. The linked block stage and the three augmentation steps therefore preserve PC degree in both directions up to constant multiples and additive constants.

The matrix trace argument is specific to characteristic zero as proved here. A reduced coordinate ring, a rank inference, and PC+Inv are not used.
