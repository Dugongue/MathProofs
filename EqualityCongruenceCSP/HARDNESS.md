# Hardness when a finite pp image fails the Taylor condition

Let the template have the finite-signature equality–congruence setting of the manuscript. Assume that it is a core and that each integer sort has pp-definable addition and the pin $1$. If $Q$ fails, its CSP is NP-hard under polynomial-time many-one reductions. The manuscript's polynomial-bit witness bound then gives NP-completeness.

Fix a modulus $N$ for which $D_N^{\mathrm{pp}}$ lacks a Taylor polymorphism. We first show that every sorted endomorphism of this finite-domain structure is a bijection. Reduction of the exact addition graph is the addition graph modulo $N$, and the pin $1$ reduces to the corresponding singleton. The integer components of an endomorphism are therefore additive homomorphisms fixing the generator $1$. They are identities, including when $N=1$.

For each original basic relation $R$ and each fixed tuple $x$ of its integer arguments, the finite fibre $R(x,-)$ is pp-definable in the original template. Pin each integer coordinate to its entry of $x$ using addition and $1$, then existentially quantify those coordinates. If there are no integer arguments, use $R$ itself. No coordinates of the finite fibre are changed by reduction modulo $N$, so the fibre is a named relation of $D_N^{\mathrm{pp}}$. Thus the finite components of an endomorphism preserve every such fibre. Together with the identity on the integer sorts, they give an endomorphism of the original template. The core hypothesis implies this map is injective. Its action on each finite sort is consequently bijective.

The finite-domain structure may have infinitely many relation symbols. Let $A_j$ be its carriers and select a prime $p>\prod_j|A_j|$. There are only finitely many sorted unary families and finitely many sorted idempotent cyclic $p$-ary families. For each sorted unary family that is noninjective on any sort, retain one relation that it fails to preserve. For each sorted idempotent cyclic $p$-ary family, retain one relation that it fails to preserve. This second choice is possible because every idempotent cyclic operation of arity $p\ge 2$ is Taylor, by cyclically moving the unique $x$ in a word with all other entries $y$. The resulting finite reduct has only injective endomorphisms and has no idempotent cyclic $p$-ary polymorphism.

To apply the finite-domain hardness theorem, take the single carrier $A=\prod_j A_j$. For each retained sorted relation, include its cylindrical extension, which tests the required coordinate of each argument. Also include the binary relation of equality in coordinate $j$, for each $j$. A polymorphism of this product structure induces a sorted family: preservation of coordinate equality says that the $j$th output depends only on the $j$th inputs. Conversely, any sorted polymorphism defines a product polymorphism, which preserves every cylindrical relation and every coordinate equality. Nonemptiness of the carriers ensures that every sorted input tuple lifts to product inputs. These correspondences preserve idempotence and cyclicity. They show that the product structure is a finite core and has no idempotent cyclic $p$-ary polymorphism. If it had a Taylor polymorphism, the idempotent algebra generated by that operation would have a cyclic term of arity $p$ by Barto–Kozik, Theorem 4.1. That term would be a polymorphism, a contradiction. The finite-core hardness theorem of Bulatov, Jeavons and Krokhin therefore gives NP-hardness of the product CSP. [Barto–Kozik, Theorems 1.4 and 4.1](https://lmcs.episciences.org/673/pdf)

Reduce a product instance to a sorted instance by introducing one variable per coordinate of each product variable. Replace cylindrical constraints by their sorted constraints and coordinate equalities by typed equalities. Solutions correspond upon forming or projecting product tuples. For the further reduction to the original template, represent each integer-residue variable by an integer variable, and retain each finite variable in its original sort. For each constraint $q_N(S)$, take a fresh copy of a fixed pp definition of $S$. At a numerical argument, equate its local variable to the shared representative modulo $N$. This condition has a pp definition using a fresh $z$ and the equation $x-y=Nz$ within the sort. At a finite argument, identify the local variable with the shared finite variable. Replace any equality of integer-residue variables by the same congruence condition.

A satisfying original assignment descends to a solution of the sorted instance. Conversely, given a solution of the sorted instance, choose a shared representative of each numerical residue. Each constraint has an exact local lift in $S$ by the definition of $q_N(S)$. Those lifts match the representatives modulo $N$ and have the required shared finite values. Their separate existential witnesses solve the translated instance. Each translation replaces an atom with a fixed-size gadget because $N$ and the reduct are fixed. This proves the claimed polynomial-time reduction.
