# Polynomial-Time Local-Unitary Equivalence of Labelled Qubit Stabilizer Codes
MathProofs, AI-assisted informal proof, November 4, 2026.

STATUS. Complete informal proof candidate; three independent internal
mathematical reviews found no gap. No Lean verification or publication-priority
claim. The exact controls described at the end supplement the proof.

THEOREM. Given signed binary Pauli generator descriptions of two valid
stabilizer codes on the same n labelled physical qubits, deterministic
polynomial-bit-time computation decides whether a product of single-qubit
unitaries maps their whole code spaces to one another, and constructs an
exact symbolic witness if so. The number k of logical qubits is arbitrary.
Physical-qubit permutations and a specified logical-basis transformation
are outside this theorem. No supplied axes, CSS promise or restricted
logical action is assumed.

Exact output means finite one-qubit Clifford/Pauli labels and rational-turn
phase gates. Their binary descriptions have polynomial total length; a
fully expanded cyclotomic field is not the representation contract.

The proof works directly with stabilizer projectors. Its diagonal-orbit
compression and paired-adjugate flag equations avoid the arbitrary joint
reference action that obstructs the previous k=1 purification route.

Part A supplies exact Pauli conventions, computational support, diagonal
phase equations, integer orbit compression, torus solving and the witness
denominator bound. Part B gives the full arbitrary-k algorithm. Part C
gives an equivalent explicit finite-module implementation with exact
coverage, not a numerical approximation.

## PART A. DIAGONAL FOUNDATION AND EXACT PHASE COVERAGE

## 1. INPUTS AND EXACT PAULI CONVENTION

Write an n-qubit Pauli as (h,x,z) = i^h X^x Z^z, with h in Z/4Z and x,z in F_2^n. Its computational-basis action is
  (h,x,z)|y> = i^h (-1)^(z dot y) |y+x>.
Products obey
  (h,x,z)(h',x',z') = (h+h'+2 z dot x', x+x', z+z').

A valid stabilizer group S is abelian, contains no -I, and is generated by at most n independent Hermitian Paulis. Standard binary elimination with the displayed phase update checks validity, removes redundant generators, detects -I, and retains witnesses for row combinations in polynomial time. A code with n-k independent generators has dimension 2^k. Its projector is P_S = |S|^(-1) sum_{s in S} s. Invalid input can be rejected. A convention admitting the zero code can instead handle that case separately.

## 2. COMPUTATIONAL SUPPORT DATA

Let C be the image of S under (h,x,z) -> x. Let D be the kernel subgroup consisting of Paulis with x=0, including their signs. Every element of D has even h. Define the affine binary space
  A = { y in F_2^n : h + 2 z dot y = 0 mod 4 for every (h,0,z) in D }.

The space A is nonempty for a valid stabilizer group. Its homogeneous translation space A_0 is the orthogonal complement of the binary Z-label space of D. Commutation gives C subset A_0. Binary elimination computes D, a point y_0 of A, a basis a_1,...,a_d of A_0, and a basis c_1,...,c_a of C. Here a,d <= n. For each c_i retain one stabilizer representative g_i=(h_i,c_i,z_i).

For y in A, the matrix entry <y+c|P_S|y> is nonzero for every c in C, and its phase is that of any representative (h,c,z) in S:
  i^h (-1)^(z dot y).
The absolute value of this entry is |D|/|S| = 1/|C|. Outside y in A and c in C the matrix entry vanishes. This follows by summing over a coset of D: on A all its character terms agree; off A they cancel.

Consequently a diagonal unitary can relate S and S' only if their signed D subgroups coincide and their C spaces coincide. Conversely these two tests guarantee equal computational support and equal nonzero entry magnitudes. Equality of affine A spaces is equivalent to equality of signed diagonal stabilizer groups, since a binary affine space determines all of its signed parity equations.

For the rest assume these tests pass. Use the same basis c_i and choose representatives g_i'=(h_i',c_i,z_i') in S'. All choices and membership operations are polynomial-time binary linear algebra with exact phase updates.

## 3. COMPLETE DIAGONAL PHASE EQUATIONS

Let t_j be turns, so the proposed local diagonal is diag(1, exp(2 pi i t_j)). Put
  ell_i = z_i + z_i' in F_2^n,
  delta_i = h_i' - h_i mod 4, represented by an integer 0,...,3.

The required generator equations are, for every i and every y in A,
  sum_j c_ij (-1)^(y_j) t_j
       = delta_i/4 + (ell_i dot y mod 2)/2   mod 1.                 (E)

Indeed the diagonal phase acquired by an entry (y+c_i,y) is
  exp(2 pi i sum_j t_j c_ij (1-2 y_j)).
Multiplying it by the source entry phase and comparing the target entry phase gives (E).

These equations are sufficient, not just necessary. Every c in C is a sum of basis c_i. Traverse the corresponding sequence of translations starting from y in A. All intermediate points remain in A because C subset A_0. Both stabilizer entry phases multiply according to their group law, while the diagonal phase differences telescope. Thus (E) gives the required phase equality for every c in C and every y in A. Section 2 then gives exact equality D_t P_S D_t^dagger = P_S'. This compares the whole codespace and permits an arbitrary induced logical unitary.

## 4. SIGNED-ORBIT INTEGER-LATTICE COMPRESSION

For fixed i define the integer row
  v_i(y) = (c_i1 (-1)^y_1,...,c_in (-1)^y_n,
            -(delta_i+1), (-1)^(ell_i dot y)) in Z^(n+2).
Let w(t)=(4t_1,...,4t_n,1,1). Since
  (ell_i dot y mod 2) = (1-(-1)^(ell_i dot y))/2,
equation (E) is exactly
  v_i(y) dot w(t) = 0 mod 4.                                    (F)

Every translation y -> y+a by a in A_0 acts on these rows by the diagonal integer sign map
  T_{i,a} = diag((-1)^a_1,...,(-1)^a_n, 1, (-1)^(ell_i dot a)).
The maps commute and square to I. Let L_{i,j} be the integer row lattice spanned by v_i(y_0+b), where b ranges over the span of a_1,...,a_j. Then
  L_{i,0} = Z v_i(y_0),
  L_{i,j+1} = L_{i,j} + T_{i,a_{j+1}} L_{i,j}.                   (G)
The identity is exact: the new affine orbit is the union of the old orbit and its translate. Applying an integer-linear map to a generating basis preserves its whole image lattice.

Compute a rectangular row Hermite normal form after each update. Its number of basis rows is at most n+2. There are at most n updates for each of at most n generator equations. At the end L_i=L_{i,d} is exactly the lattice of ALL rows v_i(y), not their rational span or a relaxation. Requiring (F) for any Z-basis of L_i is equivalent to requiring it for every y in A.

This is the essential distinction: rational row reduction alone is insufficient for equations modulo one. Integer lattice equality is used throughout.

The bit sizes are polynomial. Every L_{i,j} is generated by actual orbit rows whose entries have absolute value at most 4 and norm at most 4 sqrt(n+2). A basis can be put in Hermite normal form with entries bounded by standard minor bounds. Hadamard bounds every rho-by-rho minor by (4 sqrt(n+2))^rho, rho <= n+2, so the retained integers have O(n log(n+1)) bits. Polynomial-bit HNF algorithms therefore apply to each at-most-2(n+2)-row update. This is a polynomial number of polynomial-size operations. There is no enumeration of A and no dependence on 2^k.

Stack the at-most-n(n+2) final rows. For a row v the compressed equation is
  sum_{j=1}^n v_j t_j = -(v_{n+1}+v_{n+2})/4 mod 1.             (H)
It has polynomial-size integer coefficients and quarter-integer right side.

## 5. DETERMINISTIC TORUS SOLVING: THEOREM A

Write the compressed system as B t = b in (R/Z)^M. Compute a Smith normal form U B V = Delta with unimodular integer U,V, retaining the transformations. Set y=V^(-1)t and b'=U b mod 1. For every zero row of Delta, require b'_i=0 mod 1. Each nonzero diagonal row has the equation s_i y_i=b'_i mod 1 and is always solvable; take the rational lift y_i=b'_i/s_i. Set free coordinates to zero and return t=V y mod 1.

This is a complete consistency test over the torus. Multiplication by U and V is invertible over R/Z. The zero-row conditions are necessary, and the displayed divisions supply all nonzero-row solutions. Smith normal form with transformations is polynomial in the dimensions and input bit size. The output rational numbers have polynomial bit size. All normalization, support tests, lattice updates and torus solving are polynomial-bit operations. Together with Section 3 this proves Theorem A.

For a SUPPLIED rational phase vector t_j=p_j/q, the final verifier can skip Smith solving. Check the rows by
  4 sum_j v_j p_j + q(v_{n+1}+v_{n+2}) = 0 mod 4q.             (I)
This uses only integer arithmetic of polynomial bit size, even if q has exponentially large numerical value. In particular no expansion of Q(exp(2 pi i/q)) is needed.

## 6. UNIVERSAL POLYNOMIAL-BIT PHASE COVERAGE

The polynomial output bound above can be strengthened to an explicit existential denominator bound independent of HNF/SNF implementation.

Suppose (E) is feasible. Choose a real representative t of a solution. Among ALL original coefficient rows c_i odot (-1)^y, choose rho <= n linearly independent ones spanning their rational row space. Choose rho columns making an invertible rho-by-rho submatrix B_0. Each selected row satisfies
  row dot t = b_row + z_row,
with b_row a quarter-integer and z_row an integer. Set all unselected coordinates to zero, and solve the selected equations EXACTLY with these same right-hand sides. This defines t* with B_0 t*_J=b+z. The difference t*-t is annihilated by the selected rows, hence by every original coefficient row, since they span the full rational row space. Therefore all equations (E), including every integer lift, remain satisfied.

Cramer's rule shows that all t*_j share a denominator dividing
  q=4 |det B_0| <= 4 rho^(rho/2) <= 4 max(1,n^(n/2)).          (J)
Here B_0 has entries in {-1,0,1}; Hadamard gives the bound. Reduce each phase modulo one, writing it as p_j/q with 0 <= p_j < q. For rho=0 choose all phases zero; if a feasible system has no coefficient rows, its right sides are already integral. Thus the whole rational-turn vector has O(n^2 log(n+1)) bits.

The selected rows and integer lifts are used only in this coverage proof. They are not assumed to be supplied, found by an oracle, or exhaustively enumerated by the verifier. The verifier (I) checks the resulting phase vector against the complete compressed system.

## PART B. FULL ARBITRARY-LOGICAL-RANK ALGORITHM

## 1. PHYSICAL FACTORIZATION.
For unsigned label space S<=F2^(2n), compute RREF. Join physical qubits in the support of each RREF row; missing qubits are singleton identity factors. Connected components give the finest physical direct-sum decomposition. Indeed each row lies in its computed part; conversely Gaussian elimination respects every existing disjoint-coordinate direct sum, so its unique RREF cannot cross such a partition. The normalized density is 2^(-n) times the signed Pauli sum. It factors across a cut iff S splits across it, by partial trace and uniqueness of Pauli coefficients. Product unitaries preserve every product cut. Thus equivalent inputs have the same finest labelled factor partition and matching ranks on each part. Reject mismatches and process factors independently. Singletons are identity or pure Pauli eigenstates and have direct Clifford maps. Two-qubit pure entangled factors are Bell factors and have product Clifford maps. n=0 is immediate. Remove these cases explicitly.

## 2. UNIVERSAL POLYNOMIAL AXIS EXTRACTION.
On each remaining indecomposable factor and each qubit i, greedily delete other coordinates while S_omega still contains a Pauli nontrivial at i. Feasibility is binary linear algebra. At most n deletion tests produce a support omega minimal for this property. Every element of S_omega nontrivial at i has full support omega.
The projection at i has binary rank u=1 or 2. This and minimality are LU-invariant, even for mixed codes: the traceless-at-i correlation tensor of the reduced density is X_i*B_X+Y_i*B_Y+Z_i*B_Z. Nonzero B_X,B_Y,B_Z are mutually orthogonal sums of distinct rest Paulis; two different i-axes cannot have the same rest-label in an abelian stabilizer. Its rank is therefore 0,1,3 according as u=0,1,2. Local unitaries preserve that rank for every omega.
If u=1, source and target have unique unsigned axes sigma_i,tau_i, and the rank-one correlation tensor forces U_i sigma_i U_i^dagger=+/-tau_i in EVERY equivalence. Align these axes with Z by fixed local Cliffords and put i in T.
If u=2, choose g,g' with different i-axes. g,g',gg' all have full support omega, so g,g' differ at every site. No nonidentity h in S_omega can have identity at i: matching h_j to g_j or g'_j would shorten one of those supports; otherwise h_j equals (gg')_j on its support and shortens gg'. Thus S_omega has exactly four elements, all three nonidentity Paulis full-support. Commutation implies |omega| even. Size 2 is a removed Bell factor; hence size>=4.
This reduced code forces all its local maps Clifford. A self-contained standard minimal-support argument: its full-support traceless correlation tensor has three terms, whose factors are the three distinct Pauli axes at each site. Flatten any pair of sites versus the rest. The pair-side image is a matched diagonal-matrix space with exactly three rank-one lines. Product local rotations must permute these lines, so each rotates Pauli axes to Pauli axes, hence is Clifford. Repeating pairs covers every site. Put i in W. This is the usual content of Gross--Van den Nest Proposition 1, written here to expose coverage.
Consequently T,W cover every qubit without supplied flags. After fixed axis alignments, every possible equivalence is, up to a product Pauli and global phase, Q_W D_T: diagonal gates on T and Clifford gates on W. A minus forced-axis sign gives an anti-diagonal X times a diagonal, absorbed into the final product Pauli. Binary matching therefore suffices if signs are repaired at the end.

## 3. COMPLETE DIAGONAL ORBIT.
Keep D=ker(X_T on S) pointwise FIXED. Choose a complement g_1,...,g_a whose X_T labels are independent; a<=|T|. Let pi delete Z_T coordinates, retaining X_T and all W coordinates, and K=pi(S). Diagonal T gates commute with every Pauli of D, so D is fixed. They only mix Z_T labels inside each fixed (X_T,W-label) Pauli fiber. Each fiber is invariant under conjugation; invertibility preserves its nonzeroness. The nonzero fibers are exactly K, so K is fixed too.
Every diagonal stabilizer image therefore has representatives D unchanged and g_i'=(h_i+delta_i,x_i,z_i+ell_i), with ell_i supported on T and delta_i mod4. Matching source/target representatives with the same K-label proves coverage.
Let A be the source computational affine support, computed from signed Z-only stabilizers (Part A Sections 2-3). Unknown phase turns theta_j, alpha_ij=ell_ij/2 mod1, beta_i=delta_i/4 mod1 must satisfy
 sum_{j in T} x_ij (-1)^y_j theta_j - sum_{j in T} y_j alpha_ij - beta_i =0 mod1
for every y in A, plus 2 alpha=0 and 4 beta=0. The ordinary dot product replaces parity because alpha is half-integral. D generators have no phase or label correction.
These equations are sufficient, including code validity. Adding the equation at y and y+x_i proves the Hermiticity congruence delta_i=x_i dot ell_i mod2. Comparing translations x_i,x_j proves x_i dot ell_j=x_j dot ell_i mod2, the commutation condition. D commutes since its X_T is zero. Independent X_T complement over unchanged D keeps full generator rank and forbids -I. Any nonzero complement combination has nonzero X_T, so the Z-only subgroup and A are unchanged. Generator phase equations telescope along translations, giving exact equality of full projectors under D_theta. This avoids an assumed valid unknown code.

## 4. COMPUTING ALL BINARY CORRECTIONS WITH PHASE PREIMAGES.
Project A onto T, retaining an affine point and a binary basis of homogeneous translations. For fixed i the equation row is
 r_i(y_T)=(x_i,T odot (-1)^y_T, -y_T, -1) in Z^(2|T|+1).
It pairs with (theta,alpha_i,beta_i). Translation by b flips the first-block signs; on the second block z_j=-y_j it acts as z_j -> (1-2b_j)z_j+b_j c, where c is the last coordinate, which stays fixed. These are commuting integer-linear involutions. Start with the row at one point and update L<-L+T_b L once for each basis translation, reducing by rectangular row HNF after each update. Exact orbit-lattice induction gives every row, retaining at most 2|T|+1 generators. Original orbit rows are bounded by one; Hadamard/Hermite minor bounds keep all retained bit lengths polynomial.
Embed these compressed rows into the common variables (theta, all alpha, all beta), and append 2alpha=0,4beta=0. This is a homogeneous integer torus system M u=0 with O(n^2) variables and equations. Smith normal form U M V=Delta parametrizes u=V z: nonzero diagonal d_j allows z_j in (1/d_j)Z/Z, and zero columns are free torus parameters. The alpha projection is finite by 2alpha=0. A free continuous column has zero alpha coordinates as integers, so contributes nothing. Project the polynomially many finite torsion generators V e_j/d_j to alpha, multiply by two and binary-row-reduce. This computes a basis omega_1,...,omega_b of the COMPLETE binary correction space Omega with exact rational theta and beta preimages. Smith algorithms with transformations have polynomial bit bounds.
For epsilon in F2^b, let Delta(epsilon) be the corresponding Z_T-only correction matrix, zero on D. Then G+Delta(epsilon) is an actual diagonal image label space of the same rank, with retained phase preimage. Conversely every diagonal image has such a correction. Addition is exact: composing diagonal gates adds alpha,beta in their torus groups; alpha projects to binary addition, and X_T labels are fixed. No unknown joint logical circuit is assumed.

## 5. LINEAR FLAGS AND DETERMINANT PROPAGATION.
Define target D'=ker X_T on S', K'=pi(S'), with the SAME T and W. Unknown binary Q acts as identity on T and arbitrary 2-by-2 blocks Q_w on W. Define Q# to have identity T blocks and blockwise adjugate on W. Over F2, adjugation is LINEAR, and
 Q Q#=Q# Q=E=I_T direct-sum_w det(Q_w) I_2.
Require the four containments
 DQ subset D', D'Q# subset D,
 K Qbar subset K', K' Qbar# subset K.
Each is LINEAR in Q block entries using fixed-subspace membership tests. No invertibility is presumed.
If T is nonempty, these imply E preserves D and K. Let B be the W vertices whose determinant is zero. P_B=I-E is the physical coordinate projection onto B and preserves D,K. Any such projection also preserves S: for s in S, choose u in S with pi(u)=P_B pi(s), possible because K is preserved. Then X_T(u)=0 so u belongs to D; P_B u belongs to D subset S, and its W coordinates equal P_B s while all T coordinates vanish. Thus P_B u=P_B s. Therefore S splits across B and its complement. Source physical indecomposability and T nonempty force B empty. EVERY Q_w in EVERY solution has determinant one.

## 6. THE MAIN BINARY AFFINE SOLVER.
Choose the source generator coordinates from the fixed D/complement basis. Since corrections occupy only Z_T and Q is identity on T,
 (G+Delta(epsilon))Q=GQ+Delta(epsilon).
Thus requiring each row of this matrix to lie in S' is LINEAR jointly in Q entries and epsilon. Add the four flag containments and solve by Gaussian elimination.
Soundness: determinants are one by Section 5. Omega supplies an actual rank-preserving diagonal image. Q is invertible and source/target ranks match; hence the main inclusion is equality. Lift each Q_w to a local Clifford, use the retained diagonal phase preimage, then restore signs.
Completeness: every actual LU map has the universal form from Section 2 up to a product Pauli. Its diagonal image belongs to Omega. Its Clifford Q maps corrected S to S'. D and K are diagonal invariants, and for invertible binary 2-by-2 matrices adj(Q_w)=Q_w^(-1), so all forward and reverse flag containments hold. Thus every genuine equivalence yields a solution.

## 7. FACTORS WITH T EMPTY.
Every actual equivalence on this factor is Clifford. Solve S Q subset S' and S' Q# subset S, both linear. Their composition makes E=diag(det Q_w) preserve S. Indecomposability makes every determinant flag equal: otherwise its zero/one coordinate projection splits S. Choose one anchor vertex and enumerate its SIX GL2(F2) matrices, adding their four entry constraints. Any consistent branch has determinant one everywhere. Equal ranks give equality; every true Clifford equivalence lies in one branch. This is a polynomial algorithm, not an exponential Clifford search. All-Pauli identity factors were already removed.

## 8. SIGNS, EXACT OUTPUT AND BIT COMPLEXITY.
Any local Clifford lifts of accepted Q blocks determine an unsigned equivalence together with the stored rational diagonal phase preimage. Two signed stabilizer groups with the same unsigned labels differ by a binary character on S. A physical Pauli realizes every such character, because the ambient symplectic form is nondegenerate and maps onto the dual of any subspace. Solve this binary linear system to restore exact signs. This also absorbs anti-diagonal T-axis flips. Reinsert fixed source/target axis alignments and singleton/Bell maps.
All phases are returned as exact rational turns in symbolic one-qubit gates. No huge cyclotomic field is expanded. Earlier Part A Cramer coverage gives O(n^2 log(n+1))-bit phase witnesses. They can be chosen dyadic: if common q=2^a o with o odd, choose k=o*l with k=1 mod4. Multiplying phase turns by k preserves all quarter-integer-right-side equations and removes the odd denominator. This is an existence refinement, not needed to expand fields or enumerate precision.
Factorization/minimal supports use polynomial binary linear algebra. There are O(n^2) deletion tests. Orbit lattices have polynomial size and bit length, and the whole torus system has O(n^2) variables/rows. Exact HNF/Smith algorithms and the final affine binary systems are polynomial bit time. Each nonempty-T factor uses one final system, and each empty-T factor at most six. All output preimages, sign correction and factor recombination are polynomial. No supplied flags, restricted k, CSS/connectedness promise, bounded logical action, all-codeword list or imaginary compression oracle is used.

## PART C. EXACT FINITE-MODULE IMPLEMENTATION

UNIVERSAL DYADIC GRID AND EXPLICIT MODULAR KERNEL
Implementation addendum to Part B; independently reviewed.

Fix T of size t and a particular feasible pair (alpha,beta) of the phase-image equations. The original theta coefficient rows are in {-1,0,1}^t and their right sides are quarter-integers. The Cramer argument in Part A Section 6 produces a solution whose common denominator q0 is at most 4 max(1,t^(t/2)). Write q0=2^a o with o odd. Choose l in {1,3} such that k=o*l is 1 modulo4. Replacing theta by k theta modulo1, WHILE KEEPING alpha,beta FIXED, preserves every equation: its right side b is a quarter-integer, so k b=b modulo1. The new denominator divides 2^a. Hence it divides
  q=2^B, B=2+t ceil(log2(t+1)).
The same conclusion holds at t=0, with q=4. The exact half/quarter alpha/beta parameters also lie on the q-grid. Thus the alpha projection of the finite kernel M u=0 modulo q is EXACTLY the whole continuous-torus alpha image Omega. No precision promise or exhaustive modulus search has been introduced. log q is polynomial in n.

For the modular coordinates, u=q*(theta,alpha,beta). Compute a diagonal reduction over R=Z/q, retaining column transformations V. Select a nonzero remaining entry of minimum 2-adic valuation, exchange its row/column into the pivot, and multiply the pivot row by an odd unit so the pivot is p=2^v. Every remaining entry is divisible by p. Clear the pivot column and row by integer multiples modulo q; their divisions are only by the known common factor p. Repeat. These are invertible row/column operations over R. At most min(rows,cols) pivots occur, with polynomially many O(B)-bit modular operations.

If the pivot in coordinate j is p_j, the corresponding diagonal kernel coordinate is generated by q/p_j modulo q. A free coordinate is generated by 1. Thus physical-turn kernel generators are V e_j/p_j for pivots, and V e_j/q for free columns. Project onto alpha, multiply by2 and binary-row-reduce, retaining the theta/beta preimages. This is exactly the kernel-image interface in Part B Section 4. The implementation modular_kernel.py uses this explicit method. In its control wrapper a formal diagonal q records a coordinate that is free MODULO q; it is not falsely identified as a nonzero diagonal of an integer Smith form.
