# Mathematical transfers from AgentAlphaXiv

This packet contains informal proofs following a review of the [AgentAlphaXiv technical report](https://www.alphaxiv.org/abs/2611.society-ai-scientists) and its [pinned dataset release](https://huggingface.co/datasets/alphaXiv/AgentAlphaXiv/tree/a63f46066ac16fcb470f41933415e175825b6bcc). The source experiments suggested ways to preserve an invariant or separate local verification from search. The proofs establish their own mathematical premises.

| Result | Scope |
| --- | --- |
| [Turán spectral determination](TuranSpectralMoments.md) and [sharp three-moment result](TuranPencilAddendum.md) | Answers the three matrix cases explicitly raised in Section 6.2 of Sason, Krupnik, Hamud and Berman. The pure-degree case is also classified. Every Turán graph is determined by the order and first three moments of any real adjacency–degree combination with nonzero adjacency coefficient. For the normalized Laplacian the exceptions are complete bipartite Turán graphs on at least four vertices. Prior work already covers several of the full-spectrum cases. |
| [Matching-number criterion for symbolic subgraph circuits](MatchingNumberSubgraphCircuits.md) | Over characteristic zero, if a pattern class has bounded matching number the symbolic subgraph polynomials have fixed-parameter-size ordinary circuits. For every computably enumerable unbounded-matching class, the same circuit bound is equivalent to VFPT = VW[1]. Extends the earlier MathProofs path result. |
| [Wreath-product completion](OneElementCompletion.md) | Two sufficient criteria for polynomial-time prescribed-coset completion in a nonabelian chief layer, including split transitive noncyclic abelian actions. Progress on Collins–Grochow–Levet–Weiß Question 8.3. The unrestricted question remains open. |
| [Attention orientation](AttentionOrientation.md) | Rank-one scores with identical singular values have causal softmax stable ranks tending to 1 and growing logarithmically, respectively. A complementary quantitative bound controls true two-sided Haar reorientation. This advances the transfer issue discussed by Li and Yao. |
| [Generalized friendship adjacency spectra](FriendshipAdjacency.md) | For every clique size at least two, a generalized friendship graph has a disconnected adjacency-cospectral mate. This answers the uniform adjacency direction of Sason et al. Question 6.4 for each clique size; the triangle case was known. The proof also recovers the earlier uniqueness result among connected candidates. |
| [Small signless spectral certificates for multicones](MulticoneSignless.md) | An independent proof of the previously settled multicone classification using less spectral data. Cites the prior resolution and gives the scope of its answer to Sason et al. Question 6.4. |
