# Weighted 1-homology localization over binary-encoded prime fields

## GP-0998 — Bounded width and a variable prime

Let $K$ be an explicit oriented simplicial complex, let $z$ be a 1-cycle over $\mathbb F_p$, and let nonnegative integer weights be assigned to edges. Minimize the sum of weights of nonzero coefficients in $z+\partial_2 x$. Let $w$ be the width of a supplied tree decomposition of the bipartite boundary-incidence graph of edges and triangles. Exact optimization takes $p^{O(w+1)}N^{O(1)}$ bit operations on input size $N$. If the supplied graph includes vertices and their incidences, restriction gives the same bound.

There is a randomized polynomial-time reduction from Subset Sum to this problem on genuine simplicial 2-complexes with an absolute constant-width decomposition even of the full simplex–facet incidence graph. Consequently $f(w)\operatorname{poly}(N,\log p)$ exact bit time, even restricted to these instances, would imply $\mathrm{NP}\subseteq\mathrm{ZPP}$. The reduction is randomized only in choosing the binary-encoded prime, and it can use an always-correct Las Vegas prime-generation step. Even for $p=2$, an exact $2^{o(w)}N^{O(1)}$ algorithm would violate the Exponential Time Hypothesis. These two bounds address the separate width and coefficient-size obstructions. They leave the sharp joint dependence on $w,p$ open.

### Incidence algorithm

Use a nice tree decomposition with each nonzero boundary incidence introduced once. Guess the coefficient of every active triangle and keep the partial signed sum for every active edge. Update the latter at each incidence, add partial sums and match triangle guesses at joins, and charge an edge weight when it is forgotten exactly if its complete signed sum plus $z_e$ is nonzero. Maintain the minimum accumulated weight for each state. Every table stores one field value per active vertex and pairwise joins have $p^{O(w+1)}$ combinations. This is the same incidence accumulation as in the homological cut result, with a primal edge-support objective.

### From sparse affine equations to simplicial 1-cycles

Consider an integer matrix $M$ with entries given in unary and an affine constant vector $b$ over $\mathbb F_p$. The objective is the weighted number of nonzero entries of $b+Mx$. Implement each row $j$ by a separate directed three-edge loop, with all loops sharing exactly one vertex, and call its cycle $\gamma_j$. These loops are 1-dimensional and their triangular interiors are absent. Set $z=\sum_j b_j\gamma_j$.

For each nonzero column $i$, make a disjoint subdivided source circle, with its oriented edge walk mapping to the concatenation of the row loops $\gamma_j$ repeated and possibly reversed according to $M_{ji}$. If its consecutive source vertices are $a_\ell,a_{\ell+1}$ and their row-graph images are $b_\ell,b_{\ell+1}$, add the mapping cylinder triangles
$$
(a_\ell,a_{\ell+1},b_{\ell+1}),\qquad
(a_\ell,b_{\ell+1},b_\ell).
$$
The vertices $b_\ell,b_{\ell+1}$ are distinct along every row edge. Repeated row vertices or edges in the walk produce only the intended common simplices in the row graph, since every $a_\ell$ is private to that circle position. Cap the source circle by coning to a new private vertex. The triangles of a column are coherently oriented as a disk mapping to the row graph along its boundary. Edges outside the row graph have exactly two incident column triangles with opposite induced orientations. The dual adjacency on triangles via those edges is connected, including from every cylinder sector to the cap. Hence zero boundary coefficient on each private edge forces one common coefficient for every triangle of that column. Its contribution on the row graph is exactly that coefficient times $\sum_j M_{ji}\gamma_j$, allowing an overall orientation reversal of the column disk if needed.

Give all three edges of a row loop that row's affine support weight. Give each private edge a weight strictly larger than the decision budget. Under that budget, a homologous cycle must come from common triangle coefficients per column. Conversely such coefficients yield no private-edge support. This multiplies the affine support cost by three and gives equality of threshold decisions for suitably tripled budgets. The construction uses $O(\sum_{ji}|M_{ji}|+\#\mathrm{rows})$ simplices.

If the row/column incidence graph has bounded pathwidth and each column has only a constant number of incidences with bounded integer coefficients, this construction preserves bounded width. To see this, keep the common row-loop vertex in every bag. Replace each row node in a bag by its constant number of loop simplices and each column node by all its private simplices. Every incidence within a gadget is covered, and every inter-gadget incidence lies over one row–column edge. All occurrences of a simplex are connected, since it belongs to one fixed gadget (or is the common vertex). This supplies an explicit constant-width decomposition of the full simplex–facet incidence graph.

### Subset Sum at constant width

Take positive integers $a_1,\ldots,a_m$ and target $T$ with $0\le T\le S=\sum_i a_i$. Choose a prime $p>S+2$. A prime of bit length $O(\log(S+2))$ can be found in expected time polynomial in $\log(S+2)$ by random uniform trials in an interval $[X,2X]$, $X\ge S+3$ a power of two, and deterministic primality testing. The prime number theorem guarantees a fraction $\Omega(1/\log X)$ of primes in this interval, with finitely many small cases handled explicitly. [Agrawal–Kayal–Saxena, deterministic polynomial-time primality test](https://annals.math.princeton.edu/2004/160-2/p12)

Create two unit-weight rows $x_i$ and $x_i-1$ for each item. They contribute at least one cost, and exactly one if and only if $x_i$ is 0 or 1. Use heavy rows of weight $m+1$ for the remaining equations. Within item $i$, compute $u_i=a_i x_i$ by scanning the binary digits of $a_i$, starting with zero and using $u'=2u+b x_i$ for digit $b$. To bound occurrences, transport the current copy of $x_i$ to the next stage by a heavy equality, using fresh copies along the digit scan. Compute sums $y_i=y_{i-1}+u_i$ by heavy rows, starting at $y_0=0$, and impose $y_m=T$ by a heavy row. Each variable appears only a constant number of times, all nonzero matrix entries lie in $\{\pm1,\pm2\}$, and the bipartite incidence graph has constant pathwidth. A bag sequence follows the item and digit scans, retaining the pending preceding sum and the current and next register and copy variables. Each local equation node is introduced with its incident variables and removed once checked. No item variable besides the outgoing sum needs to be retained after its block.

Total affine cost at most $m$ holds exactly for all heavy equations and Boolean item choices. Since $p>S+2$, the final congruence is equivalent to the integer Subset Sum equality. The simplicial compilation above with budget $3m$ preserves this equivalence, uses polynomial input size, and comes with a constant-width certificate. This proves the asserted obstruction to polynomial dependence on $\log p$.

### Fixed-prime width bound (published, with a second derivation)

The same construction at $p=2$ gives an ETH lower bound on the width exponent, also established by the catalogue source in its stronger manifold setting. Apply the sparsification lemma to 3-SAT. Introduce one common variable $f$ interpreted as false after globally complementing all Boolean values if necessary. Each OR clause $(a,b,c)$ becomes the constraint $\operatorname{NAE}(a,b,c,f)$, where $\operatorname{NAE}$ requires that the arguments are not all equal. This in turn is equivalent to the existence of a fresh $t$ with $\operatorname{NAE}(a,b,t)$ and $\operatorname{NAE}(\bar t,c,f)$. If $a=b$, the first triple forces $t$ to their other value and the second fails precisely when $c=f=a$. If $a\ne b$, the first triple is free and there is some choice satisfying the second. Make an edge requiring different labels between every variable and its negation. For each NAE triple put a triangle on its three literal vertices, so the triangle has two cut edges exactly when the triple is satisfied. Repeated parallel edges are allowed as separate tests. Clauses can start with distinct underlying variables, or duplicated literals in the triple can be handled with multiplicities. The sum of the per-edge complement-pair upper bounds and the per-triple upper bounds is attained exactly when all conditions hold. This is a linear-size reduction to an exact Max-Cut threshold with $O(v)$ edges for a sparse $v$-variable formula.

For every demanded cut edge $uv$, use a unit-weight affine row $x_u+x_v-1$ over $\mathbb F_2$. Its nonzero predicate measures failure to cut that edge. The simplicial compilation is linear-size even if some columns have large degree, since their total word length counts edge incidences. A one-bag decomposition of the resulting graph has width $O(v)$. The suggested subexponential-in-width algorithm would therefore solve sparse 3-SAT in subexponential time, contradicting ETH. The $p^{O(w+1)}$ upper bound is thus single-exponential in width with a matching exponent scale at this fixed prime. [Impagliazzo–Paturi–Zane, sparsification and ETH](https://doi.org/10.1006/jcss.2001.1774)

This is a written proof. The weighted support objective is the same one used by the portfolio's surface homology localization reduction, while these bounded-width simplicial complexes need not be manifolds.
