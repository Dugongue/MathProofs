# Four parametric discrete-convexity results for isomorphism

1. [Principal flags and exact tensor instability](Flags.md). A support function obtained from the parametric subrepresentation lattice gives the exact affine Hilbert–Mumford margin under products of special linear groups on layered quivers. The rectangular formula distinguishes explicit tensors with the same flattening ranks, maximum matrix rank, and noncommutative rank.
2. [Sharp diagonal special-linear invariants](Tensor.md). For strictly balanceable rectangular slice supports, ordinary invariant monomials of degrees $L$ and $2L$ generate the full invariant character lattice. Two exact power tests complete the orbit test over the given field, and an integral transportation network gives the discrete-convex penalty path.
3. [Valuated matroid normalization and projective witnesses](Valuated.md). Parametric minimum-base optimization gives a permutation-equivariant normalization modulo element-price shifts. Applying it at the supplied prime places gives exact projective linear witness recovery for the specified $\mathbb F_2(t)$ configurations.
4. [Sparse polymatroid slopes and unmarked tensor transport](Arrangements.md). Recover the weighted hypergraph of a split subspace arrangement by support-sensitive slope queries. A matroid intersection certifies the split representation. An adjoint algebra extracts the slice axes in arbitrary coordinates over each fixed finite field, and the resulting ordinary tensor transporter counts are exact.

The main proofs are written mathematics. Lean and an independent axiom audit checked the [finite-set minimality lemma](MinimalSupport.lean) used in result 4. Each note distinguishes its claims from the prior work used in the proof. Publication priority remains unconfirmed.
