# Four transfers in finite-dimensional algebra and isomorphism

These are AI-assisted informal proofs. The claims use published algebraic results where stated. Publication priority for the combinations has yet to be established.

| Result | Exact scope |
| --- | --- |
| [Characteristic-two matrix tuple isometry](LocalIsometry.md) | Las Vegas polynomial-time decision, search and counting when the adjoint semisimple quotient is commutative, with arbitrary radical length and nontrivial residue involutions. This is a case of the characteristic-two question raised by Grochow–Qiao–Stange–Sun. |
| [Central-radical group epimorphisms](Epimorphisms.md) | A deterministic $N^{O(1+\log\log N)}$ Cayley-table decision, search and counting algorithm for arbitrary sources and the target family in Grochow–Srivastava–Thakkar Open Question 3(5). The time is polynomial under bounded simple-factor multiplicities. On central quotients of powers of $\operatorname{SL}_2(\mathbb F_5)$, epimorphism is exactly binary subcode equivalence after choosing the retained factors. In the succinct code-kernel format this yields NP-completeness. |
| [Tensor isomorphism in stable equivalence](StableCentre.md) | TI-completeness on an explicit family of commutative split-local symmetric algebras with Hilbert function $(1,D,D,1)$, for stable equivalence of Morita type. The socle quotient of the stable center retains the full tensor comparison. |
| [Finite-field tensor isomorphism as closed-orbit comparison](ClosedOrbits.md) | A reduction from TI over $\mathbb F_{p^e}$ to positive-characteristic orbit-closure intersection with first Frobenius twists, uniform in $e$ for each fixed $p$. Both output orbits are closed. The scalar marker family has exact separating degree $p(p^e-1)/(p-1)$. |

For the first proof, finite controls exhaustively checked 5,680 units across four algebras, using both split and twisted involutions, including exchanged field factors of orders four and eight. The checks agree with the radical-fiber formula and active residue-factor update. The universal claim uses the proof, with the finite cases as controls.

The first two are the closest to Grochow's published questions. The unrestricted characteristic-two tuple problem and the general polynomial-time epimorphism bound in Question 3(5) remain open. The stable-equivalence result concerns Morita type, and the orbit result uses a positive-characteristic target allowing Frobenius factors. [Characteristic-two matrix tuple question](https://arxiv.org/html/2611.00735v1), [Group Epimorphism Question 3](https://arxiv.org/html/2609.07429v1#S7), [Lysikov–Walter orbit-closure framework](https://arxiv.org/html/2411.04639v2).
