# Minimum generating sets of nilpotent groups in logspace and FOLL

**Theorem.** Given the Cayley table of any finite nilpotent group $G$ of order $n$, a minimum-cardinality generating set can be produced by a deterministic logspace transducer and by deterministic logspace-uniform Boolean circuits of polynomial size and depth $O(\log\log n)$. The circuits use only AND, OR and input negations. No generating set, Sylow subgroups or normal series are supplied. The logspace conclusion resolves the constructive question posed in Collins–Grochow–Levet–Weiß, Remark 7.7, for this exact input model. [Original Remark 7.7](https://arxiv.org/html/2402.00133v5#S7.SS1).

For $n=1$ return the empty set. For each prime $p\mid n$, let $P_p$ be the Sylow $p$-subgroup. A finite nilpotent group is their direct product. Thus $P_p$ is the set of labels $x$ satisfying $x^{p^{v_p(n)}}=1$. The group table makes every label's membership in $P_p$ available using the uniform FOLL powering predicate, or using repeated squaring in logarithmic space. The identity and all inverses are found by comparing table entries.

For a Sylow subgroup $P=P_p$, the set
$$
T_p=\{x^p:x\in P\}\;\cup\;\{[x,y]:x,y\in P\}
$$
generates its Frattini subgroup $\Phi(P)=P^p[P,P]$. A label's membership in $T_p$ can be tested by taking the OR over all choices of $x,y$ and using constant-depth group multiplication and the powering routine, or by checking the choices sequentially in logarithmic space.

For each $x\in P$, select $x$ exactly when
$$
x\notin \langle T_p\cup\{y\in P:y<x\}\rangle,
$$
where $<$ is the input label order. The images of the selected labels are exactly the greedy basis of the elementary abelian quotient $P/\Phi(P)$. In fact, the span of the images of the whole prefix equals the span of the previously selected images. A label is in the subgroup generated by the prefix and $T_p$ precisely when its quotient image belongs to that span. The definition requires no previous selection outputs, so all selections can be determined in parallel. By Burnside's basis theorem their lifts generate $P$, and their number $d_p=\dim_{\mathbb F_p}P/\Phi(P)$ is minimal.

Each test is a Cayley group membership problem for the **original** table and a supplied subset of its labels. General Cayley group membership is in deterministic logspace by undirected reachability on the graph with edges $g\longleftrightarrow gs$ for selected labels $s$. The edges can be computed in logspace from the table and the selection subset. Substitute the logspace computation for the subset into the membership test by recomputing requested bits. For the circuit algorithm use logspace-uniform FOLL for membership for nilpotent groups, or the more recent such result for all solvable groups. The input-subset circuits and membership circuits compose at depth $O(\log\log n)$; all primes and candidate labels run in parallel. [Collins–Grochow–Levet–Weiß, Theorem 3.14](https://arxiv.org/html/2402.00133v5#S3) · [Stober–Thumm–Weiß, Efficient Compression in Semigroups](https://arxiv.org/html/2601.04747v2).

For each $P_p$ put its selected labels $x_{p,1},\ldots,x_{p,d_p}$ in increasing label order and pad with the identity. The logspace algorithm can count preceding selected labels by scanning and recomputing the independent tests. The circuit uses the [sparse indexing argument](boolean-labeling.md) on at most $\lceil\log_2 n\rceil$ labels for each prime. It gives exact prefix ranks and hence selects the correct label for each slot at extra depth $O(\log\log n)$. The size $d_p$ can be read from the nonempty slots.

Set $d=\max_{p\mid n}d_p$. For $1\le i\le d$ output $g_i=\prod_{p\mid n}x_{p,i}$, where missing entries are the identity. For a fixed prime $p$, the Chinese remainder theorem gives an integer congruent to $1$ modulo $|P_p|$ and to $0$ modulo every other $|P_q|$. Raising $g_i$ to this integer recovers $x_{p,i}$. Thus the output generates every Sylow subgroup and hence their direct product. Conversely any generating set maps onto every Sylow factor, so has size at least every $d_p$, hence at least $d$. This proves optimality. The logspace transducer multiplies labels successively. The circuit multiplies at most $\log_2 n$ labels in a balanced tree of constant-depth table lookups and emits $d$ and the first $d$ slots. In particular the extra product depth is $O(\log\log n)$.

The new step is replacing the sequential basis search by membership tests on entire candidate prefixes. This yields a constructive bound from raw multiplication tables. It does not require the output generators to belong to an arbitrary marked subset of $G$. The proof is informal and the priority search is provisional.
