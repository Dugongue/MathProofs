# Thirteen Ken Wu Lab and MathProofs crossovers

These are complete written arguments. The cited theorems and earlier results are credited in each manuscript. Independent internal review and exact checks support the proofs. External review and priority assessment are pending.

| Proof | Main result |
| --- | --- |
| [Sharp exchangeable phase coefficients at every order](CodePhaseQuadrature.md) | The asymptotic minimum with exact Haar marginals is \(-\lfloor m/2\rfloor!\lceil m/2\rceil!\,N^{-m}\) at order \(2m\). This closes the higher-order conjecture in the MathProofs phase program. |
| [Universal optimal configuration LPs](OptimizationConfigurationDenominators.md) | With job sizes 1 and 3, at most three eligible machines per job, and makespan gap \(4/3\), the optimal LP face maps onto any rational polytope, with exact scaled denominator grids and a continuous section. Every nonzero additive denominator spectrum is realized as well. |
| [Unique matching spectral minimizers](MatchingResidueTwo.md) | Solves the minimum adjacency spectral-radius problem for the full residue class \(n\equiv2\pmod k\), where \(k\) is the matching number and \(n>2k\). The proof gives a recursively balanced rooted tree and a separate grounded-Laplacian extremum. |
| [Positive exchangeable phase endpoint](CodePhasePositiveEndpoint.md) | Proves existence and effective computability of the positive Haar endpoint, with a strict gap of more than \(2^{-36}\) from the four-phase optimum of \(1/2\). |
| [Fixed-redundancy Sylvester boosting gaps](HadamardFixedRedundancy.md) | A bounded family of exact rational programs computes the gap at every fixed support redundancy. This gives closed formulas in the first three regimes, including an exact value of \(1/3\) for order 16 with six columns. |
| [Exact divisor residues](SquareProductExactResidues.md) | On every \(N\equiv2\pmod4\), the square-plus-product divisor sum modulo four equals a weighted sum over the two-square representations of \(N\). The two residues on twice a split prime each have relative density one half. |
| [Infinite Gao–Gu counterexample family](MorseLinksInfiniteCounterexamples.md) | The same three indices refute the proposed valuation identity for every exponent \(k\equiv2\pmod4\), including 2-adic exponents. |
| [Automatic Dyck congruence tests](WeightedDyckAutomaticProbes.md) | A computable automaton checks weighted Dyck congruences at any specified prime-power precision over all indices. Compatible tests characterize the full valuation identity. |
| [Cycle rank and matching spectral extrema](MatchingCycleRankExtrema.md) | A sharp bound and equality classification at fixed cycle rank when minimum cover size equals matching number, including connected bipartite graphs. |
| [Transporters inside the spectral extremizers](SpectralTransporterSchemes.md) | Fixed-extremal-radius constructions retain all-ring colored transporter schemes, unrestricted similarity over fields, and exact colored Polynomial Calculus degree. |
| [Cospectral extremizers with distinct arithmetic](SpectralCospectralArithmetic.md) | Prescribed-cycle-rank bipartite spectral minimizers can have arbitrarily many different characteristic-two similarity classes within one common real adjacency spectrum. |
| [Sparse quadratic cost proof lower bounds](OptimizationQuadraticProofDegree.md) | An exact unit integer optimum coexists with linear degree and exponential expanded refutation size for the specified exact binary-cost encoding over every field. |
| [Timetable proof-degree transfer](TravelExactProofDegree.md) | Width-three timetable event graphs retain graph-coloring solution schemes and exact proof degrees, with each physical station appearing at most twice. |
