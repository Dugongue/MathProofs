# Sparse Polynomial Calculus bounds for matrix conjugacy and congruence

For diagonal projections of ranks $r$ and $r+1$ on $2r+1$ coordinates, the minimum sparse refutation size is $\Theta(n^2\log n)$ for conjugacy. For the very same matrices the congruence system requires $\Omega(n^4)$ and has size $O(n^4\log n)$. Both lower bounds allow arbitrarily high proof degree, in every characteristic. The difference comes from the equations in the published question. Conjugacy imposes the linear equations $XA=BX$, whereas congruence imposes the quadratic equations $XAX^T=B$. Both systems also impose $XY=YX=I$. Size counts expanded monomial occurrences in all used lines, including inputs, in ordinary two-premise Polynomial Calculus (PC). [Published Question 7.3](https://arxiv.org/html/2305.19320#S7.SS3) · [Conjugacy proof](CriticalMatchings.md) · [Congruence proof](FourVertexCongruence.md)

### How the unrestricted lower bounds work

For the conjugacy lower bound, evaluate a proof on near-bijections whose unmatched columns move to disjoint sets. Each input fails on at most one test, while the last line fails on all of them. Binary addition forces a total of order $n\log n$ nonzero evaluations before any line covers half the tests. A fixed monomial of any degree changes on only $O(1/n)$ tests in expectation. This accounts for the logarithm in the sparse lower bound. [Detailed proof](CriticalMatchings.md)

For congruence, partition the source and target block copies into vertices. On a bounded residual instance a parity argument shows that a refutation must contain a monomial touching four distinct vertices. The proof constructs all auxiliary assignments by linear algebra, including in characteristic two. Under a random restriction that retains a bounded number of copies per discrepant type, each fixed monomial has probability $O(n^{-4})$ of supplying that witness. A union bound gives the quartic estimate. Higher prime-power divisibility can make the matching lower bound stronger. ### Further consequences

* The proportional-gap case admits a sharp bound under a measurable symmetry condition. For an $r$-by-$s$ inverse system, let $I$ count the distinct sets of proof monomials obtained by permuting rows and columns. Every size-$S$ proof satisfies $IS\ge\binom{r}{k}(s)_k$ for $2k\le r$ and $1\le k\le p^{v_p(s-r)}$ in characteristic $p$. Here $(s)_k$ is the falling factorial. With $r,s,p^{v_p(s-r)}$ proportional to $n$, the optimal size among proofs with $I\le\exp(Cn)$ is $n^{\Theta(n)}$ for each fixed $C\ge0$. This includes invariant monomial sets and extends to diagonal conjugacy. The unrestricted proof can have a much larger orbit. [Orbit bound and proof](RelabelingSize.md)
* For a symmetric source geometrically congruent to $I_r\oplus0$ and displayed target $I_s\oplus0$, $r<s$, exactly $\binom{r+2}{2}$ distinct Gram inputs are needed. For an alternating source of rank $2r$ and displayed target of $s>r$ hyperbolic planes, the answer is $(r+1)^2$. A general target in the latter geometric orbit instead needs $\binom{2r+2}{2}$. These are exact input counts with inverse equations freely available. [Proof by completions](GramInputs.md)
* Every pair of $n$-square matrices over a finite field reduces over the same field to invertible nonsymmetric forms of side $10n$. Sparse congruence proofs pull back to sparse conjugacy proofs with additive overhead $O(n^5\log(2n))$. This includes binary inputs with arbitrary Jordan data. [Construction by Frobenius orbits](FiniteFieldTransfer.md)
* For any nonconjugate pair in characteristic zero, a degree-three refutation of sparse size $O(n^5\log(2n))$ exists in its original coordinates. The same size bound holds for all geometrically noncongruent pairs in characteristic zero. Current worst-case lower bounds are cubic for conjugacy and quartic for congruence. A separate characterization determines when every individual intertwining input is indispensable. [Conjugacy upper bound](QuinticUpper.md) · [Congruence upper bound](CongruenceSize.md) · [Indispensable inputs](IndispensableInputs.md)

### Verification and remaining scope

The main results are written proofs awaiting independent review and priority assessment. Lean checks the ordered coloring lemma used in the Gram-input argument. Exact finite checks cover 49 binary input minima, 696 single-omission witnesses on the dense families, 196 nonconjugate binary pairs of side two, 74 congruent completions for bordered pencils, and 373 weighted equations in the four-vertex construction. The new bounds use no Dirichlet GRH assumption.
