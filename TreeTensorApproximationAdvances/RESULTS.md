# Four results on tree tensor approximation and prescribed bond caps

1. **The two-cut improvement accumulates across a whole tree.** If $E$ is optimal squared Frobenius error and $b$ original cut ranks exceed their caps, pair the active cuts in postorder. The factor is $b-\sum 1/(r+3)$ with exact projections and $b-\sum 1/[2(r+3)]$ for rational inputs in deterministic polynomial bit time when $b\ge2$, with $r$ the first cap in each pair. The sole active cut gives the exact optimal value by ordinary matrix truncation and an arbitrarily accurate relative rational approximation. [Proof](paired-cuts.md)
2. **Relative approximation at the original caps works deterministically even on cyclic networks.** Physical mode compression leaves $O(m\rho_v/\varepsilon)$ dimensions at vertex $v$. The reduced real algebraic problem gives a fixed-parameter $(1+\varepsilon)$ squared-error algorithm for arbitrary prescribed graphs and CP rank, when the border optimum is positive. Zero border error and exact real membership are decided separately. [Proof](relative-error.md)
3. **The paired-cut guarantee holds directly on compressed input cores.** Exact Gram contractions and an implicit-cut minor bound give deterministic polynomial bit time in the native tree encoding, for arbitrary source and target ranks and degrees on the same tree. The ambient coefficient array need never be formed. [Proof](compressed-cores.md)
4. **One common set of tree cores can control the worst channel error.** Repeated weighted stacks followed by a direct sum give factor $(1+\varepsilon)\alpha$ against the fixed-cap common minimax optimum, with logarithmic bond inflation in the number of channels for fixed $\varepsilon$. The fixed-parameter solver upgrades this guarantee to $(1+\varepsilon)$ with the same order of rank inflation. [Proof](shared-cores.md)
