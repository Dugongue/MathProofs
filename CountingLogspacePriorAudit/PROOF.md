INDEPENDENT HERMITE DERIVATION.
Let n,k,r be unary and 0<=2r<=nk. The Gaussian polynomial G(q)=[n+k choose k]_q has degree nk, nonnegative integer coefficients c_j and coefficient sum binom(n+k,k)<=2^(n+k). Set W=n+k+2 and B=2^W. Every c_j is strictly below B. Therefore c_r is exactly the W-bit block of G(B) beginning at bit Wr, with least-significant bit numbered zero.
The evaluation is the exact positive integer quotient
 G(B)=product_{i=1}^k (2^(W(n+i))-1) / product_{i=1}^k (2^(Wi)-1).
Both products have polynomial bit length in the unary input length: the numerator length is bounded by 1+W(kn+k(k+1)/2), and the denominator is smaller. Every factor is a run of ones whose length is logspace computable. Empty products handle k=0.
Hesse--Allender--Barrington Corollary 6.3 provides fully uniform TC0 integer multiplication and division, hence deterministic logspace transducers. These arithmetic inputs remain VIRTUAL: the simulated arithmetic transducer's input-head position is stored, and a requested factor/product bit is recomputed by a deterministic logspace generator. A fixed number of such compositions uses O(log input_length) space and polynomial time, because every virtual string has polynomial length. No huge integer is stored on a logarithmic work tape.
Extract c_r and c_(r-1), setting c_(-1)=0. Their difference is the exact Hermite coefficient by the source's rectangular identity. Subtraction is FL; this does NOT assume #L is closed under subtraction. Nonnegativity follows from its interpretation as a representation multiplicity in the valid two-row range.
For an explicit positive counting machine, pad the result h with W bits. Guess one W-bit integer z from left to right, maintaining only the bit index and a three-state prefix comparison against deterministically recomputed bits of h. Accept iff z<h. There is exactly one computation path per z, so exactly h accepting paths, with logarithmic work space and polynomial time. No witness is reread.

GENERAL SCOPE CHECK.
The prior draft applies the same argument to s_lambda(1,q,...,q^k) using the hook-content product quotient. Unary partition size N and k give polynomial degree Nk and a coefficient bound from at most (k+1)^N tableaux fillings. If length(lambda)>k+1, output zero; otherwise all hook/content exponents are positive and polynomially bounded. Hook lengths, conjugate column lengths and factor bits can be generated by repeated scans with O(log input_length) counters. The quotient is exact because it evaluates an integer polynomial. Adjacent differences then give the GL2 plethysm function for arbitrary outer length. No multivariate or general LR conclusion follows.
