# Example data

See [published-examples.md](../published-examples.md) for source attribution, the exact constructions, and the distinction between published examples and generated family tests.

Regenerate and independently validate all shipped matrices:

```console
python examples/generate.py
python examples/validate.py
```

JSON matrices use point rows and block columns. Each fixture stores `incidence`, optional point and block labels, expected properties, and provenance. Positive fixture source truth tables are independent reference material; the recognizer should receive only `incidence` when testing recovery from unlabeled data.

The examples are mathematical data generated by original standard-library code. No external implementation or personal operational metadata is bundled.
