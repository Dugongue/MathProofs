# Recovering vectorial bent functions from their vanishing-flat designs

We give a polynomial recognition and reconstruction algorithm from a raw block list with arbitrary point names. We also give an exact test for whether a proposed subdesign arises by adjoining one or more coordinates to a specified vectorial bent function. The proof uses the MathProofs vanishing-flat rigidity theorem. We give a shorter proof that works under a broader spectral condition, and classify the six Steiner subdesigns in the smallest bent example.

These are informal proofs. Meidl, Polujan and Pott’s concluding Problem 4 asks both about subdesign existence and about realization of a given subdesign. The reconstruction theorem gives a decision method for the realization question across the entire admissible range. The universal yes-or-no assertion already has a negative answer in the MathProofs file `Polujan369.lean`. The question of finding an appropriate subdesign of an arbitrary given vanishing-flat design is separate. [Meidl–Polujan–Pott, §6](https://arxiv.org/html/2012.06866v2#S6) · [MathProofs realization counterexample](https://github.com/Dugongue/MathProofs/blob/main/Polujan369.lean)

## 1. The reconstruction criterion

Let $n$ be positive and even and $1\le m\le n/2$. Put $N=2^n$, $Q=2^m$ and $d=N/Q$. The input is a simple family $\mathcal B$ of four-element subsets of a point set $P$ of size $N$. Form the binary code

$$K=\left\{u\in\mathbb F_2^P\colon \sum_{p\in B}u_p=0\text{ for every }B\in\mathcal B\right\}.$$

The input is isomorphic to the vanishing-flat design of a vectorial bent $F\colon \mathbb F_2^n\to\mathbb F_2^m$ if and only if the following checks pass.

1. Every pair lies in exactly $d/2-1$ blocks and $\dim K=n+m+1$.
2. Extend the constant word $\mathbf 1$ to a basis $\mathbf1,u_1,\ldots,u_{n+m}$ of $K$. The images $a_p=(u_1(p),\ldots,u_{n+m}(p))$ are pairwise distinct.
3. In $G=\mathbb F_2^{n+m}$, the complement $H$ of the set of sums $a_p+a_q$ for distinct $p,q\in P$ is a subspace of dimension $m$.

When the checks pass, project the $a_p$ to $G/H$. They form a transversal of $H$ because no difference of distinct $a_p$ lies in $H$, and $|P|=|G/H|$. Choose a linear splitting $G\cong\mathbb F_2^n\times H$ and read the values of $F$ from the resulting graph. This produces a coordinate label for every original point and a full truth table. The choices of bases and splitting change the representative by extended-affine equivalence.

To prove sufficiency, every input block has image sum zero by the code equations. For each represented sum $w=a_p+a_q\ne0$, every input block through $p,q$ supplies a distinct second unordered pair with sum $w$. Thus $w$ has at least $d/2$ unordered representations. There are exactly $(N-1)Q$ represented sums and $\binom N2=(N-1)Q\cdot d/2$ unordered pairs, so every represented sum has exactly $d/2$ such pairs. In graph coordinates, each nonzero input difference and each output value have exactly $d$ ordered derivative representations. This is the usual uniform-derivative characterization of vectorial bentness. Every zero-sum quadruple through $p,q$ corresponds to an additional pair with sum $w$, so there are exactly $d/2-1$ of them. The input already supplies that many, hence it is the whole vanishing-flat design.

Necessity follows from the rigidity theorem in §3. For a genuine graph $A=\{(x,F(x))\}$, $K$ consists exactly of the restrictions of affine forms on the ambient space. These restrictions are independent: a nonzero component of a bent map cannot be affine, and the remaining coordinate and constant words are independent. Consequently basis evaluation recovers the graph up to an affine change of coordinates. Each nonvertical difference occurs in a bent graph and each nonzero vertical difference is absent. A bent graph therefore has the required missing-sum subspace, and every pair belongs to exactly $d/2-1$ blocks.

For complexity, the dimension and basis use binary Gaussian elimination on at most $N$ columns, the membership array for $H$ has length $NQ \le N^{3/2}$, and all point pairs can be processed in $O(N^2(n+m))$ bit operations. All other checks and coordinate reconstruction use polynomial time in the explicit incidence input and point count. For accepted inputs, the recovered graph together with the point labels is a directly checkable certificate. The method does not perform design isomorphism search or enumerate vectorial Boolean functions.

## 2. Reconstruction with a specified projection

Let $F\colon \mathbb F_2^n\to\mathbb F_2^s$ be vectorial bent, and let $s+r\le n/2$. Suppose $\mathcal D\subseteq \mathcal{VF}(F)$ is a proposed $2$-$(2^n,4,2^{n-s-r-1}-1)$ subdesign on the given point labels. Form $K$ from its blocks. The independent, known words $\mathbf1,x_1,\ldots,x_n,F_1,\ldots,F_s$ are in $K$.

If $\dim K\ne n+s+r+1$, reject. Otherwise extend the known words to a basis by any $r$ functions $g_1,\ldots,g_r$. Set $\widetilde F=(F,g_1,\ldots,g_r)$ and test whether $\mathcal{VF}(\widetilde F)=\mathcal D$. This test can check the derivative histograms. Every given block already vanishes and every represented derivative fiber has at least the target size. Uniform derivative counts are therefore equivalent to exact equality with the given subdesign.

If an extension existed, its derivative fibers would all have size $2^{n-s-r}$. Indeed through any pair $\{x,x+a\}$ there is one vanishing flat for every other unordered pair $\{y,y+a\}$ in the same derivative fiber. Thus all nonempty fibers have the asserted size. Counting forces every output to occur, giving bentness. Its affine coordinate words then fill $K$ by rigidity. Any choice of a basis completion changes its added coordinates by an invertible binary mixing and sums of known coordinates and affine functions. This preserves all zero-sum tests on affine flats on which $F$ vanishes. Thus the algorithm accepts whenever an extension exists and rejects otherwise. In particular a certificate of incompatibility can be obtained either from the rank or from an excluded quadruple with incidence vector in the block span of $\mathcal D$.

For the latter assertion, if a basis-completion trial fails then every block of $\mathcal D$ already vanishes under the trial by construction. The failing extra quadruple vanishes under the known words and every trial word, hence under all of $K$. Its indicator is therefore in $K^\perp$, the given block span. The 64-point counterexample in `Polujan369.lean` has a particularly short such certificate: the excluded block is the binary sum of two included blocks. [MathProofs realization counterexample](https://github.com/Dugongue/MathProofs/blob/main/Polujan369.lean)

## 3. A shorter rigidity proof and a sufficient condition beyond bentness

Write $A=\{(x,F(x)):x\in\mathbb F_2^n\}\subset G=\mathbb F_2^n\times\mathbb F_2^m$. A vanishing flat is a distinct-point quadruple of $A$ with sum zero. A Boolean function $\varphi$ on $A$ lies in the block kernel if it has zero sum on each such quadruple. The published six-variable computation identifies this kernel as the augmented graph code. MathProofs’ existing `Polujan365.lean` proves this for every vectorial bent function. The following proof uses connectivity of a sum graph and applies more generally. [Meidl–Polujan–Pott, Theorem 3.5](https://arxiv.org/html/2012.06866v2#S3) · [MathProofs rigidity proof](https://github.com/Dugongue/MathProofs/blob/main/Polujan365.lean)

Let $d_{\min}$ be the minimum, over nonzero input shifts $a$ and all outputs $b$, of $|\{x:F(x+a)+F(x)=b\}|$. Let $M$ be the largest absolute Walsh coefficient of any nonzero linear component of $F$. If

$$d_{\min}>M(1-2^{-m}),$$

then the block kernel is exactly the code of restrictions of affine forms on $G$.

For any nonvertical $w\in G$, the pair parity $\psi(w)=\varphi(p)+\varphi(q)$ for $p+q=w$ is well-defined. Two different unordered representations cannot share exactly one point, so comparing them gives a vanishing quadruple. The strict inequality guarantees $d_{\min}>0$, and all represented sums have at least two ordered representations because swapping the pair changes the first coordinate of the first point.

For each $t\in G$, we show that $\varphi(p)+\varphi(q)+\varphi(r)$ is constant over triples of graph points with sum $t$, allowing repeated entries. For $t\in A$ this follows at once from the quadruple condition and gives $\varphi(t)$. For $t\notin A$, let $B_t$ be $A$ minus the unique point lying over the first coordinate of $t$. On $B_t$ join $p,q$ when $t+p+q\in A$. There are no loops and all vertices have degree at least $d_{\min}$: the neighbors of $p$ enumerate one derivative fiber for the nonvertical sum $t+p$. A neighbor cannot be the removed point, since its mate would have the same first coordinate as $p$ and the graph property would force $t\in A$.

This graph is connected. The ambient symmetric real matrix $C_t$ with entries $1_A(t+g+h)$ is diagonal on the normalized binary characters with eigenvalues $\chi(t)\widehat{1_A}(\chi)$. For a mean-zero real vector $v$ supported on $A$, the squared norm of its projection onto characters trivial in the output coordinate is exactly $\|v\|^2/Q$: the projection averages $v$ over each vertical fiber, and $A$ contains one point per fiber. The constant character has zero projection and all the remaining characters in that slice have eigenvalue zero because $A$ projects bijectively to the inputs. It follows that

$$\langle v,C_t v\rangle\le M(1-1/Q)\|v\|^2.$$

If the graph on $B_t$ had multiple components, choose a nonzero mean-zero real vector constant on each component and zero outside $B_t$. The quadratic form would be the sum of the squared vertex values times their degrees, at least $d_{\min}\|v\|^2$, a contradiction.

The parity of any triple with first term $p\in B_t$ is $\varphi(p)+\psi(t+p)$, independent of the other terms. An edge joins two first terms that contribute the same parity, by using their shared triple. Connectivity therefore defines an unambiguous triple parity $u(t)$ for every $t$.

Fix a nonvertical step $w=p+q$, and choose a representation with $p$ not above the first coordinate of $t$. Both choices of ordering of one pair already ensure such a representation. Then $t+p$ is nonvertical and $(t+w)+q=t+p$, so

$$u(t)+u(t+w)=\varphi(p)+\psi(t+p)+\varphi(q)+\psi(t+p)=\psi(w).$$

The nonvertical steps generate $G$, and thus every directional derivative of $u$ is constant in $t$. Equivalently, $u+u(0)$ is additive. Since $u$ agrees with $\varphi$ on $A$, this proves the claim. For a vectorial bent function, $d_{\min}=N/Q$ and $M=\sqrt N$, so the hypothesis holds throughout the Nyberg range, including $m=n/2$.

The same argument certifies rigidity after changing $h$ values of a bent truth table whenever

$$N/Q-2h>(\sqrt N+2h)(1-1/Q).$$

Changing one table entry affects at most two terms of each derivative histogram and changes any component Walsh coefficient by at most two. For example, starting with $n=12,m=3$, changing any $h\le121$ entries preserves rigidity. More generally for any functions obeying the spectral condition, an isomorphism of their vanishing-flat designs identifies the two block kernels, hence extends to an affine isomorphism of their graphs by basis evaluation. The graph determines the vertical subspace as the set of missing nonzero pair sums together with zero. Thus the affine graph isomorphism has extended-affine form. The resulting reconstruction and isomorphism statement concerns exact graphs and does not assume knowledge of which entries were changed.

## 4. The 16-point case and exact realization of all six subdesigns

We first prove a small general fact. If every nonzero derivative of a vectorial Boolean map takes exactly two values, their image directions all agree. Write $D_a F(x)=v_a+u_a h_a(x)$, with $u_a\ne0$ and a nonconstant scalar function $h_a$. When $u_a\ne u_b$, commuting $D_a,D_b$ gives $D_b h_a=D_a h_b=0$, because $u_a,u_b$ are independent. Therefore $D_{a+b}F(x)=v_a+v_b+u_a h_a(x)+u_b h_b(x)$. Its image has exactly two values, so the pairs $(h_a(x),h_b(x))$ have exactly two values with both coordinates nonconstant. Hence $h_a$ and $h_b$ differ by a constant. If two different $u$ occur, comparing each $a$ with one of these two directions shows that all $h_a$ agree modulo constants. Each $h_a$ is periodic under $a$, so their common representative would be invariant under all translations. This is impossible for a nonconstant function. Quotienting by the common output direction makes every derivative constant, proving that the quotient is affine. Splitting it off shows $F$ is affine plus one scalar Boolean coordinate in a fixed output direction. If the original two-valued derivatives are balanced on their image, that scalar coordinate is bent.

In a $2$-$(16,4,3)$ vanishing-flat design every nonempty derivative fiber has size $2(3+1)=8$ by counting flats through a pair. Each nonzero derivative therefore takes two equiprobable values. The preceding argument reduces any vectorial realization to one bent scalar coordinate modulo affine terms. A bent Boolean function in four variables has degree at most two, and its quadratic polar form is nondegenerate. Thus the unique realizable design is the set of affine translates of all isotropic two-dimensional subspaces in a four-dimensional binary symplectic space. [Bent degree bound and quadratic classification](https://doi.org/10.1007/s10801-025-01415-5)

Every $2$-$(16,4,1)$ subdesign of this design is an affine plane. To see its parallel classes, any point outside a block lies on five blocks, four of which meet the original block in its four points. The remaining block is disjoint from the original block. This uniqueness makes equality or disjointness an equivalence relation on lines, with five classes, and lines from distinct classes meet at exactly one point. The direction spaces of two affine flats meeting at exactly one point have zero intersection. Each class has one line through $0$, and the five directions of these origin lines partition the $15$ nonzero vectors. Any other line of a class has direction disjoint from the four origin-line directions of the other classes. It must therefore share the direction of its own origin line. Thus the subdesigns are exactly the complete coset families of symplectic spreads.

Any two complementary isotropic two-spaces $U,W$ can be given dual bases for the symplectic pairing. Further isotropic directions complementary to both are graphs of invertible symmetric $2\times2$ matrices over $\mathbb F_2$. These are $I$, $J=\left(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\right)$, $C=\left(\begin{smallmatrix}1&1\\1&0\end{smallmatrix}\right)$, and $D=\left(\begin{smallmatrix}0&1\\1&1\end{smallmatrix}\right)$. Two graphs are complementary precisely when their matrices differ by an invertible matrix. The only possible triple is $I,C,D$. Thus each complementary pair lies in a unique symplectic spread. There are 15 isotropic directions, since each nonzero vector lies in three, and each direction is complementary to eight others. Counting unordered complementary pairs gives $(15\cdot 8/2)/\binom52=6$ spreads. Dual bases also show transitivity on complementary pairs, hence on spreads. The count agrees with the classical description of spreads of $W(3,2)$. [Lévay–Szabó, three-qubit pentagrams and the six spreads of the doily](https://arxiv.org/abs/1608.03400)

For realization, use $\mathbb F_4^2$ with the binary alternating form $((x,y),(x',y'))\mapsto\operatorname{Tr}(xy'+x'y)$. This form is nondegenerate, and its five $\mathbb F_4$ lines are a symplectic spread. The product map $(x,y)\mapsto xy$ has as its vanishing flats exactly the cosets of these five direction spaces, by the determinant criterion $xy'+x'y=0$. It has first coordinate $\operatorname{Tr}(xy)$ under a suitable choice of output basis. Any quadratic bent function with that polar form differs from $\operatorname{Tr}(xy)$ by an affine term, which can be added to the first coordinate without changing any vanishing flats. Symplectic spread transitivity now realizes every one of the six subdesigns by an added Boolean coordinate. In particular dimension six in the known counterexample is minimal within admissible parameters, because dimension four is the first possible source dimension for a positive-output extension.

The accompanying check exhausts all exact covers of the 120 pairs by the 60 vanishing flats and finds six, all with five directions occurring four times each. The classification and reconstruction theorems have mathematical proofs independent of this computation.

## Reproduce

Run `python check_design.py` with Python 3.10 or later. It checks the whole 16-point exact-cover count, reconstructs all six Steiner subdesigns as extensions of one fixed scalar bent function, and tests recognition after relabeling points on multiplication designs in dimensions 2, 4, 6 and 8. It also recovers multi-coordinate extensions in dimensions 6 and 8 and rejects the classical nonrealizable 16-point Singer design. [MathProofs documentation for the Singer construction and its provenance](https://github.com/Dugongue/MathProofs/blob/main/ClassicalSubdesignFreeDesign16/PROOF.md)

For a new instance, `python recognize_design.py recognize input.json` expects keys `points`, `blocks`, and `output_dimension`. Use distinct JSON strings or integers as point labels. The output `point_coordinates` is aligned with the input `points` array, and `truth_table` is indexed by those recovered coordinates. `python recognize_design.py extend input.json` expects `source_table`, `source_dimension`, `added_dimension`, and `blocks`, with integer point labels indexing the source truth table. It retains the source output in the low bits of each reconstructed value. The checker and the algorithms use only the Python standard library.
