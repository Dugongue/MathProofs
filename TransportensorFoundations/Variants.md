# Variants of Transportensor Isomorphism

Use the object and morphism definitions in [Transportensors.md](Transportensors.md). A variant specifies which data are supplied and which witness maps are allowed. Only invertible maps occur in the isomorphism tests below. All finite-field complexity comparisons here assume a fixed field, fixed signature (a reduction may choose a different fixed signature), explicit graphs, and basis-explicit data. The full classification proof is in [Complexity.md](Complexity.md).

| Variant | Definition and consequence |
|---|---|
| Fixed skeleton | Supply a vertex and edge correspondence and require that specific graph part. In the unlabelled problem both maps are unknown. The one-vertex tensor subproblem survives either convention. |
| Pointed or colored | Require marked vertices, edges, subspaces, vectors or operations to match with their specified labels. Marked subspaces need only be preserved setwise unless explicitly declared pointwise fixed. |
| Shared or permutable modes | Repeating a mode in a signature forces a shared map. A separate variant permits one global permutation of a fixed signature preserving port words, operation types and any named constraints. Its fixed finite choices give a finite disjunction of ordinary tests. |
| Local special linear | Supply determinant-line volumes (or use the input bases as oriented bases). Require each individual fiber isomorphism to have determinant one relative to these volumes. This differs from a constraint on only the product of determinants. |
| Local symplectic | Each mode carries a specified nondegenerate alternating form; local maps must be isometries. Positive-dimensional symplectic modes are even-dimensional. |
| Local orthogonal | Choose a specified convention: isometries of a symmetric nondegenerate bilinear form, or isometries of a specified quadratic form. These definitions need not agree in characteristic two. |
| Local unitary | Fix a field with involution and supply nondegenerate Hermitian forms. Fiber maps are field-linear isometries. Finite-field unitary groups and complex positive-definite unitary groups have different input models. |
| Permutation and monomial | Supply a coordinate basis at each mode and allow permutations, or permutations and independent nonzero scalings. For fixed finite fields, both unrestricted-graph decision variants are GI-equivalent. |
| Semilinear | Allow a single common field automorphism on coefficients, followed by linear changes. With a fixed finite field enumerate its Frobenius automorphisms and test the corresponding ordinary instances. Allowing independent automorphisms at different vertices would need a different edge contract. |
| Symmetric or alternating vertex data | Require explicitly named local multilinear forms to satisfy the chosen symmetry or alternation identities. Repeated-mode congruence and independent-mode equivalence must be distinguished. In small characteristic, specify forms, symmetric tensors or homogeneous polynomials explicitly when they differ. |
| Parallel or invertible-edge subclass | Parallel edges in the sense of *parallel tensor data* require every edge to intertwine all its endpoint operations; this is distinct from a graph having multiple edges. An invertible-edge subclass instead requires each transport to be invertible. Neither condition implies the other. |
| Search, counting, canonical form and generators | Return a witness, the number of witnesses, a canonical representative, or generators of the automorphism group, respectively. Nontrivial automorphism asks whether the automorphism group contains an element beyond the identity. These output specifications are distinct. |

### A witness-preserving padding theorem

An elementary feature of the graph gives a stronger statement than decision hardness. For every object append one distinguished loop at *each* vertex at a threshold strictly greater than all old thresholds. Use the same new value across the input pair; a single-object convention can instead assign one plus the object's maximum, with an empty fallback. Require the old signature on all vertices. For local GL to local SL replace each $V$ by $V\oplus k$. For GL to symplectic or split quadratic orthogonal replace it by $V\oplus V^\vee$. The marker loop carries the projector onto $V$ in each padded mode. Extend every old transport $L$ to $\operatorname{diag}(L,0)$ between padded endpoints. Extend a vertex operation by projecting each input to its old space and including each old output into its padded space. Empty products use the identity on $k$.

A padded witness must preserve these loops and their projectors. Thus it is block diagonal, with first block an original isomorphism $g$. In SL the second block is forced to be $\det(g)^{-1}$. For symplectic use the standard alternating pairing between $V$ and its dual. For quadratic orthogonal use $Q(v,f)=f(v)$, including in characteristic two. Either form forces the second block to be $g^{-t}$. The same argument works for hyperbolic Hermitian forms on a space and its conjugate dual, with second block $\overline g^{-t}$. Conversely those block maps satisfy every padded equation, even for noninvertible old transports. Extension and restriction preserve composition. There is precisely one extension per original witness, and the automorphism groups are isomorphic. This theorem permits a supplied hyperbolic form in the target; it does not assert such padding for positive-definite real or complex forms. The finite-field applications are polynomial in basis-explicit input size. In the equal-type, zero-vertex case there is still one empty witness.

### Which restrictions can be compiled back to GL?

- For a prescribed bilinear form add it as a named vertex operation with two inputs and scalar output. Its preservation is exactly the isometry requirement. In particular this gives a reverse reduction for symplectic and symmetric-bilinear orthogonal inputs of arbitrary given form type.
- For quadratic orthogonal inputs over any characteristic, introduce $U=V^\vee$ with evaluation, and a fresh sort $S=\operatorname{Sym}^2 U$ with its quotient product $U\otimes U\to S$. Mark the form by its coefficient element of $S$. Use zero transport on the new sorts, so the original edge data need satisfy no extra equations. Evaluation forces the auxiliary dual action and the surjective product forces the symmetric-square action. Preserving the marked element is precisely preservation of the quadratic form as a homogeneous polynomial, even in characteristic two.
- For unitary groups over the fixed field $k=\mathbb F_{s^2}$ with involution $a\mapsto a^s$, encode a Hermitian form by its formal bihomogeneous polynomial $\sum h_{ab}X_a^sY_b$ on two copies of a mode. Its coefficients give a marked element of $\operatorname{Sym}^s(V^\vee)\otimes V^\vee$. Under a linear substitution, Frobenius sends a sum to the sum of the powers. Thus the coefficient transformation is exactly the Hermitian congruence transformation. The distinct monomials recover each form entry. Build the symmetric power by intermediate named symmetric powers and their surjective products with $V^\vee$; use a nullary operation for the marked element and zero auxiliary edge maps. The transformations on the added spaces are forced. This construction is polynomial for *fixed* $s$; it supplies no uniform bit bound as $s$ grows.
- A volume element in top exterior degree describes local SL intrinsically. Its degree grows with the local dimension. The fixed-signature arguments here establish GL to SL and do not establish the reverse reduction for unrestricted local dimensions over general finite fields. Over $\mathbb F_2$, local GL and SL coincide directly.

Combining the padding with the reverse constructions gives polynomial reductions in both directions which preserve transporters between ordinary Transportensor inputs and the corresponding full symplectic, quadratic-orthogonal (allowing hyperbolic instances), and fixed finite-field Hermitian variants, with the stated signature changes. Hence their expressive decision versions are TI-complete in those settings. The reverse construction for symmetric-bilinear orthogonal inputs works directly as well, and its hyperbolic padding uses the symmetric pairing $f(w)+h(v)$ on $(v,f),(w,h)$. These arguments concern the network language; classical-group reductions for plain tensors already have a literature. [Chen, Grochow, Qiao, Tang and Zhang](https://arxiv.org/abs/2306.03135). The project's earlier TI–symplectic result also concerns plain tensors. The marked network loop accounts for the uniqueness of each extension here.

For permutation maps, record tensor coefficients, edge coefficients and directed incidence as a colored bounded-arity relational structure on the basis positions. For monomial maps over fixed $k$, additionally give each position a copy of its nonzero scalar multiples with the named right action of $k^\times$. Any equivariant bijection between these copies is multiplication by a unique nonzero scalar. Include the corresponding dual copies with their evaluation pairings and encode all tensor and edge evaluations on these spanning labels. This forces precisely the allowed maps. The resulting structure has polynomial size and reduces to GI. Zero-dimensional mode data retain the ordinary graph lower bound in both variants.

These definitions also support structural parameters such as maximum fiber dimension, total tensor arity, number of components, or the number of vertices left ambiguous by their invariants. Complexity on those restricted families needs a separate proof for the parameter and encoding in question.
