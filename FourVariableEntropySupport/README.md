# Negative coefficient support of four-variable entropy inequalities

Let $h(S)=H((X_i)_{i\in S})$ for four jointly distributed finite-valued random variables, with $h(\varnothing)=0$. Write $c\cdot h\ge 0$ for a linear inequality in the fifteen nonempty coordinates. It is **valid** if it holds for every such distribution and **Shannon-type** if it holds on the cone of monotone submodular set functions with $h(\varnothing)=0$.

For a pair $\{a,b\}$ of indices and complementary pair $\{u,v\}$, set

$$
P_{ab}=\bigl\{\{a\},\{b\},\{u,v\},\{a,b,u\},\{a,b,v\}\bigr\}.
$$

**Theorem.** If the negative coefficient support of $c$ contains none of the six patterns $P_{ab}$, then $c$ is valid exactly when it is Shannon-type. Each $P_{ab}$ is the exact negative coefficient support of a valid inequality that is outside the Shannon cone of inequalities. In particular, the minimum size of the negative coefficient support of a valid non-Shannon inequality is five.

## Sufficiency of the support condition

The four-variable polymatroid cone has 41 extreme rays. Entropy functions generate 35 of the rays. The other six are the permutations of the ray generated by the set function $v$ with $v(i)=2$ for singletons, $v(34)=4$, $v(ij)=3$ for the other pairs, and $v(S)=4$ in sizes three and four. This is the Matúš–Studený classification. [Studený, *Contribution of František Matúš to the research on conditional independence*, Section 6.1](https://www.kybernetika.cz/content/2020/5/850)

For each $s\in P_{12}$, the vector $v-e_s$ is entropic, where $e_s$ is one in coordinate $s$ and zero elsewhere. The following table gives row bases for four subspaces of $\mathbb F_{13}^4$ for each of these five vectors. Each entry is a list of row vectors.

| --- | --- | --- | --- | --- |
| $1$ | `(8,2,12,3)` | `(5,12,8,6) (3,3,4,4)` | `(3,9,4,0) (0,3,1,1)` | `(4,11,6,5) (7,3,12,8)` |
| $2$ | `(8,2,12,3) (5,12,8,6)` | `(3,3,4,4)` | `(7,7,9,2) (3,12,6,9)` | `(0,9,9,3) (12,5,5,3)` |

For a uniformly random column in $\mathbb F_{13}^4$, take $X_i$ to be its list of products with the rows of subspace $i$. Using logarithms base 13, joint entropy is the rank of the matrix obtained by stacking the relevant rows. Row reduction modulo 13 gives $v-e_s$ in all 15 coordinates for each row of the table. An exact check is included below.

If $c$ is valid and $P_{12}$ is absent from its negative support, choose $s\in P_{12}$ with $c_s\ge 0$. Then

$$
c\cdot v=c\cdot(v-e_s)+c_s\ge 0.
$$

Relabeling gives nonnegativity on the other five exceptional rays because their respective patterns are absent as well. Validity gives nonnegativity on the 35 entropic rays. Thus $c\cdot h\ge 0$ holds on the entire polymatroid cone. The converse follows because all entropy functions are polymatroids.

## Sharpness

The Zhang–Yeung inequality is

$$
Z(A,B,C,D)=I(A;B)+I(A;CD)+3I(C;D\mid A)+I(C;D\mid B)-2I(C;D)\ge 0.
$$

[Zhang and Yeung, *On Characterization of Entropy Function via Information Inequalities*, Theorem 3](https://doi.org/10.1109/18.681320)

Take $Z(3,4,1,2)+I(1;2\mid 4)+I(3;4)$. This is valid. Expanding it in joint entropies yields

$$
-2h_1-2h_2+3h_{12}+3h_{13}+3h_{23}-4h_{123}
+2h_{14}+2h_{24}-2h_{124}-2h_{34}\ge 0.
$$

Its value at $v$ is $-1$, and its negative support is exactly $P_{12}$. Every other pattern is obtained by relabeling. $\square$

## Exact rank checks

```python
common = [(8, 2, 12, 3), (5, 12, 8, 6)]
second = [(3, 3, 4, 4), (10, 6, 7, 3)]
third = [(4, 4, 7, 3), (4, 1, 0, 1)]
certificates = {
    1: [common[:1], [common[1], second[0]], [(3, 9, 4, 0), (0, 3, 1, 1)],
        [(4, 11, 6, 5), (7, 3, 12, 8)]],
    2: [common, second[:1], [(7, 7, 9, 2), (3, 12, 6, 9)],
        [(0, 9, 9, 3), (12, 5, 5, 3)]],
    7: [common, second, [(3, 7, 6, 2), (11, 1, 1, 12)], third],
    12: [common, second, third, [(0, 10, 8, 10), (7, 1, 7, 5)]],
    11: [common, second, third, [(6, 10, 10, 12), (2, 11, 5, 6)]],
}


def rank(rows):
    matrix = [list(row) for row in rows]
    next_row = 0
    for col in range(4):
        pivot = next((i for i in range(next_row, len(matrix))
                      if matrix[i][col] % 13), None)
        if pivot is None:
            continue
        matrix[next_row], matrix[pivot] = matrix[pivot], matrix[next_row]
        inverse = pow(matrix[next_row][col], -1, 13)
        normalized = [(inverse * entry) % 13 for entry in matrix[next_row]]
        for i in range(next_row + 1, len(matrix)):
            factor = matrix[i][col]
            matrix[i] = [(x - factor * y) % 13 for x, y in zip(matrix[i], normalized)]
        next_row += 1
    return next_row


for lowered, spaces in certificates.items():
    for subset in range(1, 16):
        size = subset.bit_count()
        if size == 1:
            value = 2
        elif size == 2 and subset != 12:
            value = 3
        else:
            value = 4
        stacked = [row for i, space in enumerate(spaces)
                   if subset & (1 << i) for row in space]
        assert rank(stacked) == value - (subset == lowered)

print("All 75 rank identities hold over F_13")
```
