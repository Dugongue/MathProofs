# Cross-length complete invariants by polynomial descent

## Target and new conclusions

Fortnow and Grochow's Open Question 5.11 asks for an oracle $A$ with $\mathsf{CF}^A\subsetneq\mathsf{Ker}^A=\mathsf{PEq}^A$, for equivalence relations on all binary strings. The prior length-preserving construction gives this separation for relations that only relate strings of the same length. This note gives a cross-length extension to classes admitting polynomial descent to a common encoding length, and proves that universal recovery of even a polynomial upper bound on the minimum class-member length would collapse $\mathsf P^A$ and $\mathsf{NP}^A$. The unrestricted oracle question remains open in this work. [Fortnow–Grochow, Question 5.11](https://arxiv.org/html/0907.4775v2#S5) · [Prior length-preserving construction](https://github.com/Dugongue/MathProofs/blob/e1dd0327f41109018c3bd7608dc15da84a032f77/LengthPreservingEquivalenceOracle/PROOF.md).

## 1. Recovering a common encoding length without canonical representatives

**Theorem 1.** Fix an oracle $A$ for which $\mathsf{Ker}_{=}^A=\mathsf{PEq}_{=}^A$. Let $E\in\mathsf{PEq}^A$. Suppose the following data and hypotheses hold.

1. A polynomial-time oracle algorithm lists a finite set $D(x)$ of possible descendants of each string $x$. Every $y\in D(x)$ satisfies $xEy$ and $|y|\le |x|$. Any descent sequence from $x$ has at most $p(|x|)$ steps for some polynomial $p$. Call $t$ terminal when $D(t)=\varnothing$.
2. A function $g(t)$ on terminals can be evaluated in polynomial time with oracle $A$, and $2|t|+1\le g(t)\le q(|t|+1)$ for some polynomial $q$.
3. Whenever $u,v\in D(x)$, there exist terminal descendants $t_u,t_v$ of $u,v$ with $g(t_u)=g(t_v)$. Descendants may include the starting point.
4. The equivalence $E$ is generated by the directed descent edges, considered undirected, together with a set $S$ of equal-length pairs in $E$. Each pair $xSy$ admits terminal descendants $t_x,t_y$ with $g(t_x)=g(t_y)$.

Then $E\in\mathsf{Ker}^A$. In particular, a polynomial-time kernel reduction maps it to a length-preserving equivalence relation.

**Proof.** Every string has at least one terminal descendant. A string $x$ with no outgoing edge has a unique terminal grade. Induction on the longest descent path from $x$ shows that all its terminal descendants have the same grade. Indeed, every one-step descendant has a unique terminal grade by induction, and hypothesis 3 makes those grades equal. This unique grade is unchanged along a descent edge. Hypothesis 4 gives equality along the remaining generating pairs, so the grade is constant on every $E$-class.

From $x$ compute a terminal $\rho(x)$ by repeatedly taking the first descendant in a fixed order. Termination and nonincrease of length make this a polynomial-time procedure. There is no requirement that different starts select the same terminal. Let $P(t)$ be the self-delimiting code $1^{|t|}0t$ extended by zeroes to length $g(t)$. The code can be parsed and its validity, terminality, and required length checked in polynomial time on an arbitrary encoded string. Define $E'$ to equate valid $P$-codes of equal length if their decoded strings are $E$-equivalent, and to make each invalid code a singleton. This is a polynomial-time length-preserving equivalence. The map $x\mapsto P(\rho(x))$ is a kernel reduction to $E'$. Equivalent inputs yield the same encoding length and remain equivalent after descent. Conversely their terminals can be equivalent only if their starting strings were equivalent. Compose the reduction with the complete invariant for $E'$. $\square$

A useful sufficient condition for the grade hypotheses is a commuting descent system up to $S$. Suppose $S$ is an equal-length equivalence relation and, for each $xSy$, every step $x\to u$ can be matched by a step $y\to v$ with $uSv$. By symmetry this works in both directions, so terminality and reachable terminal lengths match across $S$. Suppose every local fork has descendants $u',v'$ with $u'Sv'$. Extending from $u'$ to any terminal and simulating those steps from $v'$ gives terminals of the same length. Thus $g(t)=2|t|+1$ satisfies the conditions of Theorem 1. The rules may choose different terminal strings in the same class.

**Minimum-length variant.** If the descendant algorithm lists some strictly shorter equivalent string at every non-minimal string, one can use only the strictly decreasing steps. The computation always reaches a shortest class member, although it may reach different shortest strings on different starts. Apply the equal-length invariant for $E$ restricted to its equal-length pairs to any reached shortest member. There is no hypothesis on the behavior of the rules among the distinct shortest strings.

As one concrete sufficient condition, fix $c$. Suppose every non-minimal $x$ has an equivalent shorter string of length at most $c\log_2(|x|+2)$. At each step enumerate all strings up to that length bound, retain shorter ones satisfying $E$, and choose the first if one exists. There are at most $2(|x|+2)^c$ candidates per step, and at most $|x|$ reductions. Empty strings and singleton classes are handled without separate choices.

**What plain padding already gives.** If a polynomially bounded class-invariant integer $g(x)\ge 2|x|+1$ is already supplied or computable on the original strings, the same encoding proves the transfer with no descent. In particular, any polynomially computable bucket of lengths that contains every member of a class can be padded to its upper endpoint when the endpoint is polynomial in the input length. Theorem 1 instead derives a robust common encoding length after reduction, and does not bound the largest raw representation of a class.

## 2. A cross-length strict separation in this restricted oracle class

**Corollary.** There exists an oracle $A$ such that each polynomial-time equivalence satisfying Theorem 1 has a polynomial-time complete invariant, yet one such equivalence has no polynomial-time canonical form. In the separating equivalence, infinitely many classes contain strings of unboundedly different lengths. The same separating equivalence excludes the bounded-error randomized canonizers ruled out by the prior construction.

Use the prior oracle $A$ with $\mathsf{Ker}_{=}^A=\mathsf{PEq}_{=}^A$ and a hard length-preserving relation $R^A$ having classes of size at most two. For every binary string $x$, form the code family
$$
\operatorname{enc}(x,k)=1^{|x|}0x\,0^k,\qquad k\ge 0.
$$
Define an equivalence $\widetilde R$ on valid codes by $R^A$ on the decoded strings and make invalid codes singletons. Decoding is unambiguous, and the relation is decidable with oracle $A$ in polynomial time. Descend every positive-padding code to $\operatorname{enc}(x,0)$ in one step. Take $S$ to be the restriction of $\widetilde R$ to these unpadded codes. It is length-preserving since $R^A$ is. The grade conditions are immediate from this presentation, and arbitrary padding gives unbounded ratios of lengths within each code class.

If $\widetilde R$ had a polynomial-time canonical form, apply it to $\operatorname{enc}(x,0)$ and decode its output. The result is $R^A$-equivalent to $x$ and constant on each $R^A$-class. This would give a polynomial-time canonical form for $R^A$. The same composition preserves the per-input success guarantee of a randomized canonical form. This explicit lifting of the previous witness uses ordinary padding. The broader sufficient condition of Theorem 1 also permits nonlinear normalization rules that are not duplicate encodings of one supplied core. [Prior separating oracle and randomized guarantee](https://github.com/Dugongue/MathProofs/blob/e1dd0327f41109018c3bd7608dc15da84a032f77/LengthPreservingEquivalenceOracle/PROOF.md).

## 3. A universal class-length estimate would decide NP

Write $m_E(x)=\min\{|y|:xEy\}$. The following equivalence goes beyond the observation that returning a shortest representative would decide a search problem.

**Theorem 2.** For every oracle $A$, the following three assertions are equivalent.

1. $\mathsf P^A=\mathsf{NP}^A$.
2. Every $E\in\mathsf{PEq}^A$ has a polynomial-time oracle algorithm returning a class-constant natural number $b_E(x)$ satisfying $m_E(x)\le b_E(x)\le p_E(|x|+1)$ for some polynomial $p_E$.
3. The same as assertion 2 for every $E\in\mathsf{Ker}^A$.

The numerical bound may be given in binary. No representative of any length need be returned.

**Proof.** Under assertion 1, existence of an $E$-equivalent string of length at most $j\le |x|$ is a polynomial-time oracle test. Binary search gives $m_E(x)$ exactly. Assertion 2 implies assertion 3.

For the other direction, take any language $L\in\mathsf{NP}^A$ with a polynomial-time oracle verifier and witness lengths at most $(n+2)^e$ for $n=|x|$. Use the previously proved equivalence from Fortnow–Grochow Question 5.10. For each $x,d$ with $d\ge1$, one class consists of a long anchor
$$
a(x,d)=0\,1^{|x|}0x\,1^d0\,0^{(|x|+2)^d}
$$
and the short strings
$$
b(x,d,w)=1\,1^{|x|}0x\,1^d0w
$$
for accepted witnesses $w$. All remaining strings are singletons. One complete invariant parses the class descriptor $(x,d)$, checks the verifier for witness strings and checks the padding for anchor strings using capped powers. It distinguishes invalid singleton strings with a separate tag. This belongs to $\mathsf{Ker}^A$ independently of the language's decidability in $\mathsf P^A$.

Let the assumed bound $b_E$ satisfy $b_E(z)\le C(|z|+1)^k$. Choose a constant $d>ek$ with $2^{d-ek}>C(d+10)^k$. This choice occurs after fixing $b_E$, and the same relation already includes all $d$. If $x\in L$, some witness has an encoding of length at most $(d+10)(n+2)^e-1$. Constancy of $b_E$ on the class gives
$$
b_E(a(x,d))=b_E(b(x,d,w))
\le C(d+10)^k(n+2)^{ek}
<(n+2)^d
\le |a(x,d)|.
$$
If $x\notin L$, the anchor is a singleton and $b_E(a(x,d))\ge |a(x,d)|$. Since $d$ is fixed, constructing the anchor and comparing the computed bound to its length is polynomial time in $n$. This decides each $L\in\mathsf{NP}^A$ and proves assertion 1. $\square$

Thus supplying a class-invariant padding length for every arbitrary relation by first moving into a representative that fits that length cannot be the mechanism for an oracle with $\mathsf P^A\ne\mathsf{NP}^A$. Such a length would itself be the $b_E$ of Theorem 2. The oracle's complete invariants may instead use labels much shorter than every representation of a class. No such lower bound on label length is present in the Fortnow–Grochow definition. ## 4. Assignment of cross-length labels and the remaining separation issue

There is a direct adaptation of the earlier forcing construction that makes cross-length invariant rows internally consistent. It supplies an invariant for each activated relation, but alone gives no separation.

For each clocked decider $D_i$ and reserve index $c$, put all bits of the label of an input of length $m$ at one oracle-word length $L_{i,c}(m)$. Choose $L_{i,c}$ strictly increasing, polynomially bounded in $m+1$ for each fixed row, and with the following property. All queries of $D_i$ on pairs with both input lengths at most $m$ are strictly shorter than $L_{i,c}(m)$. A stronger square-root bound can also be imposed. Include enough room in a row's encoding that a fresh reserve index starts above any fixed finite oracle prefix.

Suppose a row was activated because $D_i$ decides an equivalence relation in every then-admissible total completion. Require all assigned labels in this row to agree exactly on the pairs it accepts, including pairs of different lengths. At the new length $L_{i,c}(m)$, all earlier argument lengths in that row already have labels. For each class among its inputs of length at most $m$, inherit the label of its shorter members if there are any. All those labels agree by consistency of the earlier assignment. Otherwise choose a fresh binary label of length at most $2m+2$. There are fewer than $2^{m+1}$ strings of length at most $m$, so there is ample room. Every inherited label still fits. The label for an individual argument has polynomially many bits, including its encoded length and padding in the oracle.

Finite-prefix extension works by increasing oracle-word length. At one stage all relevant comparisons have oracle transcripts in the completed shorter prefix. A previously admissible completion extending that shorter prefix shares those transcripts. Every active decider is an equivalence in that completion, so its restriction to these inputs permits the label inheritance rule. For a newly activated row the same is true by the activation test. An induction therefore extends any locally consistent prefix. As in the existing forcing proof, if some old admissible completion makes $D_i$ fail to be an equivalence, one can fix a finite prefix deciding that failure. Otherwise activate a fresh row. This construction forces $\mathsf{Ker}^A=\mathsf{PEq}^A$ on the final oracle while leaving base blocks formally free during each extension. The issue is whether one can arrange that the base computation remains hard in the presence of these additional labels.

For example, the tempting rule of giving every class first seen at argument length $m$ a label of exactly $2m+2$ bits reveals $m_E$ directly. Theorem 2 then implies $\mathsf P^A=\mathsf{NP}^A$. A different distribution of labels must avoid that revelation.

There is also a distinct issue in the prior proof's lazy sampling. In an equal-length row, comparing the newly queried input against previously exposed arguments only asks shorter oracle words than the common block containing these labels. For a cross-length row, a shorter new argument $y$ may follow an already exposed longer $x$. The comparison $D_i(x,y)$ is only bounded by the oracle block for $x$, and can ask words at the block for $y$. This can affect what should be returned as $y$'s label. Even a relation with disjoint classes of size at most two can have cross-length membership controlled by such a shorter oracle bit. For example, for each parameter $u$ take two short strings $y_0(u),y_1(u)$ and a much longer string $x(u)$. The long string is paired only with $y_{A(w(u))}(u)$, with $w(u)$ a chosen oracle query whose length is polynomial in the long string length. The relation is valid for every oracle and its equality test has this dependence. This demonstrates why the earlier tier argument does not apply to cross-length labeling simply by adding pair comparisons.

An extension of Question 5.11 still needs an independently proved separation after enforcing the globally consistent labels. Both the output-size analysis and the shorter-after-longer comparison issue must be accounted for.
