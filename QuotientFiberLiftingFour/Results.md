# Four applications of quotient–fiber lifting

These informal research notes address four published questions. Each proof specifies which quotient data can be recovered, which lifts must be considered together, and what the procedure costs on its original input. All four questions remain open in their unrestricted form in this packet. Publication priority for the restricted results has not been established.

1. [Characteristic-two matrix-tuple isometry](Tuples.md). Given raw ordered matrix tuples, find an isometry and count all isometries in Las Vegas polynomial time whenever the adjoint algebra has commutative semisimple quotient. Its radical may have arbitrary depth. The algorithm recovers a shift by testing one residue element per free factor, then keeps or fixes each factor independently. The unrestricted [Part V question](https://arxiv.org/html/2611.00735v1#S1.SS4) allows matrix algebras among the simple factors.
2. [Epimorphisms onto bounded-generator groups](Groups.md). For groups given by Cayley tables, count all epimorphisms and construct a witness in polynomial time when the target generator bound is fixed and the number of common prime factors, counted with multiplicity, of the kernel order and the order of the derived Fitting subgroup is bounded. The proof gives an explicit prime-by-prime bound beyond that regime. [Open Question 3(2)](https://arxiv.org/html/2609.07429v1#S7).
3. [Central quotients of products of double covers](Central.md). For products of the double cover of the alternating group on five letters, recover the center-relation codes and enumerate the candidate image subcodes. A single candidate suffices on an infinite wheel-code family where the target code dimension exceeds the source dimension by a linear amount. The [exhaustive check](check_codes.py) compares the image-subcode criterion with actual coordinate permutations in 14,322 code-pair and weight cases of lengths one through four. [Open Question 3(5)](https://arxiv.org/html/2609.07429v1#S7).
4. [Complete invariants across different lengths](Oracle.md). A polynomial descent that reaches a common length on each class extends an equal-length complete invariant across lengths. In the opposite direction, even allowing an upper bound on the shortest representative, a polynomially bounded class-constant bound for every polynomial-time kernel relation relative to an oracle is equivalent to P = NP relative to that oracle. The unrestricted oracle requested in [Question 5.11](https://arxiv.org/abs/0907.4775) remains unconstructed.

The code check tests the subcode enumeration on small inputs. The proofs and general runtime statements are informal.
