# Attribution and reproducibility

AI-assisted informal mathematics. STATUS.json states the exact scope;
PROOF.md credits the classical ingredients and prior sources. No upstream Lean
module or prior repository source code is bundled. External human validation,
Lean verification and publication priority remain separate and pending.

The Python controls use the standard library. Run each .py program from this
directory with Python 3.10 or newer; it rewrites its JSON receipt. Finite checks
corroborate identities, not universal statements or low-space complexity. Some
controls deliberately store large integers and are not the theorem algorithm.
