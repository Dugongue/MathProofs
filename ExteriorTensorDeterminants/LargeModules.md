# Determinants of intrinsic operator modules

A large raw tensor mode can have an intrinsic module structure even when the action contains no small invariant projective point list. The determinant then splits between a natural matrix-algebra module and its multiplicity space. Using a single operator algebra for all three modes makes the natural contribution occur only once per simple factor, with exponents that combine across radical layers.

## Exact determinant profile from a functorial operator algebra

Fix a finite field F of order q and encode a 3-tensor T on the three modes V_1,V_2,V_3. Work in the convention in which transporters act by the corresponding mode maps. If a mode is written in dual or bilinear coordinates, convert its determinant by inversion as needed. The determinant-one condition is independent of that conversion.

Assume there is a polynomial-time rule which computes a unital block-diagonal subalgebra A(T) of End_F(V_1⊕V_2⊕V_3) as a linear basis. Require the exact covariance

    A(S) = g A(T) g⁻¹

for every ordinary transporter g from T to S, where g denotes the block-diagonal map on the sum of the modes. For example, compute the full three-mode derivation Lie algebra by linear equations. The associative algebra generated by its block-diagonal action, or by the action of its commutator subalgebra, has this covariance. Compute its unital associative envelope by linear-span closure under multiplication. There are at most (sum_i dim V_i)^2 independent matrices, so this computation is polynomial.

Let D=(F×)^3. One may use any explicitly computed subgroup D_0 contained in the determinant image of Aut(T). Taking D_0={1} always works. The adjoint-unit saturation algorithm gives one computable choice of a larger D_0. All calculations below concern the profile in D/D_0, followed by restoring the full cosets in D.

Write J for the Jacobson radical of A. The semisimple quotient is a product of factors Q_σ=Mat_{d_σ}(E_σ), where each E_σ is a finite extension of F. Compute J, the quotient map and explicit factor coordinates using the finite-field algebra decomposition in Theorem 18 cited below. Its deterministic cost is polynomial in the matrix dimension, log q and the characteristic, which is polynomial here because F is fixed. Compute the intrinsic mode filtrations J^r V_i and their successive quotients by linear algebra. The J-action on each quotient vanishes, so the quotient is a module over A/J. Let m_{i,r,σ} be the multiplicity over E_σ of the natural d_σ-dimensional module in the σ-factor of that layer.

Call a natural determinant relevant for σ when the subgroup

    { (x^{Σ_r m_(1,r,σ)}, x^{Σ_r m_(2,r,σ)}, x^{Σ_r m_(3,r,σ)}) : x ∈ F× }

fails to be contained in D_0. Call a multiplicity determinant relevant for (i,r,σ) of positive multiplicity when the subgroup with x^{d_σ} in coordinate i and 1 elsewhere fails to be contained in D_0. Define w as the maximum of d_σ for the relevant natural determinants and m_{i,r,σ} for the relevant multiplicity determinants, with maximum zero if none are relevant. The dimensions of the full modules may grow without bound even when w is zero.

**Theorem.** With these data, compute the entire set of transporter determinant tuples using ordinary 3-TI decision queries in deterministic bit time and total query length polynomial in L+2^w, where L is the explicit input length. The parameter is measured on the source after an ordinary positive query. Thus w=O(log L) is a sufficient polynomial-time condition. The result does not need the operator algebra to consist of pair adjoints, or its inner automorphisms to lift to tensor automorphisms.

### Recover the algebra label maps

For each center degree choose one common explicit finite-field model. Label each primitive central factor idempotent together with every Frobenius conjugate of a chosen generating field element in that factor. These finite sets have polynomial total size. Every induced quotient-algebra isomorphism permutes or matches the labels, and a complete matching determines each center map. One can find a generator, identify the centers with common models and compute these labels by finite-field factoring and linear algebra in polynomial time for fixed F. The explicit primitive-element procedure and the label format are the same as in the earlier adjoint multiplicity reduction.

To test a partial label matching, include the original tensor, A, its action on the modes, the quotient A→A/J, the quotient multiplication, and the marked labels in a bounded-order tensor system. A mark is a map out of a fixed scalar sort. The algebra action on the sum of the modes is faithful, so the induced A-map must be conjugation by the original maps. It consequently induces the quotient map as required. Every genuine transporter with the partial label matching extends to these sorts. In particular, the marked oracle tests feasibility exactly, without narrowing the possible actions on unmarked factors or radical layers.

First test ordinary TI. Greedily fix each source label to one of its target possibilities using the partial label oracle, giving one full feasible matching for a positive ordinary pair. To compute generators for the permutation image of Aut(T) on its labels, at each position pin earlier labels to themselves and test every possible image of the current label. For each positive branch, greedily complete it to a full feasible permutation. The resulting permutations generate the image by the stabilizer-chain argument. Their total number and all oracle calls are polynomial. To get its determinant profile, it remains to obtain one determinant class for a lift of each chosen permutation, the identity-label kernel's full class image, and a class for the reference transporter. All of these tasks concern a single prescribed full label matching at a time.

### Factor the transported maps on the radical layers

For one full matching identify the matched centers through its specified maps. In these aligned E_σ coordinates the induced isomorphism of Q_σ is center-linear, so by Skolem–Noether it has the form a↦g_σ a g_σ⁻¹ for some g_σ∈GL_{d_σ}(E_σ). The same g_σ works across every mode and every layer, since all layer actions arise from the same quotient map.

In each Q_σ-layer piece choose a basis of the first diagonal matrix unit's image over E_σ. The other first-column units give an adapted frame of the entire piece. In this frame it is the tensor product of E_σ^{d_σ} with a multiplicity space of dimension m_{i,r,σ}. A map intertwining the Q_σ-action is exactly

    g_σ ⊗ h_{i,r,σ},

where h_{i,r,σ} is an invertible E_σ-linear multiplicity map. Indeed, dividing by g_σ on the natural factor leaves an endomorphism commuting with every matrix unit, which forces the same map on every natural coordinate. Conversely these product maps give precisely the intertwiners. This argument is independent of the scalar ambiguity in choosing g_σ, which is absorbed by h_{i,r,σ}.

Choose the adapted layer frames in matched orders, then lift them to adapted frames of the full modes. Taking determinants along the filtrations and extending from E_σ to F gives

    det_F(g_i) = c_i ∏_σ Norm(det g_σ)^{Σ_r m_{i,r,σ}}
                     ∏_(r,σ) Norm(det h_{i,r,σ})^{d_σ}.

Here c_i is the ratio of target to source full frame determinants over F. It is computable from the label matching alone. It accounts for all frame orderings and all center changes. The formula is the tensor-product determinant in E_σ followed by the determinant-of-restriction-of-scalars identity. Triangular terms between layers contribute no factor.

### Encode the relevant determinant contributions

Include the actual filtration inclusions and quotient maps, Q_σ actions and factor inclusions to distinguish all matched layer pieces. Add a single E_σ^{d_σ} sort per σ with its standard Q_σ-action to encode g_σ. This forces g_σ to implement the same factor algebra isomorphism as the one induced by the original transporter. Add each multiplicity sort and the actual bilinear map from its natural and multiplicity spaces to its layer piece, using the above matrix-unit frames. Its compatibility forces that piece to act as g_σ⊗h_{i,r,σ}. Tie all E_σ-linear maps to the explicit scalar actions in the aligned field models. Every original transporter with the full matching extends to this diagram. Conversely, every solution reflects to an original transporter and the displayed determinant formula. All of these maps have order at most three as tensors over F.

Drop the factors that are individually neutral modulo D_0 by the definition of w. For each remaining g_σ or h_{i,r,σ}, attach the full exterior algebra in its E_σ-dimension. Its multiplication and the degree-one inclusion force the action on the top exterior line to be the determinant. A line over E_σ scaling by λ can give an F-line scaling by Norm(λ). Insert copies linked by the explicit F-linear Frobenius maps in E_σ, multiply their scalars using E_σ-multiplication maps, then restrict the resulting F-valued scalar to an F-line. Multiply the readouts with the required exponents in the three modes and fix the output line multipliers by vector marks. To test a requested class, enumerate its finitely many representatives in D and account for the known frame ratios c_i. A signature with polynomially many sorts and polynomially many tensors of order at most three compiles into ordinary TI by the earlier uniform fourteen-component packing followed by the published fixed-component compiler. This is the same packing used for the determinant-line construction of the earlier adjoint result. The full exterior algebra has dimension [E_σ:F] times 2^w, and the remaining data are polynomial-sized.

For the identity-label kernel enumerate the determinant classes satisfying the tests. For each generator of the label permutation image, find one realized class of a lift by the same tests. These classes and the kernel classes generate the full stabilizer class image. Translate by one computed class of the reference transporter and restore D_0 to obtain the exact profile. Correctness follows because every transporter with a fixed full matching extends to the encoded diagram, and corrections in D_0 can always be composed with a transporter. This proves the theorem.

## A large family with scalar pair adjoints and no point lists

Take F=F_3. Let A_0=F^m, with m divisible by four, and let G be the four-cycle. Use an input copy of A_0 at every vertex in both modes. In the output use a copy of Sym²(A_0) for every loop and undirected edge, eight copies altogether. For x from the first input block at vertex i and y from the second at vertex j, define their product to be xy in the symmetric-square component [i,j] when i=j or ij is an edge. It is zero otherwise, and [i,j]=[j,i]. This table is concise. Its diagonal products separate every input coordinate and all loops and edges span the output.

For its two-input pair adjoint, write the maps in vertex blocks. At a pair of distinct vertices (i,j) the output in the square component [j,j] forces P_{ji}=0, since no term from T(u,Qv) lies in [j,j]. Vary u and v, and use that any nonzero vector has nonzero symmetric products. The square [i,i] similarly forces Q_{ij}=0. Both maps are block diagonal. At every loop the equation (P_i x)y=x(Q_i y) forces P_i,Q_i to be a common scalar. This can be seen by comparing coefficients of pure squares and mixed monomials in a basis. At every edge the scalars agree across its endpoints, so connectedness forces one common scalar. Symmetry under identifying the two input spaces now gives scalar pair adjoints involving the output as well. For example T(Pu,v)=C T(u,v) implies the two-input relation T(Pu,v)=T(u,Pv), and then spanning makes C the same scalar. In particular the centroid is scalar.

For the full derivation calculation write the equation as R T(u,v)=T(Pu,v)+T(u,Qv). The closed neighborhoods of distinct vertices in a four-cycle are incomparable. For k≠i choose j in the closed neighborhood of k outside that of i. At inputs (i,j) the product is zero, and the output component [k,j] in the derivation equation forces P_{ki}=0 because the second term has i as one endpoint, whereas [k,j] does not. The analogous argument makes Q block diagonal. On a loop or edge the resulting bilinear expression must be symmetric in its vector arguments, since the prescribed map R acts on their symmetric product. This forces P_i−Q_j to be scalar by the same coefficient argument. Loops and connectedness show P_i=P+α_i I and Q_i=P+β_i I for one P on A_0. Equality of the two induced expressions on the output edge [i,j] says α_i−β_i=α_j−β_j. Conversely all such data are derivations, with output action on [i,j] equal to ρ(P)+(α_i+β_j)I, where ρ is the induced Lie action on Sym²(A_0).

It follows that the derived Lie algebra acts by the same sl_m element in all input copies and by the same ρ(sl_m) element in all output copies. Commutators of arbitrary P span sl_m. Its natural associative envelope is the full matrix algebra, since off-diagonal units belong to sl_m and their products give diagonal units. On the symmetric square, the product ρ(E_ij)^2 ρ(E_ji)^2 for i≠j projects to the pure square e_i² with coefficient four, a unit in F_3. Composing this rank-one projector with appropriate matrix-unit derivations on each side gives every matrix unit on the symmetric-square monomial basis. For example replacing one e_i by e_j sends the pure square to the mixed monomial with coefficient two, and replacing e_j by e_i reads only that mixed monomial into the e_i² coefficient. Replacing both equal factors links any two pure squares. Thus the symmetric-square envelope is full as well.

The simultaneous envelope is the product of these two full matrix algebras, embedded with multiplicities. It surjects on each factor, and the factors have different matrix sizes. An algebra surjecting onto two simple factors is their full product unless it is the graph of an isomorphism. To see this, project the kernel of the first map to the second factor. Its image is an ideal, hence zero or all. In the first case the second map factors through a surjective map from the first simple factor, which must be an isomorphism. In the second case the full product is obtained. Here the two sizes differ, so the product is full.

The natural factor has degree m and multiplicity four in each input. The symmetric-square factor has degree m(m+1)/2 and multiplicity eight in the output. Degrees and multiplicities are all even. Hence w=0 with D_0 trivial. This gives an ordinary-TI algorithm which computes the determinant signs from adapted frame ratios, even after arbitrary raw rebasings. The two factor types are distinct and both centers are F, so every ordinary transporter induces the same label matching and the algorithm needs only the original ordinary query. In particular the source stabilizer has trivial determinant image. Reflecting one mode yields an ordinary positive pair with no special-linear transporter.

For any extension K/F, simultaneous GL_m(K) in all input blocks and its symmetric-square action on the output are tensor automorphisms. A projective point in an input has a nonzero projection to some vertex block. Its orbit projects onto the whole projective space of K^m in that block. Any nonempty invariant point list in such a mode therefore contains at least (|K|^m−1)/(|K|−1) points. Two point lists could only be obtained by including at least one of these modes, so polynomial-size lists are impossible even over the base field. The envelope test uses neither point list.

## Scope and sources

This is an informal extension of the earlier pair-adjoint multiplicity method. Natural contributions which could previously be normalized using pair units are instead represented explicitly by a shared natural sort. The determinant exponents aggregate across layers and modes, and large inactive sorts require no determinant volume. A generic operator algebra can still leave a full-dimension active factor, so the width hypothesis gives a sufficient reduction and does not decide unrestricted SL-TI. The graph example demonstrates a class beyond individual pair-adjoint width tests and polynomial point enumeration.
