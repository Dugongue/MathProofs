# Eight sufficient theorems for TI versus TI_SL

These proofs address the reverse direction from determinant-one equivalence to ordinary tensor equivalence on explicit families. The forward reduction in the dense ordered model adds an unused line in each mode. The three free complementary determinants can be chosen independently, and every transporter restricts to the intrinsic contraction supports. The unrestricted reverse reduction remains open here.

| Field and proof | Two results |
| --- | --- |
| [Higher-rank valuations and division algebras](Arithmetic.md) | An intrinsic commutator Pfaffian gives a same-field reverse reduction on the stated raw division multiplication tensors. The extension theorem computes the full correction lattice and sharp primitive and universal extension degrees. |
| [Real-closed semialgebraic geometry](Geometry.md) | A quadratic imaginary centroid encodes orientation by one ordinary tensor query on balanced inputs. The ordered two-slice algorithm decides signed equivalence for rectangular pencils, including singular summands. |
| [Incidence parity and neighborhood orders](Combinatorics.md) | Degree-difference gcd one gives equality of ordinary and special-linear orbits, with GI-complete examples. A same-field Kummer reduction handles the stated odd-gcd and even-degree incidence families. |
| [Elliptic theta groups](Theta.md) | Theta translations and the pole-order weights give the exact splitting of the ordinary orbit over an algebraic closure. Presented finite-field section tensors admit a signed transporter algorithm using no discrete logarithms. |
