# Simultaneous monomial code equivalence across different fields

Let a list of pairs of linear codes have the same coordinate set of size n. Within a pair the field agrees, but different pairs may use different explicitly presented finite fields. Let a subgroup of the coordinate permutations be given by generators, optionally with a specified coset. Decide whether one allowed permutation carries every source code to the corresponding target code after multiplying coordinates by nonzero scalars. The scalars may be chosen separately for each pair. There is a deterministic algorithm costing 2^{O(n)} times a polynomial in the total bit length, including field encodings. It returns the full coset of allowed coordinate permutations. Field operations are charged at their usual polynomial cost in an explicit irreducible-polynomial representation.

**One pair.** Choose an information set B of the source and enumerate possible target information sets of the same size. In each chart put both generator matrices in systematic form [I | M], with rows indexed by basis coordinates. A candidate permutation preserving the indicated sides transports the row space up to coordinate rescalings exactly when it carries the bipartite support of M to that of the target matrix and the corresponding nonzero edge labels differ by vertex factors. Indeed, rescaling a basis coordinate forces the inverse row scaling to restore the identity block, while each nonbasis column can be scaled independently. Elementary row operations in the normalization cover all choices of generator matrices.

For any circuit in the bipartite support graph, multiply its labels on alternating edges and divide by the product on the other edges. Mark one edge and take it in the numerator. These values are invariant under all vertex scalings. For a fixed support isomorphism, equality on induced cycles suffices. The oriented ratios for the discrepancy between the two labelings multiply along concatenation of walks, with a reversed edge contributing the inverse. Splitting at a chord gives the original value as a product of shorter cycle values with the chord canceled. Trivial values on cycles give vertex potentials by multiplying along spanning forests. This also handles disconnected supports, isolated vertices and zero columns.

Every induced cycle is determined by its vertex set. Enumerate subsets, test for one induced cycle, and record its ratio for each marked edge. The record consists of a subset of the n coordinate names, two marked names and a field label. For simultaneous comparison give equal field values in both inputs the same color. There are at most 2^n times a polynomial in n records. They can be compared by Luks's simply exponential hypergraph isomorphism algorithm on O(n) underlying vertices. Here are explicit size details: use three colored copies of the coordinate set for subset membership and the two marks, and pair corresponding vertices across copies by separate matching records. Use a constant number of fixed tags to distinguish matching, support, and cycle records. Encode the binary ID of each field color by including its bit positions from a fixed palette of O(n + log(n+1)) vertices. Require those palette and tag vertices to be fixed. The copy colors, matching, and point restrictions can equivalently be imposed in the underlying permutation group. The bit bound uses the number of realized labels rather than the size of the field. The enumeration of possible information sets adds a further factor at most 2^n. Ranks zero and n are immediate.

The same decision test allows partial coordinate matches as extra marks. Obtain one witness by individualization. For source automorphisms, fix the coordinates successively, testing every possible image of the next coordinate and recovering one witness per attainable image. The union of these transversals generates the permutation image of the monomial automorphism group by the stabilizer chain. The coset obtained this way includes all feasible coordinate permutations even when different target information sets were considered.

**Shared permutation.** Intersect the cosets for successive code pairs and the input permutation coset, representing each permutation by its n-dimensional binary permutation matrix. Qiao–Zhang Theorem 7.3 returns a representative and generators of each intersection in 2^{O(n)} times a polynomial in its input size. Generators can be kept polynomial in n by ordinary permutation-group sifting after every step. This accounts for an arbitrary input-length list without multiplying exponential costs. Given a final representative, the spanning-forest computation recovers its coordinate scalings independently in every field.

This is an informal consequence of the cited algorithms. The fixed-basis cycle computation and binary intersection argument detail the transfer. Prior work on code equivalence, multiple codes, and permutation-group intersection precludes interpreting the ordinary single-code simply exponential bound as a new record. No lower bound or literature-priority claim is made here.
