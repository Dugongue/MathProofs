# Constructive minimum generation of finite groups

Collins, Grochow, Levet, and Weiß ask whether minimum generation of Cayley-table groups belongs to deterministic logspace. They define the search problem as returning a minimum set and also give the threshold decision variant. The proofs below distinguish those tasks. [Question 8.1](https://arxiv.org/html/2402.00133#S8) · [Definitions](https://arxiv.org/html/2402.00133#S2.SS1)

- [Main theorem](Proof.md) outputs an actual minimum generating set for every finite Cayley-table group in deterministic logarithmic workspace. It answers the search version as well as the decision version. The proof combines [direct access to the quotient tower](QuotientTower.md), [solvable-radical lifting](SolvableRadicalLift.md), and [nonabelian semisimple lifting](SemisimpleLift.md).
- [Minimum generator number](MinimumGeneratorNumber.md) computes the exact minimum cardinality for every finite Cayley-table group in deterministic logarithmic space. This settles the threshold decision version.
- [Solvable groups](SolvableGroups.md) gives a deterministic logarithmic-space algorithm that outputs an actual minimum generating set for every finite solvable Cayley-table group. It lifts through a whole abelian Fitting layer using streamed linear algebra and uses the Pálfy–Wolf bound to control nested workspace.
- [Solvable-radical lifting](SolvableRadicalLift.md) proves that unrestricted minimum-generator search reduces in deterministic logarithmic space to the same search problem on groups with trivial solvable radical. The reduction preserves group generation and lifts to an optimal set in the original group.
- [Products of nonabelian simple groups](SimpleProducts.md) construct a minimum set in deterministic logarithmic space by selecting distinct automorphism orbits independently for each type of factor. Together with the radical lift this covers groups whose quotient by the solvable radical is a direct product of nonabelian simple groups.
- [Arbitrary groups](ChiefFactorTranscript.md) construct a minimum set in polynomial time using $O(\log N\log\log N)$ workspace for groups of order $N$. [The radical-index bound](RadicalIndex.md) strengthens this to $O(\log N+\log(B+1)\log\log(B+2))$ for $B=\max(2,[G:R(G)])$ and gives a logspace test for Frattini subgroup membership.

All the proofs are informal. Publication priority is unestablished. The structural results of Lucchini and Thakkar, the linear-group order bound of Pálfy and Wolf, and Reingold's connectivity algorithm are used with attribution in the proofs.
