# Exact special-linear witnesses for Hamming code equivalence

**Theorem.** Over each fixed finite field k of order q, permutation equivalence and monomial equivalence of linear codes separately admit polynomial, objectwise encodings as concise ordinary three-mode tensors. On the displayed encodings, the special-linear transporter is in composition-preserving bijection with the entire corresponding code transporter. The general-linear transporter has exactly two additional independent scalar factors. The code may have repeated or zero coordinates, arbitrary dimension and arbitrary hull. “Monomial” includes independent coordinate scalings and excludes field automorphisms. The results are informal.

### The scaffold and the quotient

Use any full-row-rank generator for a code of dimension r and length n. Its columns c_i span U=k^r. In the permutation version use n slots, put d_i=c_i and take the identity successor. In the monomial version use slots (i,l) for l in k*, put d_(i,l)=l c_i, and give each fiber the successor (i,l) ↦ (i,g l) for a fixed generator g of k*. Write h for this permutation on the slots and s for the slot count. A permutation commuting with h in the monomial version permutes the n cycles and independently rotates each cycle. Paired with a linear isomorphism H carrying each d_j to the corresponding target column, it specifies exactly a monomial code transporter. H is unique since the columns span. This convention corresponds to the monomial matrix sending e_i to the respective multiple of e_(πi) in the equation H G = G' M. Over a fixed field, choosing g costs a constant.

Put t=q−1. Build a simple graph with four distinct layers, each indexed by the slots. Join corresponding slots around the four edges of a layer cycle. Add edges (1,j) to (3,hj) and (2,j) to (4,hj). All six layer pairs are distinct even for short successor cycles. Take a fixed core on M vertices, the complement of a tree with branches of lengths 1, 2, M−4 at a common root. It is rigid. Attach every vertex of each layer to its own four prescribed core anchors, and attach all vertices of layer 1 to another 2t distinct prescribed anchors, arranged into pairs indexed by b=1,...,t. Choose M at least 30+4t, increasing it by at most t−1 so that R=M+4s is 1 modulo t. All core vertices have degree at least M−4, exceeding every slot degree. The core positions and layer identities are intrinsic. The four matchings force one common permutation of the slots, and the two successor matchings force it to commute with h. Thus all scaffold isomorphisms are exactly the desired permutations before testing the columns. This includes n=0 with empty layers.

Write A for the space on graph vertices, B for that on graph edges, E for the edge count, X for the span of the 2E vertex-edge incidences inside A⊗B. Map X onto Q=kz ⊕ U_1 ⊕ ... ⊕ U_t, with each U_b a copy of U. For each of the two extra anchors of b and each slot j, send the anchor-side incidence of the edge to (1,j) to d_j in U_b. Send every other incidence to z. Call this map Φ. Let S=ker Φ. Our tensor in A⊗B⊗S* is the inclusion of S. Gaussian elimination constructs it. Use the fixed core ordering, layer order and displayed slot order for vertices. For edges group the core, each matching, and each anchor attachment separately, ordering each moving family by the slot in its specified source layer. Consistently orient X by listing the two incidences of each edge consecutively, using endpoint roles (fixed core positions and layer labels) for their order. Orient Q by z and the ordered blocks with the displayed generator bases. Choose the basis of S so that it followed by lifts of the displayed Q basis has determinant one in X. This is achieved by rescaling one basis vector. This orientation convention is part of the encoder and works for unrelated choices of generator matrix.

### Why every witness is a code map

Each row contains at least three filler incidences. Therefore at least two independent edge vectors y satisfy a_v⊗y ∈ S. If x has two or more supported rows, x⊗y ∈ S forces y to be supported on the common edges of these rows. In a simple graph there is at most one such edge. Thus the row lines are intrinsically characterized by the dimension-at-least-two condition. Off any specified row, Φ is still surjective because there are two anchors for each U_b and fillers at many rows. Consequently, projecting S onto any row gives its whole incident-edge space. Intersections of these spaces recover all the edge lines and their endpoints. These facts also prove full support in A and B; the inclusion gives full support in the third mode.

Any tensor transporter acts monomially on the first two modes, with its permutations determined by the same scaffold isomorphism. It induces an isomorphism on Q. On each filler incidence this isomorphism sends z to the same product u_v w_e times the target z, for row and edge scaling factors u_v and w_e. The bipartite graph of filler incidences is spanning and connected: the intact core and ordinary anchors connect all rows, and each special edge retains its slot incidence. Hence all u_v equal one scalar u and all w_e equal one scalar w. On each U_b, the quotient map divided by uw must carry every d_j to its matched d'_j. The same H works on all blocks and is forced. Conversely any code transporter and any u,w give the indicated transport on S, forcing its contragredient in the third mode. This proves the general-linear assertion, including injectivity for zero columns because slots distinguish the underlying coordinate operations.

### The determinant calculation

Let π be the matched slot permutation. The row permutation repeats π four times. The four cycle matchings repeat π four times, the successor matchings twice, and the attachment families 16+2t times. All signs are positive. Core edges are fixed. Endpoint roles are preserved, so the permutation of the 2E incidences also has positive determinant with the chosen ordering. Removing u,w, the quotient determinant is (det H)^t=1. By the determinant identity in the exact sequence S → X → Q and the specified basis normalization, the induced map on S has determinant one. Thus, putting D=2E−1−tr, the full triple of determinants is

$$\big(u^R,\quad w^E,\quad (uw)^{-D}\big).$$

Because R is 1 modulo t, a special-linear witness has u=1. Then w^E=w^D=1 and w^t=1. Since 2E−D−tr=1, w=1 as well. All code witnesses have a unique lift. Reading the permutation gives its inverse operation, including on the automorphism groups. For fixed q the dimensions are O_q((n+1)^2) and a dense polynomial-size tensor suffices. There is no asserted bit-polynomial bound in log q for varying fields.

### Reading hidden coordinates

On the general-linear image over a fixed field, row lines can be *computed*, as distinct from characterized. Inside the regrouped S⊗S intersect with the space symmetric in A⊗A and alternating in B⊗B, taking the span of y⊗z−z⊗y for the latter, including in characteristic two. Any coefficient on two distinct rows would force a full rectangle on two distinct columns, impossible for vertex-edge incidence in a simple graph. Conversely two independent allowed row vectors give each row square after contraction on B⊗B. The resulting span is exactly that of the a_v⊗a_v. Its left multiplier algebra on A is the full diagonal algebra in the hidden basis. Refine by eigenspaces of a basis, trying all q scalars. Row projection and intersection now find every edge line. Recover the rigid tree positions from its unequal branch lengths; identify the layers, matchings and successor from their adjacency.

In arbitrary choices of line generators, quotient images of all filler incidences lie on one line and are nonzero. Choose a generator of that line and propagate row and edge rescalings along a spanning tree of the filler incidence graph to make all these images equal that generator. The equations are consistent on the image; verify them on every remaining incidence. Once normalized, the two copies of each data column at the paired anchors agree, and their span within any one chosen block recovers the column space presentation. List slots in an arbitrary order or, for the monomial version, choose a starting point in each directed cycle and follow the successor. These choices give exactly coordinate permutations and coordinate scalings. Taking a basis of the data span gives a generator. This supplies a polynomial inverse on ordinary hidden-basis orbits and permits canonization there given a code canonizer. An arbitrary GL re-presentation may change the SL orbit; the exact SL witness assertion concerns the oriented outputs of the encoder. No hidden-basis SL canonizer is needed for the forward theorem.

### Comparison

The decision reductions from permutation and monomial code equivalence to GL tensor isomorphism were already known. Adding a zero direction in each mode of a concise representative even makes each general-linear witness extend to a special-linear witness for decision. The positive statement here controls *all* witnesses in concise targets and gives their inverses. The earlier centered graph encoding corresponds to a one-dimensional quotient; the code constraint here is a high-codimension kernel. ## Exact reverse SL test on hidden inputs

There is also a reverse SL decision reduction on the general-linear image. Use the previous decoder, fixing pivots and choices deterministically. Having identified the slots, rows and columns, the normalized generators give the first two linear maps F from the model of the recovered code to the input. Any common change of basis of the extracted columns leaves their relations unchanged. On a promised image every data block has these same relations, so the maps take the model kernel onto the input flattening image. The third map is obtained by comparing the two flattening inclusions. For recognition, check the graph, dimensions and all required splitting and normalization conditions, and verify the computed triple on the actual array; failure rejects. Acceptance supplies a certificate of membership.

For a triple of nonzero determinants let χ(a,b,d)=a^(DE) b^D d^E, where exponents are ordinary integer powers. The scalar triples (u^R,w^E,(uw)^(−D)) lie in its kernel since R≡1 modulo t. This embedding of the scalar pair group has trivial kernel by the proof above. The character χ maps onto k* since gcd(D,E,t)=1. Its kernel therefore has order t², exactly the size of the scalar image. Put μ(X)=χ(det F_1,det F_2,det F_3). Changing the decoded model by a code isomorphism has a determinant-one lift, and changing a lift adds only a scalar triple. Thus μ is well-defined and computable. For two hidden inputs in the image, SL equivalence holds exactly when their decoded codes are equivalent and their values of μ agree. Indeed an arbitrary code equivalence yields a GL comparison whose character is the quotient of the two values; if the quotient is one, its determinant triple can be removed by scalar lifts. A negative scalar comparison can be returned as a fixed no-instance. This gives polynomial decision reductions in both directions on the recognizable image, for each code variant.
