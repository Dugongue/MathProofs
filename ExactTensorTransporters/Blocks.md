# Special-linear isomorphism for tensors with repeated small summands

Fix a finite field $F=\mathbb F_q$, a constant $C$, and dense inputs of total length $L\ge 2$. An ordered three-tensor has three independent changes of basis, with $(g_1\otimes g_2\otimes g_3)T=S$. Prescribe a triple $\delta\in(F^\times)^3$ in the input bases. Setting $\delta=(1,1,1)$ gives special-linear tensor isomorphism.

**One-instance theorem.** Consider concise nonzero tensors whose intrinsic direct summands all have maximum side dimension $b\le C\log_2 L$. Fix a deterministic polynomial-time ordinary-isomorphism invariant of individual blocks, including their ordered dimensions. Require all blocks of a given invariant value within each input to be mutually ordinary-isomorphic. On this class there is a deterministic polynomial-time many-one reduction of the prescribed-determinant question to **one ordinary ordered three-tensor isomorphism instance over the same field**. The reduction can also reject inputs outside the class as part of the same decision. In particular the invariant can be just the ordered dimensions. The number of copies of an indecomposable type is unrestricted and their internal bases need not agree.

**Arbitrary mixtures.** With the same width bound, arbitrary mixtures of inequivalent blocks with identical invariant values admit a deterministic polynomial-time **nonadaptive truth-table reduction** to ordinary three-tensor isomorphism. One batch gives the entire set of attainable determinant triples. This result allows both inputs in unknown bases and requires no block canonizer.

## Recover the summands

Compute the centroid by solving $X_1 T=X_2 T=X_3 T$, where each operator acts in its own mode. For two solutions $a,b$, move the action of $b$ to a second mode and the action of $a$ to a third. Operators on different modes commute. Moving the actions back in the opposite order proves $a_i b_iT=b_i a_iT$ for every mode $i$. Conciseness gives componentwise commutativity, and moving the two operators in turn gives closure under componentwise multiplication. Primitive idempotents in this commutative algebra cut out simultaneous direct summands in the three modes. Orthogonality and the centroid equations kill all mixed components. Conversely each simultaneous splitting gives centroid projections. These facts identify the finest splitting intrinsically, up to permutation. The center method is established in the literature. [Huang, Lu, Ye and Zhang](https://arxiv.org/abs/2110.07915)

The fixed subalgebra of the $q$-power map is $F^k$, with one coordinate per local factor. Indeed, an element fixed by this map has residue in $F$ in each factor, and any nilpotent fixed by the map vanishes by iteration. The scalars in each local factor are fixed. Compute the fixed algebra by a linear kernel and split its multiplication operators into simultaneous eigenspaces over the fixed field by testing all $q$ scalars. Each resulting line contains a uniquely determined nonzero idempotent. Every transporter permutes its block subspaces and restricts to an isomorphism on each matched block. Conversely those maps assemble by direct sum. These computations, including the conciseness and width checks, take polynomial time.

## Remove the permutation freedom on a homogeneous class

Compare the multiplicities of each invariant value, rejecting unequal profiles. Sort the invariant values and choose any ordering within each value on each side. Match the resulting lists by position. Pick ordered bases inside all blocks. In mode $i$, let $P_{T,i}$ and $P_{S,i}$ be the matrices whose columns concatenate these bases in the chosen orders and set $\kappa_i=\det(P_{S,i})/\det(P_{T,i})$. If the position-preserving maps have coordinate matrices $g_{j,i}$, their ambient determinant is $\kappa_i\prod_j\det g_{j,i}$.

For a class $a$ with at least two copies and mode dimensions $d_{a,i}$, put $h_a=((-1)^{d_{a,1}},(-1)^{d_{a,2}},(-1)^{d_{a,3}})$. A transposition between two isomorphic source blocks can use an isomorphism in one direction and its inverse in the other. Their determinants cancel and the transposition of two $d$-dimensional summands has sign $(-1)^d$. This constructs a source automorphism with triple $h_a$, without requiring the reduction to compute the isomorphism. Arbitrary permutations within each class lift by products of such swaps. Given any transporter, precompose by lifted permutations to make it position-preserving. Conversely, multiplying a position-preserving transporter by the selected swaps realizes all corrections in $\langle h_a\rangle$. Thus $\delta$ is attainable exactly when some position-preserving collection and signs $z_a\in F^\times,\ z_a^2=1$ satisfy
$$
  \kappa_i\,\prod_j\det g_{j,i}\,
  \prod_{a\,:\,d_{a,i}\ {\rm odd}} z_a = \delta_i
  \qquad(i=1,2,3).
$$
Only repeated classes enter the second product. One sign per class is shared by its three equations. In characteristic two it is automatically one.

## Encode the product in one ordinary instance

Use a tensor system with independently labelled vector spaces and named mixed tensors of order at most three. Give each position its own three spaces and its local tensor, thereby allowing independent block maps. For every block mode $V$ of dimension $d$, add the graded spaces $\Lambda^r V$ for $2\le r\le d$ and the exterior multiplications $V\times\Lambda^{r-1}V\to\Lambda^r V$. Use $\Lambda^1 V=V$. Each multiplication spans its codomain, so preservation forces the induced map to be $\Lambda^r g$, inductively. Conversely these induced maps preserve all multiplications, including in characteristic two. Relative to the chosen top wedge, the scalar on the last line is $\det g$. For $d=1$ that line is $V$.

Use a one-dimensional space $U$ marked with $1$ on both sides. For each repeated class, put the standard nonzero bilinear map from its auxiliary line times itself into $U$ on both sides. A scalar on this line is now precisely a choice $z_a^2=1$. For each physical mode $i$, form a chain of standard nonzero bilinear multiplications of lines starting at $U$, using in sequence all its local top lines and the sign lines of its repeated odd-dimensional classes. The last scalar is the product in the displayed equation without $\kappa_i$. Put the mark $1$ on its source output line and $\delta_i/\kappa_i$ on the target output line. The maps exist exactly when the three equations hold. All constructions use actual finite-field coordinates.

To recognize the homogeneous-class condition itself, add independent copies of the ordinary comparison between the first block of each class and each other block of that class, separately for each input. Concretely put two blocks from the *same* input on opposite sides of a fresh three-space comparison. These comparisons use disjoint spaces, so they impose only their own isomorphism tests. The decision of the complete system now incorporates all of them. If width bounds, dimensions or class multiplicities fail at preprocessing, return a fixed negative pair.

The graded spaces for one mode have total dimension at most $2^b$. Their dense multiplication tables have size polynomial in $2^b$ and $b$. The number of chains, added comparisons and labels is polynomial in $L$. Apply the uniform polynomial compiler from a variable list of tagged spaces and mixed tensors of order at most three to one ordinary tensor pair. Briefly, it puts the labelled spaces inside one direct sum, using distinct binary cyclic words of common length together with a shift and a diagonal marker. Commuting with both forces each map to preserve its labelled summand and repeat identically along the cycle. A marked auxiliary line supplies the unit for padding shorter tensors. A further space with a shift and a marked cyclic generator fixes all component labels. Group the padded components by their eight variance patterns, and flatten a pair of tensor factors using a named identity pairing. This yields a fixed signature of order at most three with polynomial dimensions, to which the fixed-system tensor universality theorem applies. The final equivalence concerns existence of witnesses. [Uniform compiler and proof](https://github.com/Dugongue/MathProofs/blob/5072239cac626156b25b8e37ab6dff94f907184d/LinearStructureUniversality/PROOF.md) · [Futorny, Grochow and Sergeichuk](https://arxiv.org/abs/1810.09219)

## One parallel round for heterogeneous classes

Make a list of all blocks of both inputs with a fixed ordered basis on each. For every equal-format pair in that list and every $\gamma\in(F^\times)^3$, submit an ordinary TI query consisting of the block comparison and its three local top-line marks for $\gamma$, as above. All queries can be constructed before any answers arrive. There are $O(k^2(q-1)^3)$ queries for $k$ total blocks. Each is polynomial in the input size.

The nonempty answer tables partition the list into actual ordinary isomorphism classes. Reject if a type has different multiplicities on the two sides. Order and pair positions within each true class. Multiply the returned local determinant sets for those pairs in the finite group $(F^\times)^3$, multiply by the computed concatenated-basis triple $\kappa$, and close under the sign triples of all repeated true classes. The permutation argument proves equality with the global determinant set. Finite set multiplication and all postprocessing take polynomial time for fixed $q$.

The centroid splitting, the determinant signs of swaps, and assembly once the true isomorphism types and local determinant sets are available are prior project results. The two conclusions here specify what can be done with one ordinary query on homogeneous invariant classes and with one nonadaptive batch on arbitrary mixtures of logarithmic-width blocks. Both specialize to ordinary raw tensor inputs. These are informal proofs; formal verification and publication priority for the refinements are unestablished.
