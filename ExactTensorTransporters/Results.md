# Exact transporters for codes, graphs, tensor summands and graphical groups

A Transportensor places tensors at graph vertices and linear maps on edges, with the same change of coordinates acting wherever a space is shared. Four informal arguments develop one aspect of this idea: preserving the actual maps between two objects when changing their representation. The first two results produce a single ordinary three-tensor with determinant-one changes on its three modes. A tensor is concise when each mode uses its whole space.

| Source problem | Conclusion | Proof |
|---|---|---|
| Arbitrary linear codes over each fixed finite field | For permutation equivalence and monomial equivalence separately, every code isomorphism has exactly one special-linear tensor lift, and these exhaust the lifts. On arbitrary hidden bases of an encoded object the inverse decision needs the recovered code and one computable field element. | [Code theorem](Codes.md) |
| All finite simple graphs | One concise integer tensor preserves the entire isomorphism scheme over the integers. This realizes every finite group as a full stabilizer, uniformly in all characteristics. A second construction selects either prescribed parity in characteristic different from two. | [Field construction](Signed.md) · [Integral strengthening](Integral.md) |
| Graphs encoded as succinct groups | Over the residue rings of every fixed prime, including 2, arbitrary prime-power precision is allowed. From centered coordinates, the graph and explicit group maps can be recovered in polynomial time. Every graph witness has an exact, uniform number of lifts, even with both determinants prescribed on nonempty graphs. | [Group theorem](Groups.md) |
| Tensors given in unknown bases over a fixed finite field | For logarithmic-width intrinsic summands, one nonadaptive batch of ordinary TI queries gives all global determinant triples. For blocks isomorphic within each efficiently identified invariant class one ordinary TI instance suffices. | [Block theorem](Blocks.md) |

The code and graph results sharpen earlier *decision* reductions by controlling search, counts and automorphism groups. The graph result proves the special-linear side of the GI inclusion suggested just after Open Question 1.8 in Chen, Grochow, Qiao, Tang and Zhang. The class equality in Question 1.8 and the unrestricted reverse reduction in Question 1.9 are separate statements. The group result addresses a recognizable subclass of succinct presentations. The four proofs are informal, and publication priority of the stated refinements is unverified. [Published question and context](https://arxiv.org/html/2306.03135#S1.SS5) · [Earlier code reductions, Appendix B](https://epubs.siam.org/eprint/VA7M2DT6DFQMVDVWIBBN/full)

The included [finite code checks](check_codes.py) compare explicit codeword sets against the column-relation criterion and exercise the synchronization and determinant calculations. They cover 19,872 transporter comparisons and 20 scaffold checks over three prime fields. These checks exercise ingredients of the proof; they do not enumerate general-linear tensor isomorphisms.
